# ChemLab 参数详解（所有可调变量）

> 对应版本：2026-11-21 夜间交互改造后。界面里每个滑块右侧都有可**直接键入数值**的 SpinBox，
> 下方小字是该参数的简明说明；本文给完整定义、公式、取值范围与调参建议。

## 0. 三层结构（先理解这个，参数就好懂了）

```
Godot 界面 (main.gd)                模拟核心 (sim.gd)                    内核侧车 (kernel_server.py)
 控件 / 按钮 / 曲线     ──改 p──▶   每拍 step()：温度→重力→力→锁→反应   ──TCP 8765──▶  规则 1~11 / resolve
                                                                    （唯一负责"分子式→产物"的判定）
```

- **一切"反应变成什么"只由内核决定**（`natural_engine`，与 Python 实验脚本 T83~T90 完全同源）；
- `sim.gd` 只负责**位置、运动、温度场、锁定、反应触发时机**；
- 所以：想改"化学"，改内核；想改"物理与生态"，改本文这些参数。

## 1. 运行区

| 参数 | 默认 | 范围 | 含义 |
|---|---|---|---|
| 速度（拍/秒） | 20 | 1~120 | 每秒推进多少个模拟步（`_process` 里按累计时间步进）。数值越大越快，但每拍开销固定，60 以上主要靠"每帧多步"。 |
| 播放 / 暂停 / 单步 / 重置 | — | — | 重置会重建世界（保留参数与投料清单）。 |

顶部 HUD：

```
tick=78  N=408 种=3 | complete=30 incomplete=0 none=0 drops=0 并入=55 | T_env=463.8 p=0.015 pending=0
```

- `tick` 当前拍数；`N` 存活分子数；`种` 当前不同分子式数；
- `complete/incomplete/none`：内核 `resolve` 的三种判定次数（完全反应 / 不完全断键重连 / 不反应）；
- `drops`：反应成功但产物无处安放（被丢弃）的次数——**这是需要关注的异常**，正常应接近 0；
- `并入`：产物成功放回世界的次数；
- `T_env`：当前环境温度；`p`：当前每接触反应概率（`p_react`）；`pending`：等待内核回复的异步反应数。

## 4. 物理区（三素力 + 运动 + 锁定）

所有分子的三素量由内核给出（只读，这里不能改）：

- 吸引力强度 `A` = 聚素族（O/X/C）按原子数加权平均，0~3；
- 排斥力强度 `D` = 动素族（P/W/L）按原子数加权平均，0~3；
- 吸引力半径 `ratt`、排斥力半径 `rrep` 由散素族（K/A/F）点数 Q 决定：`ratt = 1 + [Q≥10] + [Q≥20]`，`rrep = 1 + [Q≥15] + [Q≥30]`；
- 质量 `mass` = (3·n_O+2·n_K+1·n_P)/相关原子数，0~3（轻/中/重阈值 1.67 / 2.30）；
- 物态 `state` = (3·n_X+2·n_W+1·n_A)/相关原子数，0~3（气/液/固阈值 1.70 / 2.22）；
- 热值 heat = wC·n_C + wL·n_L + wF·n_F（整数，可为负；默认权重 C=−1、L=+1、F=+2，面板里可改：F 最热、L 温、C 冷源）。

| 参数 | 默认 | 范围 | 公式 / 含义 / 调参影响 |
|---|---|---|---|
| 重力 G | 0.300 | 0~1.0 | 每拍 `gacc += G·mass`，累计 ≥1 就整块下移 1 格（最多 4 格/拍）。质量 3 的分子约 0.9 格/拍，质量 1 约 0.3 格/拍。调大：分层/沉积更快更极端；调 0：无重力，纯三素力驱动。 |
| 吸引力 KA | 2.500 | 0~6.0 | 相互作用里吸引项系数：`att = KA·A_self·decay(d, ratt)`。与内核 S 短键 κ0=2.5 同量纲。调大：更"粘"，小团更多；调小：更松散。 |
| 排斥力 KR | 0.500 | 0~3.0 | 排斥项系数：`rep = KR·D_other·decay(d, rrep_other)`。KA/KR=5:1 是 T81 校准值（保证同种净吸引、异种多双弱）。 |
| 作用力半径 | 6 | 1~12 | 合力扫描的切比雪夫半径**下限**：实际作用半径 = max(该值, 分子自身半径 ratt/rrep)。稀疏气体里分子间距常常 >3，若半径太小就会"谁都不理谁"（零重力下几乎不动的原因）。默认 6 使 ~1% 密度下也能互相作用；调大：长程作用更强、计算更贵（邻居数 ∝ 半径²）。 |
| 力→位移系数 | 1.00 | 0~4.0 | 把合力换算成位移：`facc += |F|·系数·迁移率`，累计 ≥1 就朝合力方向走 1 格（和重力同一机制）。默认 1.0 时 \|F\|≈2 的分子约 1~2 格/拍，与重力（0.3~0.9 格/拍）同量级。调大：分子更"活跃/抖"；调 0：只靠重力移动。 |
| 粘附锁阈值 | 1.0 | 0~4.0 | 两个相邻（d=1）分子，若**双向**净力都 ≥ 该值（`min(w_ab, w_ba) ≥ lock_w`），则互相锁定：任何一步移动后两者距离不得超过「锁断裂距离」，否则该步移动被拒绝。这就是"吸引到一定程度锁在一起"。 |
| 锁断裂距离 | 2 | 1~5 | 锁定时允许拉开的切比雪夫距离；超过则拒绝移动（1 = 必须始终相邻）。数值越大越"韧"。 |
| 气态迁移率 | 1.000 | 0~1.5 | 迁移概率乘子：`p_move = mob(state)·min(1, 0.25+0.75·|F|)`；state<1 用气态值。 |
| 液态迁移率 | 0.600 | 0~1.5 | state∈[1,2) 用。 |
| 固态迁移率 | 0.250 | 0~1.5 | state≥2 用。三档合起来就是"物态→碰撞/运动"轴。 |
| 每拍最多反应对 | 600 | 0~2000 | 每拍最多向内核发起多少次反应判定（防止一帧内过多异步请求）。调低=反应更稀疏但帧率稳。 |

**力的方向与不对称性**：`force_on` 对每个邻居算 `w = att(self) − rep(neighbor)`，但邻居之间的力各自独立计算（A 可能吸 B 而 B 斥 A），所以整体动量不守恒——这正是 T87 里"自主移动团簇"的来源。**力是位移驱动**：每拍把 `|F|·force_scale·迁移率` 累加进 `facc`，≥1 就移动一格；移动失败（目标格被占/锁约束）时 `facc` 封顶 0.99，下一步再试。

**锁定不是化学键**：锁只约束相对位置，不改分子式、不占价键位点；化学键只由内核 `F(v)` 生成。

## 5. 温度区（热值权重 / 环境温度场 / 热门控）

| 参数 | 默认 | 范围 | 公式 / 含义 |
|---|---|---|---|
| 热值权重 C / L / F | -1 / 1 / 2 | 每个 -4~+4 | 温度轴改成可调权重：heat = wC·n_C + wL·n_L + wF·n_F。默认冰 C=−1（冷源）、电 L=+1（温）、焰 F=+2（热源）；改完点「应用热值权重」立即重算所有分子。热值可为负数。 |
| 初始温度 T0 | 1000.0 | 0~1200 | `schedule_T(0) = T0`。Thermal 单位与内核 resolve 的 `c` 同量级（c = 原子数−1），所以"温度够不够"直接可比。 |
| 终温 T_end | 10.0 | 0~400 | 降温曲线终点。 |
| 降温拍数 | 600 | 10~3000 | `t < ct` 时 `T(t) = T_end + (T0−T_end)·exp(−6t/ct)`；t ≥ ct 后：开平台 → 恒为 T_end；关平台 → `T_end·exp(−3(t−ct)/ct)` 继续降向 0。 |
| 恒温平台 | 勾选 | 开/关 | 开：降到 T_end 后不再变化，留出长时间"低温反应窗口"（T85~T87 的设定）；关：一直降，最终几乎冻结反应。 |
| 环境耦合强度 | 3.0 | 0.1~20 | 局部温度 = `(Σ_{2 格内分子 heat} + ec·T_env) / (n + ec)`。ec 越大，环境温度越占主导（反应更均匀）；越小，越"局部热点决定"。 |

**反应触发条件**（sim.gd `_react_phase`）：

```
相邻（d=1）且 natoms_a + natoms_b ≤ cap
先用局部温度：T_local(接触点附近 2 格) ≥ c_a + c_b + react_margin
再按 p_react 概率，向内核 resolve([a,b], T_local)
resolve → complete / incomplete / none
```

- `c` 来自内核（c = max(1, natoms−1)），所以**两个大分子很难反应**（c_a+c_b 大），小分子之间容易；
- 局部温度由分子自身 `heat` 抬升：**富 F/L 的分子就是"热源"**，这就是"温度维度做反应控制"的实现。

## 6. 反应区

| 参数 | 默认 | 范围 | 含义 |
|---|---|---|---|
| 反应概率/接触 | 0.020 | 0~**1.0** | 条件满足后每次接触的触发概率。**1.0 = 每次满足温度与 cap 的接触都必反应**（不再抽样）；调 0：纯物理对照。 |
| 温度门槛余量 | 0.0 | 0~20 | `T_local ≥ csum + 余量`。调大：更难反应（更"冷"）；T91 建议用 `+2` 防止 C 自身富集区自触发。 |
| 反应原子上限 cap | 36 | 4~80 | `natoms_a + natoms_b ≤ cap` 才尝试反应。调大：允许更大分子参与（更慢、更可能裂多产物）；调小：只允许小分子。 |

> 内核判定：`complete` = 完全反应（产物可为 1~3 个分子）；`incomplete` = 温度不足以完全重排，断一根最不稳的键再重连；`none` = 不反应。三者比例是温度与 cap 的直接反馈。

## 10. 参数联动速查（现象 → 先调什么）

| 现象 | 首先检查 | 其次 |
|---|---|---|
| 完全没有反应 | 温度够不够（csum 与 T_local）、cap、p_react | 局部热：投料里有没有富 F/L 的"热源" |
| 反应太多/世界被小碎片填满 | p_react、cap、react_margin | 降低 env_coupling（减少全域反应） |
| 主体被冲散 | lock_w、锁断裂距离、mob_* | 增大 KA 或降低 brown |
| 分子全沉底堆成一层 | G、硬墙 | 关硬墙（环面）或降低 G |
| drops > 0 | cap（产物太大放不下）、世界密度 | 增大 W/H 或降低投料量 |
| pending 很大、卡顿 | speed、max_react、p_react | 降低每拍反应对上限 |
| 热区不出现 | heat 来源（F/L 含量）、env_coupling | 提高 T0 或放慢降温（cool_ticks↑） |

## 11. 已知限制

1. 目录外产物的骨架形状未知 → 渲染为灰色方块（占 1 格）；不影响物理。
2. 内核调用是逐次 TCP 往返（本地 ~1ms，缓存后更快）；每拍最多 `max_react` 次，避免卡顿。
3. 反应是**异步**的：本拍发起的判定结果会在后续帧返回；期间两个分子可能已移动/死亡（已做存在性检查）。
4. 温度是 0~1200 的"热单位"，不是摄氏；与内核 c（原子数−1）同量级，便于直接比较。
5. 存档只存分子式与锚点，不存朝向/能量/锁状态；读档后由内核重建。

## 12. 内核协议（高级）

`kernel_server.py` 监听 127.0.0.1:8765，按行 JSON：

| op | args | 返回 |
|---|---|---|
| `ping` | — | `{ok, catalog: 84225}` |
| `molecule` | `{formula}` | 分子信息（natoms/vec/attrs/cell/grades/k/A/D/ratt/rrep/heat/c） |
| `resolve` | `{mols:[{formula},…], T}` | `{ok, data:{type, products:[formula], csum}}` |
| `f` | `{vec:[9]}` | `complete_products(vec)` 产物式 |
| `feed` | `{elements:[…], n}` | `[{formula,count}]`（元素等份额配平投料） |
| `stats` | — | 内核统计（缓存命中、调用数） |

改端口：`kernel_server.py` 顶部 `PORT`；`scripts/kernel_client.gd` 的 `PORT` 同步即可。

## 附：温度权重的默认含义

| 元素 | 默认权重 | 含义 |
|---|---|---|
| C（冰） | −1 | 冷源：让局部温度降低，抑制反应 |
| L（电） | +1 | 温：中性偏热 |
| F（焰） | +2 | 热源：抬高局部温度，促进反应 |

点「应用热值权重」后立即重算全部类型与现存分子。

## 附：锁断裂距离 lock_r 与「锁团刚体下落」

- `lock_r` 是**锁住的分子之间允许的最大棋盘（Chebyshev）距离**。移动时对每个锁伙伴检查：
  移动后距离 > lock_r 就拒绝这一步。
- 因此 `lock_r = 1` 时，任何"把自己拉出伙伴 8 邻域"的移动都会被拒；而重力是**逐分子下移一格**
  实现的，分子若有正上方/斜上方的锁伙伴，下移会让距离变成 2 > 1 → 被拒。整团又不会自己平移，
  于是簇看起来"悬空、不受重力"。
- 默认 `lock_r = 2` 时，上方分子可以先下移一格（距离 2 仍允许），下一步 `rebuild_locks` 只认
  距离 ≤1 的邻居，锁自然松开，团簇便能缓慢下沉/重组——所以默认值看不到悬空现象。
- **`锁团整体下落`（`lock_rigid_fall`，默认开）**：重力阶段先把锁连通分量（BFS）当作刚体，
  整团一起下移一格；只有整团所有目标格都空才成功。于是锁住的簇会像刚体一样下落、直到被地面
  或其他分子挡住。关掉它则回到旧的"逐分子下落"行为（`lock_r=1` 时会悬空）。
- 测试：headless 自检加 `--lock1` 可把 `lock_r` 设为 1；加 `--no-rigid` 关闭刚体下落。
  240 拍后对比 `rows: mean=… high(…)=…`：刚体开时悬浮分子明显更少。

## 附：2026-11-23 更新 —— 线性作用半径 + 空间哈希

- 删除旧的「作用力半径 force_r」参数；现在只有一个可调的「作用距离上限 R_MAX」（参数 `r_cap`，默认 12，范围 2~24）。
- 每个分子的作用半径由其散素点数 Q 线性决定：
  - `Q = 3·n_K + 2·n_A + n_F`
  - 吸引半径 `R_att = clamp(Q, 1, R_MAX)`
  - 排斥半径 `R_rep = clamp(round(0.7·Q), 1, R_MAX)`
- 加速度衰减：`decay(d,R) = 1 (d<=1)；(R+1-d)/R (1<d<=R)；0 (d>R)`，d 为切比雪夫距离。
- 空间哈希：桶边长 = R_MAX，每拍重建一次；每个分子只检查周围 3×3 个桶内的候选。复杂度从 O(N²) 降到 O(N × 每桶分子数)。
- 性能（240 拍、T91 预设、约 400 分子、headless 无渲染）：R_MAX=12 → 约 22.4 ms/拍；R_MAX=20 → 24.9；R_MAX=24 → 25.6；零重力 → 11.5。
- 注意：R_MAX 越大，长程吸引越强，整个世界的分子可能被拉成一个巨团；默认 12 格约为世界宽（200 格）的 6%。

### 预设（下拉第 0~55 项）

|---|---|

「应用预设（先清空）」会清空世界后按预设的元素子集生成投料；预设分子数由「预设分子数」控制。

### 按勾选元素配平投放

勾选 1~9 个元素 → 点「按勾选元素配平投放」：内核按"元素等份额 + 分子式 2~8 原子"用 IPF 配平，返回 `{formula, count}` 清单，总量精确等于「预设分子数」（四舍五入的余量自动补到第一物种）。

### 随机投料（按勾选元素）

- **物种数**（默认 6）：从"只含勾选元素、2~最大原子数 个原子"的目录物种池里随机抽 k 种。
- **最大原子数**（默认 8）：物种池的分子大小上限。
- 按钮「随机生成清单（按勾选元素）」：只生成清单，写入下面的「自定义投料清单」，不立即投放。
- 按钮「随机生成并直接投放」：生成后立刻清空世界并投放。
- 每次随机用新的 seed（结果可复现：内核返回 `seed`，也可手动传固定 seed）。
- 内核协议：`{"op":"random_feed","elements":["O","X"],"n_mol":400,"n_species":6,"natoms_max":8,"seed":123}`
  → `{"ok":true,"data":{"rows":[{"formula":"O2","count":..},...],"pool":N,"seed":123}}`。

### 投料清单与投放

- 「自定义投料清单」支持手工加（分子式 + 数量 → 加入清单）、删除选中、清空。
- 「应用清单（叠加）」：往当前世界追加投放；「应用清单（先清空）」：清空后投放。
- 总量语义：`n_mol` 是目标分子总数，内核会把清单归一到恰好 n_mol（避免小投料出现几百种各 1 个分子）。

### 内核 feed 协议

`{"op":"feed","elements":[...],"n_mol":N,"natoms_min":2,"natoms_max":8}` →
`{"ok":true,"data":{"rows":[{"formula":..,"count":..}],"pool":P}}`（`rows` 与 `feed` 同义，旧客户端只读 `feed`）。
