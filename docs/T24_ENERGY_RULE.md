# T24 · 基于键能权重与「每根键释放 2 单位」的自然反应规则

> 键能权重：短键 S=3、角键 C=2、长键 L=1；分子键能 `E = Σ(键型权重 × 键数)`。
> 规则：一次自然反应中，每有一根键断开并重连，必须释放 **2 单位**键能（=一根角键的能量）。
> 推导/验证脚本：`t24_energy_rule.py`；数据：`t24_energy_rule.json`。

## 1. 由规则直接推出的结论

单根键断开+重连的释放量 = `w_old − w_new`，取值只能是 {−2,−1,0,1,2}。
要达到"每根键释放 ≥2"，唯一可能是：

```
w_old = 3（短键 S） 且 w_new = 1（长键 L）
```

即：**被交换的每一根端帽-骨架键，必须从短键 S 变成长键 L**（释放 2，恰好等于门槛）。

因此在键能层面，"每根键释放 2" 这条规则可以直接改写成：

> **自然反应 = 端帽从「短键位」迁移到「长键位」**；其他任何键型变化（S→C、C→L、L→C…）
> 释放量都 <2，不允许；相同键型（S→S）释放 0，不允许。

## 2. 由此决定"谁可以参与"

S 和 L 同时被允许的"端帽-骨架"元素组合只有 **聚–散**：
- 聚素端帽（C 冰、X 晶）↔ 散素骨架原子（A/K/F 等）之间，S 与 L 都允许；
- 散素端帽（F 焰、A 气）↔ 聚素骨架原子（O/X/C）之间，S 与 L 都允许；
- 动素端帽（L 电、W 流）与任何原子的组合都不能同时含 S 和 L（聚-动只有 S/C，动-散只有 C/L）→ **动素端帽完全不参与自然反应**。

所以自然反应只有：
- 聚素端帽从"聚-散短键"迁移到另一个"聚-散长键"；
- 散素端帽同理反向迁移。

## 3. 数据（≤8 原子，3,931 种物质）

| 指标 | 数值 |
|---|---|
| 端帽全部以 S 键连接的物质（唯一可能的候选） | **861 / 3,931（21.9%）** |
| 同 K 且双方端帽全 S 的候选对 | 38,911 |
| 其中能完成 S→L 交换的对 | **1,594（4.1%）** |
| 允许反应中产物都在大锅目录 | **1,534 / 1,594（96.2%）** |
| 允许反应中含目录外新分子式 | **60 对（3.8%）** |
| 相对全部同 K 抽样对（100,435）的反应率 | **约 1.6%** |

重要：这里**没有任何"产物必须在已知目录"的白名单规则**；"几乎不产生新物质"（96.2% 产物已知）
是键能与 2 单位门槛**自动**造成的。这正好回应了上一版规则"过于粗暴"的问题。

## 4. 规则形式化（可直接实现）

```
E(M) = Σ_bonds w(type) × mult,   w(S)=3, w(C)=2, w(L)=1
自然反应事件：两分子交换一组端帽（1 价容量 1；2 价双键端帽容量 2），两边的端帽容量和相等
允许条件：
  ① 每根被交换的端帽-骨架键在反应前必须是 S，反应后必须是 L；
  ② 几何/价数合法（含 L 键中点为空）；
  ③ （可选）活化概率 p
结果：释放能量 = 2 × 交换键数，恰好达到门槛；E 严格下降
```

## 5. 为什么能稳定

- 每次反应 E 至少下降 2（键数 ≥1），E 有下界 ⇒ 必然终止，无循环；
- 只有"端帽全 S"的分子才可能反应（21.9%），且还要能改接成 L（候选对中仅 4.1%）；
- 反应只把 S 键换成 L 键（长键/弱键），即结构中的"强连接"逐步退化为"弱连接"；
  当没有可迁移的端帽时，分子就是自然稳定态。

## 6. 可调参数

- **门槛 e**：要求每根键释放 ≥e。e=2 → 只有 S→L；e=1 → S→C、C→L 也允许（反应变多）；
  e>2 → 无反应（绝对稳定）。
- **键能权重**：改变 w 表即可改变允许的迁移方向（例如让 C=3, S=2 时允许 C→S 等）。
- **部分交换**：每次只交换部分端帽（容量相同），条件仍是每根被交换键满足 w_old−w_new ≥ e。
- **活化概率 p**：进一步降低反应频率。

## 7. 例子

- `C2A + C2K2 → C2A + C2K2`（端帽位置异构化：S→L，E 14→10）
- `XF2 + O3PF2 → XF2 + O3PF2`（同上，E 26→22）
- 含新分子式的允许反应（60 对中的例子）见 `t24_energy_rule.json`。
