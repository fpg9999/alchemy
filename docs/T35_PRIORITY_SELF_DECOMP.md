# T35 · 全求和温度判定 + 不稳定物质自分解优先

> 温度判定全部改为「阈值加和」：
> - 不完全反应：`T ≥ Σ i(M)`（参与者 = 含当前全局最不稳定类的分子）
> - 完全反应：`T ≥ Σ c(M)`（参与者 = 接触集合内所有分子）
> - 单分子自分解：`T ≥ c(U)`（U 为不稳定物质）
>
> 关键优先级：当完全和没达到、但某个不稳定 U 的 `T ≥ c(U)` 时，**先让 U 自分解**；
> 再对自分解后新产生的接触集合重新按加和阈值判定完全/不完全反应。

## 1. 完整判定算法（伪代码）

```
resolve(接触集合 S, 温度 T):
    # 1) 完全反应优先级最高
    if T >= sum(c(M) for M in S) and 完全反应条件成立:
        return 完全反应(S)

    # 2) 不稳定物质自分解优先于不完全反应
    changed = False
    S2 = []
    for M in S:
        if is_unstable(M) and T >= c(M):
            S2 += F(v_M)     # 自分解产物（大锅可产物）
            changed = True
        else:
            S2.append(M)
    if changed:
        return resolve(S2, T)   # 新接触集合重新判定（回到第 1 步）

    # 3) 不完全反应（加和阈值）
    P = [M in S if M 含有当前全局最不稳定类的键]
    if T >= sum(i(M) for M in P) and 不完全反应条件成立:
        return 不完全反应(P)

    # 4) 都不满足
    return 不反应
```

- 自分解后的产物是 F 不动点（稳定），因此不会无限自分解；
- 每次自分解消耗一个不稳定分子，递归有限步终止；
- 若自分解后新集合的 `Σc` 降到 ≤T，完全反应可能变得可行（递归第 1 步会抓住它）。

## 2. 题述情形：U 达到自身 c，但没达到与 B 的 Σc

条件：
- `T ≥ c(U)`（U 是**不稳定**物质）
- `T < c(U) + c(B)`（两物质不能完全反应）
- 通常还有 `T ≥ i(U)+i(B)`（本来能不完全反应）

判定过程：
1. 完全反应：`T < c(U)+c(B)` → 不成立；
2. **自分解优先**：`T ≥ c(U)` → U 先自分解为 `F(v_U)`；
3. 用新集合（F 产物 + B）重新判定：
   - 若 `T ≥ Σc(新集合)` → 完全反应（新产物 + B）；
   - 否则若 `T ≥ Σi(新参与者)` → 不完全反应；
   - 否则不反应。

**结论：U 不再参与原来的不完全反应**；它的不完全反应被自分解"抢先"，
后续是否还有反应取决于分解产物与 B 的新阈值。

## 3. 一个数值示例

设：
- U：不稳定，`c(U)=5`，`i(U)=1`
- B：稳定，`c(B)=6`，`i(B)=1`
- `T=5`

判定：
1. 完全和 = 5+6=11 >5 → 不能完全；
2. `T=5 ≥ c(U)=5` → U 自分解；
3. 设 `F(v_U)` 得到总键数为 3 的稳定小分子：
   - 新完全和 = 3+6=9 >5 → 仍不能完全；
   - 新不完全和（若产物有 i=1）=1+1=2 ≤5 → **新集合发生不完全反应**；
4. 若 `T=9`：U 自分解后新完全和 =9 ≤9 → **完全反应**（分解产物 + B 一起被大锅重置）。

→ 自分解不仅"抢先"，还可能**降低总键数和**，使原本达不到的完全反应变得可达。

## 4. 优先级总结

| 条件 | 结果 |
|---|---|
| `T ≥ Σc(所有接触分子)` | **完全反应**（最高优先级） |
| 否则：存在不稳定 M 且 `T ≥ c(M)` | **自分解 M → F(v_M)**，然后对新集合重判 |
| 否则：`T ≥ Σi(不完全参与者)` | **不完全反应** |
| 否则 | 不反应 |

要点：
- **稳定物质即使 `T ≥ c(M)` 也不会自分解**（F(v_M)=M，分解等于不变）；
- 自分解优先于不完全反应：不稳定物质在"能完全分解"的温度下不再参与部分反应；
- 多个不稳定物质都满足 `T ≥ c` 时，一次性全部自分解，再做后续判定（避免顺序歧义）。

## 5. 与之前规则相比的变化

| 场景 | T33（单个阈值 max） | T35（全加和 + 自分解优先） |
|---|---|---|
| U 不稳定，T≥c(U) 但 < c(U)+c(B) | 与 B 发生不完全反应 | **U 先自分解**，产物再参与判定 |
| 稳定 A，T≥c(A) 但 < c(A)+c(B) | 不完全反应 | 不完全反应（A 不自分解） |
| 完全反应 | T≥max c 即可 | T≥Σc（多分子很难） |
| 温度行为 | 单点阈值 | 每个不稳定 U 有"自毁温度" c(U) |

## 6. 这条规则带来的新规律

1. **高温自动清理不稳定物质**：一旦 T 达到某 U 的 c(U)，U 自分自解，不再参与不完全反应；
   高温环境里不稳定中间体无法长期存在。
2. **温度筛分/分馏**：不同 U 的 c(U) 不同；升温时 c 小的先分解、c 大的后分解，
   可按温度分段"消除"不同中间体。
3. **自分解可能解锁完全反应**：分解产物总键数变小后，Σc 可能降到 ≤T，
   触发对"新集合"的完全反应——高温下可能出现"先分解、后被大锅一锅端"的连锁。
4. **不完全反应窗口被压缩**：U 只有在 `T < c(U)` 时才能参与不完全反应；
   超过 c(U) 就自动退出，链式循环中的不稳定中间体会被高温提前终止。
5. **稳定物质的行为不变**：稳定物质的 c 达标也不会自分解；它们只受完全和/不完全和约束。
6. **"加和"让大体系更稳定**：Σc 随分子数增长，多分子完全反应门槛极高；
   自分解优先又让不稳定物在高温下先消失，进一步减少复杂连锁。

## 7. 游戏性含义

1. **热纯化**：把混合物加热到刚超过某个不稳定中间体的 c，它会自分解成稳定大锅产物，
   从而"提纯"出稳定物质；温度是纯化工具。
2. **温度筛分**：不同 c 的中间体在不同温度自毁，可分温度段依次收集/销毁。
3. **保护中间体**：想利用不稳定中间体做不完全反应时，必须把温度压在其 c 以下。
4. **高温重置**：当 Σc 满足时，整个接触集合被完全反应重置；配合自分解可形成"分解→重置"连招。
5. **热汇/抑制剂**：加入高 c 的稳定分子会抬高 Σc，阻止完全反应；但它不会自分解，
   天然适合做"热汇/稳定剂"。
6. **危险连锁**：自分解产物可能降低 Σc，使完全反应突然变得可行，造成整锅重置。

## 8. 需要注意的边界

- `i(M)`、`c(M)` 的"参与者"定义要固定：
  - 不完全：含当前全局最不稳定类的分子；
  - 完全：接触集合内所有分子；
- 旁观者（无该类键）不计入不完全和；但若发生完全反应，所有接触分子都计入 Σc；
- 自分解产物若本身是不稳定物质（理论上 F 产物应为稳定），需要递归处理或设最大迭代次数；
- 反应条件（价数/几何）仍需满足，温度加和只是"许可门槛"；
- 若完全和已达到，即使有不稳定 U 也优先完全反应（不再单独自分解）。
