# T10 · 含一种三价元素的物质的「骨架形式」与规律

> 对象：只含一种三价元素（秩O / 势P / 沌K 之一）的物质 —— O 类 2612 种、P 类 2481 种、K 类 2721 种，共 **7,814 种**。
> 骨架定义：物质中**三价原子之间的键**构成的诱导子图（不含下价元素装饰）。
> 数据源：`t9_single_trivalent.json`；脚本：`t10_skeleton.py`、`t10_module_check.py`、`t10_render.py`。

## 1. 核心结论

**三价骨架 = 7 种「模块」的不交并；每个连通模块最多 3 个三价原子。**

对全部 7,814 种物质逐一验证：三价原子诱导子图的**最大连通块恰好 ≤3 原子**（无例外），
连通块只有下面 7 种（P/K 与 O 拓扑完全相同，只是键型不同：O–O 短键 S、P–P 角键 C、K–K 长键 L）。

| 模块 | 图结构 | 度数 | 键多重 | 每个原子的挂键数（剩余可接下价元素的键） |
|---|---|---|---|---|
| ① 单原子 | 孤立 | 0 | — | 3 |
| ② 单键二聚体 | 2 原子 | 1,1 | 1 | 2,2 |
| ③ 双键二聚体 | 2 原子 | 2,2 | 2 | 1,1 |
| ④ 三键二聚体 | 2 原子 | 3,3 | 3 | 0,0（完全饱和） |
| ⑤ 三元链 | 3 原子链 | 1,2,1 | 1,1 | 2,1,2 |
| ⑥ 三元环·全单键 | 三角形 | 2,2,2 | 1,1,1 | 1,1,1 |
| ⑦ 三元环·含一条双键 | 三角形 | 2,3,3 | 1,1,2 | 0,0,1 |

挂键数恒等于 `3 − 该原子在三价骨架中的度数`；整个分子的挂键总数 = `3·n三价 − 2·键总数`，
必须刚好被下价元素（X/C/W/L/A/F）的键填满。

## 4. 规律（为什么只能长成小模块）

1. **同类三价原子之间的键是「最低优先级」**：同种元素周期表距离 = 0，是最后一级（0 级）才成键。
   在它之前，三价原子会优先与下价元素成键（O 先找 X=1、C=2、L/F=4、W/A=5 级…），
   所以只要下价元素够用，三价原子就表现为**孤立原子**（0 条三价键）——这就是"单原子"模块占比最高的原因。
2. **只有在三价元素过量时才会出现三价–三价键**，而且规则 2（剩余键和最大）会把"最满"的两个原子反复配对到饱和：
   三键二聚体最先出现，然后是双键→单键二聚体；再剩余时形成三元链/三元环。
3. **无法长出更大的连通骨架**：三价原子最多 3 根键，配对被"局部吃满"；而规则 5（最小分子+最大分子）
   与规则 6~8 会把小模块与已成型模块合并，不会留下可无限延伸的"活跃端点"。
4. 因此骨架规模的唯一增长方式是**模块数量增加**（例如 13 个孤立 O），而不是连通块变大。
