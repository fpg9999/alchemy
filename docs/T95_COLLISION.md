# T95 碰撞/推挤引擎实现与 A/B 报告

> 任务：task-7（T95）。在 T94 试验场（O2 主体 / PK 高 D 膜 / E4 环境）上实现
> 「受阻时链式推挤」的碰撞动力学，并对比 v0（当前 T94 规则）/ v1（P1 单格推挤）/
> v2（P2 团簇速度场+动量）三版行为。
> 本报告全部数字来自 `t95_ab.json`（6 臂 × 3 版 = 18 组 × 600 拍，seed=20261124），
> 运行日志 `t95_run.log`，图 `images/t95_push.png`、`t95_core.png`、`t95_vfield.png`。
> 引擎：`t95_collision.py`；运行器：`t95_run.py`；出图：`t95_render.py`。

## 1. 摘要

- 三版引擎在 18 组配置（3 版 × 6 臂）× 600 拍全部跑通：**总耗时 163.65 s**
  （单臂 4.05~16.48 s），**元素守恒与 5 项结构不变量在 18/18 组全部通过**
  （A1~A5 全 True）。
- P1/P2 推挤通道确实被触发：v1 成功推挤 **3,080~8,748 次/臂**，v2 成功
  **8,712~16,774 次/臂**；相应地出现大规模动量判据失败（最高 v2 双层 G=0.2
  臂 **228,138 次**），说明「锁网 + 地面支撑」使 J_B 很大，多数受阻事件仍推不动。
- 保护效果不因推挤而单向改善：
  - 无膜臂 envC：v0 0（G=0）/12,256（G=0.2）→ v1 3,522/18,350 →
    v2 8/20,269。v1 的推挤链把接触「传导」进主体（G=0 也出现 3,522 次），
    v2 的团簇动量在 G=0 时反而把接触压回 8 次，但 G=0.2 时升到 20,269。
  - PK 膜 G=0.2 臂：envC v0 9,344 → v1 7,368 → v2 **4,901**（v2 减半），
    cov 由 0.08 升到 0.36；双层 G=0.2 臂：envC v0 584 → v1 **0** → v2 **0**。
  - G=0 时 v2 的 PK 与双层膜保持 cov **1.00 / 1.00**、envC **0 / 0**
    （v1 为 1.00/0.92、860/1,624）。
- 结论：碰撞/推挤在规则上可实现且守恒稳定；它显著改变接触统计（可好可坏），
  但没有无条件提升隔离，主要价值是 **让「膜被撞开/被推走」与「主体被链式推挤」
  成为可观测机制**。v2 的团簇动量是维持 G=0 膜覆盖的关键（mean|v| 最高 0.160 格/拍）。

## 3. 实现差异与口径（重要）

1. **移动通道**：本引擎**不引入布朗运动**（总工程已删除）。v1/v2 的逐分子移动
   与 v0 完全同口径：`force_on` 只影响方向与「走/不走」概率
   `p = STATE_MOB[state]·min(1, 0.20+0.80·norm)`，`norm≈0` 时不动。
   ←→ 这是关键口径：v1 与 v0 的唯一区别是「目标格被占时改走链式推挤」，
   因此 A/B 差异可归因于碰撞规则本身，而不是输运/热噪声差异。
2. **v2 的团簇动量**：每拍首对锁连通分量（size≥2、非主体）累加三素力：
   `v ← (1−gamma)·v + (ΣF/M)·F2V`，再按 `Vmax` 限幅；若团簇平均累积位移
   `|Δ|≥1` 格，则尝试整体平移 1 格（边界/链外占格/锁检查通过才提交）。
   `F2V=0.02` 是实现标定常数（非用户参数），不进入 `t95_config.params()`。
3. **主体锚定**：主体（O2 冻结体）不被推挤、不参与团簇位移、不被链推动；
   链构造中一旦包含主体成员即 `n_push_fail`。这保证「主体冻结」语义与守恒。
4. **重力**：沿用 T94 的 `gacc += grav·mass` 累积位移（与 v0 同口径）；
   v1/v2 只在「下方被占」时用推挤判据（`gravity=True` 时 `J_A` 加 `M_A·grav`），
   并计入 `n_grav_push`。
5. **多格团簇的推挤**：v1 只允许单格分子进链（P1 的限制）；v2 允许锁团簇作为
   刚体单元进链（P2）。团簇旋转/断键不在本轮（设计 §8 明示不做）。
6. **速度记账**：`vx,vy` 只承载「碰撞冲量 + v2 团簇受力加速」；逐分子位移仍
   走 v0 的随机尝试通道。因此 v1 的 `mean|v|` 近 0（只有冲量且不参与移动），
   v2 的 `mean|v|` 才显著（0.007~0.143 格/拍）。
7. **与 T93/T94 数字不可比**：T93/T94 无碰撞通道、无 E4 环境、且 T94 用的是
   dyn 环境。本报告只在 v0/v1/v2 之间比较；跨报告不可外推。

## 6. 分项解释

### 6.1 推挤是否真的发生、代价多大
- v1/v2 每臂成功推挤 3,080~16,774 次；失败 20,239~228,138 次。
- 失败主因（按判据）：①质量门槛 `M_A < 0.5·M_B`：小分子推不动团簇/主体；
  ②`J_B` 中的锁粘附与地面支撑：膜环内分子互相锁定（PK 的 w_self 强），
  以及 G=0.2 时下方有支撑，使 J_B 远大于自由分子；③`Kmax=6` 上限；
  ④整链占格/边界冲突。→ 与设计预期一致：碰撞不是「一碰就动」，
  而是强依赖质量比与锁网。
- 性能：v0 4.05~9.19 s/臂；v1 4.73~12.38 s；v2 5.93~16.48 s。v2 最慢（双层
  G=0.2 16.48 s，同臂 v0 为 9.19 s，约 1.79×），低于设计目标 2×，仍远低于
  单次 10 分钟限制。

### 6.2 保护效果（envC / coreER / cov）
- **G=0**：v0 的 PK/双层膜已把 envC 压到 0、cov 1.00；v1 仍保持 cov
  1.00/0.92 但 envC 升到 860/1,624（推挤把个别环境分子沿链「传」到主体）；
  v2 的 envC **0/0**、cov **1.00/1.00**（团簇动量让膜整体滑动而少开缺口）。
  → **微重力下 v2 最接近甚至优于 v0**。
- **G=0.2**：v0 重膜沉降（PK cov 0.08、envC 9,344），v1 略改善（cov 0.28、
  envC 7,368），v2 进一步把 envC 减半到 4,901、cov 0.36；双层 v0 584→v1/v2 0。
  → 推挤有助于「被撞开的膜重新闭合/整体让位」，但不能修复沉降（cov 仍 <0.5）。
- 无膜对照：v1 的 envC 反而大于 v0（G=0：0→3,522；G=0.2：12,256→18,350），
  v2 在 G=0 时降到 8（接近 0），但 G=0.2 时升到 20,269。原因是「碰撞链」把
  主体与环境的接触沿链传递，且推挤使环境分子更容易越过表面层。
  → **推挤不是无条件的保护增益**。
- coreER 所有版本均为 0~6（p_react=1.0 下接触即反应，但概率上很少真接触到
  核心），说明主体与环境的化学攻击被 H 层/食物/膜挡在化学步之前；A/B 的
  差异主要体现在「物理接触计数」而非核心被消化数。

### 6.3 主体生长与自身物质
body 原子从 48 增长到最高 136（v0 双层 G=0.2）、最低 62（v2 无膜 G=0.2）：
主体靠吞并内部食物与 E4 环境里的 O/X/C 生长。v2 的 G=0.2 无膜臂 body 原子
最低（62）——推挤让主体生长出的松软组织更易被推散/被环境带走；v2 有膜臂
body 原子 101~115（2.1~2.4×），说明膜在碰撞下仍能保住主体物质。

### 6.4 输出不变量
18/18 组 A1 元素守恒、A2 footprint、A3 占格唯一、A4 主体冻结、A5 速度有界
全部通过；`conservation_ok=True` 全为 True；未出现重复占格/负质量/越界。

## 7. 失败模式（已知且未修）

1. **v1 多格团簇不动**：P1 只允许单格分子进链，k=2 的 OXC/OP 分子被下方阻挡
   时仍可能悬浮/卡住；这是设计 §0 的已知限制，v2 才用团簇刚体解决。
2. **v2 团簇不做旋转/破碎**：锁网被视为刚体，团簇撞墙时整体停住，可能夸大
   膜的「刚性」；设计 §8 列为后续。
3. **推挤判据对粘附极敏感**：`J_stick` 用 `pair_w` 的净吸引和；强粘膜（PK）的
   锁邻居多，J_B 很大 → 失败率极高（最高 228,138）。这符合设计，但意味着
   「碰撞」在强粘网里退化为「几乎不动」。
4. **v2 性能**：最慢为双层 G=0.2 臂 16.48 s（同臂 v0 9.19 s，约 1.79×），
   在 2× 目标内；若扩大规模仍需缓存 force_on 或降低团簇重建频率。
5. **速度口径**：v1 的 `mean|v|≈0` 是因为冲量速度不参与逐分子移动（设计上
   v1 只做位移推挤）；不能用它判断 v1「没有动量」。
6. **单 seed / 单环境族**：E4 仅 O/X/C 等丰度；富 F/O 或含 P/W/L 的环境族
   （T94 的 dyn/fo）未覆盖，结论不能外推到其他环境。

## 9. 局限

- 旧 T87/T93/T94 数字与本报告不可比：环境（E4 vs dyn）、是否有碰撞通道、
  p_react=1.0 与 T93 的 gate 口径都不同；本报告内只做 v0/v1/v2 同口径对比。
- 速度场是「碰撞冲量 + 团簇受力」的混合量，不是完整的牛顿动量场；旋转、
  断键、团簇破碎未实现（设计 §8）。
- `J_stick` 用当前锁邻居的 `pair_w` 求和，未考虑锁的断裂能；真实材料会先
  断弱键再整体移动。
- 主体锚定（不可推动）是建模选择，等价于「主体质量远大于环境分子」；
  若主体可动，A/B 结论可能改变。
- E4 单环境族、单 seed；E4 实现份额与目标偏差 <0.02，但物种仅 28 种。
- 与 T95 设计稿的差异：①未实现「真正动量场/速度每拍由力积分」的完整版，
  逐分子位移仍用 v0 的随机尝试（为保证与 v0 可比）；②v2 的团簇速度用
  `F2V` 标定，非物理常数；③失败计数把「多格拒绝」等结构性失败一并计入。
