> 日期：2026-11-12　工作目录：`G:\AI work\deepseek\work1\alchemy`

> **规则 1~8 仍并列时，优先选择「结合之后分子式包含的大类更多」的一对分子结合；
> 大类数相同，则按结合后分子式内各大类的元素数量比较：聚素数量最多者优先，其次散素，最后动素。**

1. **效果接近完美**：
   - **T≤8 全部投料 0 歧义**（T=6/7/8 用穷举并列 DFS 精确验证）；
   - T=9 仅剩 **4 个**（30 次随机并列采样，11,938 个投料中占 0.034%）；

     都收敛为**唯一产物**；
   - 随机投料 T=10~20、T=21~30 抽样也没有发现歧义。
2. **残余的 4 个 T=9 投料**：首次并列都是 **2~4 个 O-K 对**（O 为聚素、K 为散素），
   结合后的大类计数完全相同 `(大类数=2, 聚=1, 散=1, 动=0)`，所以规则 9 在该步无法区分；
   但后续分支仍可导向两种产物。
3. 若接受 0.03% 残余，这条规则已经足够；若要 100% 确定，再补"规范形/规范编号"兜底（`T8_RULE9.md`）。

## 1. 规则实现

在规则 1~8 的 key 之后追加：

```
key += ( -大类并集数, -结合后公式中聚素原子数, -结合后公式中散素原子数, -结合后公式中动素原子数 )
```

- "结合后公式" = 两个组分分子式的并集（同一元素计数相加）；
- 大类数多者优先；大类数相同 → 聚素原子数多者优先 → 再比散素 → 再比动素。

实现：`t11_rule9d.py`（模拟 + T=3..9 统计）、`t11_trace.py`（残余分歧定位）、
`t11_exact.py`（T=6..8 穷举 DFS 精确验证 + T=9 随机采样）。

## 3. 残余的 4 个 T=9 例子

| 投料 | 两种产物 | 首次并列 | 并列候选的"大类计数" |
|---|---|---|---|
| `O1 C1 P1 L1 K4 A1` | `CPK2A+OLK2` / `CPK2+OLK2A` | 4 个 O-K 对 | 全部 `(2, 聚1, 散1, 动0)` |
| `O1 C1 P4 W1 K2` | `CP2WK+OP2K` / `CP2K+OP2WK` | 2 个 O-K 对 | 全部 `(2, 聚1, 散1, 动0)` |
| `O2 P4 W1 K1 F1` | `OP2F+OP2WK` / `OP2K+OP2WF` | 2 个 O-K 对 | 全部 `(2, 聚1, 散1, 动0)` |
| `O4 X1 P1 L1 K1 F1` | `O2LK+O2XPF` / `O2PF+O2XLK` | 4 个 O-K 对 | 全部 `(2, 聚1, 散1, 动0)` |

**原因**：并列对都是同一种元素对（O-K），结合后的"大类数、各大类原子数"完全相同，
规则 9 无法区分；后续在不同并列选择下仍可能走向不同产物。
