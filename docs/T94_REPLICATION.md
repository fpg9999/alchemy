## 0 摘要

1. **目录宇宙**：84,225 条分子、84,225 个互异元素组成 → **comp ↔ 物种双射，本宇宙不存在同分异构体**；最小分子 2 原子，最大 97 原子；不含 E（恒素）原子。
2. **三体自复制（规则层）**：`natoms(A) ≤ 12` 的门内，共有 **2,596 个模板 A 满足 `F(2·comp(A)) = [A, A]`**（A+B+C → 2A 的规则前提），其中 **2,411 个模板**能在目录内找到食物拆分 `B + C = A`（B、C 均 ≥2 原子），展开成 **24,708 组「模板 × 食物对」三体候选**。
3. **最小自复制体**：`A2F2 + A2 + F2 → 2 A2F2`（A=nA 4、食物各 2 原子），**T_env ≥ 26°C 起可行**，放热 +8，今晚降温日程里窗口 **204 拍**；同温并列 `W2F2`、`X2F2`；中位候选要在 160°C 以上。
4. **但模板的作用是零**：`complete_products` 只依赖总元素计数向量，`F(comp(B)+comp(C)) = [A]` 在抽查的 80/80 个候选上成立——**食物 B、C 单独就能合成 A**，模板 A 从不参与产物判定。因此这是「**加和合成式自洽增长**」，不是模板复制：没有信息传递。
5. **没有变异**：组成唯一决定物种 ⇒ 产物骨架与模板完全同形，保真度 2,594/2,596 为 2/2；剩 2 个 n=11 模板（X3P2K6、X3P6K2）的 F(V) 是「同组成的另一骨架」，复制一次即规范化（0/2），属**一次性确定映射**，不是可遗传变异。没有差异就没有选择。
6. **二元催化 0 例**：扫描 946,946 对（A 为 3~8 原子、B 为 2~4 原子、总原子 ≤12），A 被保留且 B 变成 C≠B 的案例 **0**；另有 198 例「A 被复制」全部是 A==B 的同种对（2A→2A 惰性）。有定理级原因（§3.3）。
7. **能量只有温度**：反应要求 `T_local ≥ csum（总键数）`，等价于 `T_env ≥ T_env_min = 7·csum − 2·heat_sum`；24,708 行候选中 T_env_min ∈ [26.0, 252.0]°C，**21,716 行在今晚 200→0°C 冷却中有正窗口**（最长 204 拍、中位 22 拍、均值 30.1 拍），2,992 行窗口为 0，其中 2,751 行在 200°C 起点也不满足。**0°C 平台无任何候选**。
8. **结论**：现有规则可以给出「**最简自复制化学式**」，但它只是 `B + C → A` 的加和合成，缺少遗传、变异、代谢、边界与空间区隔，因此**不构成生命**；要成为生命至少需要 5 项规则扩展（§4.4）。

## 1 方法

### 1.1 数据与组成表示

- 目录每条记录含 `formula / natoms / atoms / edges`；`comp` 为 9 维元素计数（ORDER=`O X C P W L K A F`），`c` 为总键数（Σ 键级），`label` 为 `pot_all.mol_label` 规范化骨架串。
- **comp ↔ 物种双射**（`catalog.distinct_comps == 84,225`）：同一组成只对应一个已验证分子。这是本报告多条结论的结构性前提。
- 小池规模：n=2 18 条、n=3 64、n=4 160、n=5 309、n=6 630、n=7 1,073、n=8 1,677、n=9 2,555、n=10 3,747、n=11 5,037、n=12 7,102（n≤16 共 82,961 条，n≥17 为少量大分子）。

### 1.2 反应引擎与温度口径

- 完全反应 `F(vec) = complete_products(vec)`：规则 1~11 的「大锅反应」，**结果只由总元素计数向量决定**，与分子的连接方式、身份无关。
- `resolve(mols, T)`：① 若 `T ≥ Σc` 且完全反应可行 → `complete`，产物 = `F(Σvec)`；② 否则先让不稳定且 `T ≥ c` 的分子自分解，回到①；③ 否则 `T ≥ Σi` 且不完全可行 → `incomplete`；④ 否则 `none`。
- 温度口径（`t94_config`）：`heat(C,L,F) = (−1,+1,+2)`；`T_local = (Σheat + 0.5·T_env)/(n + 0.5)`，n=3 时除以 3.5；`T_env(t) = 200·exp(−t/100)`（t<600 拍），600 拍后平台 0°C。
- 本报告的「可行」一律指 `T_local ≥ csum = c(A)+c(B)+c(C)`，这是 `resolve` 走 complete 分支的必要条件；对每组 (A,B,C) 反解出 **T_env_min = 7·csum − 2·heat_sum**（ec=0.5 时精确等价）。窗口结束拍数 `t_end = floor(100·ln(200/T_env_min))`，上限 600。

### 1.3 三体自复制判据

对目录内每个 `comp V`（n ≤ 12）算 `F(2V)`，判据：

> 产物恰为 2 个分子，且两个产物的元素计数都等于 `comp(V)`。

满足者为「复制模板」。对每个模板枚举 `B + C = comp(V)` 的食物拆分，要求 B、C 均在目录内且各 ≥2 原子（目录无单原子分子、无异核双原子 OX/OC/XC，因此 n=2、n=3 模板无法拆分）。再把 `resolve([A,B,C], T_env)` 在 T_env=200/100/50/20/0 五档实测，核对解析窗口是否与 `T_local ≥ csum` 一致。

### 1.4 遗传保真度

产物与模板同组成，比较骨架标签：两产物 label 都等于模板 label 记 2/2，否则 0/2。由于 comp 唯一决定物种，保真度按构造几乎必然为 2/2；例外只能来自「F 输出的规范骨架 ≠ 目录骨架」（§2.9）。

### 1.5 二元催化判据

A 取 3~8 原子、B 取 2~4 原子、总原子 ≤12（A 3,913 种 × B 242 种 = 946,946 对）。判据：

- `A_destroyed`：产物里不含 A；
- `single_product`：`F` 只给 1 个分子（规则不动点，无多产物可拆）；
- `inert`：产物恰为 `[A, B]`；
- `A_duplicated`：产物含 ≥2 份 A（放大）；
- `catalytic_decomposition`：A 保留且 B 变成 ≥2 个碎片（C≠B 的催化分解）。

## 3 关键发现（解释）

### 3.1 「自复制」在规则层退化为加和合成

`complete_products` 是总组成的函数：`F(Σvec)`。三体自复制的三条输入 `A + B + C` 与 `B + C` 的总组成相同（因为 `comp(B)+comp(C)=comp(A)`），所以：

> `F(comp(A)+comp(B)+comp(C)) = F(2·comp(A)) = [A, A]`

但 `F(comp(B)+comp(C)) = F(comp(A)) = [A]` 同样成立。也就是说，**模板 A 是否存在不影响产物**：环境中只要有 A 的两种原料，A 就自动出现。所谓「复制」只是「原料充足时按化学计量自动合成」，没有模板读出、没有自催化、没有信息流。

### 3.2 没有变异的基础

- comp 唯一决定物种（双射）⇒ 产物恒等于模板物种，保真度构造性为 2/2。
- 唯一的 2 个例外是确定性规范化（§2.9），不产生可遗传差异。
- 没有差异 → 没有选择 → 没有进化。

### 3.3 二元催化为零是定理，不是巧合

设 A+B 的总设计 `F(compA+compB)`。若无同分异构体：

- 若产物里保留 A 且只有 1 个产物，该产物必须是 B 本身（否则它会是 comp 的另一个物种，即同分异构体）→ 惰性；
- 要得到 C≠B，必须让 B 的 comp 被拆成 ≥2 个碎片重新组合（产物 ≥2 个且不含 A 或含 A+碎片）。扫描 946,946 对中 0 例。
- 三体路径同理：`F(2compA)=[A,A]` 要求 compA 恰是 F 的 2-产物族；一旦 B+C 能给出 A，模板就无用。

### 3.4 能量：温度是唯一能源，窗口很窄

- 反应阈值 `T_local ≥ csum` 等价 `T_env ≥ T_env_min = 7csum − 2heat_sum`（ec=0.5）。
- 今晚日程：`T_env(t)=200exp(−t/100)`；T_env_min 越高，起点越晚、窗口越短：

| T_env_min (°C) | 26 | 30 | 40 | 50 | 60 | 80 | 100 | 120 | 150 | 200 |
|---|---|---|---|---|---|---|---|---|---|---|
| 窗口结束 t_end（拍） | 204 | 189 | 160 | 138 | 120 | 91 | 69 | 51 | 29 | 0 |

起点时刻全部为 t=0：今晚起点 T_env(0)=200°C 已覆盖所有可行候选（T_env_min ≤ 200），差别只在窗口长度。T_env_min > 200 的 2,751 行则完全没有窗口。

- 结论：**升温即复制、降温即停**。0°C 平台（600 拍后）没有任何候选可行（T_env_min 全部 >0）。
- 放热模板（1,271 个，行数 13,842）可用自身反应热降低阈值；吸热模板（551 个，行数 6,055）必须靠环境热浴，降温后先失活。

### 3.5 如果它要成为生命，还缺什么（问题清单）

1. **模板零作用**：需要「产物依赖模板结构」的规则（如模板决定键合序列），否则复制只是合成。
2. **没有变异**：目录无双射之外的异构体；需要允许同分异构体/突变，才有可遗传差异。
3. **食物对合成**：B+C 单独即可生成 A；需要「无模板时 B+C 不反应」的动力学约束（如配位、催化位点）。
4. **温度窗口极窄**：最快候选也要 26°C，今晚只有 ~204 拍窗口；需要持续热源或恒温环境。
5. **二元催化 0**：没有 A+B→A+C 的催化闭环；需要催化规则（降低阈值/模板加速）。
6. **没有空间区隔/边界**：产物与模板同锅，无法区分「自己的后代」；需要 T93 那样的固态占格膜（OXC 等）做隔室。
7. **没有恒素/能量货币**：恒素 ρ/E 不参与代谢；需要「恒素门控」把环境耦合进反应速率（T83 的 gate=0.15+0.85ρ）。
8. **碰撞概率没算**：cap=36 的世界里三体同时相遇概率低；静态普查只给「规则允许」，不代表动态会发生。
9. **大分子惰性**：n≤14 中 44,855/44,859 是 F 不动点，反应需要特定配比与温度。
10. **目录外物质未知**：84,225 条为已验证集合；引擎可输出目录外骨架（§2.9），环境里若有目录外中间态，本普查不覆盖。

## 4 环境条件建议（今晚 200→0°C 日程）

### 4.1 可运行区间

- **T_env ∈ [26, 200]°C**：全部/部分候选可行；最简 A2F2 在 t=0..204 拍可行。
- T_env < 26°C：**无候选**（T_env_min 最小 26.0）。
- 600 拍后平台 0°C：**全部停止**。
- 想延长窗口：升高起点温度（T_env_min 上限 252°C → 若 T0=300°C 则最慢候选也有窗口），或选小模板（n=4~6）。

### 4.2 分子选择建议

- **最容易起复制**（26~40°C）：A2F2 / W2F2 / X2F2（F2+同核二聚体，放热 +8）。
- **无 F 的温和档**（42~56°C，中性热）：CLA2、CW2L、X2CL、LK2F、O2LF、P2LF、L2K2、O2L2、P2L2、CLK2、CP2L、O2CL。
- **吸热档**（C2A2、C2K2、C2P2、O2C2，−4）：需要环境热，降温早停。
- 避免大模板（nA≥10，中位 160~192°C，窗口 ≤50 拍）。

### 4.3 若要「生命感」，先补哪三条规则

1. **模板依赖**：让产物键序列由模板读出（复制信息），否则一切「复制」都是合成。
2. **同分异构体**：允许同一 comp 多个骨架 + 复制错误率，才有变异与选择。
3. **隔室化**：用 T93 的固态占格冷壳（OXC/O4XCK/O2XK4 等）把「自己」和「环境」分开；T93 已证明力排斥膜不可行、物理封闭可行。

## 6 局限

1. **静态普查**：只判「规则允许」，没跑动态世界；三体碰撞概率、空间输运、coupled 热场都未模拟。
2. **温度窗口用解析式**：`T_local ≥ csum` 是 resolve 走 complete 的必要条件，但不保证动态中反应物真的同时到达；窗口长度是上限。
3. **热场简化**：只按 `T_env(t)` 的均匀温度；实际分子处在有温度梯度/壳层保温（T93）的环境中，局部温度会不同。
4. **目录外状态**：84,225 条为已验证集合；引擎能输出目录外骨架（2 例），其它非目录态未普查。
5. **保真度只看骨架标签**：规则 10 的「同中间态骨架」未逐键比较，label 相同即视为同形。
6. **二元扫描范围有限**：A n=3~8、B n=2~4、总原子 ≤12；更大组合未扫（但定理与规模无关，见 §3.3）。
7. **未计恒素门控**：T83 的 ρ/gate 会随环境温度压低反应率，本文用 p_react=1.0；若接入门控，0°C 平台会更早失活。

## 附录 A 公式

- 温度口径：`T_local = (Σheat + ec·T_env)/(n + ec)`，n=3、ec=0.5 → 除以 3.5。
- 阈值：`T_local ≥ csum = c(A)+c(B)+c(C)` ⇔ `T_env ≥ T_env_min = ((3+ec)·csum − heat_sum)/ec`，ec=0.5 → `7·csum − 2·heat_sum`。
- 窗口：`t_end = floor(100·ln(200/T_env_min))`，clamp [0,600]。
- 自复制判据：`F(2·comp(A)) == [A, A]`（按 comp 判，非按 label）。
- 保真度：产物 label 与模板 label 相同个数 / 2。
- 催化判据：产物含 A 且含 ≥2 个不等于 B 的碎片。
