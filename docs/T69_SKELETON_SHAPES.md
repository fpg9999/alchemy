# T69 大分子骨架形状语言（连接件与端帽 / 元素隐去版）

> 目标：把 T68 的"骨架图鉴"再往前推一步——**去掉元素字形与字母，只留骨架外轮廓**，
> 并给出**连接处（融合 / 二价桥）与端帽的固定图形语法**，让 36 个稳定大分子可以只用图形读懂。
> 结论标注：本文件里"已验证"= 由脚本重算并核对过；"示意"= 为了可读性做的图形约定，不对应真实几何比例。

## 1. 三层图形语法

### 1.1 骨架单元（block）= 一个家族容器
- 图元不是"原子"，而是 **6 级骨架块**（一个骨架内部可含多个块；G13 的骨架 2 = 两块 OP4K 融合）。
- 每个块按它的三价元素组成归入 **7 个家族**，画成对应外形（容器内不再画任何元素字形）：

| 家族 | 三价组成 | 容器外形 |
|---|---|---|
| 纯秩 | 只含 O | 三角形 |
| 纯势 | 只含 P | 圆形 |
| 纯散 | 只含 K | 正多边形（角数随 K 数增加） |
| 秩势 | O+P | 拱形（上圆下三角） |
| 秩散 | O+K | 盾形（上三角下方） |
| 势散 | P+K | 圆角方 |
| 秩势散 | O+P+K | 六边形 |

- 容器内标注**块短组成**（如 `OP4K`、`P2K`），左上角圆徽章是块序号 ①②③…（与右侧面板对应）。
- 已验证：36 个分子的 115 个 6 级块全部落在 38 库内（库外 0），因此"每个块一种家族外形"覆盖完整。

### 1.2 融合（同一骨架内部两个块之间的 0 级同类三价键）
- 图形约定：**两个容器让一条边正对贴合**，接缝压一条**实心焊带**（深色 + 浅色刻痕 + 两侧焊点），读作"焊死"。
- 已验证：36 个分子里只出现 1 处融合——G13 的骨架 2 = OP4K ⊕ OP4K（1 根 P–P 键），图上就是 ②③ 两块边对边焊在一起。
- 其余分子中 0 级同类三价键数量为 0（稳定分子价数饱和），所以融合图形只出现一次，这是数据事实而不是遗漏。

### 1.3 连接件（骨架之间的二价桥）
桥的桥原子决定连接件形状（按用户要求）：

| 桥原子 | 图形 | 语义 |
|---|---|---|
| 晶 X | **三角楔块**：尖端深插一侧容器，另一侧压一块焊板 | 最短最粗，焊死 |
| 流 W | **可拉伸肌腱**：两端窄、中间鼓，带张力纤维 | 可弯曲 / 伸缩 |
| 气 A | **长条薄膜**：长方形横置，长边贴着两侧容器 | 隔空软连 |

- 多元素桥的组合规则：**按链上元素顺序逐段放置连接件，同种元素合并成一段；整条链沿同一轴线排布；两端段各自嵌入所连容器**（X 用楔块/焊板，W 用肌腱端，A 用膜边）。于是 W–A–W 读作"肌腱＋薄膜＋肌腱"的组合接头。
- 同一对骨架之间若有多条同类桥，图上**合并画成一个连接件并标 `xN`**（面板里仍逐条列出），这是为了可读性的约定（示意）。

### 1.4 端帽触肢（一价端帽）与装饰
| 端帽 | 图形 | 语义 |
|---|---|---|
| 冰 C | 尖三角触肢（正/倒三角） | 硬尖刺 |
| 焰 F | 四边形软触肢 | 软须 |
| 电 L | 椭圆细长软触肢 | 细长软须 |

- 端帽从容器边缘沿"原布局方向"向外伸；尺寸随所属容器大小缩放。
- 骨架内桥：容器边上的小铆钉；支臂：容器边缘伸出的管状触须。

### 1.5 元素组成标注
- 每个容器内标块组成，右侧面板给全分子的**元素组成**（如「秩O×3 晶X×4 冰C 势P×16 流W×5 电L 沌K×5 气A×3 焰F×2」）与分子式，实现"元素隐去但可查"。

## 2. 排版（示意）
- 骨架层：以桥连接度为枢纽（hub）做**星形排布**，其余骨架按桥辐射展开、再微调避免重叠。
- 骨架内：融合块沿与父方向垂直的方向排成一行，间距 = rA+rB−0.56（边对边叠合）。
- 说明：这是**示意图排版**，不还原原六边形网格里的真实相对位置；连接件的长短也随之是示意值。

## 3. 数据与复核（已验证）
- 36 个分子 = T68 选样（T61 13 / T64 12 / T62 8 / T63 3），全部 `F(v_M) = {M}`，pot_v4 复核 36/36。
- 合计 1147 原子、114 个骨架、115 个 6 级块、114 条二价桥（S 9 / C 45 / L 4 / 混合 56）。
- 桥原子元素覆盖：X、W、A 三类都有实例（G16 含 A，G26 含 A/W 多元素）。

## 4. 文件与复现
- `t69_bodies.py`：块/骨架/布局（`build_layout`）。
- `t69_pieces.py`：连接件与端帽的画法（楔块/肌腱/薄膜/触肢/支臂/铆钉）。
- `t69_draw.py`：容器、焊带、连接件、装饰、面板的绘制与页内排版。
- `t69_render.py`：36 张卡片 → 18 页 + 总览 + 图例页。
- 数据：`t68_data.json`（T68 产物，含 place/role/skeletons/bridges/decoration）。
- 复现：
  ```
  cd alchemy
  python t69_render.py            # 生成 images/t69_giants_01~18.png、t69_overview.png、t69_legend.png
  python t69_draft.py G13 G14     # 单卡草稿 images/t69_draft_G13.png
  ```

## 5. 局限（当前版本）
1. 连接件按"骨架对"合并画一个并标 ×N，不逐条画 114 条桥。
2. 布局是星形示意排版，空间关系不等于原始六边形摆放。
3. 端帽/支臂的位置取"原布局方向 + 避让"的启发式，不保证与桥的相对方位完全一致。
4. 容器外形按家族归类，同一家族内不同块（如 OP4K 与 OP3K 都是六边形）外形相同，靠块短组成与序号区分。

## 6. 版本调整记录
- **v3（当前）**：按反馈把连接件整体改小、晶 X 改成**小钝三角**（尖端只插进容器 0.5s、三角半宽 0.40s，
  另一侧焊板也缩小），同时把骨架之间的间距压到最小（桥间隙：X 0.28 / W 0.72 / A 1.05 个骨架半径单位；
  多元素 `0.50+0.16k`），容器之间基本贴在一起，连接件只在小缝里露出一段——可读性优先、不追求比例。
- 端帽触肢尺寸也随容器半径缩小（0.34r / 0.32r），避免端帽比连接件还抢眼。
