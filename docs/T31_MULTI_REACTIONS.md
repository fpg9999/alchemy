## 4. 统一分类规律（两分子 + 多分子）

对任意 k 个输入分子，不完全反应可由三个分类轴穷尽描述：

### 轴 A：参与度
- **全体参与**：所有输入分子都发生了改变（需要所有分子都含同一全局最不稳定类）——极稀有；
- **部分参与**：只有一部分分子参与，其余是"旁观者"（不含该类键，保持原样）——多分子的主流（k≥3 时 90% 以上）。

### 轴 B：产物分子数 vs 输入分子数
- **合并**：产物数 < k（典型 k→k−1，两分子合并）；
- **交换**：产物数 = k（碎片互换/重排）；
- **裂解**：产物数 > k（极罕见）。

### 轴 C：是否有新物质
- 产物中出现目录外分子式 → 新物质；
- 否则只生成已有物质（复原/旧物质）。

## 5. 规律总结

1. **反应率随分子数上升**：8.2% → 14.4% → 18.0% → 22.8%（k=2→5）；
   产新率：5.4% → 10.4% → 12.4% → 16.0%。
2. **多分子反应绝大多数是"部分反应"**：一个子集（通常 2 个分子）完成合并/交换，其余分子旁观；
   因此多分子体系本质上是**局部两两反应的集合**，而不是所有分子一起参与。
3. **典型产物数 = k−1**：两个分子合并，其余不动；少数为 k（交换）；裂解极少。
4. **全体参与极稀有**：需要所有分子共享同一全局最不稳定键类；本次只找到 3 分子全体合并的稀有例
   （`O2LK + O2XLF + OP3 → O5XP3L2KF`）。
5. **多分子会产生更大、更复杂的新物质**：合并产物包含更多原子，新物质率显著高于两分子。
6. **旁观者惰性**：不含当前全局最不稳定类的分子完全不变；它们既不参与、也不被消耗。
7. **两分子与多分子共享同一必要条件**：至少两个分子含有同一全局最不稳定键类；否则不反应。
8. **新物质主要来自合并/交换**（两分子数据中 136/137）；裂解几乎只断出目录内小分子。

## 6. 设计含义

- 多分子环境是"新物质工厂"：反应率、新物质率、产物尺寸都随分子数上升；
- 但反应通常是"局部发生"：可以让规则引擎只检查"含最不稳定键类的分子子集"，计算量更小；
- 旁观者机制可用于：
  - 让某些物质在环境中保持不被破坏（只要环境中存在更低距离的键类，它们就完全不动）；
  - 制造"惰性保护/隔离"效果；
- 全体参与的稀有反应可作为特殊事件（例如三个分子合并成一个巨大新分子），适合做稀有发现。
