# T90：主体 A 团簇的"抓取 → 体内反应再生 A → 并入 → 生长"

> 2026-11-20。回答用户 m03715：**"是否真的能存在一个环境，能生成较为稳定的团簇？……能靠抓取周围物质和自身团簇内的其他物质反应再生成 A 然后并入到主体部分进行生长。"**
> 这是对 T78/T80/T89 的追问：T80 证明过"脚本化抓取+并入"能生长，T89 证明 T87 规则里自发稳定团簇极少；T90 回答"**需要什么样的环境才能让它成立**"。

## §0 摘要

**能。** 在下面这套环境里，A 团簇稳定存在，并且完成完整闭环：

1. **稳定**：24 个 A 的团簇在 700 拍内一个不散（no-react 对照：尺寸 24、半径 8 全程不变）。
2. **抓取**：营养物 F1、F2 被 A 的聚素吸引力拉向主体，500 个营养物最终只剩 24 个（no-attr 对照：0 个被拉近）。
3. **体内/表面反应再生 A**：F1+F2 → A（规则 1~11 单产物），只在主体表面 3 格内发生，共 239 次（no-seed 对照：0 次）。
4. **并入生长**：新生成的 A 落在主体邻格即并入，主体 24 → **263 个 A（×11）**，半径 8 → 62 格，176 次显式并入 + 其余靠连通自动归并。

但必须诚实：**这三条（固态主体、表面催化、营养物被吸引）是建模假设**，不是从底层动力学自发涌现的。T89 已经证明：在没有这些假设的 T87 规则里，自发稳定团簇极少（3/1,243 条尺寸稳定 mover）。所以"能存在"= 只要环境满足这三个条件；"能否自己长出来"仍是开放问题（见 §4）。

## §1 环境设定

| 项 | 值 |
|---|---|
| 世界 | 方阵硬边界 240×160，每格最多 1 分子，分子占 k 个格（k = 骨架块数） |
| 主体 A | **C3K3F2**：8 原子、5 位点、self w=0.833（三素公式），初始 24 个 A 排成紧凑团 |
| 营养物 | F1 = **C2K2**（4 原子）、F2 = **CKF2**（4 原子）；各 250 个，闭合池 |
| 反应 | **F1 + F2 → 单个 C3K3F2**（规则 1~11，complete_products 已验证）；只在距主体 ≤3 格处发生，p=0.03/接触/拍 |
| 运动 | 营养物被 A 吸引 → 每拍朝主体质心移动（概率由三素 att 决定），另有布朗；主体设为固态（不移动） |
| 并入 | 反应产物 A 若邻接主体 → 加入主体集合；主体 = 含种子的 A 连通分量（8 邻接） |
| 对照 | full / no-attr（无吸引）/ no-react（不反应）/ no-seed（无主体） |

## §2 结果（700 拍，seed 20261120）

| 臂 | 主体 A | 半径 | 反应 | 并入 | 剩余营养物 |
|---|---|---|---|---|---|
| **full** | **263** | 62 | **239** | **176** | 24 |
| no-attr | 24 | 8 | 0 | 0 | 500 |
| no-react | 24 | 8 | 0 | 0 | 500 |
| no-seed | 0 | 0 | 0 | 0 | 500 |

生长曲线：t=0 24 → t=160 169（最快）→ t=320 254 → t=480 262 → t=700 263，**在营养物耗尽后自然停止**（自限）。

## §3 形态与规律

1. **生长是"表面增生"**：反应只发生在主体表面 3 格内，新 A 紧贴主体生成并并入 → 主体向外长。
2. **长成疏松网络，不是紧凑球**：半径 8 → 62 格，主体 263 个 A 只占 263 格（1 格/分子），远小于 π·62² —— 因为新 A 沿表面凸起附着，形成树状/网络状轮廓（图 C 可见十字形+分支）。
3. **生长自限**：营养物耗尽即停（500 → 24），与 T80 的结论一致——没有"持续供给"就没有持续生长。
4. **三个环节缺一不可**：无吸引 → 营养物到不了主体；无主体 → 没有表面催化位点，反应不发生；不并入 → 合成再多 A 也长不大（T80 farspawn 对照）。

## §4 与"自发涌现"的差距

- T90 是**设计出来的环境**：主体固态、表面催化、A 吸引营养物，都是我们写进规则的；现实里对应的机制是"固体表面 + 表面催化位点 + 吸附"，在化学上合理，但在本宇宙的 T87 规则里并不会自发产生。
- 想在 T87/T88 规则里**自发**得到"稳定主体 + 选择性生长"，需要补：
  1. **边界/表面层**：表面 A 与内部 A 的粘附强度不同（否则团簇会像 T89 那样随时并合/破碎）；
  2. **模板/催化位点**：只有特定构型的表面位点能催化 F1+F2（否则反应在环境里随机发生，A 到处生成、不集中在主体）；
  3. **持续供能/非平衡**：粘附锁需要能量维持，否则 T87 里的大团最终被重力压成沉积层（T87 最大团 6,046 但无内部结构）。
- 结论：**"稳定团簇 + 代谢式生长"在规则上可以存在、也能跑通闭环；但"自发生成并维持"需要上述三个额外机制，目前尚未实现。**
