## 0. 一句话结论

**能力 = 元素在分子结构中的"作用核"（位形计数 × 键型适配）；器官与生命 = 这些作用核在局部界面上
按联动矩阵与节律相互作用后、在"组装体 → 功能子图 → 器官系统"三个尺度上涌现的性质，任何一层都没有
`alive` 标志或一票式"生命度"分数。**

四层单位：L1 分子（只提供位点与能力，不提供身份）→ L2 组装体（界面键连通分量）→
L3 器官（组装体内满足功能通量阈值的**功能子图**）→ L4 生命体（器官系统 + 判据向量全真 + 功能回路闭合）。
设计公理：无生命标志（A0）、局域性（A1）、能力即物质操作（A2）、反馈（A3）、界面非共价（A4，分子间
键能上限 ~3 而分子内共价键 ~100，故界面可逆）、窗口化观测（A5，`T_obs=600` tick、前 300 tick 预热）。
反模式：给分子/组装体打"有机度"总分、按分子式查表赋予器官类型、中心化"生命场"驱动、任何
"这一步之后就是生命"的分支。

## 1. 三大类 9 小类 → 9 元素 1:1 操作能力

### 1.1 三大类（沿用 聚 / 散 / 动，不改名）

沿用而非改成"合/分/运"的三条理由：①兼容成本——27 三轴、键型 S/C/L、相变、27 物性格、t68/t71 器官
全部按"聚/散/动"编码，改名同时打断 6 套数据与文档；②语义足够——聚=把东西凑到一起、散=拆散/摊开、
动=让东西动起来，动词由 9 小类承担；③闭环完整性——聚↑键合数、散↓键合数、动守恒键合数只搬运能量与
信息，三类合起来才有"物质循环 + 能量流"的代谢可能。

| 类 | 主方向 | 操作集合 | 对体系的作用 |
|---|---|---|---|
| 聚 | `poly` | 支撑 O · 刚性 X · 粘合 C | 把离散单元结合成整体：框架、外壳、膜、基质 |
| 散 | `scatter` | 分化 K · 吸附 A · 切割 F | 把整体拆开、在界面交换物质：分叉、捕获、断键 |
| 动 | `move` | 储能 P · 移动 W · 信号 L | 键合数不变，重分布能量与信息：蓄能、位移、传导 |

## 2. 可计算定义：公式、阈值与证据

### 2.1 公式模板（位形计数 × 键型适配，不乘价数）

记号：`C_e` = 元素 e 的原子集；`τ(i)` = 原子 i 的三价（O/P/K）邻居数；`role(i)` ∈ {bridge, intra, arm, free}；
`share_K` = e 原子所连键中键型属于 K 的比例（S 短键/刚性共边、C 角键/柔性共顶点、L 长键/隔空弱连）；
`mult` = 键级 m≥2 的比例；`end(i)` = 度为 1；`adj_tri` = 邻接三价原子；`single` = 单键率。

| 操作 | 数值公式（每位载体原子的权重 × 键型适配） |
|---|---|
| 支撑 `sup` | `Σ_{i∈O} (τ(i)≥2 ? 1 : 0.5) × (1 + 0.15·share_S)` |
| 刚性 `rig` | `Σ_{i∈X} (role∈{bridge,intra} 且 S 焊桥 ? 1 : 0.4) × (1 + 0.20·share_S)` |
| 粘合 `adh` | `Σ_{i∈C} (adj_tri ? 1 : 0.3) × (1 + 0.20·single)` |
| 分化 `dif` | `Σ_{i∈K} (τ(i)≥2 ? 1 : 0.5) × (1 + 0.20·share_L)` |
| 吸附 `ads` | `Σ_{i∈A, role∈{bridge,free}或邻 MONO} (1 : 0.4) × (1 + 0.20·share_L)` |
| 切割 `clv` | `Σ_{i∈F} (end ? 1 : 0.4) × (1 + 0.30·single)` |
| 储能 `sto` | `Σ_{i∈P} (τ(i)≥2 ? 1 : 0.5) × (1 + 0.50·mult)` |
| 移动 `mov` | `Σ_{i∈W, role∈{bridge,arm}} (1 : 0.3) × (1 + 0.25·share_C)` |
| 信号 `sig` | `Σ_{i∈L} (bridge/arm/adj_tri ? 1 : 0.4) × (1 + 0.25·share_{S∪C})` |

三主方向合计：`poly = sup+rig+adh`、`scatter = dif+ads+clv`、`move = sto+mov+sig`。
档位函数复用 `ability.sub_tier(value, th)`（`≤t1 低`、`≤t2 中`、否则高，0 归低），保证三档语义与 v4 一致。
"功能位形"是 v5 与 v4 最大差别：同一元素原子处在骨架节点/桥位/端帽位，操作强度不同；同一分子式、
不同结构，能力谱不同（G01 与 G02 同为 14 原子，谱不同）。

### 2.2 阈值来源与全目录实测

- 命令：`python op_stats.py --n 6000 --seed 20261118`（脚本在 `intake/tmp/ability/`，只读目录）。
- 数据：`t4_catalog_all_validated.json` 84,225 条；245 条无 `place`（0.29%，无法判键型）后有效池 **83,980**；
  抽样 6,000。阈值 = 非零样本 p33/p67（见 §1.2 表）。
- 全目录结构基准（探针实测）：`P(n_skeletons≥2)=0.6295`、`P(有桥)=0.6295`、`P(natoms≥8)=0.9732`；
  骨架数分布 1:31,029 / 2:42,680 / 3:7,462；键型总量 S=388,356、C=442,132、L=365,664；
  端帽中位数 5~6 个/分子。约 63% 分子天然多骨架/带桥 → 界面位点充足。

### 2.3 与物性 27 格的关系（三层正交性）

物性三轴（`attrs.py`）按**价数径向**分：3 价→密度（O 3.0/K 2.0/P 1.0，阈值 (10,16)）、2 价→粘性
（X 3.0/W 2.0/A 1.0，阈值 (6,11)）、1 价→温度（F 3.0/L 2.0/C 1.0，阈值 (3,6)）；能力按**类别角向**分，
几何垂直，这是定义层正交的来源。

| 检验 | 结果 |
|---|---|
| 与物性相关系数（Pearson，6,000 抽样） | 支撑~密度 **+0.81**；刚性~粘性 **+0.78**；切割~温度 **+0.79**；控制 `log(natoms)` 的偏相关几乎不变 |
| 列联表强度（能力三档 × 物性三档，Cramér's V） | 0.58 / 0.52 / 0.45 |
| 27 物性格覆盖 | **27/27 有样本**（n=57~429）；每格内至少有 4 项操作出现中/高档，能力谱不退化 |
| 覆盖缺口（实现约束） | 9 个"温低"格：切割=信号=0%；9 个"粘低"格：刚性=0%；9 个"密低"格：支撑仅 2~7% |

结论：**定义层正交（径向价数 × 角向类别）、数值层必然相关、组合层不退化**。相关是 9 元素↔9 操作
1:1 的必然代价，有意保留（"加 O 会变强"的直觉成立）；正交性限定在定义层与组合层使用，不能拿相关
系数当"两套维度重复"的证据。覆盖缺口进一步说明：任何单一物性区都长不出完整操作集，**必须跨类别取料**。

### 2.4 有机 vs 无机证据（按 T74 生命度分组，仅作分组维度）

分组：`t74_rules.life_class(mol)`，有机物 2,162（36.0%）、活性无机物 2,509（41.8%）、无机晶体 1,329（22.2%）。

| 操作 | 有机物 | 活性无机物 | 无机晶体 | 判读 |
|---|---|---|---|---|
| 支撑 | 1.92 | 1.75 | 1.76 | 三者接近，支撑是普适能力 |
| 刚性 | 0.64 | 0.72 | 0.62 | 接近 |
| 粘合 | 0.94 | 0.82 | 0.78 | 有机物略高 |
| 分化 | 1.62 | 1.84 | **2.04** | **无机反而更高**（K 重骨架常见） |
| 吸附 | 1.38 | 1.11 | 0.61 | 有机物高 |
| 切割 | **1.19** | 1.10 | 0.94 | 有机物高 |
| 储能 | 2.01 | 1.84 | 1.67 | 有机物高 |
| 移动 | **1.70** | 1.46 | 0.72 | **有机物高 2.4 倍** |

### 3.2 六条协同 → 六种器官模块（类器官的第一层）

| 模块 | 耦合项（Λ） | 类器官形态 | 载体例 |
|---|---|---|---|
| 骨/壳 | 撑×锁 1.5 | 承重框架、外骨骼 | O 骨架 + X 焊桥 |
| 基质/膜 | 撑×黏 1.2 | 片层、被膜、胞外基质 | O 骨架 + C 端帽 |
| 重组/愈合 | 黏×断 1.4 | 断口焊接、修复芽 | C 端帽 + F 末端 |
| 消化腺 | 捕×断 1.0 | 触手 + 酶面、消化腔 | A 外露端 + F 末端 |
| 肌/马达 | 蓄×移 1.5 | 可收缩纤维、摆臂 | P 骨架 + W 铰接桥 |
| 神经原基 | 分×传 1.3 | 感受器、传导链 | K 分叉 + L 端点 |

另有两条同系协同：**移×传 1.5**（运动+信号=反射弧/趋化，感知-运动闭环）、**锁×黏 1.3**（刚性件+胶
=复合骨板）。模块判定：`Λ_ij ≥ 1.2` 生成候选模块；模块含 ≥3 项操作且成员 ≥3 → 升格"类器官"。

### 3.3 拮抗与"组合层不退化"

强拮抗：**锁×断 0.2**（刚性抗切割、切割加工刚性材料效率极低）、**撑×断 0.3**（框架抵抗断裂，两者
互毁）、**撑×移 0.3**（固定框架限制位移）、**断×移 0.3**（切割破坏运动结构）。弱拮抗/竞争：
黏×移 0.5（黏住就难动）、断×传 0.5（断裂中断传导）、锁×蓄 0.5（刚性容纳重键会应力集中）。

不退化证据（6,000 抽样，同一分子内 9 项 Spearman）：36 对 `|ρ|≤0.20`、均值约 −0.09，最负
撑×分 −0.20、锁×黏 −0.17。即"协同"不是同分子内自动发生，而是**跨分子/跨器官**的组装耦合——
这正是涌现发生的位置；同时保证矩阵不是把 9 项操作线性捆绑成一个标量。

## 4. 分子间组装（L1 → L2）

### 4.1 位点提取（分子只提供位点，不提供身份）

| 位点 kind | 判定 | 全目录探针量级 | exposure |
|---|---|---|---|
| `cap` 端帽 | 度=1 的原子（一价 C/L/F 为主，也含单连二价） | 0 个 738、1 个 1,295、中位约 5 | 1.00 |
| `hull` 骨架面 | 分子凸包上、属于某骨架块的原子 | 每骨架 1~3 个 | 0.55 |
| `bridge` 桥端 | `bridge_members` 中位于凸包上的原子（T76 桥=功能件） | 多骨架分子 1~4 个 | 0.70 |

每分子最多保留 12 个位点（按 `exposure·σ` 取前 12）；每位点最多 1 条界面键；每分子界面键上限
`max_contacts = min(n_sites, 3 + natoms//8)`。位点强度：
`σ = tier_score[tier] × exposure[kind] × affinity[element]`，`tier_score = {低:0.35, 中:0.70, 高:1.00}`
（tier 来自 v5 九项档位；affinity 默认 1.0，留作标定参数）。例 O3XP4WK3A：O=3.25 高、P=4.16 高、
W=1.12 低，端帽位点 σ≈0.7~1.0、骨架面位点 σ≈0.2~0.4。

### 4.2 结合强度与动力学

```
w(i,j) = κ0 · σ_i · σ_j · M_eff[a_i][a_j] · K[t_i][t_j] · Φ(i,j) · Ψ(kind_i, kind_j)
κ0 = 2.5；W_MIN = 0.15；M_MIN = 0.25；w ≤ 2.5（界面键能上限 ~3，符合 A4 非共价量级）
Φ = exp(-|Δ粘性|/8) · exp(-|Δ温度|/6) · (1 - 0.5·|Δ密度|/40)
```

键型兼容核 `K`：S-S 1.00、S-C 0.85、S-L 0.55、C-C 0.75、C-L 0.60、L-L 0.45（S=共边/刚性、
C=共顶点/柔性、L=隔格/弱作用，跨类取并集，见 `elements.py`）。形状核 `Ψ`：顶点对 1.00、
端帽-顶点 0.90、桥-任意 0.80。`M_eff<0` 时 `w<0`，产生排斥力 `w_rep=0.4·|M_eff|`（扩散步推开一格，
防止万物互粘）。物性兼容 Φ 只乘在结合强度上，**不单独作判据**：Δ粘性大=一黏一滑抓不住；Δ温度大=
热噪声易断；Δ密度大=界面错配、接触面积下降。

```
k_on  = k_on0 · exp(β·(w - W0))                 p_on  = 1 - exp(-k_on·Δt)
k_off = k_off0 · exp(-β·(w - W0) + β·λ_s·s)     p_off = 1 - exp(-k_off·Δt)
k_on0 = k_off0 = 0.05 /tick，β = 1.8，W0 = 0.30，λ_s = 1.0
```

详细平衡：`w=W0` 时 `k_on=k_off`，界面键平均占据率由 `w` 决定，不靠手工开关。反馈：剪切/热噪声
`s` 由温度场、拥挤度、损伤事件决定；大组装体内部被屏蔽 → `s` 低 → 更稳（正反馈），同时资源被消耗
（负反馈）。世界为二维六边形环面格 `L×L`，分子=多格骨牌（每骨架 1 格），接触=格相邻且位点间距 ≤1.5。

### 4.3 组装体判据与六类形态

组装体判据（四条同时成立才**登记**，不满足的键仍保留，下 tick 可重新满足——避免状态机）：
①连通 `|V|≥2`；②总界面能 `E=Σw_b ≥ E_min=2.5`；③内聚度 `c=E/(|V|·0.8) ≥ c_min=0.50`；
④基线噪声下存活 `τ_min=30` tick。

| 序 | 形态 | 判定（全满足） | 物理含义 |
|---|---|---|---|
| 1 | 壳 shell | β0≥1 且 hole 且 n≥6 且 t≤2 | 闭合边界，隔出内外（边界器官原型） |
| 2 | 网络 network | β0≥2 且 κ≥2 且 deg_max≥3 且 n≥8 | 承力桁架（支撑器官原型） |
| 3 | 膜 membrane | n≥6 且 t≤2 且 R/n≥1.6 且无 hole | 二维铺展面（边界/防御原型） |
| 4 | 链 chain | β0=0 且 deg_max≤2 且 d=n-1 且 n≥4 | 线性传动/输运（运输/信号原型） |
| 5 | 簇 cluster | n≤4 且 d≤2 | 小聚集体（种子/催化核心） |
| 6 | 团 mass | n≥5 且 R/n≤1.30 且 β0≤1 且 d≤2√n | 致密团块（储能/防御原型） |

（β0=回路数，κ=顶点连通度，d=界面图直径，R=包围盒面积，t=最小占用厚度。）形态只影响器官原型的
先验权重，**不进入生命判据**——"看起来像器官"不等于"是器官"。

## 5. 器官涌现（L2 → L3）

### 5.1 器官的严格含义

器官 = 组装体内满足以下条件的**功能子图**（边集 `E_k⊆E_asm`）：功能通量 `F_k` 在 20 tick 窗口内
≥ θ_k，且模块度 `Q_k = W_in/(W_in+W_out) ≥ 0.6`，且持续 ≥ `τ_org=60` tick。同一组装体可同时是
1~3 个器官的载体；同一器官可横跨两个组装体；器官身份上下文相关（分子集合不变，环境/界面改变 →
器官类型可变、可消失）。只有输出没有输入/消费者的子图登记为"潜在器官"（`active=False`），不进 L4。

### 5.2 九类器官原型

`θ_keep = 0.8·θ`（滞回：形成难、维持易，防闪烁）；"最小能力组合"要求两能力在该子图位点中出现且
`M_dir` 对应项 ≥0.4。器官类型由**哪个通量最先/最强超过阈值**识别，不由配方表分配。

| # | 器官 | 最小能力组合 | 功能输出 F_k（窗口内） | θ | 失效条件 |
|---|---|---|---|---|---|
| 1 | 支撑 | 支+刚(+粘) | `F_sup = Σ w_b/(n·κ0·0.5)` | 0.30 | 载荷 >0.8·强度，或裂缝连通到边界 |
| 2 | 边界 | 粘+吸(+刚) | `F_bnd = 闭合率·(1-J_leak/J_in)` | 0.45 | 泄漏 >0.5·J_in，或壳/膜破损 |
| 3 | 能量 | 储+移(+切) | `F_nrg = J_E/(J_E_emit+ε)` | 0.35 | 储量 <e_min，或净能量为负 |
| 4 | 运输 | 移+储(+粘) | `F_trn = 定向到达数/发出数` | 0.30 | 堵塞（到达率 <0.1） |
| 5 | 传感 | 信+吸 | `F_sen = Δ响应/Δ刺激`（归一化） | 0.25 | 饱和/配体耗尽（增益 <0.05） |
| 6 | 信息 | 信+分 | `F_int = 输出事件/输入事件`（限幅） | 0.35 | 回路断开，或传递 <1 跳 |
| 7 | 防御 | 切+刚(+粘) | `F_def = 1-J_cut_in/(J_cut_out+ε)` | 0.30 | 被切割率 > 修复率 |
| 8 | 催化 | 吸+切(+分) | `F_cat = 产物通量/底物通量` | 0.25 | 活性位点堵塞/覆盖 |
| 9 | 复制 | 分+支+粘 | `F_rep = 事件数·保真度 f` | 0.25 且 f≥0.85 | 错误率 >15%，或无模板 |

通量只用**事件计数**：`J_bind/J_break`（界面键形成/断裂）、`J_dmg/J_repair`（损伤/修复）、`J_E`
（能量量子到达）、`J_m`（吸附捕获/释放的分子数）、`J_s`（信号脉冲到达）、`J_cut`、`J_rep`、`J_leak`、
`I_sig`（刺激→响应的经验互信息）。原型只约束通量来源（哪两种能力协同），**不约束分子种类**：任何
具有"粘+吸"位点、能形成闭合壳并降低泄漏的分子集合就是边界器官，与分子式无关。

### 5.3 判定、滞回与器官系统

算法：对 9 原型各取候选边集（两端位点能力对 `M_dir≥0.4` 且在原型所需集合内）→ 算窗口通量 →
`F_k≥θ_k 且 Q_k≥0.6 且 持续≥τ_org` 则登记。同一分子被 >2 器官登记只保留 Q 最高两个；两器官共享
>70% 边则合并。状态：潜在 → 活跃 → 退化（`F<θ_keep` 持续 30 tick，边集保留可重激活）。
器官系统 = 器官耦合图连通分量，耦合边权 `C_kl = Σ w_ij·|M_dir[a_i][a_j]| ≥0.5` 连边；须满足
`|organs|≥3`、`β0_sys≥1`（能量/物质/信号闭环）、至少含 1 个能量或边界器官 + 1 个信息或传感器官、
方向一致性（能量净流出为正）。器官输出通过 `M_dir` 调制其它器官反应速率（如信息脉冲使修复速率
×(1+0.5·pulse)）。

## 6. 生命判据（L3 → L4）

### 6.1 五项判据（+ 可选适应）

窗口：预热 `t_warm=300`，观测 `T_obs=600` tick，每 10 tick 采样一次（60 点），全部用变化量/通量积分，
禁止末态快照或静态结构打分。

| 代号 | 名称 | 定义（窗口内） | 通过条件 |
|---|---|---|---|
| B | 边界维持 | `B = 1 - J_out/(J_in+ε)`；同时要求存在壳/膜子图且面积变化 ≤20% | `B ≥ 0.55` |
| M | 能量流/代谢 | `M = (E_harvest - E_dissipated)/(E_maint+ε)`；窗口末储量 ≥0.5·窗口初储量 | `M ≥ 0.25` |
| R | 自维持/修复 | `R = J_repair/(J_dmg+ε)`；中段施加 10% 断键扰动，`0.3·T_obs` 内恢复 ≥90% 界面键 | `R ≥ 0.8` 且 `J_dmg≥3` 且恢复成功 |
| I | 信息传递 | `I = I(X;Y)/H(X)`，X=传感刺激事件、Y=执行器官响应事件（≥2 跳、衰减后仍可辨） | `I ≥ 0.45` |
| H | 复制/遗传 | 复制器官产出 ≥1 个 `\|V\|≥3` 子代，保真度 `f=组成向量余弦相似度`；子代自身窗口 B、M 通过 | `f ≥ 0.85` 且子代可育 |
| A | 适应（可选） | 3 次重复刺激响应强度 F1→F3 斜率 >0 且 `F3 ≥ 1.2·F1` | 通过时报告"适应"，不参与四档主判定 |

`h = 1 - 变异度/允许变异度`（3 次复制平均组成距离）；I 在无信号器官时恒为 0，不会误判通过。

### 6.2 四档分类（判据向量的函数，不是分数）

| 档 | 条件（全部满足） | 对应历史口径（仅顺序对应） |
|---|---|---|
| 无机晶体 | 无 L2 组装体，或 `|organs|=0`，或 B..H 全假 | 旧生命度 <3 |
| 活性无机 | `|organs|≥1`；B/M 中通过 1~2 项；无器官系统（<3 器官或无回路） | 旧 3~5 |
| 拟生命 | `|organs|≥2` 且系统连通；B、M 通过；R/I/H 中通过 1~2 项；**无闭合回路或无 H** | 旧 5~8 |
| 有机生命 | B∧M∧R∧I∧H 全真；`β0_sys≥1`；≥1 个可育子代；≥3 类器官（含边界/能量/信息中的 2 类） | 旧 ≥8 |

反一票制条款：任何一项判据为假，有机生命即不成立，不能由其它判据补偿；`L_report = Σpassed +
0.5·回路闭合 + 0.5·可育子代` 只用于报告/排序，**严禁与阈值比较产生档位**；判据之间允许弱耦合
（M 供能修复、B 提供边界），但不允许任一判据直接由结构式给出。

### 6.3 与旧生命度口径的区别

历史口径（T71/T74）：`molecule_traits` 结构门控加权打分，`≥8 有机生命 / 5~8 拟生命 / 3~5 活性无机 /
<3 无机晶体`。本文件：**取代它**——文件保留为历史，`legacy_life_score()` 只读复算作对照，不进入
`life_report()`；档位改由 B/M/R/I/H 判据向量 + 回路闭合决定。旧口径的核心缺陷是"单个分子可拿高分
（G13=10.6）"，而新口径下**单个分子永远到不了 L4**：B/M/R/I/H 全部是窗口内动力学量，必须由组装体
与器官系统提供。

## 7. 动力学与反馈

### 7.1 每 tick 的局部规则（S1–S8）

- **S1 环境**：恒素浓度 `ρ_E` 扩散（`D_E=0.15`）并被组装体吸附；温度场按物性叠加；能量输入
  `I_E=ρ_E·η` 只注入局部，不全局广播。
- **S2 扩散**：分子按移动(W)能力加权向高 ρ_E 移动（`P(方向)∝exp(β_m·W·∇ρ_E)`），碰撞不动。
- **S3 界面**：邻接分子对 → 位点匹配 → `w` → `p_on/p_off`；成键耗 1 能量、断键释放 0.8（滞后损失=
  耗散来源之一）。
- **S4 物质交换**：A 位点按 `∝ A·ρ_ligand` 捕获自由分子；F 位点切断邻居界面键并释放碎片；P 位点
  按 ρ_E 充能并向 W/F/分 供能。
- **S5 信号**：L 位点把捕获/断裂事件编码为脉冲（宽 3 tick、衰减 0.7/跳），沿 `M_dir≥0.3` 的键传播，
  调制修复速率与 `k_on`（×0.7~×1.5）。
- **S6 损伤/修复**：`p_dmg = 1-exp(-d0·exp(-w/βT))`；支/分/粘 位点消耗 `e_rep` 重连，速率受 S5 调制。
- **S7 复制**：仅"复制器官"活跃且有模板（该器官内最大分子）时按保真度 f 复制，元素替换突变率 μ=0.02/原子。
- **S8 观测识别**：每 `τ_asm=10` 重建组装体（并查集）、每 `τ_org=20` 重算器官通量、每 `τ_sys=50`
  重算器官系统、每 tick 记录观测量。**不写任何生命状态。**

### 7.2 四条反馈回路

1. **富集正反馈**：组装体吸附 ρ_E → 局部浓度升高 → 结合率升高 → 更大组装体；受自由分子耗尽 +
   扩散限制平衡（不会无限长大）。
2. **热屏蔽正反馈**：大组装体内部温度低 → 损伤率低 → 更稳定；但内部物质交换困难 → 通量下降（负反馈）。
3. **功能控制回路**：传感→信息→（修复/运输/结合速率调制）；能量不足 → 运输降速，形成"需求驱动"。
4. **损伤-修复回路**：损伤率↑ → 修复通量↑（需求驱动），修复耗能 → 储量↓ → 限制修复（负反馈防无限修复）。

### 10.2 `alchemy/ops.py`（v5 物质操作层，依赖 mol 结构，不依赖 catalog）

```python
MATERIAL_OPS: tuple[tuple[str, str, str, str, str], ...]   # (key, 中文, 载体元素, 动词, 主方向)
OP_TH: dict[str, tuple[float, float]]                      # 全目录非零 p33/p67（§1.2 表）
OP_TIERS = ("低", "中", "高")
def op_tier(value, th=None) -> str                         # 复用 ability.sub_tier 语义
def op_features(mol: dict) -> dict[str, float]             # 9 项位形计数/键型适配率
def op_scores(mol_or_formula, weights=None) -> dict        # {"formula","ops":{9},"poly","scatter","move"}
def op_profile(mol_or_formula) -> dict                     # {"formula","ops":[{key,name,value,tier,main}]}
def material_abilities_of(mol_or_formula) -> list[dict]    # 与 ability.abilities_of 同形
LINKAGE: dict[tuple[str, str], tuple[float, str, str]]     # (系数, 类型, 理由)，对称只存 i<j
def linkage(a, b) -> tuple[float, str, str]
def assembly_ops(members: list[dict]) -> dict              # {"raw","gain","ops","modules","features"}
def organ_modules(members: list[dict]) -> list[dict]       # §3.2 六种模块候选
```

合成公式：`S_i=Σ_m v_i^(m)`（原始总量）、`q_j=S_j/(max_k S_k+1e-9)`（相对丰度）、
`β_i=1+Σ_{j≠i}Λ_ij·q_j`（耦合增益）、`A_i=S_i·β_i`（涌现后能力）；模块判定 `Λ_ij≥1.2` 生成候选，
含 ≥3 项操作且成员 ≥3 → 类器官。`β` 只放大已出现的操作，不会凭空造操作。
兼容约束：`op_*` 接收 `{atoms,edges,place}`（与 t68/t71 相同字段）；纯公式字符串退化为 v4 计数近似并
标注 `"degraded": True`；v5 值禁止塞进 v4 阈值或 27 格判定。

## 11. 未定项与风险

1. **v5/v4 数值不可比**（高风险）：v5 支撑=位形计数（G13=3.25），v4 支撑=价数加权（OXC=3.0）；
   一旦混用阈值会得到相反档位。对策：独立模块 + 文档/命名隔离（§10.2）。
2. **与物性数值相关无法消除**（r 最高 0.81）：9 元素↔9 操作 1:1 的必然代价。若把"统计独立"当硬指标，
   只能放弃一一对应、重写 §2（≈返工）。当前口径：正交性只在定义层/组合层主张。
3. **v5→L4 尚未跑通**：所有器官/生命数字都是设计值，不是实测；E0~E5 跑完前，"有机生命 0.2~1.5%"只是预测。
4. **阈值子集问题**：黏/断/传中档占比 <12%，三档实际退化为"低/高"；建议这三项改四分位或保留 v4 阈值。
5. **生命度代理未复刻融合键**：目录记录无 `n_fusion_bonds`，本报告取 0；8 个与 t68 重叠分子上代理与
   t71 真值完全一致，但含融合键的分子（如 G13 的 P–P 融合键）会被低估 1.2 分；全目录含 tri-tri 重键
   （m≥2）分子占比未统计，有机物占比可能被低估（仅影响 §2.4 分组比例，不影响能力值）。
6. **G13 等 36 个大分子不在目录**：示例用 `t68_data.json` 结构；全目录统计口径要一致需先补入 catalog（另开任务）。
7. **联动矩阵是设计值**：未经组装模拟标定；建议用 36 个大分子做回归（对已知器官组合 G11 桥接 /
   G13 多器官 / G24 触手检验 Λ 能否复现 T71 生命特征）。
8. **区域覆盖缺口**：温低格无切割/信号、粘低格无刚性、密低格支撑仅 2~7%；若要求"任何物性区都能长出
   某操作"，需外部补料或改载体定义。
9. **性能与规模**：6000×1200 tick 预计 60~150 s/seed（未实测）；器官/系统增量重算周期是性能与滞回的权衡点。
10. **器官原型数量**：9 类是设计选择；"防御/催化"都以 F 为核心，是否合并待 M1 数据决定。
11. **视觉一致性**：T75 投影只到接口级，器官描边/纹样配色需 appearance 侧确认（见 docs/APPEARANCE.md 的缺口 G1~G9）。
