## 1. 三个规则版本到底差什么

### 1.1 代码与 API

| 版本 | 文件 | `simulate` 签名 | key 项数 | 并列裁决 |
|---|---|---|---:|---|
| 规则 1~8 | `pot_all.py` | `simulate(atom_list, rng=None)` | 13 | `rng=None` 时取候选顺序第一个（`tied[0]`），传 `rng` 可随机裁决 |
| 规则 1~9 | `pot_v3.py` | `simulate(atom_list, rng=None)` | 14（13 + 规则 9） | `rng` 仅为 API 兼容，**被忽略**，恒 `tied[0]` |
| 规则 1~11 | `pot_v4.py` | `simulate(atom_list, return_level6=False)` | 16（14 + 规则 10 + 规则 11） | `tied[0]`；**没有 `rng` 参数**；`return_level6=True` 返回 `(mols, level6)` |

> `pot_v3.simulate` **不支持** `return_level6`；`pot_v4` 失败时若 `return_level6=True` 返回 `(None, None)`。
> `pot_v4` 的规则 9 直接 `from pot_v3 import rule9_extra`；规则 10 的块号来自 `pot_v4.ring_flags`/`level6` 捕获逻辑。

### 1.2 key 的字典序分量逐项对照

`key` 越小越优先（`min(key)`）。前 13 项三版逐字相同（`pot_v3`/`pot_v4` 的循环体是 `pot_all` 的复制）：

| # | 表达式（代码原文） | 含义 | 方向 | v1 | v3 | v4 |
|---|---|---|---|---:|---:|---:|
| 1 | `-dt[i][j]` | 周期表距离（异类价数和，同类价数差） | 大者优先 | ✓ | ✓ | ✓ |
| 2 | `-(rem[i]+rem[j])` | 两端剩余价数和 | 大者优先 | ✓ | ✓ | ✓ |
| 3 | `fam[i][j]` | 族组合序号（同大类 0；跨大类：聚-散 0 < 聚-动 1 < 动-散 2） | 小者优先 | ✓ | ✓ | ✓ |
| 4 | `cross` | 同分子 0 / 跨分子 1 | 小者优先 | ✓ | ✓ | ✓ |
| 5 | `gd` | 同组件内 BFS 图距离（跨组件 999） | 小者优先 | ✓ | ✓ | ✓ |
| 6 | `min(csize[ci], csize[cj])` | 较小组件原子数 | 小者优先 | ✓ | ✓ | ✓ |
| 7 | `-max(csize[ci], csize[cj])` | 较大组件原子数 | 大者优先 | ✓ | ✓ | ✓ |
| 8 | `-ut` | 并集元素种类数 | 大者优先 | ✓ | ✓ | ✓ |
| 9 | `ti + tj` | 两组件元素种类数之和 | 小者优先 | ✓ | ✓ | ✓ |
| 10 | `min(ti, tj)` | 较小组件种类数 | 小者优先 | ✓ | ✓ | ✓ |
| 11 | `max(ti, tj)` | 较大组件种类数 | 小者优先 | ✓ | ✓ | ✓ |
| 12 | `-(ri + rj)` | 两组件剩余价数和 | 大者优先 | ✓ | ✓ | ✓ |
| 13 | `-min(ri, rj)` | 较小剩余价数 | 大者优先 | ✓ | ✓ | ✓ |
| **14** | `rule9_extra(celem[ci], celem[cj])` | **规则 9**：并集分子各元素个数，优先级 `O>X>C>K>A>F>P>W>L`（9 元组，多者优先） | 9 元组字典序 | — | **新增** | ✓ |
| **15** | `0 if level6 is None else (0 if blockid[i]>=0 and blockid[i]==blockid[j] else 1)` | **规则 10**：同一 6 级中间态骨架块内优先；6 级阶段恒取 0 | 小者优先 | — | — | **新增** |
| **16** | `rf[i] + rf[j]` | **规则 11**：链先于环（环标志 0/1/2，`ring_flags` 每步重算） | 小者优先 | — | — | **新增** |

补充：
- `pot_v4` 的规则 11 **在 6 级阶段也生效**（`ring_flags` 每步都算）；规则 10 在 `level6 is None`（6 级尚未结束）时恒为 0，只在 6 级之后生效。
- 规则 9 的 9 元组写在 key 的**第 14 位**，所以它只在规则 1~13 完全并列时起作用；规则 10/11 同理只在前面的分量完全并列时起作用。三个版本是严格的"前缀扩展"，不是替换。
- `pot_all.py` 的 `embed_mol` 有 L 中间格 bug，几何判定一律用 `pot_v2.embed_mol2`/`validate_place`（三版共用）。

### 1.5 哪类投料会真正产生不同结果

- **T = n(O)+n(P)+n(K) ≤ 3 的投料：永远不会不同**（98,000+ 次实测 0 例）。
- **T ≥ 4 且能形成多个 6 级块、或同时存在环/链选择**：从 T=4 开始出现（≤8 原子穷举里 T=4 的 1,650 个投料中有 168 个不同 = 10.2%；目录里最小的差异记录只有 7 原子）。
- **越大越容易不同**：目录里 13~16 原子物质的差异率 17%~21%，7~8 个三价原子的物质差异率 28%~35%。
- **含 O/P/K 越少、越小**（如纯 X/C/W/L 或只带 1 个三价原子）的投料：三版结果完全一致，玩家感知不到。

## 5. 结论：口径分歧实际影响什么、不影响什么

1. **分子式（formula）层面：v3→v4 完全不受影响。**
   3,000 随机投料、12,245 个 ≤8 原子穷举投料、84,225 条目录全量：v3 与 v4 的产物分子式多重集差异 **0**；目录 84,225 条的 `formula` 与 v4 产物公式 100% 一致。
   但 **v1→v3 会改分子式**（≤8 原子穷举 22/12,245 = 0.18%，例：`L1K2A3F1` → 规则 1~8 给 `KAF+LKA2`，规则 1~9 给 `KA2F+LKA`）。所以"分子式不变"只在 v3→v4 成立，不能推广到 1~8→1~11。

2. **结构（edges）层面：影响 17.35%（14,615/84,225），替换层面 17.51%（14,745）。**
   差异全部是"同分子式、不同异构/键位/环链选择"；集中在三价原子 ≥4、13~16 原子的大分子（T=7~8 时 28%~35%）。**≤16 原子的小分子中 17.40% 受影响；6 原子及以下 0/1,181，7 原子 8.4%（90/1,073）。**

3. **place 层面：245 条为空（0.29%），其中只有 24 条 ≤16 原子。**
   这 24 条是 v4 替换直接造成的新 None：6 条（11~12 原子）已用无预算完整搜索证明几何不可实现，18 条（16 原子）为预算未判定；另外 217 条历史 None 全部是 search 大分子，其中 216 条现在可直接摆出（属于"历史未计算"，可修）。这不是"口径分歧"本身，而是"替换未做合法性筛选"的副作用（`t52` 的既定策略），T45/t51 的"1200/1200 可摆放"抽样没有覆盖到它们。

4. **骨架分类（38 库、6 级块）：结论仍然成立，而且比预期更强。**
   - (O,P,K) 计数总和 ≤12 的 **454 组全部组合**：规则 1~8 / 1~9 / 1~11 的 6 级块多重集 **逐组完全相同**（0 组不同）；
   - 规则 1~11 下 ≤11 三价全分支扫描（`t50`）：**0 歧义、0 库外**；
   - v4 口径全目录：6 级块库内 **84,225/84,225**，终态三价组件=6 级块之并 **84,225/84,225**，块大小分布与 `t40` 的 1~9 结果**逐项相同**。
   → 规则 10/11 只改变 6 级之后的 0 级同类键选位（最终异构），不改变 6 级骨架库、也不改变"库内块 + 加固/融合"的结构定理。

5. **玩家只关心"投料 X 得到什么物质"时：取决于"物质"如何定义。**
   - 若物质 = **分子式**（目录/索引的主键）：**感知不到** v3→v4 的分歧（分子式 0 变化，且 84,225 个公式在 v4 下都可由同一投料得到）；但若引擎是 v4、而旧攻略/旧数据来自规则 1~8，则约 0.2% 的小投料会给出**不同分子式**（例 4）。
   - 若物质 = **具体结构/摆放**（渲染、`place`、`edges` 参与后续反应）：**能感知**——17.35% 的目录物质在 v4 下结构不同；24 条小分子（如 `O2K6A3`）在 v4 下**根本摆不出来**（place 为空，渲染会缺坐标）。这是当前唯一"硬伤"级别的口径代价。
   - 骨架/分类玩法（38 库、6 级块）：**感知不到**，结论稳定。
