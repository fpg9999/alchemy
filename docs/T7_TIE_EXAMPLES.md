# 并列裁决敏感的具体例子（`PROJECT_HANDOFF.md` §7.4 的详细补充）

> 日期：2026-11-12　工作目录：`G:\AI work\deepseek\work1\alchemy`
> 问题：同一元素计数向量投锅，规则 1~8 在部分步骤存在**多个 key 完全相同的候选对**（并列）。
> 不同并列裁决是否会导致不同的产物（按分子式多重集比较）？本文给出具体例子、统计与机制。

---

## 0. 结论

1. **并列歧义确实存在**：同一投料在不同并列裁决下可得到**不同的分子式多重集**。
2. **最小规模是 6 个原子**：T=6 的偶价数投料中有 **9 个**并列敏感投料（下面全部列出）；
   T=3/4/5 全部投料都**没有**并列歧义。
3. 系统扫描（全部 9 元素投料、T≤9）的统计见 §2；T≤8 为全量，T=9 因记录上限提前停止（≥200 个）。
4. 歧义只影响「同样这些原子如何分组成分子」，**元素/原子总数守恒**，
   不产生新的元素组合，也不影响有限性/511 类别分类（只是物质清单的口径问题）。
5. 项目物质目录采用 `pot_all.simulate` 的确定性裁决口径（并列时取 `tied[0]`）。

---

## 1. 方法（可复现）

- `t7_tie_examples.py`：**并列分支 DFS**——每步找出 key 完全相同的候选对集合，
  若 >1 则穷举所有选择分支，收集所有终态产物分子式多重集；若得到 ≥2 种 → 该投料"并列敏感"。
  对小 T 是**精确**的（除扫描时的分支上限）。
- `t7_tie_trace.py`：对较大的投料，用随机并列多次重跑，直到产物与确定性裁决不同；
  比较两条"选键序列"得到**首次分歧步**与该步的全部并列候选。

## 3. 最小例子：T=6 的全部 9 个

| # | 投料（9 元序 O X C P W L K A F 的简写） | 产物 A（`tied[0]` 裁决） | 产物 B（另一种裁决） | 首次并列候选对 |

| 1 | X1 W1 L1 K2 F1 | WKF + XLK | WLK + XKF | 2 个 **X-K** 对 |
| 2 | X1 P2 L1 A1 F1 | PLA + XPF | PAF + XPL | 2 个 **X-P** 对 |
| 3 | X1 C1 W1 K2 F1 | WKF + XCK | CWK + XKF | 2 个 **X-K** 对 |
| 4 | X1 C1 W1 L1 K2 | WLK + XCK | CWK + XLK | 2 个 **X-K** 对 |
| 5 | X1 C1 P2 A1 F1 | PAF + XCP | CPA + XPF | 2 个 **X-P** 对 |
| 6 | X1 C1 P2 L1 A1 | PLA + XCP | CPA + XPL | 2 个 **X-P** 对 |
| 7 | O2 W1 L1 A1 F1 | OAF + OWL | OLA + OWF | 2 个 **O-A** 对 |

## 4. 7 原子详细例子：`O3 F A2 W`（T=7）

- 投料：O=3, F=1, A=2, W=1（9 元向量 `[3,0,0,0,1,0,0,2,1]`，共 7 原子）。
- 确定性裁决（`tied[0]`）：**O2WA（秩2流气）+ OAF（秩气焰）**。
- 另一种裁决：**O2A2（秩2气2）+ OWF（秩流焰）**。
- 并列分支 DFS 统计：产物多重集 `(O2WA, OAF)` 出现 **48** 条并列选择路径，
  `(O2A2, OWF)` 出现 **24** 条路径（合计 72 条完整反应路径）。
- **首次分歧：第 0 步**。该步并列候选为 **6 个 O-A 对**：
  `(O1,A1),(O1,A2),(O2,A1),(O2,A2),(O3,A1),(O3,A2)`；
  确定性选 `(O1,A1)`，另一条路径选 `(O3,A1)`。
- 复现：`python t7_tie_examples.py example`

## 5. 较大例子（T=29 / T=33；由随机并列重跑发现）

### 5.1 T=29：`O8 C7 W2 K4 A3 F5`（9 元向量 `[8,0,7,0,2,0,4,3,5]`）

| 裁决 | 产物分子式多重集 |
|---|---|
| 确定性 `tied[0]` | `C2, C2, CF, CF, CF, O2KAF, O2WKF, O4WK2A2` |
| 另一种 | `C2, C2, CF, CF, CF, O2KAF, O2KAF, O4W2K2A` |

- 首次分歧：**第 0 步**，该步有 **32 个 O-K 并列候选对**；
  确定性选 `(O1,K18)`，另一条路径选 `(O3,K18)`。

### 5.2 T=33：`X10 W9 K6 F8`（9 元向量 `[0,10,0,0,9,0,6,0,8]`）

| 裁决 | 产物分子式多重集 |
|---|---|
| 确定性 `tied[0]` | `F2, F2, F2, F2, X3W3K2, X3W3K2, X4W3K2` |
| 另一种 | `F2, F2, F2, F2, X3W3K2, X7W6K4` |

- 首次分歧：**第 0 步**，该步有 **60 个 X-K 并列候选对**；
  确定性选 `(X1,K20)`，另一条路径选 `(X2,K22)`。

> 这两个例子说明：**并列歧义不限于很小的锅**；T=29/33 的大投料也可出现。
> 复现：`python t7_tie_trace.py`

## 6. 机制解释

1. 并列来自**同类型原子的对称性**：例如多个同元素原子（3 个 O、2 个 A）在规则 1~8 下完全等价，
   它们与另一元素的候选对 key 完全相同 → 第一步就有多个等价选择。
2. 第一次选择不同后，后续的 key（特别是规则 5 的分子大小、规则 6~8 的类型统计）
   会把反应导向不同的原子分配，最终产物分子式多重集不同。
3. 注意：**元素计数守恒**；不同结果只是把同样原子分成不同的分子（分子数量也可能不同）。
4. 在 511 类别分类中，这些歧义不产生新的元素组合，也不影响"有限性"（都还在同一元素池内）。

## 7. 对项目交付物的影响 / 口径

1. **目录口径**：`t4_catalog_*`、`T4_CLASSIFICATION.md`、`T4_CATALOG.md` 均采用
   `pot_all.simulate` 的**确定性裁决**（`tied[0]`）。本文列出的"另一种产物"**不在目录中**
   （除非它们也能由别的投料/裁决产生）。
2. **有限性/分类不受影响**：歧义只是同一投料内部的分配不同，不改变组件规模上界的讨论。
3. 若需要"**所有并列裁决的并集**"物质目录，需要在枚举器中做分支（工作量约 ×2~10，视分支数），
   目前未做；本文档可作为该工作的起点与测试用例。
4. 早期 T4 文档中的"745 个随机锅中 4 个（≈0.5%）"是**一次随机抽查**的样本；
   本文 §2 是**全量扫描**（T≤9）的统计。两者现象一致（规模越小比例越低，T=6 起出现，T=8 约 1.9%）。
