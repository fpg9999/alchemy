# T76 桥的功用标签

> 桥（连接两个骨架的二价元素链）**不参与硬度/粘性/温度计算**，它是纯粹的功能件。
> 但"怎么连"决定它干什么活：晶 X 是刚件、流 W 是柔件、气 A 是空腔；段数与混编顺序决定最终功能。

## 1. 判定规则

| 组成 | 规则 | 功能 |
| --- | --- | --- |
| 晶 X | X → 刚性焊接；XX → 承重锚固 | 锁死 / 传力 |
| 流 W | W → 铰接关节；WW → 可伸缩肌腱；WWW+ → 牵拉缆索 | 转动 / 弹性 / 长距承拉 |
| 气 A | A → 隔空软连；AA → 缓冲气囊；AAA+ → 隔热隔振 | 留空 / 减震 / 隔断 |
| 刚 + 空（XA / XXA / XAA） | 定距隔空 | 刚性件把间距锁住，空腔不传热、不传振 |
| 刚 + 柔（XW / XXW） | 刚柔复合 | 一端锁死一端可弯，定位 + 微调 |
| 柔 + 空（WA / WAA） | 隔振软索 / 缓冲软索 | 柔件传力、空腔吸振 |
| 三元素（XWA / XWAA / XXWA） | 多点编织 | 不同段分担载荷，既牢又保留柔性 |

实现：`t76_bridge_fn.py`
- `FUNCS`：13 个功能标签（中文名 / 代码 / 说明）；
- `bridge_chain(bridge)`：取桥原子链序；
- `classify(bridge, mol, parallel=1)` → `(key, 中文名, 说明, 判定理由)`；
- `all_bridges(mol)`：该分子每条桥 → `{bid, fn, fn_zh, elems, k, par, bundle, comps}`；
- `stats(mols)` / `fanout(mols)`：功能分布与逐功能明细。

**并联**：同一对骨架之间若有多根桥并行，仍按组成定主功能，另记 `并联×n`（整体更牢）。

## 2. 探索结果：36 个稳定大分子共 114 条桥

| 功能 | 条数 | 占比 | 说明 |
| --- | --- | --- | --- |
| 定距隔空 | 42 | 37% | 最常见：晶 + 气把大块骨架维持在半接触的固定间距里 |
| 多点编织 | 29 | 25% | X/W/A 三段混编，大分子里的"柔性长连接" |
| 刚性焊接 | 24 | 21% | 单晶桥，把小块直接焊在大块上 |
| 刚柔复合 | 10 | 9% | 晶+流，定位 + 可弯 |
| 铰接关节 | 3 | 3% | 单流桥，允许转动 |
| 隔空软连 | 3 | 3% | 单气桥，两块不接触也能联动 |
| 承重锚固 | 2 | 2% | 双晶桥，传力 |
| 牵拉缆索 | 1 | 1% | 三流长链，承拉 |

其中"并联"桥 53 条（同一对骨架 ≥2 根并行）。

## 3. 例子

- **G13**（4 骨架 7 桥）：桥1 X→刚性焊接；桥2/3/4 X→刚性焊接（并联×2、×3、×3）；
  桥5 W→铰接关节；桥6/7 W→铰接关节（并联×2、×3）——全是"焊 + 关节"，没有一根柔性长连。
- **G16**（5 骨架 4 桥）：两根单 X（刚性焊接）+ 两根 W-A-A（多点编织）——气段留空、流段可弯，
  合起来是两条柔性长连接，因此 G16 比 G13 更"松"。

## 5. 局限

- 目前功能只看元素组成与链长，还没用"两端骨架的属性差"来判定（例如同一根刚性焊桥，
  连在两个高硬度骨架之间是承重、连在低硬度骨架之间更像固定件）。
- 并联只作修饰，没有按载荷分摊计算。
