## 2. 物性：密度 / 粘性 / 温度，27 格（`alchemy/attrs.py`，269 行）

### 2.1 三属性与权重

| 属性 | 由哪一价元素决定 | 权重 | 阈值（低 / 中 / 高） |
|---|---|---|---|
| 密度 density | 三价 O / K / P | O 3.0、K 2.0、P 1.0 | (10, 16) |
| 粘性 stickiness | 二价 X / W / A | X 3.0、W 2.0、A 1.0 | (6, 11) |
| 温度 temperature | 一价 F / L / C | F 3.0、L 2.0、C 1.0 | (3, 6) |

- 等级：`≤ 低阈值` → 低；`≤ 高阈值` → 中；否则高（0 归低）。
- 27 格 = `密度档 × 9 + 粘性档 × 3 + 温度档`，格名如 `密-低|粘-低|温-低`；
  同一格内再按主元素组合细分（27 格全有物质，最多 7.3%、最少 1.0%）。
- 为什么把「硬度」换成「密度」：硬度与「固态」重合，会产出 254 例「刚性液体」；
  且无三价元素时硬度恒 0（XA、WA 这类小分子无法区分）。密度对固/液/气都适用。

### 2.2 接口与示例

`molecule_attrs` / `attrs_of` / `skeleton_units` / `grade` / `cell_of` / `property_of` / `grid`；
`skeleton_units` 返回 `{members, atoms, size, bridge_members}`（跨骨架二价桥同时计入两侧）。

| 分子 | 密度 / 粘性 / 温度 | 27 格 |
|---|---|---|
| OXC | 3.0 / 3.0 / 1.0 | 密-低\|粘-低\|温-低（index 0） |
| F2 | 0 / 0 / 6.0 | 密-低\|粘-低\|温-高（index 2） |
| O2X3C3K3A3 | 12 / 12 / 3 | 密-中\|粘-高\|温-中（index 16） |
| O3XP4WK3A | 19 / 6 / 0 | 密-高\|粘-中\|温-低（index 21） |

6000 样本实测档位占比：密度 0.297 / 0.368 / 0.335，粘性 0.312 / 0.321 / 0.366，
温度 0.298 / 0.316 / 0.386（与 `CALIBRATION` 常量一致；本轮独立复算偏差 ≤2% 采样噪声）。

## 3. 能力：三项数值 + 9 项次级三阶（`alchemy/ability.py`，343 行）

### 3.1 v3：三项数值（主方向）

| 方向 | 元素 | 权重 | 三阶阈值（低/中/高） |
|---|---|---|---|
| 聚 poly | O / X / C | 3 / 2 / 1 | (6, 13) |
| 散 scatter | K / A / F | 3 / 2 / 1 | (6, 12) |
| 动 move | P / W / L | 3 / 2 / 1 | (6, 13) |

- 权重 = 元素价数；`scores()` 同时给绝对值、per_atom 归一、三方向份额与主方向。
- 6000 样本主方向三阶分布：聚 36.4 / 33.1 / 30.4%、散 38.2 / 29.7 / 32.1%、动 33.2 / 33.8 / 33.0%。

### 3.2 v4：9 项次级能力（三阶）

| 元素 | 次级能力 | 阈值（低/中/高） |
|---|---|---|
| O | 结构支撑 | (6, 12) |
| X | 刚性 | (2, 6) |
| C | 粘合 | (1, 2) |
| K | 分化 | (3, 12) |
| A | 吸附 | (2, 6) |
| F | 切割 | (1, 2) |
| P | 储能 | (6, 12) |
| W | 移动 | (2, 6) |
| L | 信号 | (1, 2) |

- 只判三阶；**不做能力组合**；9 项并存互不影响；0 归低。
- 低阶占比偏高（实测 52.0% 分化 ~ 79.2% 信号；一价元素接近 79% 为低，
  约一半分子没有任何一价端帽）。
- 次级名取自 `docs/T71_ABILITIES.md` 材料层能力表。

### 4.4 内核 → 外观的缺口（本轮实测确认）

`docs/APPEARANCE.md` 曾称 `skeleton_units`「足以驱动」方块画法，本轮核实后结论是**只能驱动抽象层**：

| # | 缺口 | 具体表现 |
|---|---|---|
| G1 | 适配器缺失 | `skeleton_units` 只给 `{members, atoms, size, bridge_members}`；`t75_tiles` 需要 `place` 坐标、`skeletons[].idx/num/blocks/block_forms/fusion`、`bridges[].comps`、`decoration.*`、`role` ≈ `t68_data.json` 的结构 |
| G2 | 27 格无视觉语法 | 方块颜色只按家族（7 色）；T75b 色条是 36 分子内 min-max 归一，不是 (10,16)/(6,11)/(3,6) 阈值 |
| G3 | 能力无图形表达 | 全仓库没有 ability 的消费方；聚/散/动与 9 项次级能力没有任何方块变量 |
| G4 | 坐标缺失 | 端帽朝向、融合位置依赖原 `place`；内核不存几何坐标 |
| G5/G6 | 家族/块形态/融合对未入内核 | 需查 38 库匹配 `block_forms`，并识别 0 级同类键（全目录唯一 1 处融合在 G13） |
| G7 | 无三价原子分子 | `skeleton_units` 返回 `[]`，T75 无 0 方块分支（小分子只能走 `t73_small.py`） |
| G8 | 混合桥分段 | 114 条桥中 56 条是混合元素；`t75_tiles` 按 X>W>A 坍塌为单一图形，T69 要求按链分段 |
| G9 | 文档不同步 | `APPEARANCE.md` 漏 T75b/T76/T71~73；T75 仍写「硬度」；「156 张图谱」实为 121 种 |

实测佐证（G13 `O3X4CP16W5LK5A3F2`，40 原子 4 骨架 7 桥）：逐骨架 H 5.40/10.80/2.40/2.40、
V 0/4.00/0/0、T +3.50/0/−2.00/+3.00（与 `T75_BLOCK_WORLD.md:85` 示例逐位吻合）；
114 个骨架中 65 个粘性=0、103 个温度=0，说明「桥不计、只看三价」是主流量级而非边角。
整页渲染很快（3 页 < 0.5s），但必须用带 Pillow 的 Python（仓库根 Python 3.11 无 Pillow）。

### 4.5 现有限制（文档 vs 代码）

- 方块排布是 BFS 贪心嵌入，5~7 块的大分子会出现不规则的 2×N 形状（视觉近似，不是化学拓扑）。
- 器官「颈」是直线连回体表，2D 投影无前后遮挡关系。
- T75b 属性色条文档写「右下角」，代码画在**右上角**并与块数点同角（小尺寸总览会重叠）。
- 端帽文档写「C 三角钉 / F 方钉 / L 细圆钉」，代码统一为矩形钉内再画三角/波线/圆点。
- 外观权重（硬度 1.20/0.90/0.60、粘性 1.00/1.40/0.40、温度 −2.00/+0.50/+3.00）与内核权重（3/2/1）
  **两套并存、无换算表**；T75b 逐骨架属性与内核整分子 27 格也是两套口径。
- 外观层与物性/能力数值**尚未连线**：方块/卡片上还没有渲染 27 格物性与 9 项能力的标记。
