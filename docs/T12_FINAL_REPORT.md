## 0. 任务

把「两个物质之间的反应」研究推进到：
1. **连续反应链**：A+B→C，C 再与其它物质反应，产物继续反应 —— 寻找链的规律与有趣现象；
2. **纳入全部元素/全部物质**：在 84,225 条物质目录范围内研究两两反应规律。

## 1. 理论基石（本报告先给出，子任务结果见 2~4 节）

记物质的 9 维元素计数向量为 v。反应结果只由 vA+vB 决定，记 F(v) = 产物分子式多重集（失败则 F 无定义）。
由此得到一组**严格定律**（部分已在 T11 报告中验证）：

| 编号 | 定律 | 说明/证明要点 |
|---|---|---|
| L1 | 交换律 | F(vA+vB)=F(vB+vA) |
| L2 | 向量决定 | vA+vB 相同 ⇒ 反应结果完全相同（与分子结构、原来是什么物质无关） |
| L3 | 守恒 | 产物原子总数向量 = vA+vB（元素计数逐项守恒） |
| L4 | 单产物=加法 | A+B→C（唯一产物）⇔ vC=vA+vB；故无催化/取代/单向转化 |
| L5 | 幂等 | F∘F = F：把一次反应的全部产物再投锅，得到**同一组产物**（因产物总向量仍为 v）。数值验证 63/63 通过（t12_theory.py） |
| L6 | 循环 | 单产物链严格增大向量、不可回环；**允许副产物时循环大量存在**：真 2-环 2,432 个（聚素内112/无三价内2031/跨类289），A 作为催化剂被再生（T11B） |
| L7 | 失败 | F 可能无定义（价数配不平或产物不能摆放）：二元混合存在"不相容"现象；含 O 的组合最易失败 |
| L8 | 规模封顶 | 每个元素子集 S 存在分子大小上限 C_S（纯大类 9、O/X/K 42、全 9 元素≥97 等）。因此**反复反应不会造出越来越大的分子**：产物分子尺寸被 C_S 压住，链再长也只是小分子越来越多 |
| L9 | 等价类 | 所有投料对按总向量分组；每组结果相同 ⇒ "反应性质"可按总向量分类（不是按物质对分类） |

**推论（持续反应的命运）**：一条反应链只要一直用"载流分子 + 新试剂"推进，总向量单调增加（L3），
但每一步的产物分子都被 C_S 限制在有限大小（L8）。因此：
- 链的**步数**可以无限延续；
- 链中**分子大小**很快饱和；
- 真正有趣的长期行为只有三类：**催化循环**（L6）、**收敛到稳定小分子池**（惰性）、**失败终止**（L7）。

## 2. 子任务 A：反应链（T12A）——已完成，详见 `T12A_CHAINS.md`
实验规模：198 个种子（29 聚素 + 175 无三价，按向量去重）× natoms≤8 试剂池的 1000 个抽样 = **198,000 条固定试剂链**；
另做自由模式转移图（551 载体 × 242 试剂 = 133,342 对）与 2-环 × 20 轮验证。

- **幂等性**：97/97 成功向量"产物全部再投锅完全复原"；原子顺序打乱不改变结果（97/97）；单分子自复现 209 次全过。
- **链的终止方式**（198,000 条）：INERT **79.62%**、OVERSIZE 8.64%、CYCLE **7.43%**、FAIL 4.31% —— **绝大多数链几步内就因"惰性（混合不反应）"停止**。
- **链长分布**：中位数 3 步（0步 9,934、1步 22,209、2步 45,195、3步 55,720、4步 33,300…），最长 14 步、平均 3.00 步。
- **快速饱和**：载体平均原子数 4.8 → 3 步时 11.1 → 8 步 16.6 → 逐步走平；链中最大分子 30（受 --max-atoms 保护），说明链长增长但分子尺寸饱和。
- **单产物增长链**（每步恰好一个产物）：共 136,421 条；**最长 6 步**，例如 `O2 + WA` 反复加成：O2 → O2WA → O2W2A2 → … → O2W6A6（2→14 原子），之后无法继续。→ "真正的一直长大"最多 6 步。
- **循环**：`t11_cycles.json` 的 2,432 个真 2-环各 20 轮，**2432/2432 通过**；A 为催化剂，每轮净反应固定、副产物线性累积；涉及 169 个催化剂（C2、X2、CF、WA、CL、XA、XW、LF、F2、X3 等）。
- **自催化（单步）不存在**：58,564 对 + 133,342 对自由模式中，产物含投入物的非惰性反应 **0 例**；结构性原因：simulate 只加键不断键，A 的原子若仍组成 A 分子就不可能与 B 成键。真正的"自催化"只能在多步循环尺度出现。
- **振荡**：小规模 ≤4 原子池检出载体周期振荡 3,727 例；例：`A2 + CK3` 体系载体周期 C2K2→C3K3→C2K2（周期 2）。
- **一锅不动点 3 例**（产物再投完全复原）；同总向量不同分解收敛到同一混合 3 例。

## 5. 统一规律清单（通宵研究总结）

1. **总向量定律**（最核心）：二元反应 R(A,B)=F(vA+vB)，只取决于两种物质的元素计数之和。证据：小分子集 99.6% 的对落在"含 ≥2 对"的等价类中（656,343 类），抽检 380 对同向量独立复算 0 不一致；全目录抽样 100/100 一致；分层碰撞率 L1=99.59%。
   工程后果：7.73M 对只需算 656k 个向量（压缩 11.78×）。
2. **守恒与幂等**：产物原子总数 = 投料和（0 违例）；把一次反应产物全部再投锅得到同一产物集（F∘F=F，幂等；97/97 + 100/100 验证）；失败是吸收态。
3. **单产物=严格向量加法**：1,061,160 对单产物全部满足 vC=vA+vB（0 违例）→ 不存在催化/取代/单向转化式的单产物反应。
4. **失败结构定理**：两个合法物质混合总价数恒为偶数 ⇒ 无奇价失败；"剩键"失败 100% 是「1 个 2 价原子（X/W/A）被晾在一边（rem=2）、其余饱和」；另一类失败是产物摆不出来（大分子为主）。
5. **尺寸/组成规律**：失败率随三价原子数上升（0→0%，12→9.3%）；惰性随总原子数下降（8→45%，16→1.6%）；**惰性只出现在同大类内部，异大类纯物质对从不惰性**；多产物占绝对多数（76%），大投料几乎必然重组。
6. **循环定律**：单产物链严格增大向量、不可回环；允许副产物时存在大量催化循环——真 2-环 2,432 个（聚素内 112 / 无三价内 2,031 / 跨类 289），2432/2432 可无限延续（20 轮实测），A 作为催化剂每轮再生，副产物线性累积；自催化被守恒排除（0 例）。
7. **链定律**：固定试剂链每步总向量单调增加 ⇒ 必须在有限步终止（幂等、饱和）；自由模式下载体 2-环 5,872 对（振荡；另有固定试剂链 CYCLE 终止 14,721 条）；链中分子尺寸很快饱和（分子尺寸有元素子集封顶），反复投料只增加副产物数量。
8. **封顶被刷新**：本项目原"最大合法分子 97 原子"是搜索下界；本次采样发现并 **lead 独立复核** 140 原子合法分子 `O28X27P47WK11A20F6`（8M 节点预算，65s，validate_place=True），另有 108、87 原子新分子。
9. **口径**：正式模拟器 pot_v3（规则 1~9）与 pot_all（规则 1~8）在小投料上 400/400 相同，全量差异约 0.44% 的对，不改变宏观规律。
