## 0 摘要

用户把三素重新定义为**相互作用三维度**，与已有的质量/物态/温度三轴并存：

| 维度 | 代表 | 点值（3/2/1） | 作用 |
|---|---|---|---|
| 聚素 | 吸引力 | O秩=3, X晶=2, C冰=1 | 把分子拉到一起 |
| 散素 | 覆盖范围 | K沌=3, A气=2, F焰=1 | 吸引/排斥能作用到多远（网格半径） |
| 动素 | 排斥力 | P势=3, W流=2, L电=1 | 把分子推开 |

两个分子 i, j 的相互作用只用四个数决定：吸引力 `Att`、排斥力 `Rep`、各自覆盖半径、以及**组成重叠度** `J`。净作用 `w = Att − Rep` 决定能否粘住。全部系数只有 2 个可调（κA=2.5、κR=0.5）+ 1 个单位换算（10 点 = 1 半径档）。**没有匹配度等额外变量**，`J` 就是"组成有多像"。

全目录 84,225 个分子校准（当前规则 1~11）：

- **同种之间净吸引 95.5%**，强粘（w≥1）**82.0%** —— 满足"绝大部分相同分子相互吸引"；
- **异种随机对最常见的是双弱**（Att<0.5 且 Rep<0.5：**58.7%**；<1.0 时 **94.6%**），强吸只剩 **5.4%** —— 满足"不同分子间最常见的是都很弱"；
- 覆盖半径：吸引 1/2/3 档覆盖 54.4%/31.7%/13.9%，排斥 73.2%/25.8%/0.9% —— **排斥始终落后于吸引**；
- 27 格（A/B/D × 高/中/低）**27/27 全覆盖**，最大格 `高·高·高` 12,279（14.6%），最小格 21。

动态验证（方阵环面 8 邻域、点粒子）证实：强吸引分子自发成团、混合世界出现强组成选择性（同性键占比 0.63~1.00，随机期望 0.16）；但**同质吸引本身不足以让一个"种子体"选择性长大**（游离单体彼此成团竞争），这是本实验的诚实结论，见 §4。

## 1 三个维度的数值定义

每个分子先按元素点数求和（P=聚素点数和、Q=散素点数和、S=动素点数和），再按**族内平均**得到三个 0~3 的强度量（缺族记 0）：

```
P = 3·n_O + 2·n_X + 1·n_C          A = P / n_att       （吸引力强度）
Q = 3·n_K + 2·n_A + 1·n_F          B = Q / n_rng       （作用范围强度）
S = 3·n_P + 2·n_W + 1·n_L          D = S / n_rep       （排斥力强度）
```

覆盖半径由**绝对点数**决定（用户 m01694 的规则：10 点→半径 2、20 点→3；排斥落后 1.5 倍）：

```
r_att = 1 + [Q ≥ 10] + [Q ≥ 20]
r_rep = 1 + [Q ≥ 15] + [Q ≥ 30]
```

于是 `r_rep ≤ r_att` 恒成立（同 Q 下排斥最多与吸引同档，通常小一档）。举例：O2K2A2 的 Q=10 → r_att=2、r_rep=1；O2K6A2 的 Q=22 → r_att=3、r_rep=2。

## 2 配对公式

对两个分子 i、j（组成记为元素计数向量），先算组成 Jaccard：

```
J_att = Σ min(P_i, P_j) / Σ max(P_i, P_j)          （聚素元素逐元素）
J_rep = Σ min(S_i, S_j) / Σ max(S_i, S_j)          （动素元素逐元素）
```

同种分子 J=1；完全不含同一族元素时 J=0。距离 d 用线性衰减（d 为环面切比雪夫距离，1 格 = 相邻）：

```
F(d, r) = 1                    d = 1
        = (r + 1 − d) / r      1 < d ≤ r
        = 0                    d > r
r_ij = max(r_att,i, r_att,j)   （同理 r_rep,ij）
```

```
Att = κA · sqrt(A_i · A_j) / 3 · J_att · F(d, r_att,ij)
Rep = κR · sqrt(D_i · D_j) / 3 · J_rep · F(d, r_rep,ij)
w   = Att − Rep
```

判定（四档，无需额外变量；**这是粘附判定，不是化学键判定**）：

| w | 含义 | 行为 |
|---|---|---|
| ≥ 1.0 | **强粘 = 粘附锁** | 锁住两分子的相对位置（拉不开）；不生成化学键、不改分子式、不占价键位点，锁强 = w |
| ≥ 0.2 | 弱粘 = 弱接触 | 可逆接触，可断，不锁死 |
| \|w\| < 0.2 | 无作用 | 不粘附 |
| ≤ −0.2 | 排斥 | 沿连线方向推开 |

> **重要语义**：三素层只回答"两个分子吸不吸附、锁多紧、推多远"。化学键（S 短键/C 角键/L 长键）
> 仍然只由反应规则 1~11 的 `F(v)` 产生；粘附锁**不消耗**化学价键位点，也不参与"分子内键数 = 价数"的校验。
> 因此"强粘"的分子对只是被物理锁在一起（类似范德华/表面吸附），不是合并成一个分子。

### 2.1 κA、κR 到底是什么

κA、κR 是**力标度（耦合系数）**：把 0~3 的强度轴换算成"力"的绝对数值。它们不是概率、不是匹配度，也不随分子变化——全目录共用同一对常数。

- 公式里 `/3` 是归一化：`sqrt(A_i·A_j)` 最大为 3（A=3 时）。所以：

```
κA = 两个 A=3 的同种分子贴邻（J=1, F=1）时的最大吸引力
κR = 两个 D=3 的同种分子贴邻（J=1, F=1）时的最大排斥力
```

- **κA=2.5**：让"最强粘附"与内核 S 短键的 κ0=2.5 同量级——吸附强度 ≈ 最强化学键的能量尺度，这样三素层和化学层的数值可以直接比较/叠加。
- **κR=0.5**：排斥上限是吸引上限的 1/5。为什么不是 1:1 或更大？因为同种分子同时有聚素与动素：
  - 若 κR=0：纯吸引，**任何**带聚素的分子都会互相粘（异种也粘），失去选择性；
  - 若 κR 接近 κA（如 2.0）：A=3、D=3 的同种分子 Att=Rep，互相不粘，"绝大部分同种强吸引"就不成立；
  - 取 0.5 时，同种 `Att−Rep = κA·√(AA)/3 − κR·√(DD)/3`，只要 `5·√(AA) > √(DD)` 就净吸——而 A,D 都在 0~3，最坏 `√(AA)=0`（无聚素，4.5%）才会不吸。
- 这对系数也直接决定异种行为：κR 越大，异种越容易被推开；当前异种 Att 均值 0.47、Rep 均值 0.09，双弱 58.7%。
- **敏感性**（实测）：κA 从 2.5 降到 2.0（κR=0.4）时，同种净吸仍 95.5%、强粘降到 70.2%、异种双弱升到 63.2%；κ 网格 25 组动态选择性在 0.72~0.83 之间波动，**定性结论不变**（最佳 (2.0,0.3)=0.829、(2.5,0.5)=0.772）。κA 取 2.5 主要是为了锚定物理量纲，不是为了刷分。
- 代码里可换：`three_su.pair_force(ci, cj, d, k_a=…, k_r=…)`；默认 `K_A=2.5, K_R=0.5`。

参数表：

| 参数 | 值 | 依据 |
|---|---|---|
| κA | 2.5 | 锚定原 emergence 的 S 短键 κ0=2.5（同种强粘分子 w=2.5） |
| κR | 0.5 | 5:1，保证同种净吸 |
| UNIT | 10 | 用户规则：10 点散素 = 1 档吸引半径 |
| 排斥偏移 | 15/30 | 用户规则：排斥比吸引落后 1.5 倍 |
| 强/弱/排斥阈值 | 1.0 / 0.2 / −0.2 | 与 T80 的 w 阈值一致 |

## 5 与质量/物态/温度三轴并存

这是**相互作用层**，不替代已有的三轴（质量→重力、物态→碰撞、温度→恒素富集）：

- 质量/物态/温度：描述**单个分子**的三条属性 → 决定它如何运动、碰撞、影响环境；
- 聚/散/动：描述**两个分子之间**的相互作用 → 决定它们能否粘住、粘多紧、能拉多远。

实现上：`three_su` 只读、纯函数；未来接入 emergence 时，把 `interface_energy` 的 w 换成 `three_su.pair_force` 的 w（保留旧的 M_eff/K 表作为"键型偏好"这一乘性项，或直接替换），并把 `_move_molecule` 的随机游走换成"合力方向 + 8 方向位移"。**目前未改内核**。

## 6 与真实化学对照

- 真实分子间作用：范德华（吸引，~1/r⁶）、静电/偶极、疏水、氢键；排斥来自电子云重叠（~1/r¹²）。
- 真实"同种强吸引、异种弱"：分子识别（氢键阵列、受体-配体）、自组装（脂双层、淀粉样纤维、晶体）、同型聚集（homotypic interaction）。
- 本模型的简化：用**元素组成 Jaccard** 代替形状/电荷匹配；用**线性距离衰减**代替 1/r⁶-1/r¹²；用**绝对点数**代替范德华半径；无温度依赖、无溶剂效应、无方向性。
- 与真实体系一致的定性事实：同种强吸引 + 异种双弱 → 相分离/自组装（本模型 E2 已复现）；单靠"同类相吸"不足以产生"一个个体选择性长大"（真实细胞靠膜/模板/代谢不对称）。

## 7 局限（诚实）

1. J 是组成相似度，不是形状匹配：同分异构体互相 J=1，会被当成"同种"。
2. 线性衰减与 8 邻域位移是游戏化近似，不守恒力/能量。
3. 半径由散素绝对点数决定，导致点值小的分子（如 OXC）半径恒 1，覆盖范围差异被压缩。
4. 4.5% 无聚素分子会自斥（w<0），与"大部分同种强吸引"不矛盾，但确实是例外。
5. 动态世界未含反应/能量/温度，验证的是"粘合层"，不是完整化学。
6. 冻结规则 + 单格一粒子（无堆叠）限制团尺寸 4~5，可能低估吸引力的聚集能力。
7. 校准用 10 万随机对（期望值稳定），全对 3.5×10⁹ 不可能穷举。
