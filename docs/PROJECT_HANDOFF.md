## 2. 规则与口径摘要（详见 HANDOFF.md）

### 2.1 元素表（9 元素，3 大类 × 3 角色，价数由角色决定）

| 大类 | 3 价 | 2 价 | 1 价 |
|---|---|---|---|
| 聚素 | 秩 O | 晶 X | 冰 C |
| 动素 | 势 P | 流 W | 电 L |
| 散素 | 沌 K | 气 A | 焰 F |

第 10 元素「恒素 E」只是催化剂，不参与反应/成键。

### 2.2 键型与允许关系（实现用：`S 合法 ⇔ 两端含聚；C 合法 ⇔ 含动；L 合法 ⇔ 含散`）

| 两端大类 | 允许键 | 几何 |
|---|---|---|
| 聚-聚 | S | 相邻格 |
| 动-动 | C | 角对角（距离 2 斜向） |
| 散-散 | L | 同轴距离 2，中间格必须为空 |
| 聚-动 | S 或 C | — |
| 动-散 | C 或 L | — |
| 聚-散 | S 或 L | — |

同一对元素可连 1~3 根（多重键）。

### 2.3 反应规则（贪心 key 的字典序，越小越先选）

```
key = (-周期表距离, -(rem_i+rem_j), 族序, cross, 分子内距离,
       规则5, 规则6, 规则7, 规则8, 规则9)
```
- 周期表距离：同类=|价差|；异类=价和；最大 6（异类 3-3）。
- 族序：聚-散=0 < 聚-动=1 < 动-散=2；同大类固定 0（规则 3 不参与）。
- cross：同分子=0、跨分子=1；分子内距离为沿键最短路径，跨分子取 999。
- 规则 5：min(两分子大小), -max(...)；规则 6：两分子元素种类并集数（取最大）的负值；
  规则 7：自身种类数之和（最小）、再按 (小,大) 字典序；规则 8：两分子总剩余键数之和（最大）。
- **规则 9（2026-11-13 正式纳入）**：按结合后分子式内元素数量比较，优先级
  **秩(O) > 晶(X) > 凝/冰(C) > 沌(K) > 气(A) > 焰(F) > 势(P) > 流(W) > 电(L)**（多者优先）。
  正式模拟器 `pot_v3.py`；实测 T≤9 全量无残余歧义（`T12_RULE9E.md`）。
- 详细规格与已核实的自检案例见 `HANDOFF.md` §5~§6。

### 2.4 口径（重要，容易踩坑）

1. **物质 = 分子式**（按分子式统计；同分异构只注明）。
2. **物质集 = 任意元素计数向量投料后能得到的产物**（允许任意投料，不要求来自已发现物质）。
3. 反应成功 = 所有原子 rem=0；且**每个产物分子都要能合法摆放**（否则整锅失败）。
4. **并列裁决（已由规则 9 处理）**：规则 1~8 存在并列；**2026-11-13 起规则 9（元素优先级）正式纳入**，
   实测 T≤9 全量无残余歧义（`T12_RULE9E.md`）。正式模拟器为 `pot_v3.py`；
   旧目录/数据（82,961 条等）是「规则 1~8 + tied[0]」旧口径，需用 `pot_v3` 重算（见 §4.1）。
5. 早期结论「有限封顶 16 原子」「无限族」均已作废，见 §7。

## 7. 重大修正记录（为什么旧结论错了）

### 7.1 可摆放性检查器的两个 bug（T4 修正）

1. **L 中间格 bug**：`pot_all.embed_mol` 用 `set` 记录 L 键中间格，回溯撤销时会误删另一个 L 键共享的中点，
   导致后续原子可放在中点上 → 非法摆放。
2. **缓存碰撞 bug**：`scan_league.py` 用「按大类着色的规范形」作缓存键，但该键丢掉了大类的具体编号，
   导致不同类别的同构分子共用同一个摆放（如 K2 的 L 型摆放被复用到 O2/C2/X2）。
   影响：旧目录约 **5.3%**（s6：4346/82,239）摆放非法；10 个伪物质（如 O3K 只能是 K4 图，格子放不下）。

修复：`pot_v2.py`（`embed_mol2` + `validate_place`）。此后一切数据都用它。

### 7.2 分类结论的两次推翻

- 旧报告：「无限 304 / 有限 207，16 个最小无限三元素」→ 错误（"小 T 一锅一分子"被误当无限增长；
  参数族是假的）。第一次复核给 224/287（9 核心）→ 也被 T4 否定（核心只有 42 原子封顶）。
- 当前：**全部 511 类有限**。

### 7.3 猜想 D 的自我更正（T6）

- T5/T6 曾提出「每组件 `rem≥2` 原子数 ≤3」。
- **本轮找到反例**：投料 `[1,2,3,6,2,6,2,0,8]`（T=30）第 7 步出现组件 `{O(rem0),K(rem0),P×4(rem2)}`（h=4）。
- 原因：旧穷举覆盖 O/X/K（无 P 参与）；修订后候选为「每组件 `Σ(rem−1) ≤ 4`」（见 §8.4）。

### 7.4 并列裁决的非确定性

- 同一投料在不同并列裁决下可得到**不同分子式多重集**（原子/元素守恒，只是分组不同）。

## 8. 有限性证明状态（最重要、也最需要继续）

### 8.1 条件性主定理（严格）

- **猜想 A（组件上界）**：对每个元素子集 S 存在常数 C_S，使任何只用 S 投料的反应，每个产物分子 ≤ C_S 原子。
- **定理（严格）**：猜想 A ⇒ 每个 S 的物质集有限；且物质数 ≤ (C_S+1)^{|S|}。
- 所以任务等价于证明猜想 A。

### 8.2 已严格证明的 6 条结构引理（详见 `T4_PROOF_ATTEMPT.md` §2）

1. 成键的周期表距离序列单调不增（6→5→…→0 逐级推进）；
2. 逐级饱和：每级结束不存在"同级距离、双方 rem>0、bond<3"的可连对；
3. μ 条件：`max(μ_i, μ_j) ≥ dist(type_i, type_j)`（跨分子也成立；μ=最后一根键的级别）；
4. 同类型末相：所有 μ=0 的原子必属同一元素类型；
5. 级联表：每级结束后的活跃类型集 = 该级距离图的独立集（完整表见 T4 文档）；
6. 0 级末相：退化为"单一类型原子、只有容量差异"的纯同类补全。

### 8.3 T5 进展（6 级子过程与纯大类）

- **引理 T1（已严格证明）**：6 级结束时最多只有一个类型的 3 价原子还活跃。
- 6 级子过程（只涉及 O/P/K 三种 3 价原子，只依赖计数）：
  - 穷举计数各 ≤30（29,791 组）+ 大规模随机 → **最大组件 = 13**，模板 `O4P7K2`（7 个活跃 P）；
  - **闭环组件只能是二聚体**（计数 ≤18 穷举 + 随机 ≤50 验证）；
  - **单组件活跃原子 ≤7**；模板库（计数 ≤18）38 种形态；模板放大只复制不增长。
- **L2**：纯大类子反应，计数各 ≤35 穷举（46,656 组）→ 最大分子 **9**（`O2X3C4`）。
- 随机/大投料各级边界：6/5 级后最大组件 ≤8，终态随机大投料只有 ~20 原子（大分子需特殊配比）。

### 8.4 T6 进展（规则 4~8 的必要性 + 新不变量候选）

- **规则 1~3 单独不够**：只保留（距离、剩余和、族序）+ 随机并列时，组件随规模线性增长
  （T=288 → 220 原子；O/X/K 42 族 ×4 → 168）。**必须完整使用规则 4~8**。
- **有界性对并列裁决稳健**：完整规则 + 随机并列，仍是有界（O/X/K×2→32；全 9 97 族×2→54、×3→46）。
- **候选不变量 E**：每组件 `Σ_{rem>0}(rem−1) ≤ 4`（"额外键容量"）。
  - 证据：反例恰为 4；大分子族（OXK42、全 9 97 族）为 3；全 9 计数各 ≤3 穷举（131,071 组）最大 3；
    爬山搜索（多 seed、T≤240）从未超过 4。
  - 动力学公式：同组件加键 `ex' = ex − 2 + d`（不增）；跨组件合并 `ex' = ex_A + ex_B − 2 + d`。
  - **证明缺口**：需要证明「rem=1–rem=1 的合并不可能把多个组件的 ex 叠加到 >4」。
- 猜想 D（≤3）已被反例推翻，详见 §7.3。

### 8.5 仍然缺什么（准确表述）

- **未获得无条件证明**。当前缺口：
  1. 证明候选 E（`Σ(rem−1) ≤ 4`），核心是 rem=1 端点合并的累加上界；
  2. 由 E 推导组件规模上界的"合并会计引理"（每次跨组件合并如何消耗 ex/活跃原子）。
- 可以写进交付物的表述：
  > "511 类全部有限"目前是**严格归约 + 6 条结构引理 + 全 511 类强数值证据**；
  > 无条件形式证明还差「不变量 E + 会计引理」。
- 不能写的表述："已无条件证明每个 S 有限"。
