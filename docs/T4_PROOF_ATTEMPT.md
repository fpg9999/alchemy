## 0. 结论摘要（TL;DR）

1. **没有拿到完整无条件证明，也没有找到反例。**
2. 得到一份**条件性证明**，把问题等价地归约到一条组合引理（猜想 A：每个 S 存在组件上界 C_S）：
   只要 C_S 存在，S 的物质集必然有限，而且物质数有显式上界。归约是严格证明的，见 §3。
3. **严格证明了 6 条结构引理**（§2），把「由大锅产出的分子」的可能形态压进一个「逐级活跃类型级联」框架：
   - 成键的周期表距离序列**单调不增**（引理 1）；
   - 每级结束时没有同级的可连对（引理 2，「逐级饱和」）；

     这正是任务提示的「每级之后还能继续成键的元素类别受到限制」的精确形式。
4. **计算实验**（§4）：
   - 对全部 **511 个子集**做均衡投料放大（T=24/48/96）：**397/511 个子集的最大分子在三个规模完全相同**，

     `O_mX_mK_{m+2}` 封顶 `O4X7K6`（17 原子），与 `TASK3_VERIFY.md` 一致（§4.5）。
   - 引理 3、引理 4 在 **所有已知物质**（O/X/K 的 204 个 + `substances_all.json` 33091 条）与数百个随机锅上
     **零反例**；同类键（距离 0）连通块大小在全部数据中 **≤3**（§4.4）。
5. **剩余缺口只有一处**（§5、§6）：低级别（1/2 级同大类子反应 + 0 级同类补全）中跨组件合并的「净增长」

## 1. 形式化设置

### 1.1 类型与距离

元素类型由 (大类 ∈ {聚,动,散}, 价数 ∈ {3,2,1}) 唯一确定，共 9 型：
`O(聚3) X(聚2) C(聚1) P(动3) W(动2) L(动1) K(散3) A(散2) F(散1)`。
周期表距离：

```
dist(t,t') = |v-v'|     若同类
           = v + v'     若异类
```

最大距离 6（异类 3-3），最小 0（同型）。

### 1.2 反应过程 = 逐根贪心加边

给定原子多重集，每步在所有「可连对」(rem_i>0, rem_j>0, bond(i,j)<3) 中取
`( -dist, -(rem_i+rem_j), 族组合, cross, 分子内距离, 规则5,6,7,8 )` 字典序最小者加一根键。
本文只用到规则 1（距离）与规则 2（剩余和）主导、规则 3~8 只在并列时生效这一点。

### 1.3 关键量：μ

对反应产物（全部产物一起看）中任一原子 i，定义

```
μ(i) = 原子 i 的所有键中周期表距离的最小值
     = 该原子「最后一根键」所在的级别（因为距离序列单调不增，见引理 1）
```

对每个级别 d ∈ {0,…,6}，定义

```
U_d = { 原子 i : μ(i) < d } = { 在 d 级键全部处理完后仍有余键（rem>0）的原子 }
```

（d 级从 6 到 0 依次处理；U_d 是「d 级结束后仍活跃」的原子集。）

### 1.4 物质

按项目口径：物质 = 某次成功反应的一个连通分量（分子），按分子式统计。
元素子集 S 的「物质集」= 只用 S 中元素投料时能得到的分子式集合。

## 2. 严格引理

### 引理 1（距离阶梯引理）

设第 t 根键的周期表距离为 d_t、两端剩余键数之和为 s_t。则序列 (d_t) 单调不增；
且同级内 (s_t) 单调不增，即 (d_t, s_t) 按字典序不增。

**证明.** 记第 t 步的候选对集合为 C_t。由于每加一根键只使 bond(i,j) 增加、rem 减少，
「可连」的两个条件（rem>0、bond<3）都只会变得更难满足，故候选集单调收缩：C_{t+1} ⊆ C_t。
每步在收缩的集合上取字典序最小 key = (-d, -s, …)，故最小 key 不降，即 d 不增、同级 s 不增。∎

*推论*：成键按 6,5,4,3,2,1,0 的级别「阶梯式」推进；不存在「先低后高」的回退。

### 引理 2（逐级饱和引理）

对每个 d，所有距离 ≥ d 的键处理完、而距离 d-1 的键尚未开始之时：
不存在一对原子 (i,j) 满足 `dist(i,j)=d`、`rem_i>0`、`rem_j>0`、`bond(i,j)<3`。

**证明.** 若这样的对存在，它就是候选对，且其距离 d 严格大于下一步会选的 ≤ d-1，
与贪心每步取最大距离矛盾。∎

*说明*：这条引理几乎由贪心定义直接给出，但它是后面所有结构结论的根。

### 引理 3（μ 条件 / 活跃集独立条件）

对反应产物中**任意两个原子** i,j（**包括不同分子之间**）：

```
max( μ(i), μ(j) ) ≥ dist(type_i, type_j)
```

等价地：对每个 d，活跃集 U_d 中不存在类型距离恰为 d 的一对原子
（U_d 是距离 d 图的独立集）。

**证明.** 反设 dist(i,j)=d 且 μ(i)<d、μ(j)<d。μ(i)<d 表示 i 至少有一根键的距离 <d，
即在 d 级键全部处理完时那根键还没形成，故 rem_i>0；同理 rem_j>0。
再由 μ(i)<d 知 i 的 3 根（≤3）键不可能全部落在距离 d 上，故 bond(i,j)<3。
于是 (i,j) 在 d 级结束时仍是可连对，与引理 2 矛盾。∎

*检验*（§4.4）：该条件在 O/X/K 的 204 个物质、`substances_all.json` 的 33091 条物质、
以及数百个随机锅的全部产物（跨分子全局检验）上**全部成立**。

### 引理 4（同类型末相引理）

任一成功反应的全部产物中（跨分子），**所有 μ=0 的原子必属同一元素类型**。

**证明.** 设 i,j 都 μ=0。由引理 3：max(0,0) ≥ dist(type_i,type_j) ⇒ dist=0。
而不同元素类型的距离 ≥1，故二者同型。∎

*含义*：整个反应里只有一种元素会通过「同类键（距离 0）」把自己接满；其余元素的原子都必须靠跨型键饱和。

### 引理 5（级联表：每级结束后的活跃类型限制）

由引理 3，对每个 d，U_d 中的类型集不能包含距离恰为 d 的类型对。距离表如下（表 1）：

| 级别 d | 该级允许的键（类型对） | U_d 中**禁止**同时出现的类型对 |
|---|---|---|
| 6 | 异类 3-3：OP, OK, PK | OP, OK, PK |
| 5 | 异类 3-2：OW, OA, PX, PA, KX, KW | OW, OA, PX, PA, KX, KW |
| 4 | 异类 3-1：OL, OF, PC, PF, KC, KL；异类 2-2：XW, XA, WA | OL, OF, PC, PF, KC, KL, XW, XA, WA |
| 3 | 异类 2-1：XL, XF, WC, WF, AC, AL | XL, XF, WC, WF, AC, AL |
| 2 | 同类 3-1：OC, PL, KF；异类 1-1：CL, CF, LF | OC, PL, KF, CL, CF, LF |
| 1 | 同类 3-2：OX, PW, KA；同类 2-1：XC, WL, AF | OX, PW, KA, XC, WL, AF |
| 0 | 同型：OO,XX,CC,PP,WW,LL,KK,AA,FF | （空，最后一相） |

由表 1 与 1.3 中「2 价原子 μ≤5、1 价原子 μ≤4」立即得到：

**推论 5.1**　所有 μ≥6 的原子都是 3 价原子，且它们的**全部**键都是 6 级键
（连向另外两个大类的 3 价原子）。

**推论 5.2**　若某个大类 c* 的 3 价原子在 6 级后仍活跃（μ≤5），则另外两个大类的 3 价原子全部 μ=6
（在 6 级就被接满）；即「6 级结束后，最多只有一个大类的 3 价原子还活跃」。

**推论 5.3**　设 c* 如上（存在）。则任何 μ=5 的 2 价原子，其两根键都是 5 级键，
另一端**只能是 c* 的 3 价原子**（其它大类的 3 价原子 μ=6，没有 5 级键）。
反之，**不属于 c* 的 2 价原子未必 μ=5**：若它在 5 级结束时仍未饱和，就必须继续在 4 级
与另一大类的 2 价原子成异类 2-2 键（或更低级）。实例：投料 `O=2, W=10, A=10` 的产物是
`O2W6A6 + 4×WA`，其中 4 个 `WA` 二聚体的 W、A 都是 **μ=4**（W-A 是异类 2-2，距离 4）。
若 c* 不存在（6 级后无活跃 3 价原子），则所有 2 价原子都 μ≤4。

**推论 5.4**　1 价原子的距离范围为 {1,2,3,4}（同大类 3→2、2→1，异类 3→4、2→3、1→2），故 μ(1 价原子) ≤ 4。
若某 1 价原子 μ=4，则它唯一的键是异类 3-1 键，另一端是 μ≤4 的 3 价原子；
在 c* 存在时这只能是 c* 的 3 价原子（其它大类 3 价原子 μ=6）。

**推论 5.5（0 级纯同类末相）**　进入 0 级时（1 级结束后）活跃原子集 = {μ=0}，由引理 4 全部同型，
记为 t*；0 级的所有键都是 t*-t* 同类键，每个原子的剩余容量 ∈ {1,2,3}。

**级联表的实例**（`t4p_cascade.py` 输出，`n` 为该分子原子数）：

| 分子 | 6 级后活跃 | 5 级后活跃 | 4 级后活跃 | 3 级后 | 2 级后 | 1 级后 |
|---|---|---|---|---|---|---|
| O9X10K23（42 原子，O/X/K） | 33 原子，类型 KX | 22，K | 22，K | 22，K | 22，K | 22，K |
| 全 9 元素 97 原子分子 | 84，ACFKWX | 75，ACFK | 60，AFK | 60，AFK | 56，AK | 10，A |

可以看到：活跃类型集随级别下降逐级塌缩，最后只剩一个类型的原子，且 3 价活跃原子从 6 级起就只剩一个大类
（上表：散类 K）。这正是「逐级饱和」的具体形态。

### 引理 6（0 级末相结构）

进入 0 级时：活跃原子全部同型 t*，每个原子剩余容量 r_i∈{1,…,v*}，且
0 级是一个「全同类型原子、只有容量差异」的贪心补全过程：
每步在两两可连的同型原子对中按 (r_i+r_j 最大，然后**同分子优先**、分子内距离最小、规则 5~8) 选边。

**证明.** 由推论 5.5 与运动规则直接得到。∎

*经验加强（未证，见猜想 B）*：在实际产物中，0 级同类键形成的连通块（同型原子团）大小 **≤3**。
在 204 个 O/X/K 物质、33091 个 `substances_all` 物质、97 原子及其他大分子、数百随机锅上
均未见到 ≥4 的同类键块（§4.4）。

## 3. 条件性主定理

### 3.1 主命题与等价归约

**主命题（每个 S 有限）**：对每个元素子集 S，只用 S 中元素投料能得到的物质（分子式）集合是有限的。

**猜想 A（组件上界 / 闭合引理）**：对每个元素子集 S，存在常数 C_S，使得任何只用 S 中元素的投料，
其反应的**每个产物分子至多含 C_S 个原子**。

**定理 1（归约，严格）**：猜想 A ⇒ 主命题。更定量地，若 S 的组件上界为 C_S，
则 S 的物质数 ≤ (C_S+1)^{|S|}（分子式由每个元素的计数决定，计数 ≤ C_S）。

**证明.** 物质按分子式统计；分子式中每个元素的原子数不超过单分子原子数 C_S，
故可能的分子式（计数向量）只有有限多个 (C_S+1)^{|S|} 种。∎

因此**整个问题恰好等价于「每个 S 存在组件上界」**。任务要求的「证明每个类别只含有限多个物质」
= 证明猜想 A。本文把猜想 A 拆成可攻击的形态，并给出它已知的全部必要条件。

### 3.2 一个更细的中间猜想（可验证、也更强）

**猜想 B（副本 / 闭合模板猜想）**：对每个 S，存在一个**有限**的「模板库」L_S
（每个模板是一个类型化多重图，即一个分子），使得任何只用 S 投料的成功反应，
其产物（不计顺序）都是 L_S 中模板的**不交并的同构副本**。

（若 B 成立，则 C_S = max{ 模板原子数 }，定理 1 即给出主命题。）

**数值证据**：§4.2 的 511 子集实验中，均衡投料下 397/511 个子集的最大分子在 T=24/48/96 三个规模下**完全相同**，
同时产物数中位数从 8→16→34（随 T nearly 翻倍）。这说明大投料只是在**复制**同一批小分子，
而不是在变大——正是猜想 B 描述的现象。代表例：

| 投料族 | t=1 | t=2 | t=8 |
|---|---|---|---|
| O=9t, X=10t, K=23t（3 元素） | 1 个 42 原子 | 32,30,11,11 | 20 个分子，最大 32 |
| O=t, K=t（等量异类 3-3） | 1×2（OK 三键） | 2×2 | 8×2 |
| O=t, W=t（等量异类 3-2） | —（t=1 价数奇失败） | 4×1 | 4×4 |
| X=t, W=t（等量异类 2-2） | 1×2 | 2×2 | 8×2 |
| 纯聚 O=2t, X=3t, C=4t | 9 | 8,8,2 | 8×12 |

（「4×1」表示 1 个 4 原子分子；完整缩放表见 §4.3。）

**猜想 B 的弱形式 B'（也足够）**：存在常数 C_S，使得任何产物中「不属于有限模板库的分子」的个数是常数级、
且每个分子 ≤C_S。本文所有数据都支持 B（更强），但在 §5 说明为何 B 的完整证明同样困难。

### 4.2 E2：全部 511 个非空子集的均衡放大实验（`t4p_all511_scale.py`）

对每个子集 S，均衡投料（尽量均分；总价数配成偶数），T=24/48/96，用 `pot_all.simulate` 跑反应，记录最大分子：

- **397/511** 个子集最大分子在三个 T 下完全相同；其余差异大多只出现在 T=96（见下）。
- 最大分子（T=96）按子集大小 k 的最大值：`k=1:2, 2:4, 3:6, 4:8, 5:28, 6:12, 7:17, 8:7, 9:8`。
- 产物数中位数：T=24 → 8；T=48 → 16；T=96 → 34（**≈ 随 T 翻倍**，即复制而非增长）。
- T=96 比 T=24/48 大 >2 的子集共 **15 个**，最大者 `{O,X,P,W,A}` 达到 28。

复核这 15 个里最可疑的 8 个（`T=96/144/192/288`，均衡投料）：

| X C P W A | 14 | 5 | 14 | 5 |
| X P W L A | 14 | 5 | 5 | 6 |

**结论**：最大分子随规模**来回振荡（5~28）而非单调增长**，是投料比例的「共振」现象，不是无限族。

## 5. 为什么卡住：机制分析与缺口定位

### 5.1 「分发—闭合」机制（数据支持的直觉）

观察 O=K=t 的平衡投料：结果总是 **OK 三键二聚体**。原因：
1. 6 级（唯一级别）开始，规则 2（剩余和最大）先把键「分发」出去：所有对剩余和都为 6，形成完美匹配式的单键；
2. 匹配完成后所有原子 rem=2，规则 2 不再区分，规则 4（同分子优先）开始起作用 → 每个 2 原子分子内部连续补键直到接满；
3. 结果就是二聚体，且大投料得到 t 个副本。

同样的「分发（规则 2）→ 闭合（规则 4）」在每一级内重复：
`O/W` 平衡投料得到 4 原子分子副本；O/X/K 的 42 原子分子是 6 级分发 + 5 级分发 + 0 级闭合的「共振」结果。
**这解释了为什么大投料不会变大**：每级的分发是「全局均衡」的，闭合发生在小分子内部。
但把这句话变成定理，需要控制规则 4/5 在边界（剩余原子数不足、跨组件合并时）的行为。

### 5.2 为什么仅凭引理 3 不够：一个反例构造（满足 μ 条件但任意大的图）

μ 条件只限制「μ=0 的原子同型」以及逐级活跃集的类型组合，**不限制原子数量**。例如取大量 K（散3）作 μ=0 原子，
配大量 O（μ=6，全接 K）、X（μ=5，全接 K）：可以构造出与 O/X/K 的 42 原子分子同一「型」、
但原子数任意大的图，它满足引理 3 与所有度条件。**因此有限性必须来自动力学（贪心的分发—闭合），而非纯图论约束。**

### 5.3 精确缺口

**缺口 G1（核心）**：证明猜想 A / B。等价地，需要一个关于以下抽象贪心过程的组合引理：

> 设 T 为有限类型集，原子带类型与容量。过程分 6 个级别；每级内按
> `(两端剩余和最大, 同分子优先, 分子内距离最小, 规则 5~8)` 贪心加边，直到该级无可连对。
> 证明：存在常数 C(T)，使得任意输入的最终每个组件 ≤ C(T) 个原子。

已知的部分：
- 高级别（6、5 级）：**6 级结束时组件很小且随规模饱和**（2 大类池 ≤5、3 大类池 ≤7；§4.7），
  但尚未证明对所有输入成立。**且该小界依赖规则 4/5 的完整并列裁决**：
  只保留规则 1~3 的重放会得到 15 原子的 6 级组件（§4.7 旁证）。
- 低级别（1/2 级）退化为「单大类内的同/异价键」子反应；0 级退化为「同型原子补全」（引理 6）；
- 规则 4 的「同分子优先」提供了强闭合倾向，规则 5 的「最小+最大分子」在跨组件合并时又提供了全局均衡倾向；
  两者相互作用正是「副本复制」的根源，也是证明的难点。

### 5.4 一条可能的证明路线（建议后续工作）

1. **子引理 L1（6 级小组件）**：6 级结束时每个组件 ≤ 常数。
   实测常数：2 大类 ≤5、3 大类 ≤7（§4.7，T=30/60/120 稳定）。
   6 级只涉及异类 3 价原子对，是**完全封闭的有限类型问题**（3 种类型 × 容量 3），
   可对全部抽象状态做穷举证明（预计状态数很小）；这是最值得先攻的。
2. **子引理 L2（同大类子反应有界）**：把每个原子抽象为 (类型, 已用容量)，
   证明纯大类 3 型系统在任意原子数与任意初始剩余容量下组件 ≤ 某常数（已知纯大类最大 9）。
3. **子引理 L3（层级递推）**：若 d+1 级结束时组件 ≤ C，则 d 级结束时组件 ≤ C + f(类型集)，
   其中 f 只依赖「d 级可连对的类型结构」（表 1）与每原子容量 ≤3。
   难点在规则 5 的跨组件合并的「最小+最大」选择：需要证明合并次数 × 单次增幅有界。
4. 由 L1~L3 归纳得猜想 A；再用定理 1 得主命题。

其中 L1、L2 是我们认为最可能先攻下的（且 L1 可做成计算机穷举证明）；L3 是真正的新数学。

### 5.5 其他子缺口

- **G2（同类键块 ≤3）**：引理 6 的经验加强。若证明，可用于 0 级计数；但注意它**不足以**单独给出组件上界
  （97 原子分子里 μ≥1 的原子有 87 个，非同型键也能大量存在）。
- **G3（几何收紧）**：把可摆放性作为额外约束纳入 C_S 的计算，可以显著降低实际封顶
  （如 129/160 原子候选图可能根本不是合法物质）。不影响有限性。
- **G4（并列/非确定性）**：规则 1~8 并未消除全部并列。`t4p_analyze.py` 的检验：
  745 个随机锅中 **4 个**（≈0.5%）在「不同并列裁决」下得到**不同的分子式多重集**
  （例：7 原子投料 `O3 F A2 W` 可得到 `O2WA + OAF`，也可得到 `O2A2 + OWF`；二者组成相同但分子不同）。
  这说明「反应结果只取决于元素总个数」严格说只到「并列集合」为止；对本题有限性无影响
  （所有可能结果都仍需有限），但对物质清单的完备性有影响：
  严格证明猜想 A 时必须对**所有并列选择**都给上界；建议项目文档标注此口径。

## 6. 结论

1. **无条件证明未完成**。目前能严格证明的是：反应的「距离阶梯」结构、逐级饱和、μ 条件、
   μ=0 原子同型、0 级纯同类末相，以及每级活跃类型级联表（§2）。这些把产物形态压缩得相当厉害，
   但**不足以**给出组件上界（§5.2 的反例构造说明必须用动力学）。
2. **反例未找到**，且 511 个子集 × 三个规模、多个大尺度族的全部实验都显示「最大分子饱和 + 副本复制」
   （§4.2、§4.3），旧「无限族」已被直接投料否定（§4.5）。
3. **条件性证明成立**：猜想 A（每个 S 存在组件上界）⟹ 每个 S 的物质集有限（定理 1）。
   因此若要在项目文档中写「每类有限」，最严谨的表述是：
   > 「所有 511 类的物质集有限」目前是**强数值证据 + 条件性证明**；
   > 唯一未证的是组合引理（猜想 A/B），其余结构结论已严格证明。
4. **后续工作优先级**：先证 L1（6 级小组件）+ L2（纯大类子反应上界），再攻 L3（层级递推）；
   同时可对每个 S 用「抽象状态枚举」做计算机辅助证明：把组件状态压缩为
   (类型多重集, 剩余容量, 组件大小) 并按级别穷举转移，若能封闭则得到 C_S 的严格上界。
