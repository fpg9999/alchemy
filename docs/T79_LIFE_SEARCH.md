# T79 · 自催化生长生命的搜索（主体 A + 辅件 B/C/D，吞小分子长成新 A）

> 生成：`t79_life_scan.py`；数据：`t79_life_scan.json`；目录：`G:\AI work\deepseek\work1\alchemy`
> 引擎口径：`natural_engine` 正式规则 1~11（`E.complete_products` / `E.resolve`），只读，不改内核。
> 触发：用户 m00871 的问题——"假设有这样一种生命，主体是物质 A，另有 B/C/D 等辅件；它抓取周围小分子，
> 经一次或几次反应产生新的 A 并加入自身。是否存在这样的生命？"

## 0. 摘要

- 用户描述的系统对应化学上的**自催化生长（autocatalytic growth）**：需要同时满足
  ①小营养物 → A 的合成、②A 并入自身（生长）、③模板/边界（繁殖与遗传）。
- 在本宇宙当前规则下检索（3,403 对营养物 + 16 条生长链 + 1,476 组"本体+营养" + 40 条随机链）：
  - **能合成新 A**：3,403 对中有 **174 对**出现"净增"——产物里出现 ≥2 份未投入的分子，例如
    `A2 + W2 → WA ×2`、`A3 + A3 → A2 ×3`、`A3 + W3 → WA ×3`、`A3 + X3 → XA ×3`；
  - **能生长**：16 个种子全部能靠逐次并入小分子长大；如 `O2 + WA` 逐级长到 `O2W6A6`（14 原子）后停，
    `O2X3 + O2CPA` 长到 40 原子后分裂成两个大分子；
  - **不能复制自己**：1,476 组"主体 A + 营养物"中，A 被保留（催化再生）**0 例**、产物含 2 份 A（净放大）**0 例**；
  - 生长链在 14~40 原子处自然饱和（取决于单体形状），随后分裂/惰性，不会无限长。
- 结论：本宇宙中**不存在**用户定义的"生命"（缺繁殖、遗传、边界、稳态代谢），但存在它的化学前身——
  **一个会吃小分子长大的自催化化学体**（实例见 §4）；它更像"晶体/聚合物生长"，不是生命。
- 真实化学中这类系统**存在**（formose 反应、Kauffman 自催化集合、自复制 RNA/肽、自复制囊泡、晶体生长），
  但没有已知自然生命以"简单物质 A 为主体、吞小分子长大"的方式存活——已知生命全部使用聚合物模板（DNA/RNA/蛋白）。

## 1. 问题拆解与判据

把用户描述形式化，一个这样的"生命"需要三层能力同时成立：

| 能力 | 含义 | 判据（本宇宙可检验） |
|---|---|---|
| 代谢 | 把周围小分子转成自身材料 A | 存在营养物对 `X + Y → 2A`（或 A 的部件） |
| 生长 | 新 A 并入自身，身体变大 | 存在单产物链 `A_n + M → A_{n+1}` 可连续多步 |
| 繁殖/遗传 | 产生新的、可继续生长的个体 | 存在 `A + M → 2A`（自身复制），或模板复制；并有变异与选择 |

真正的"生命"还隐含**边界/个体性**与**非平衡稳态**；本宇宙的化学层是点分子 + 确定性完全反应，
边界与个体性由更高层（`alchemy/emergence.py` 的 L2/L4）负责，而 L4 的 B（边界）判据在标定中恒为 False
（见 `docs/ABILITY_EMERGENCE.md`、HANDOFF §14.4），因此"拟生命/有机生命"计数为 0。

## 2. 方法（三组搜索 + 天花板测定）

- 营养物池 S：目录中 natoms=2 或 3 的全部物质，共 **82 种**（`t4_catalog_index.json`）。
- 反应：`F(vec)` = `E.complete_products(vec)`（规则 1~11；结果只由总元素向量决定，T12A 向量决定律）。
- S1：82×83/2 = **3,403 对**营养物，分类单产物/多产物/惰性/失败，统计"净增"（某产物出现 ≥2 份且非投入物）
  与"催化"（投入物之一被保留而其它被转化）。
- S2：16 个种子（T78 终态主要产物 + 常见双原子 + 几个大分子），贪心：每次并入一个营养物，
  若 `F(总向量)` 仍是单个产物且原子数增加就继续；总原子数上限 22（约为已知饱和区的 1.3~1.6 倍）。
- S3：18 个"主体候选 A"（含 T78 终态大分子）× 82 营养物 = **1,476 组**，检查产物中 A 是否保留/翻倍。
- S4：40 条随机生长链（随机选营养物），测自然步数与终态尺寸。
- 天花板补充：对 `O2`、`O2X3`、`WA` 等用 36 原子上限做贪心增长，逼近自然停止点。
- 低温对照：`E.resolve([A, 营养], T=0/2)`——低温走不完全反应（断键重连）路径，检查是否出现催化再生。

## 3. 结果

### 3.1 S1 营养物对（3,403 对，当前规则 1~11）

| 类别 | 对数 | 占比 |
|---|---:|---:|
| 成功（F 可判定） | 3,214 | 94.5% |
| 失败（价数/几何不相容） | 189 | 5.5% |
| 其中单产物 | 1,387 | 43.2% |
| 其中多产物 | 1,827 | **56.8%** |
| 惰性（产物=投入物多重集） | 549 | 17.1% |
| **净增对**（产物含 ≥2 份非投入分子） | **174** | 5.4% |
| **催化对**（投入物 A 被保留） | **0** | 0% |
| 最大产物 | 6 原子（`C2WA3`） | — |

净增实例（说明"新 A 可以凭空多出来"）：

| 营养物对 | 产物 | 净增的 A |
|---|---|---|
| `A2 + W2` | `WA ×2` | WA |
| `A3 + W3` | `WA ×3` | WA |
| `A3 + X3` | `XA ×3` | XA |
| `A3 + A3` | `A2 ×3` | A2 |
| `A2 + X2` | `XA ×2` | XA |
| `A3 + W2A` | `WA2 ×2` | WA2 |

**催化对 0 例**与 T12A 旧引擎结论一致（产物含投入物之一的非惰性反应 0 例）；原因同样是"向量决定 + 完全反应
把投入物全部拆开重连"——A 的原子若仍单独成 A，就不可能曾与营养物成键。

### 3.2 S2 生长链（贪心，总原子数上限 22）

16 个种子全部能长；两类行为：

| 种子 | 终态（22 原子上限或自然停止） | 步数 | 原子 |
|---|---|---|---:|
| CF / LF / L2 / C2 / CL | 如 `OX3C2PK3A4F` | 5 | 15（自然停） |
| WA / OK / PK / OP / XA | 如 `O2X3CW4K5A5F2` | 7 | 22（触上限） |
| OXC | `OX4C2P3A7F4` | 6 | 21 |
| OXCPWK / OXCPWKA / O2XCP3WK2 / O3X2P3WK2A / X3C3P3W3K2 | 各种 21~22 原子大分子 | 3~5 | 21~22 |

随机链 S4（40 条，上限 22）：36 条撞上限（21~22 原子），4 条在 16~20 原子自然停；步数 5~8。
→ **生长是普遍的、可多步的**；没有"14 原子硬上限"（旧 T12A 的 14~17 是旧规则 + 特定单体下的经验值）。

### 3.3 天花板：生长到哪里停？

| 体系 | 生长链 | 停止点 |
|---|---|---|
| `O2 + WA` | O2 → O2WA → O2W2A2 → … → O2W6A6 | **14 原子**（6 个 WA）；再加 WA 不反应（产物 `O2W6A6 + WA`） |
| `O2X3 + O2CPA` | O2X3 → O4X3CPA → … → O16X3C7P7A7 | **40 原子**（8 个单体）；再加 1 个 → 分裂为 `O11XC8P5A4 + O7X2P3A4`（45 原子） |
| `O2X3` + 全池贪心（36 上限） | O2X3 → … → O6X6CW4K2A5F5 | **29 原子**后无单产物生长 |
| `CL` 随机链 | CL → … | 16 原子停（部分） |

规律：**能否继续长取决于单体与身体的"形状匹配"**（几何/价数能否在六边形格上接上），
而不是固定的尺寸上限；一旦接不上，F 输出多个产物（分裂/释放），生长中断。

### 3.4 S3 自再生 / 自放大（1,476 组）

| 结果 | 组数 |
|---|---:|
| 本体 A 被保留（催化再生） | **0** |
| 本体 A 净放大（产物 ≥2 份 A） | **0** |
| 惰性 | 360 |
| 失败（F 不可判定） | 61 |
| 其它（合并/分解成别的大分子） | 1,055 |

**没有一例"主体 A 吃掉小分子后仍是 A（或多出一份 A）"**。低温对照（T=0/2，不完全反应路径）同样：
1,476 组中催化再生 0 例；T=2 下有 9 组"单产物生长"（如 `WA + XW → XW2A`），26 组分解，1,299 组惰性。

自我复制的理论分析（向量决定律的直接推论）：
- `A + M → 2A` 要求 `v_M = v_A`（M 是 A 的同分异构体），产物是 A 的稳定形态；
- 即"任何两个同分异构体相混 → 2 份稳定形态"，这是**形式复制**（公式层面惰性），不是"从营养物造出新 A"；
- 真正净增只能来自"更大的分子裂成 2 份 A"（§3.1 的 174 例），这是**分解代谢**，不是繁殖生长。

### 3.5 与 T78 环境实验对照

T78（240 min、3,922 分子）终态 78% 是双原子小分子，大分子最多 ~20 原子且 `capped`（cap=20 原子）
截断了更大的反应；反应集中在顶部高温高 ρ 区，且 complete/min 迅速衰减到 13~28 次/分钟（自熄）。
即：**在高温开放环境里，碎片化（分解）压倒了生长**；生长链只在"种子 + 合适单体"的受控条件下出现。

## 4. 找到的最接近实体：一个"会吃东西长大的自催化化学体"

把 §3.1 与 §3.3 拼起来，得到本项目宇宙里最接近用户描述的实体（称为 **端帽聚合物体**）：

```
营养物:  A2 + W2  ──F──►  WA × 2        （S1 净增；小分子→单体）
单体:    WA
身体:    O2(WA)_n     n = 0…6
生长:    O2(WA)_n + WA ──F──► O2(WA)_{n+1}   （单产物，逐级并入）
极限:    n = 6（14 原子）；再吃 WA 不反应
```

- 它满足"主体 + 吞小分子 + 产生新 A（单体 WA）+ 并入自身"的**全部前半段**；
- 它不满足生命：没有稳态（长大即止）、没有边界（单分子）、没有模板/遗传（每次生长只是加帽聚合）、
  不能繁殖（分裂是无遗传的随机片段，如 `O2X3 + O2CPA` 体系在 45 原子分成两个不同大分子）。
- 换句话说：**这是"化学晶体"而非"化学生命"**；与真实世界的晶体生长、自催化集合（Kauffman）同层。

## 5. 真实世界对照（这个"是否可能"在化学上怎么回答）

用户描述的模式在真实化学中的对应物是存在的，但都不是自然生命：

1. **自催化反应**：formose 反应（甲醛自催化生成糖类）、Butlerov 反应、BZ 振荡反应——小分子互相催化，
   但没有"个体"和遗传。
2. **自催化集合（Kauffman）**：一组分子互相催化对方的合成，整体能自我维持；理论上可"繁殖"需模板。
3. **模板复制**：自复制 RNA（von Kiedrowski 1986）、自复制肽、DNA 复制——有遗传，但复制的是模板，
   不是"吞小分子长成 A 并加入自身"。
4. **自复制囊泡/胶束**：脂质囊泡可生长、分裂（"division"），但内部化学简单、无遗传。
5. **晶体/聚合物生长**：与 §4 的端帽聚合物体最接近——有序并入单体、尺寸有限、停止于表面能饱和。

已知自然生命（细菌到人类）全部是**聚合物 + 模板 + 膜**的组合；"单一小分子 A 为主体、靠吞小分子复制"
的体系在自然界不存在（会被热力学与稀释打散），只在实验室受控条件下作为"自催化/自复制模型"存在。

## 6. 若要让这种生命在本宇宙"真的出现"，还缺什么

按 §1 判据，当前宇宙缺 5 个机制（可作为后续实验方向）：

1. **模板/遗传**：需要一个结构能"复制自身"而不仅是"并入单体"；当前规则下形式复制（同分异构体→2 份稳定形态）
   不产生变异与选择。
2. **边界/个体性**：`emergence.py` 的 B 判据恒 False；没有膜/边界，就没有"自身 vs 环境"。
3. **非平衡稳态**：现在反应是确定性 F，会单调走向惰性混合；需要能量流/恒素场（T78 的 ρ 门控只是局部化）
   维持"生长 vs 分解"的动态平衡。
4. **误差与选择**：需要复制误差 + 有限资源竞争，才有进化；当前完全反应是确定性、无噪声（只有几何约束）。
5. **大分子稳定化**：生长到 14~40 原子后必然分裂；需要"稳定大分子的规则"（如骨架加固/融合，T62 的退火
   只能收敛到小分子不动点）。
