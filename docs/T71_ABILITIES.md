## 1. 两层能力模型

**材料层**（元素给）：每个元素带 4 项能力，强度随该元素在骨架内的数量升级为 Ⅰ/Ⅱ/Ⅲ。

| 元素 | 能力（Ⅱ 级底子） | 元素 | 能力（Ⅱ 级底子） |
| --- | --- | --- | --- |
| 秩 O | 结构支撑 / 自修复 | 电 L | 导电 / 信号 |
| 晶 X | 刚性 / 耐热 | 沌 K | 分化 / 再生 |
| 冰 C | 抓取 / 粘合 | 气 A | 浮力 / 吸附 |
| 势 P | 储能 / 弹性 | 焰 F | 切割 / 发光 |
| 流 W | 移动 / 泵送 | （另有 Ⅰ 级：感知、绝缘、致密、柔韧、催化、变异、挥发、防御、耐寒） | |

**器官层**（骨架给）：骨架块按"接了几个邻居骨架、长了几根触肢"选一种**分化形态**：

| 形态 | 触发条件 | 含义 |
| --- | --- | --- |
| 抱握型 clasper | 接 ≥3 个骨架 | 分瓣包住邻居，把多个器官固定成一个整体 |
| 桥接型 bridge | 接 2 个骨架 | 两端长出接口，身体沿桥轴拉长 |
| 触手型 tentacle | 接 1 个骨架但 ≥2 触肢 | 伸出多条触须，用于探索/攻击 |
| 端接型 cap | 接 1 个骨架 | 一端长出接口与短触肢 |
| 感知型 sensory | 不接骨架、长触肢/端帽 | 专职感知与吸附 |
| 基础型 basic | 孤立或单接口 | 保持紧凑的基础形态 |

38 个骨架块各自**可分化形态**由它的三价原子数决定（0 个→基础；1 个→端接/感知；2 个→桥接/端接/触手；
≥3 个→抱握/桥接/触手），见 `images/t71_skeletons38.png`。

## 2. 生命度：结构门控打分

只有**结构上真的长出了对应器官**的能力才计分（不按元素数量通胀）：

| 特征 | 触发 | 分 |
| --- | --- | --- |
| 分化 | ≥2 骨架，或单器官出现多种分化接口 | 1.6 + 0.25×形态多样性 |
| 移动 | 有支臂，或 W 桥 ≥2 | 1.4（支臂 ≥3 再 +0.3） |
| 感知 | 有电 L 端帽/桥；或冰 C 端帽 ≥3 | 1.0 / 0.6 |
| 储能 | 势 P ≥4（≥8 再 +0.3） | 0.9 |
| 抓取 | 冰 C 端帽 ≥2 或一价端帽 ≥3 | 0.9 |
| 吸附 | 气 A ≥3 或气端帽 ≥2 | 0.7 |
| 自修复 | 秩 O ≥5 | 0.9 |
| 共生 | 有融合，或 ≥3 骨架且 ≥2 桥 | 1.2 |
| 泵送 | 流 W ≥3 且桥 ≥2 | 0.8 |
| 防御 | 焰 F ≥2 | 0.6 |
| 导电 | 电 L ≥1 | 0.4 |

分级：**有机生命 ≥8.0｜拟生命 5.0~8.0｜活性无机物 3.0~5.0｜无机晶体 <3.0**。

36 个稳定大分子的结果：**有机生命 14 / 拟生命 12 / 活性无机物 7 / 无机晶体 3**。
（生命分最高 G33 11.2、G14 10.8、G13 10.6；最低 G08 2.5、G06 2.8、G05 2.8。）

## 3. 固/液/气 与 刚/松/粘

- **固/液/气**：按晶 X / 流 W / 气 A 数量，最多者决定；并列时 **X > W > A**；三者相等取固（暂行实现，等正式规则）。
  全部只含三价元素时记作"晶态"。
- **刚性/松散/粘性**：暂行用键型占比推断（S 短键多→刚性、C 角键多→粘性、L 长键多→松散），
  **等同事正式规则上传后替换**。

## 4. 物种命名

`状态（固/流/浮）· 软硬 + 生命类 + 主体形状 + 「主要能力」`
例：`固态·粘性 生体·多器官六面簇体「分化·移动·储能」`、`固态·粘性 拟生·六面簇体「移动·感知·储能」`。

## 7. 局限（未决）

- 刚性/松散/粘性仍是键型占比的暂行规则，正式分类规则今晚同事上传后需要替换（`softness()` 单函数可换）。
- 生命度权重是手工标定的，换一批分子可能需要重新校准阈值。
- 2D 形体上还没有"器官位置会影响能力"的耦合（例如抱握型是否真的包住邻居），目前只看拓扑。
- 物种名是规则拼接，还没有做命名去重/美化。
