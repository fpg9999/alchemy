## 摘要

在 T94 默认试验场（T0=200 °C → T_end=0 °C、600 拍指数降温、p_react=1.0、G=0.2、
env_coupling=0.5、cap=36、heat(C,L,F)=(-1,+1,+2)）里，用 10 个对照臂检验「完美膜」的三项功能。
结论是：

1. **力场排斥（F4）在 D>0 环境里被验证**：PK（A=0, D=3, w_self=-0.5）膜臂的「膜-环境接触」
   在微重力下只有 1,638 次（同环境 G=0.2 重膜为 82,287 次），而无膜对照的环境-主体接触是 6,542 次；
   微重力（G=0）下 PK 膜把环境-主体接触压到 **0**、核心-环境反应压到 **0**，600 拍全程保持 92% 角覆盖。
2. **被主体吸引（F3）可测**：PK 膜有 12% 的膜分子贴附在主体 2 格内；WA2 膜达 16%。
3. **但默认重力是决定性障碍**：G=0.2 时重膜（PK，mass=1.5）整体下沉，角覆盖从 0.92 掉到 **0.00**；
   环境-主体接触反而升到 8,782（比无膜对照 6,542 更高，因为主体也被重力拖向下边界）。
   换质量=0 的 W 系轻膜（W2/WA2）可在 G=0.2 下维持环带（角覆盖 0.67/0.78），但**密封不足**：
   环境-主体接触仍有 3,638/5,698，核心-环境反应 1 次。
4. **自制造（身体生长）成立，自造膜不成立**：无膜对照靠内部食物 XA3 把主体原子 48→102（212%）；
   但自修复臂的膜「生成 20 个 vs 死亡 84 个」，膜 140→74、主体 24→13，修复反应仅 5 次，
   且只在 T_local≥40 °C 的降温前段有效。
5. **化学兼容性是隐性硬约束**：O2 主体与 P 系膜/食物接触会被消耗
   （`O2+PK→OK+OP`、`O2+O2+PK→O4PK`）；OK 主体与 PK 膜化学惰性（`OK+PK→OK+PK`），
   主体原子归因损失为 0，但重膜仍然因重力失效。

一句话：**「完美膜」在现有规则下是「微重力 + 无质量膜 + 化学惰性主体」三者同时满足时的极限态；
默认重力场里它不能以重膜形式存在。**

## 1. 判据与设计

### 1.1 「完美膜」的三条判据

| 功能 | 物理要求 | 本报告的量化指标 |
|---|---|---|
| F1 物理隔离 | 环境分子到不了主体 | `contacts_env_body`（环境-主体相邻对数，累计）、`core_env_react`（核心-环境反应次数） |
| F2 力场排斥 | 膜对 D>0 分子有真实斥力 | `contacts_env_mem`（环境-膜相邻对数）、`mem_env_react`（膜-环境反应次数） |
| F3 主体吸引 | d=1 净吸引 K_A·A_body > K_R·D_mem | `membrane_attached`（距主体 ≤2 格膜分子比例） |
| F4 铺展/存活 | 角覆盖高、留存率高 | `coverage_ang`（36 扇区覆盖率）、`membrane_retention` |
| F5 自修复 | 消耗后能补足 | `birth_mem` / `death_mem` / `repair_react` |

### 1.2 候选筛选（静态部分，沿用 T93 与 Lead 的目录扫描）

- **膜**：要求 A=0、D≥1.34、w_self≤−0.2、n≤7。完整候选 294 个；本次用
  **PK**（n=2，D=3.0，w_self=−0.5，mass=1.5，r_rep=1，r_att=1）与
  **WA2**（n=3，D=2.0，mass=0，w_self=−0.33）、**W2**（n=2，D=2.0，mass=0，w_self=−0.33）。
- **主体**：要求 A≥2、D=0。本次用 **O2**（A=3.0，mass=3.0）与 **OK**（A=3.0，mass=2.5）作对照。
- d=1 净吸引核验：K_A·A_body = 2.5×3.0 = 7.5 ≫ K_R·D_mem = 0.5×3.0 = 1.5，膜会被主体拉住。
- **内部食物**：XA3（3 个 A；`XA3+XA3 → A2+XA2+XA2`，产物全为 A≥2,D=0，可并入主体）。
- **自修复食物**：P2K4（`O2+P2K4 → 2 OK + 2 PK`，T_local≥40 °C 才发生）。

### 1.3 与 T87 / T92 / T93 的差异

| 环境分子 | 固定投料 | IPF 配平子集 | 固定攻击浴 | **按三种元素丰度从目录 IPF 采样** |
| 重力 | G=0.30 | — | 0.02/0.30 对照 | **G=0.2（默认）vs G=0 对照** |
| 结构 | 单相 | 单相 | 核+冷壳+攻击浴 | **主体 + 膜环 + 内部食物 + 环境池** |

## 2. 模型与实现（`t94_life.py`，约 1,079 行）

### 2.1 世界与三段结构

- 世界 **160×110**，环面；核心中心 `CORE_CENTER=(55,80)`。
- **主体**：24 个 O2（或 OK），放在半径 ≤3.5 的紧凑团簇，**冻结不动**（`step` 中直接跳过 body_set），
  初始 body 原子数 48。
- **膜环**：R=7.0~12.0 环带，220 个（OXC 臂 300 个，自修复臂 140 个）。
- **内部食物**：R=3.6~6.4 环带，XA3 30 个（自修复臂：P2K4 45 个）。
- **环境池**：R>13.5 区域，300 个分子，从 84,225 条目录按「元素 ⊆ support、原子数 2~8」采样并
  用 IPF 配平到指定丰度（iters=220、damp=0.5）；每种环境用独立随机流。

### 2.2 局部温度（ChemLab 口径）

```
T_local(组) = ( Σ_{组质心 2 格内分子} heat + ec·T_env ) / ( n + ec )
heat(F)     = −1·n_C + 1·n_L + 2·n_F          # heat_w = {C:-1, L:+1, F:+2}
ec          = 0.5
T_env(t)    = T_end + (T0−T_end)·exp(−6t/cool_ticks)   (t < cool_ticks)
            = T_end                                    (t ≥ cool_ticks, plateau)
T0=200, T_end=0, cool_ticks=600
```

resolve 的 `Tamb` 参数使用 **T_local**（不再使用 schedule_T 的全局值）；`p_react=1.0` 表示每个相邻
2~4 分子组都尝试一次 resolve，条件满足（T_local ≥ 产物 c 和）即反应，不抽样、无 ρ_E gate。
resolve 结果按 `(排序后的分子式, round(T_local))` 缓存。

### 2.3 环境丰度（三种）

| 标签 | 含义 | 目标元素权重 |
|---|---|---|
| dyn | 富动素 P/W/L | P .20, W .20, L .12, O .14, X .08, C .06, K .06, A .06, F .08 |
| fo | 富 F/O 反应性 | O .28, F .28, C .12, X .10, L .06, K .06, A .04, P .03, W .03 |
| bal | 九元素均衡 | 每元素 1/9 |

dyn 环境实际采出（300 分子、300 物种、平均 6.46 原子/分子）的元素份额：
**O 9.5%、X 3.5%、C 2.9%、P 22.6%、W 33.2%、L 18.3%、K 1.3%、A 1.7%、F 7.1%**
（P+W+L 合计 74.1%，即绝大多数环境分子 D>0，可被膜的 D 排斥推开；D=0 的 O/X/C 类靠占格阻挡）。

### 2.4 主体血统与并入规则（本报告的关键假设）

- `body_set` = 初始 24 个 O2/OK + 其后在主体区新生的「A≥2 且 D=0」分子；`body_set` 全部冻结。
- **并入半径 `R_BODY_JOIN = 6.0`**：新生主体物质距中心 ≤6 才并入。取 6 而不是 11，是为了让
  主体严格长在膜环内缘（7）以内，避免主体长穿膜带、把「物理隔离」指标污染成「主体-环境相邻」。
  这是建模假设，不是内核规则；若放开到 11，WA2 臂的环境-主体接触会从 5,698 升到 9,209（首跑实测）。
- 环境分子及其反应后代单独打血统（`env_lineage`），食物后代打 `food_lineage`；
  主体、膜、食物、环境四类角色互斥（优先级：body > env > membrane > food）。
- 膜-环境、膜-主体等反应会杀死旧分子并生成新分子，新分子按 (A,D) 与位置重新归类；
  「膜分子数」按血统计，因此包含反应再生的同式膜分子。

### 2.5 重力

`gacc += G·mass`，整数部分每拍最多下移 4 格；被单格分子占据时按质量比 0.75 概率交换。
主臂 G=0.2（`t94_config.DEFAULT_PARAMS["gravity_G"]`），对照臂 G=0。

## 6. 分项结果与解释

### 6.1 「完美膜」在微重力下成立：接触为零

- **PK dyn (G=0)**：600 拍内 `contacts_env_body = 0`、`core_env_react = 0`，覆盖率稳定 0.92，
  膜留存 89%，12% 膜分子贴附主体 2 格内。无膜对照同期环境-主体接触 6,542、核心-环境反应 1。
- 机制：PK 的 A=0（不吸引环境）、D=3（对 D>0 分子产生真实斥力，`contacts_env_mem` 仅 1,638），
  同时被主体的 A=3 吸引（d=1 净力 7.5 vs 1.5），所以形成贴附的斥力层。
- 注意「接触为零」只在 dyn 环境（74% 分子 D>0）下成立；D=0 的 O/X/C 分子仍只能被占格阻挡，
  并非被力场推开——这与 T93 的 F4 结论一致。

### 6.2 默认重力下重膜失效（且比无膜更糟）

- G=0.2 时 PK 膜整体沉到底部（角覆盖 0.00，膜仍存活 182 个但不再包住主体）。
- 环境-主体接触从无膜的 6,542 **升到 8,782**：膜沉底后主体暴露，且主体/环境一起被重力拖向
  下边界，接触反而更频繁；核心-环境反应 2 次（无膜 1 次）。
- 对照臂 `membrane_PK_dyn` 与 `membrane_PK_dyn_G0` 只差重力一个变量，结果从「完全隔离」变成
  「完全失效」——**重力是完美膜的第一杀手**。这与 historian 对 T93 G=0.30「危险区」的提示一致；
  即使 PK 质量只有 1.5（OXC 为 3.0），600 拍仍足以沉底。

### 6.3 轻膜能在重力下维持形状，但密封不足

- W2（mass=0，D=2，w_self=-0.33）与 WA2（mass=0，D=2）：角覆盖 0.78，膜留存 85%/58%，
  没有整体沉降；但 `contacts_env_body` 仍为 3,638 / 5,698，核心-环境反应 1 次。
- 原因：W 系膜 D=2 的斥力半径 r_rep=1，斥力只作用于相邻格；膜分子间 w_self<0 互相排斥，
  无法形成连续锁网（角覆盖 78% 意味着约 8 个扇区有缺口），环境分子从缺口渗入；
  轻膜还会被环境反应消耗（W2 dyn：birth 94 / death 111，膜-环境反应 22 次）。
- WA2 + OK 主体组合（`body_atoms` 48→94）的「低核心-环境反应（1）」有一部分是化学原因：
  OK 主体与 W 系环境的反应本就低（`body_killed=2`），不能全部归功于膜。

### 6.4 化学兼容性：O2 主体会被 P 系膜/食物消耗

- `O2+PK → OK+OP`（OP 为 D=3，非主体物质，主体原子被锁进高 D 分子）；
  `O2+O2+PK → O4PK`（含 P，D=1，非主体）；`O2+P2K4 → 2OK+2PK` 也会消耗 O2。
- 结果：PK dyn 臂主体原子 48→88（对照 102），PK FO 臂 48→79（对照 102）；
  按反应组归因的主体原子损失（非净损失）PK FO 臂中「环境来源」达 28。
- **OK 主体与 PK 膜惰性**（`OK+PK→OK+PK`，无净反应），PK+OK 臂的主体原子归因膜损失 = 0，
  但重膜仍因重力失效（角覆盖 0.06，核心-环境反应 5）——化学兼容不能替代物理维持。

### 6.5 自制造：身体能长，膜不能自造

- 无膜对照靠内部食物 XA3 自缩合（`XA3+XA3 → A2+XA2+XA2`，产物全为 A≥2,D=0）把主体从
  24 个分子 / 48 原子长到 **40 个 / 102 原子（212%）**，`body_atoms_gained=52`。
- 自修复臂（初始膜只有 140、食物 P2K4 45）在降温前段确有 `O2+P2K4→2OK+2PK`：
  累计 `birth_mem=20`、`repair_react=5`；但 `death_mem=84`，膜 140→74，主体 24→13 / 原子 48→32，
  食物 P2K4 45→7。**净结果是膜和主体一起缩水**——自修复只能延缓，不能维持。
- 修复反应需 T_local≥40 °C；T_local 在 ~160 拍后低于 40，生成通道自动关闭，
  而消耗（膜-环境反应 30 次、内部反应 67 次）持续。这是「先修复后饿死」的时间窗问题。

### 6.6 旧 OXC 冷壳对照：复现 T93 结论

- OXC 壳（A=2, D=0, mass=3）在 G=0.2 下沉底（角覆盖 0.31），`core_env_react=2`，
  但主体原子 48→**121**（比对照 102 更大）：OXC 提供 O/X/C，被主体吸收（T93 中「壳养大主体」现象）。
  主体被环境化学消耗 27 次（`body_killed`），壳自身被消耗 74 次。
- 结论：A=2 的冷壳既不能形成真正的斥力膜（D=0，对 D=0/D>0 都无斥力），又会给主体供料，
  不能当完美膜用。

---

## 7. 逐条结论

1. **在微重力 + dyn 环境下，「完美膜」的三项功能全部成立**：PK 膜 92% 角覆盖、0 环境-主体接触、
   0 核心-环境反应、12% 贴附、89% 留存（600 拍）。
2. **默认重力 G=0.2 下，重膜不成立**：PK 角覆盖 0.00，环境-主体接触 8,782（比无膜更差）；
   低质量 W 系膜能维持 0.67~0.78 角覆盖，但仍有 3,638~5,698 次环境接触，密封不足。
3. **「完美膜」需要同时满足**：膜 mass≈0、D≥2、A=0（斥力 + 自铺展/不粘环境），
   主体化学惰性（OK 优于 O2），环境以 D>0 分子为主（dyn），以及**低重力**。
4. **自制造只完成了「身体」，没有完成「膜」**：身体 48→102 原子（212%），
   膜出生 20 < 死亡 84，自修复臂整体负增长。
5. **T93 的负面结论在新参数下复现并加重**：壳被消耗、壳会养大主体、重壳会沉降；
   p_react=1.0 下「接触即反应」让膜的化学寿命成为主要瓶颈。
6. **工程含义**：若要在默认试验场里得到稳定完美膜，需要至少改一条规则——
   给膜分子质量=0（或引入浮力/支撑面）、让 D=0 环境分子也受斥力、或让自修复反应的温度窗延长到
   平台期。当前规则下，「完美膜」是微重力极限态，不是常温常重力下的稳态。

## 8. 局限

1. **并入半径 `R_BODY_JOIN=6.0` 是人为假设**：为了让主体不穿膜带，属于本报告为隔离变量所做的
   设定；原始规则没有「主体并入半径」。首跑（11）时 WA2 臂主体接触被污染（9,209 vs 5,698）。
2. **主体冻结**：24 个主体分子不随力/重力移动（T93 同款假设），真实「生命体」应可形变/移动；
   主体的重力下沉被抑制，所以 G=0.2 的接触里主体漂移被低估（body_r：无膜 6.4、G=0 的 PK 6.0、G=0.2 的 PK 10.2）。
3. **p_react=1.0 的语义**：条件满足即反应，等于把化学动力学压缩成「接触即反应」；
   原始计数不能与 T87/T93 的百分比直接比较，只能臂间比较。
4. **local_T 是局部平均**：2 格内全部分子参与热量平均，没有热容/传导时间，同一组产物可能因
   微量邻居差异跨过 c 和阈值；resolve 缓存用 round(T_local) 量化，边界情形有 1 °C 误差。
5. **环境采样**：单 seed、单次 300 分子采样；IPF 目标丰度与实际份额有偏差（dyn：P+W+L 实际
   74.1% vs 目标 52%），因为目录里富 P/W/L 的分子种类多；不同 seed 的绝对值会变化。
6. **单 seed、10 臂**：没有重复实验，臂间差异未做统计检验；重力、膜种类、环境、主体化学
   四个因素只做了成对对照，没有全因子设计。
7. **二维、点/格点分子**：没有表面张力、没有真实热传导、重力无终端速度（gacc 线性累积），
   轻膜「不下沉」是 mass=0 的直接后果，而非真实浮力。
8. **「完美膜」的 F2 只在 D>0 环境成立**：D=0 分子（O/X/C 类）仍靠占格阻挡；
   若环境是 fo（O/F 富集，D=0 多），膜的力场排斥无法生效。
