# 能力候选总目录（供挑选，有机 + 无机，v1）

> 目的：按用户要求「列举更多贴合现实的能力，越多越好，包括有机和无机，我来进行挑选」。
> 本文件只做**能力候选清单**，不改代码、不跑脚本。挑选后我再把选中的能力做进 9 操作/涌现体系。
> 相关：`docs/ABILITY_EMERGENCE.md`（现行 9 操作）、`intake/ability_spec.md`（阈值/矩阵）、`docs/THERMAL_DIMENSION.md`（温度/黏合）。

---

## 0. 怎么读这张表（挑选方法）

每条能力给出 8 列：

| 列 | 含义 |
|---|---|
| ID | 挑选时直接报编号即可 |
| 能力 | 中文名（括号英文） |
| 现实原型 | 现实中最接近的材料/生物现象 |
| 机制 | 一句话物理/化学机制 |
| 本体系载体 | 由哪些元素/操作/派生量算出（★=可算性，见下） |
| 有机例 | 有机世界的对应物 |
| 无机例 | 无机世界的对应物 |
| 器官潜位 | 可自然发展成哪类器官（支撑/边界/能量/运输/传感/信息/防御/催化/复制） |

**可算性（★）**：★★★ = 只用元素计数/比例即可；★★ = 需要结构位形（原子连接/骨架）；★ = 需要环境/动态状态（温度场、pH、光照）。

**挑选建议**：优先选 ★★★ 且能两两组合成器官的；★ 类能力留作“后期环境交互”。若某项能力本体系没有对应轴（如磁性、光学），我会先补一条“派生轴”（仍由元素比例算出，不加新元素）。
