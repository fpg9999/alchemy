## 1. 世界观与元素表

- 世界由十种基础元素组成；前 9 种公开，第 10 种「恒素」符号 **E**，目前唯一作用是**能量触媒**
  （自然反应的催化剂，消耗品，消耗量按具体情况、暂忽略）。恒素不进入产物分子、不参与成键。
- 元素分三大类，每类三种角色，**角色决定价数**（一价=1 根键、二价=2、三价=3）：

| 大类 | 三价（概念） | 二价（物质） | 一价（能量） |
|---|---|---|---|
| 聚素 | 秩 **O** | 晶 **X** | 冰 **C** |
| 动素 | 势 **P** | 流 **W** | 电 **L** |
| 散素 | 沌 **K** | 气 **A** | 焰 **F** |

（符号即分子式书写符号：O/X/C、P/W/L、K/A/F。）

## 2. 网格、坐标与方向

### 2.1 网格
正六边形密铺，一个元素占一格。格与格之间有且只有三种"位置关系"（即三种键型，见第 3 节）。

### 2.2 用户坐标（写分子式用）
- 以分子里**最左下角**的元素为 (0,0)。
- 向**正右**移一格：X+2；向**正上**移一格：Y+2；向**斜右上**移一格：X+1, Y+1。
- 合法格子满足 **X 与 Y 同奇偶**（即 X−Y 为偶数）。
- 与六边形 axial 坐标 (q,r) 的换算：`X = q`，`Y = 2r + q`；反之 `q = X`，`r = (Y−X)/2`。

### 2.3 方向编号（写键用）
- 以元素**正上方**为 1 号方向，顺时针每 30° 加 1，共 12 个方向。
- **短键 S、长键 L 用奇数方向** 1/3/5/7/9/11；**角键 C 用偶数方向** 2/4/6/8/10/12。
- 反方向 = k±6（1↔7、2↔8、3↔9、4↔10、5↔11、6↔12）。

### 2.4 方向 → (ΔX, ΔY) 完整表

| 方向 | 类型 | (ΔX,ΔY) | 方向 | 类型 | (ΔX,ΔY) |
|---|---|---|---|---|---|
| 1 | S / L | (0, +2) | 2 | C | (+1, +3) |
| 3 | S / L | (+1, +1) | 4 | C | (+2, 0) |
| 5 | S / L | (+1, −1) | 6 | C | (+1, −3) |
| 7 | S / L | (0, −2) | 8 | C | (−1, −3) |
| 9 | S / L | (−1, −1) | 10 | C | (−2, 0) |
| 11 | S / L | (−1, +1) | 12 | C | (−1, +3) |

- **长键 L 的偏移 = 短键 S 的 2 倍**（例如 L1=(0,+4)、L3=(+2,+2)、L5=(+2,−2)、L7=(0,−4)、
  L9=(−2,−2)、L11=(−2,+2)），且 L 键**中间那一格必须为空**（不能有任何元素）。
- 同一对元素之间可连 **1~3 根键**（平行多重键，最多 3）。

## 3. 键型与跨大类规则

每根键的键型（S/C/L）由两端大类决定，**取两端支持键型的并集**：

| 两端大类 | 允许的键 | 几何关系 |
|---|---|---|
| 聚-聚 | **S** | 两格共边（相邻） |
| 动-动 | **C** | 角对角，两角之间正好隔一条格边（= 距离 2 的斜向格） |
| 散-散 | **L** | 同轴距离 2，中间格必须为空 |
| 聚-动 | **S 或 C** | 既可用共边、也可用角对角 |
| 动-散 | **C 或 L** | |
| 聚-散 | **S 或 L** | |

补充：**相邻但没写键 ≠ 成键**（允许两个相邻元素之间没有键）。

等价的说法（实现时用这个）：
- 令 `cats = {两端所属大类}`。`S 合法 ⇔ 聚 ∈ cats`；`C 合法 ⇔ 动 ∈ cats`；`L 合法 ⇔ 散 ∈ cats`。

## 4. 分子成立条件

1. 每个元素的键数 **恰好等于** 价数（不能多、不能少）。
2. 分子连通（所有元素连成一体）。
3. **几何可实现**：能把这堆元素摆到六边形棋盘上，使每一根键的几何关系恰好符合第 3 节允许的键型；
   同一对最多 3 根；L 键的中间格不能有元素。摆放方式不限（允许旋转/翻转/平移），只要存在一种摆法即可。
4. 同一分子式可能有不同结构（同分异构体）；本任务按"分子式"统计，若遇到同分异构会额外注明。

## 5. 自然反应（大锅）规则 1~9

背景：把若干物质 + 恒素投入大锅，所有分子先**全部拆成单个原子**，然后按下面的优先级自动逐根成键；
玩家不能干预。**反应结果只取决于投入的元素总个数**（与原来是什么分子无关）。
走到底后如果还有元素剩着没接满的键 → **整个反应失败**；
产物必须几何可实现（见第 4 节），否则也判失败。产物可以再次投料（反复反应）。

每次选择"接下来连哪一对原子、连一根键"时，按以下顺序逐条比较（相同才看下一条）：

1. **周期表距离最大**。
   - 周期表：以恒素 E 为原点，聚/动/散三条轴；元素在轴上的坐标 = 价数（1/2/3）。
   - 两元素距离：**同类（同一条轴）→ |坐标差|；异类（不同轴）→ 坐标相加**。
   - 例：秩(3)–流(2)=5；秩(3)–晶(2)=1；秩(3)–秩(3)=0；秩(3)–冰(1)=2。
2. **剩余可连键数之和最大**（两原子各自"价数−已用键数"相加，取最大的一对）。
3. **族组合优先级**：聚-散 > 聚-动 > 动-散。（**同大类不参与此条**，跳过看下一条。）
4. **跨分子连接最少**（同一分子内的原子优先），再按**分子内实际距离最小**
   （实际距离 = 分子内沿键的最短路径长度，即隔了几根键；不同分子之间距离视为无穷大）。
5. **最小分子 + 最大分子**（两原子所在分子的原子数；优先让"最小分子"与"最大分子"配对）。
6. **两分子元素种类并集数最多**（两个分子的元素种类取并集后去重计数，取最大）。
7. **两分子自身元素种类数之和最少**（各自分子内元素种类数，先取和，取最小；再按 (较小,较大) 字典序）。
8. **两分子总剩余键数之和最多**（分子内所有原子剩余可连键数之和，取最大）。
9. **规则 9（元素优先级决胜）**：若规则 1~8 仍完全相同，则看"结合之后的分子式"
   （两个分子的元素组成相加）里各元素的数量，按以下优先级比较：
   **秩(O) > 晶(X) > 凝/冰(C) > 沌(K) > 气(A) > 焰(F) > 势(P) > 流(W) > 电(L)**。
   先比秩元素数量（多者优先），相同则比晶元素数量，再比凝/冰，依次类推。
   （"凝"按本文件元素表理解为"冰(C)"。）

已核实的结果（可用于自检）：
- 2秩+2晶+2冰 → **2 × 秩晶冰（O-X 双键、O-C 单键）**（即 冰-秩=晶）
- 2秩+4晶 → **秩₂晶₄**（链：晶=秩–晶–晶–秩=晶）
- 4秩+3晶+2冰 → **秩₂晶₂ + 秩₂晶冰₂**（两个分子，不是秩₄晶₃冰₂）
- 3秩+3晶+5冰 → 秩₂晶₂冰₄ + 秩晶冰（规则 7 生效，没有秩₃晶₃冰₅）
- 3秩+5晶+5冰 → 秩₂晶₂冰₄ + 秩晶₃冰（规则 8 生效）
- 规则 9 自检：`O3+F+A2+W`（元素计数 O3 F A2 W）→ **O2WA + OAF**；
  `X1+W1+L1+K2+F1` → **WKF + XLK**。
- 聚素范围内投料在规则 1~8 下本就无并列（规则 9 不参与）。

## 6. 模拟器实现规格（照着写即可）

### 6.1 数据
- 原子：元素符号（决定价数、所属大类）。
- 键：多重图 `bond[i][j]`（0~3）。
- 每步维护：剩余键数 `rem[]`、连通分量（并查集或 BFS）、分量大小、分量元素种类集合、
  分量总剩余键数、分量内原子间最短键距离。

### 6.2 每步选键（严格按第 5 节）
对每个候选对 (i,j)（`rem[i]>0, rem[j]>0, bond[i][j]<3`）计算 key，取**字典序最小**：
```
key = ( -周期表距离, -(rem[i]+rem[j]), 族组合序号,
        cross, 分子内距离,
        min(size_i,size_j), -max(size_i,size_j),   # 规则5
        -并集种类数,                                # 规则6
        自身种类数和, min(自身种类), max(自身种类),  # 规则7
        -(总剩余键和), -min(总剩余键),               # 规则8
        *-结合后各元素数(秩,晶,冰,沌,气,焰,势,流,电) )  # 规则9
```
- `cross` = 0 同分子 / 1 跨分子；同分子时 `分子内距离` 为最短键数，跨分子时取 999。
- 族组合序号：聚-散=0，聚-动=1，动-散=2；同大类=固定常数（如 0，排前）。
- 规则 9 之后若仍有完全并列（同一元素对、且结合后元素计数完全相同），取候选顺序中的第一个（确定性）。
  实测 T=3..9 全部投料无残余歧义（`T12_RULE9E.md`）。
  旧数据/旧目录是"规则 1~8 + tied[0]"口径；改用规则 1~9 时必须用 `pot_v3.py` 重算，不能混用。

### 6.3 反应结束判定
- 若存在 `rem[i] > 0` → 反应失败（返回 None）。
- 否则拆出各连通分量的分子图，逐个做**几何可实现性判定**（见 6.4）；任一失败 → 整个反应失败。

### 6.4 几何可实现性（typed embedding，支持跨类）
输入：分子图（元素 + 边多重数）。要判断：是否存在 单元→格 的映射 + 每根边的键型指派，满足：
- 不同原子占不同格；
- 边 (a,b) 指派键型 t 必须满足 t ∈ 允许键型(cat(a), cat(b))，且两格位置关系符合 t：
  - S：相邻（中心偏移是 6 个近邻之一）；
  - C：角对角（中心偏移属于 6 个"角向"偏移 ±(1,1), ±(2,−1), ±(1,−2) 等，即距离 2 且非共线）；
  - L：同轴距离 2（偏移 = 2×近邻偏移），且**中间格没有被分子里任何原子占用**；
- 非边原子之间允许相邻（不要求 induced）。
实现：按 **BFS 顺序**放置（保证每个新原子已有已放置邻居；否则会误判链状分子），回溯枚举候选格；
对每条已放置邻居边，收集"当前格能满足的允许键型集合"，选择其一（L 的中间格检查在全部放完后统一校验）。
多重键不影响摆放（同一对相邻格可有 1~3 根，只按有无边判定）。
**注意（踩过的坑）**：旧版按度数排序放置，会把链状分子误判成摆不出来 —— 必须 BFS 顺序。

### 6.5 多重键 & 价数
- 顶点度数 = 该元素价数（多重键按根数计）。
- 同一对之间 1~3 根。

## 7. 三类键图同构（重要简化，先验证再用）

三种键各自构成的"格子图"都是同一个**三角格子**，只是密度不同：
- 短键 S：全部格子（聚素）；
- 角键 C：格子按 index-3 子格分成 3 份，每份内部同构（动素）；
- 长键 L：格子按 (q,r) 奇偶分成 4 份，每份内部同构（散素），且 L 的中间格自动落在另一奇偶类、天然为空。
因此**纯大类内部的物质表应当是同一套公式，只把元素符号替换**：
- 聚素：O(秩)/X(晶)/C(冰)（已完成 29 种，见第 8 节）
- 动素：P(势)/W(流)/L(电) —— 对应 29 种，键型 C，方向用偶数号
- 散素：K(沌)/A(气)/F(焰) —— 对应 29 种，键型 L，方向用奇数号

**但必须先验证再交付**：用模拟器分别跑动素/散素的关键投料，确认产物公式与聚素表一一对应
（例如 2P+2W+2L → 2×势流电；2秩+4晶 的动素版 2P+4W → 势₂流₄ 等）。

## 9. 实现口径与待确认假设

1. **反应阶段不分键型**：成键时只看大类与周期表距离；键型在"几何可实现性"阶段按第 3 节允许集合指派。
   （若用户后续规定"反应时就要指定键型"，需改模拟器。）
2. 恒素 E 不参与反应与成键，只当触媒；反应结果与恒素数量无关（消耗量忽略）。
3. 规则 3 的族组合只在**不同大类**之间比较；同大类跳过此条。
4. 规则 5~8 的"分子"指当前已形成的连通分量；"大小"=原子个数；"自身元素种类"=分量内去重元素数；
   "总剩余键数"=分量内所有原子剩余可连键数之和。
5. 反应结果只取决于元素总个数；产物可再投料，所以求"可产出物质"要用**可达闭包迭代**：
   生成元 = 基础单质 + 已发现物质的元素组成向量；对每个可达的元素计数向量跑反应；
   加入新发现的物质，重复到不再新增。
6. 判定"物质存在"= 某个可达投料向量的反应产物里出现该分子式（且该次反应整体成功、产物都可摆出）。
7. 跨类时同一对元素之间仍最多 3 根键；键型可以在允许集合里任选（摆放时定）。
8. **规则 9**：按元素优先级比较"结合后分子式"中各元素数量；优先级 秩>晶>冰>沌>气>焰>势>流>电
   （"凝"= 冰(C)）。

## 11. 已知坑（务必看）

1. **几何摆放必须 BFS 顺序**（保证每个新原子有已放置邻居）。曾按度数排序导致链状分子误判"摆不出来"，
