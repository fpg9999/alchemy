# T88 环境群系：不同元素子集在 T87 规则下的终态对比

## §0 摘要

- **群系**：用 3 / 3 / 4 / 5 / 6 / 9 种元素构造 6 个环境群系，规则全部沿用 T87：
  连续重力（`gacc += 0.30·mass`）、非对称分子间力（无匹配度）、骨架 k 格占位、
  `resolve` 完全/不完全反应、2~4 分子同组、cap 36、温度 1000°C→10°C 后恒温。
- **投料**：从 84,225 目录中取"元素集合 ⊆ 子集、2~8 原子"的分子式池，
  IPF 配平到子集元素等份额，每个群系 2,500 分子（世界 240×160 硬边界，800 拍，其中 400 拍降到 10°C）。
- **一句话结论**：元素越少，群系越"纯化 + 抱团"（物种收敛到 28 种、单团占 76~84%、
  最优物种 16~29%）；元素越多，群系越"碎片化 + 多主"（1,234 种、优势种仅 6.6%、单团 63%）。
  分层（质量→重力）在所有群系里都成立，但少元素群系更极端（轻档 y≈66~72，多元素 110）。

## §3 分析

1. **元素越少，越"纯化"**。B3 两个群系只有 28 种分子式可用，终态仍是 28 种，
   反应只在池内重组（新物质 0/3），产物收敛到 1~2 个优势物种（O2L2F2 21%、OXC 28.6%）。
   元素一多，池子变大，终态物种数 282→531→656→1,234，优势度从 21% 降到 6.6%——
   这正是 T67 群系分类里"单主/主辅"到"多主"的过渡。
2. **反应以不完全为主，且不完全占比随元素数减少而升高**：B3_OFL 82%、B3_OXC 80%、
   B4 73%、B5 68%、B6 63%、B9 61%（按 resolve 判定次数 C/(C+I) 计）。
   10°C 远低于多数分子对的 Σc，所以绝大多数判定落在 incomplete 分支；
   少元素群系的 Σc 分布与产物尺寸分布不同，导致不完全占比更高——具体归因需要逐案追踪，
   这里只记录现象。
3. **分层在所有群系都成立，但少元素群系更极端**：B3 轻档 y≈66~72，几乎全部浮在顶部。
   多元素时轻档 110——因为元素多了，很多"轻"分子仍含少量重元素，质量分布连续化，
   轻档也被拉着往下走。
4. **"抱团"随元素数减少而加剧**：最大团占比 B3_OXC 84% → B9 63%。
   少元素群系产物只有 28 种、彼此高度可粘（小分子双原子居多），于是几乎全部连成一个团；
   多元素群系里物种结构更杂、粘附选择性更强，团更碎。
5. **物种池是硬上限**：B3 池 28 种，终态就是 28 种（新物质 0）——群系的"基因库"
   决定了它最多能有多少种产物；目录外新物质只有在 B4 以后才出现（169 → 336 → 263 → 288）。
6. **质量分层与反应场所**：所有群系反应都集中在底部沉积层（s>100 行），
   顶部悬浮层反应稀少；与 T87 一致（连续重力把绝大多数分子压到底部）。

## §5 诚实局限

1. 每个群系单 seed（20261120），数量级结论稳定但具体数值会随 seed 浮动。
2. 投料池按"元素集合 ⊆ 子集、2~8 原子"从目录取，B3 只有 28 种，样本受限；
   不同子集的原子/分子比不同（B3 约 4.7~4.9，B9 约 6.7），分子数相同但原子总数不同，反应率不可直接横比。
3. 全部沿用 T87 的连续重力/非对称力参数（G=0.30、KA=2.5、KR=0.5），未针对子集调参。
4. 骨架占格、粘附锁、`resolve` 都是简化模型；"群系"只是同一套规则下的不同初始元素池。
5. 类型分类阈值（A≥30%、B≥15%、C 双主≥50%）是人为约定，用于横向对比，不是物理量。
