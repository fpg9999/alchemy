# T27 · 自然环境分解规则（按键稳定性：周期表距离 + 键级）

> 用户规则：键稳定性由"元素周期表距离"决定，距离越近越不稳定（距离 0 最不稳定）；
> 距离相同时，键级越高越不稳定（三键 > 二键 > 一键）。
> 一次自然反应：在体系中找出最不稳定的键类（距离最小、键级最高），
> 所有带该类键的分子把该类键全部断开（没有该键的分子不分解）；然后所有碎片按大锅规则重新结合。
> 脚本：`t27_break_rule.py`、`t27b_pairs.py`、`t27c_iter.py`；数据：`t27_break_rule.json`、`t27b_pairs.json`、`t27c_iter.json`。

## 1. 实现口径（本次分析采用）

- 不稳定排序键：`(元素距离 d, −键级 m)`，取最小者 = 最不稳定（d 小优先，同 d 时 m 大优先）；
- 全局选择：一次反应中在所有分子里找全局最不稳定的键类 (d, m)；
- 断裂：所有含该类的键全部断开（多键整组断：三键断 3 根、二键断 2 根）；
- 没有该类键的分子保持完整（不发生分解）；
- 重结合：保留未断的键，所有碎片按大锅规则（规则 1~9）贪心补满自由价；
- 不考虑几何摆放限制（抽象图层面）。

## 2. 单分子：全部变回自身（3,931/3,931）

对全部 ≤8 原子物质逐个测试：断开各自最不稳定的键后重新结合，**结果全部回到原物质**。

原因：大锅规则优先按"距离大"的键成键（跨类键先形成），同类/近距离的键最后才形成；
而"最不稳定的键"恰好是同类、高键级的键 → 它们在大锅重建中是最后补上的，
于是重建顺序自然又把它们补回原位。

**含义**：孤立的单个分子在自然环境中不会发生变化——这条规则对单分子是"空转"（no-op）。

单分子最不稳定键类分布（3,931 种）：

| 最不稳定类 | 物质数 |
|---|---:|
| d=0, m=1 | 2,004 |
| d=0, m=2 | 262 |
| d=0, m=3 | 3 |
| d=1, m=1 | 513 |
| d=1, m=2 | 102 |
| d=2, m=1 | 265 |
| d=3, m=1 | 453 |
| d=4, m=1 | 281 |
| d=4, m=2 | 3 |
| d=5, m=1 | 6 |
| d=5, m=2 | 36 |
| d=6, m=3 | 3 |

## 3. 多分子体系：会真的发生反应，并产生新物质

对 500 个随机小分子对（≤8 原子）测试：

| 结果 | 对数 |
|---|---:|
| 无变化（恢复成原两个分子） | 366（73.2%） |
| 有变化（生成不同分子） | **131（26.2%）** |
| 重结合失败（价数无法补满） | 3（0.6%） |
| 产物含大锅目录外的新分子式 | **101（20.2%）** |

变化例子（产物均为单个更大分子）：

- `OXW3AF + PL2K3F2 → OXPW3L2K3AF3`（13 原子单分子）
- `O3CW2 + OX2P2KA2 → O4X2CP2W2KA2`
- `X5KF + PWL2K3 → X4KF + XPWL2K3`（分成两个不同分子）
- `O2C2F2 + O2X2CLF2 → O2XCLF2 + O2XC2F2`

**关键**：只有当"两个分子都含有同一个最不稳定键类"时，双方才会同时断裂、碎片才能跨分子重连，
从而生成新分子；如果只有一方含有该类键，它断裂后只会重组回自己，体系无净变化。

## 4. 迭代行为：一到两轮后稳定

对 300 个随机分子对迭代施加规则（最多 5 轮）：

| 结果 | 对数 |
|---|---:|
| 无变化 | 236（78.7%） |
| 有变化 | 64（21.3%） |
| 其中 1 轮后稳定 | 61 |
| 多轮后稳定 | 3 |
| 5 轮仍在变化 | 0 |

变化后的产物：34 对最终变成单分子，30 对保持多分子但彼此不再反应。
（单分子是固定点：再施加规则会变回自身。）

## 5. 规则的性质与问题

### 5.1 有效的地方
- **确实产生了分子间反应**（约 21~26% 的分子对），而且产物会稳定下来；
- 没有出现持续振荡（本样本 0 例 5 轮仍在变）；
- 反应具有"全局同步"特征：谁有最不稳定键，谁先断；没有该键的分子当"旁观者"。

### 5.2 主要问题
1. **单分子完全惰性**：规则对孤立分子是空转——所以"自然环境的反应"必须依赖多个分子碰巧共享同一最不稳定键类；
2. **会产生新物质**：101/500 对出现目录外新分子式（约 20%），并不是"无新物质"规则；
3. **会合体变大**：断键后的碎片跨分子重连，常把两个分子合并成一个更大的新分子；
4. **重结合失败**：3/500 对出现价数无法补满的"死碎片"，规则需要补充失败处理；
5. **全局选择依赖整个体系**：一个分子的极不稳定键会"定义"当前断裂类，其它分子即使有别的可断键，只要不是该类就完全不动——这是强非局部耦合，模拟时要注意；
6. **违反直觉的稳定性次序**：同元素键最不稳定（d=0），所以规则优先拆掉 0 级融合键、同元素二聚键等，容易破坏骨架；
7. **未考虑几何**：真实摆放会进一步降低可反应比例。

## 6. 需要你确认/补充的细节

1. "最不稳定键类"是**全局**（所有分子一起排）还是**每个分子各自**？本文按全局；
2. 一次事件是断**一类**（如所有 d=0,m=1）还是断**一根**（每次只断最不稳定的单根键）？
3. 断键后，重组时**是否允许重新形成刚断掉的键类**？
   - 允许（本文做法）：单分子复原、体系稳定，但反应少；
   - 禁止（"淬灭"）：产物会不同，反应更多，也更容易产生新物质；
4. 断裂后的碎片是否允许**跨分子合并**？（本文允许）
5. 几何摆放是否作为合法性条件？
6. 重结合失败时：视为不反应（保留原物）、还是保留死碎片？

## 7. 结论

- 这套规则是**自洽的**：单分子不变、多分子可以反应、一到两轮后稳定；
- 但它**不是"无新物质"规则**（约 20% 分子对产生新分子式），也**不是"单分子可反应"规则**；
- 它的实际效果更像：**"同类/近距离的弱键先断，碎片再合并"**——会优先拆掉同元素键/高键级键，
  然后把碎片合成更大的分子；
- 若目标是"自然环境稳定且无新物质"，需要补充限制（例如禁止重组时恢复被断裂的键类、
  或只允许碎片与同类骨架重新组合、或加入几何约束），否则这条规则会持续产生新的更大分子。
