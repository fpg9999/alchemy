# T73 器官形态的几何判定 × 小分子物质形态

> 用户 (m01805)：先做第二件事（形态与器官在体表的位置/朝向耦合），并且**把分化后的物质样貌直接画出来**，
> 而不是只写在物种卡侧边；小分子也要按结构做进一步形态设计，看起来像真实的小物质。

## 1. 器官长在哪，就长成什么形态

以前"3 种可长成形态"是按元素组成 + 编号旋转挑的，和位置无关。T73 改为**几何判定**（`t73_organs.py`）：

每个骨架块先算 5 个几何特征（都在最终排版坐标上算）：

| 特征 | 含义 |
| --- | --- |
| `on_hull` | 块心是否位于全体块心的凸包顶点（= 在身体外缘） |
| `exposure` | 到全体质心的距离 / 最大距离（越大越靠外） |
| `out_dir` | 离心方向单位向量（器官朝外生长的方向） |
| `load` | 挂了几条桥（+融合×2），表示受力 |
| `terms` / `arms` | 该块上的端帽触肢数 / 支臂数 |

判定顺序：

1. `load ≥ 2` 或带融合 → **承力型**（晶柱 / 主控腔 / 棱锥…：沿受力方向加厚）
2. `on_hull` 且 `terms+arms ≥ 1` → **感受/抓握型**（吸盘 / 神经节 / 膜翼…：朝外的感受面）
3. `on_hull` → **表面型**（鳞片 / 盾甲 / 刺盾…：铺在体表）
4. `exposure ≤ 0.4` → **内脏型**（晶格框 / 储腔…：包在体内）
5. 其余 → **过渡型**（关节球 / 球囊…）

每个家族有自己的一套"承力 / 感受 / 表面 / 内脏 / 过渡"形态（`PICK` 表），所以同一个骨架块在
不同位置会长出不同器官 —— 规则图见 `images/t73_rules.png`。

## 2. 器官形态直接画在身体上（不是文字）

`t70b_body.draw_body_molecule(..., auto_organs=True)` 现在会：

1. 先按上面规则给每块配形态（`t73_organs.analyze`）；
2. 把身体的并集蒙版平滑成一条外轮廓；
3. **外露器官**：沿 `out_dir` 从块心走到体表点，把该器官的形态图样（28 形态库里的真实绘制）
   贴在那里并留一个"颈"连回身体 → 器官变成**身体长出来的突起**；
4. **内藏器官**：画在块心位置、半透明，作为体内的器官核；
5. 形态用身体色填充 + 深色轮廓 + 内部纹线，保持"同一块物质"的统一感。

结果：`images/t73_organs.png` 里 6 个分子（G13/G14/G16/G23/G24/G33）的身体上能看到不同的突起，
右侧面板逐个说明：编号 · 器官家族 · 几何依据（为什么长成这样）· 长成的形态 · 该形态擅长的能力。

## 3. 小分子的"物质化"

小分子没有器官，但也不该只是"字形 + 线"。`t73_small.py` 把元素字形、键带、端帽先并成**一个蒙版**，
再做轻微闭运算 → 单一外轮廓 → 阴影 + 渐变 + 每原子元素色淡染 + 内膜，最后加**表面纹理**：

| 结构 | 纹理 |
| --- | --- |
| S 短键 | 一排横向刻纹（像焊纹） |
| C 角键 | 中央一圈关节环 |
| L 长键 | 沿键的虚线刻痕 + 两端波浪 |
| 晶 X | 内部晶面线 |
| 冰 C / 焰 F / 电 L 端帽 | 冰锥 / 飘带 / 粗螺旋丝，朝离心方向 |

于是 `OXC` 是一块折角的小晶体（三角+菱形+六边 + 角键环），`F2` 是带飘带端头的哑铃，
`WA` 是一根带编带纹理的短棒，`O2X2` 是四粒交替串成的小链 —— 见 `images/t73_small.png`。

## 5. 局限（未决）

- 器官"颈"是直线连回体表，长在背面/被遮挡的器官没有前后关系（2D 投影）。
- 外露判定用的是块心凸包，块特别多时个别器官会挤在一起。
- 小分子的闭运算半径是按原子数估的，个别小分子（如 OXC 的角键）转角会被磨圆一点。
- 刚性/松散/粘性与固液气仍等正式分类规则替换。

## 6. T73b 修正：分化形态**直接代替**器官外形

用户 (m02076) 指出：形态不是贴在器官旁边的小图标，而是**整个器官的外形本身**。因此新增 `t73_body.py`：

1. 每个骨架块按几何规则选出一种分化形态（同 T73 的判定）；
2. 该形态的**整张剪影**（28 形态库里的真实绘制，缩放到该块大小）就是这块器官的形状；
3. 桥接的器官之间做“打包”：把它们的中心互相压叠到 `0.56×(rA+rB)`（融合对 `0.42`），
   于是并集自然连成一个身体——不是用细杆把方块串起来；
4. 端帽触肢、支臂也并进同一蒙版；最后只保留一条外轮廓 + 体内器官线稿（淡线）。
5. 徽章只标器官编号，不再有"家族容器"。

效果：G13 的四个器官是六边形主控腔 + 椭圆储腔 + 环形神经节，直接拼成一个身体；
G24 整个就是一个"分化芽"（三芽+主芽）；G16/G33 的器官带尖端（鳞片/刺盾）成了身体的尖角。
图见 `images/t73_organs.png`（规则见 `images/t73_rules.png`）。

复现：`python t73_render.py`（`t73_render.page_organs` 已改用 `t73_body.draw_organ_body`）。
