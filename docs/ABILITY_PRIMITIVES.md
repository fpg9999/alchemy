# 基础能力原子（primitives）v1：可与其他维度结合、可组合涌现的“底层能力”

> 目的：上一版 `ABILITY_CATALOG.md` 是**宏观能力**（自愈、导热、光合……），太“结果”。本文件按用户要求下沉一层：
> 给出**具体、基础、可被维度参数化、可两两组合**的能力原子。挑选后由这些原子组合出宏观能力与器官。
> 不改代码、不跑脚本。

---

## 0. 层次说明（为什么要有这一层）

```
元素/价数 → 9 操作（材料层动作：撑锁黏 分捕断 蓄移传）
        → 36 基础能力原子（作用层机制：成键、断键、扩散、门控……）← 本文件
        → 宏观能力（催化、自愈、光合……，由原子组合）
        → 器官（支撑/边界/能量/运输/传感/信息/防御/催化/复制）
        → 生命判据（B/M/R/I/H）
```

**基础原子的判定标准**：① 可用 4 个维度（密度 ρ̂、粘性 σ̂、温度 T、结构位形）参数化；② 有明确的速率/强度公式原型；③ 两个原子能组合出第三个原子没有的新行为；④ 有现实对应物（有机/无机各一例）。

符号：`ρ̂` 归一密度（0~1）、`σ̂` 归一粘性（0~1）、`T` 整数温度（度）、`V̄` 平均价数（键容量，1~3）、`op` 指 9 操作的分量。

## 2. 组合代数（怎样由原子长出宏观能力）

四种组合方式，对应“涌现”的四种机制：

| 组合 | 形式 | 涌现出什么 | 例子 |
|---|---|---|---|
| **串联 chain** | A → B → C | 新功能（A 的产物触发 B） | 感知→门控→传导 = 神经 |
| **并联 bundle** | A ∥ B 同输入 | 阈值/协同（1+1>2） | 吸附+断键→催化（缺一不可） |
| **门控 gate** | 只有当 G 成立才允许 A | 条件性、特异性 | 膜+通道+泵 = 选择运输 |
| **反馈 loop** | A → B → 抑制/激活 A | 稳态、振荡、记忆 | 代谢负反馈、免疫放大 |

**组合示例（每个都只用原子，不写“生命”）**

- **催化** = K06 识别 + K02 吸附成键 + K03 断键 + R01 催化 + K05 可逆释放（5 原子；缺 K05 就“中毒”）
- **神经** = S01 感知 + S02 门控 + S05 转导 + S03 放大 + M02 恢复（5 原子）
- **肌肉** = M01 支撑 + S02 门控 + K02/K03 循环 + R06 相变（4 原子）
- **边界/膜运输** = M03 膜 + M04 孔 + T06 选择 + T04 泵（4 原子）
- **复制** = G03 模板 + R05 聚合 + G04 纠错 + G05 分裂（4 原子）
- **免疫** = K06 识别 + K05 可逆 + K03 断键 + S03 放大（4 原子）
- **代谢** = T03 传导 + R02/R03 氧化还原 + T04 泵 + S06 反馈（4 原子）

> 关键：**器官不是被规定的，而是“某组原子稳定共现”的产物**。所以只要原子选得对，器官与生命判据会自然出现（与 `ABILITY_EMERGENCE.md` 的 L1~L4 一致）。

## 3. 维度耦合表（“和其他维度结合”的具体方式）

| 维度 ↑ | 被增强的原子 | 被削弱的原子 | 后果 |
|---|---|---|---|
| 密度 ρ̂ ↑ | M01 支撑、M03 膜、K04 键强化、T06 过滤 | T01 扩散、K01 接近、M04 孔 | 致密→结构强、输运弱（保温/屏障） |
| 粘性 σ̂ ↑ | K02 成键、K05 可逆、M06 锚定、M03 膜 | T01 扩散（黏滞） | 易聚合/黏合，但难流动 |
| 温度 T ↑ | K03 断键、R04 裂解、R06 相变、T01/T03 传导 | K04 强化、M02 冻结、M03 膜稳定性 | 活跃、易断、易传，但结构/边界难维持 |
| 平均价数 V̄ ↑ | K04 强化、M01 支撑、R05 交联 | K05 可逆、G05 分裂 | 键强网络硬，但难可逆/难分裂 |
| 结构位形（孔/链/层） | M04 孔、T06 过滤、S05 转导、G02 定向生长 | —（位形是开关条件） | 同样的元素比例，可因位形不同长成不同器官 |

**这就是你要的“结合其他维度产生进一步涌现”**：原子本身只给速率/强度，维度给数值，组合给结构，反馈给稳态——四者相乘才出器官。
