# T33 · 温度阈值：一方达完全阈值、另一方只达不完全阈值时怎么反应？

> 温度模型：每拆 1 根键需要环境温度 +1。
> - **不完全阈值 i(M)**：不完全反应时 M 自身要拆的键数（按选中的最不稳定类，每元素对 1 根）；
> - **完全阈值 c(M)**：完全大锅反应时 M 要拆的总键数（= 分子总键数）。
> 规则：接触双方都达到各自的不完全阈值 → 才有可能发生不完全反应；完全反应同理。

## 1. 结论（方案）

> **发生「不完全反应」。**
> 反应模式由所有接触参与者的「共同能力」决定：
> - 如果所有参与者都满足完全阈值 → 完全反应；
> - 否则，如果所有参与者都满足不完全阈值 → 不完全反应；
> - 否则 → 不反应。

题述情形：`T ≥ c(A)` 但 `i(B) ≤ T < c(B)`，且 `T ≥ i(A)`：

- 完全反应：要求双方都达到 c，B 未达到 → **不能进行完全反应**；
- 不完全反应：双方都达到 i，且接触 → **可以进行不完全反应**；
- 所以实际发生的是**不完全反应**；A 的"完全能力"被浪费（或者说被 B 的弱能力"淬灭"）。

## 2. 形式化规则

```
对接触集合 S（温度 T）：
    if  ∀M∈S: T ≥ c(M)  且 完全反应条件成立:
        完全反应（大锅 F）
    elif ∀M∈S: T ≥ i(M)  且 不完全反应条件成立:
        不完全反应（T28 规则）
    else:
        不反应

# 可选：单分子自分解
for M in 未被反应消耗的分子:
    if T ≥ c(M) and M 不稳定:
        M → F(v_M)     # 见 T30
```

- `i(M)` 依赖具体反应（选中的全局最不稳定类），同一物质在不同组合中 i 可能不同；
- `c(M)` 是分子自身的总键数，固定；
- 只有"所有参与者"都满足的模式才能执行——不能用一部分人的高阈值去弥补另一部分人的不足。

## 3. 具体例子

取：

| 物质 | 总键数 c | 本次不完全阈值 i |
|---|---:|---:|
| A = `W2A` | **3** | 1 |
| B = `WA3F2` | **5** | 1 |

- **T=3**：A 达到完全阈值（3≥3），B 未达到（3<5），但双方都达到不完全阈值（3≥1）。
  → **不完全反应**：`W2A + WA3F2 → W3A4F2`（目录外新物质）。
- **T=5**：双方都达到完全阈值 → **完全反应**：`W2A + WA3F2 → WA + WA + WA2F2`（大锅产物）。
- **T=0**：双方不完全阈值都未达到 → 不反应。
- **T=1~4**：不完全反应（B 的完全阈值始终未达到，A 的超额温度不改变模式）。

## 4. 为什么这样设计（原因）

1. **完全反应是集体过程**：大锅反应需要所有原子的键全部断开再重排；B 的若干键在 T 下仍不可断，所以完整大锅无法包含 B。把 A 单独完全分解不是"A 与 B 的反应"，而是 A 的自分解（另一条规则）。
2. **不完全反应已经满足**：双方的不完全阈值都达到了，且接触；没有理由阻止这个允许的反应。
3. **不能有"A 完全 + B 不完全"的混合模式**：完全反应要求全部原子解锁；只对 A 断全部键、对 B 断部分键，不是任何已定义的规则，会破坏能量/阈值一致性，也无法定义产物。
4. **不选择"完全不反应"**：温度是"能力"而不是"触发开关"；B 的较高完全阈值不能用来否决双方都能做的低阶反应。否则温度越高反而可能让某些反应消失，违反直觉。
5. **A 的超额能力仍有去处**：若 A 是不稳定物质且 T≥c(A)，A 可以单独自分解（M→F(v_M)）；若 A 已在不完全反应中被消耗，则不再单独自分解。这样"单方面完全能力"不会凭空消失。

## 5. 阈值依赖的细节（需要确认的边界）

- `i(M)` 是"本次不完全反应中 M 实际要断的键数"，与选中的全局最不稳定类有关；同一物质遇到不同伙伴，i 可以不同。
- 如果某一方的不完全阈值不满足（T < i），即使另一方达到完全阈值也不能发生不完全反应；此时若达到完全阈值的一方是不稳定物质，它可单独自分解，否则不反应。
- 完全反应条件除温度外，还要求大锅规则本身可执行（价数/几何/元素向量可行）。
- 单分子自分解和接触反应同一 tick 的优先级建议：**先接触反应（共同模式），再对未消耗的分子自分解**，避免同一分子在同一时刻既参与不完全反应又自分解。

## 6. 设计含义（游戏性）

1. **温度分区**：T=0 死寂；中间温度只发生不完全反应（产新物质）；高温才进入完全反应（大锅产物、把不稳定中间体也拆掉）。
2. **淬灭机制**：一个"高热稳定"的弱伙伴 B 可以把"本该完全分解"的 A 拉进不完全反应；混合顺序/伙伴选择可控制产物，天然适合做"淬灭剂/抑制剂"道具。
3. **温度不是越高越好**：高温完全反应会抹掉不完全反应产生的新物质；玩家要在"中间温度"采集/利用新物质。
4. **A 的完全阈值变成隐藏属性**：只有同温度下遇到同样"完全达标"的伙伴才会显现；单独时只是自分解或不反应。
5. **级联**：不完全反应产物的阈值若 ≤T，可继续自分解/完全反应，形成 T32 的链式循环。
