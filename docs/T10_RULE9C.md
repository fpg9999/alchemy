# 规则 9（优化版）验证：大类数 + 大类优先级（聚>散>动）

> 日期：2026-11-12　工作目录：`G:\AI work\deepseek\work1\alchemy`
> 待验证规则（用户优化）：
> **若规则 1~8 仍相同，则优先选择「结合之后分子式包含的大类（聚/动/散）更多」的一对分子结合；
> 大类数相同，则按分子式内包含的大类优先级 聚素 > 散素 > 动素 裁决。**

---

## 0. 结论

1. **效果很好**：与上一版（只按大类数）相比大幅改进——
   - **T≤7 全部投料完全消除歧义**（T=6、T=7 歧义数 → 0）；
   - T=8 仅剩 **6** 个（0.09%），T=9 约 **10** 个（≈0.08%，随机采样估计）。
2. **仍不是 100% 消除**：残余分歧全部出现在「并列候选对是**同一元素对**」的场合
   （如 5 个 W-K 对、5 个 P-A 对、8 个 P-K 对、32 个 O-K 对、60 个 X-K 对）：
   这些候选结合后的大类集合完全相同（如 {动,散}、{聚,散}），规则 9 无法区分。
3. 大锅例子 **T=29、T=33 仍各剩 2 种产物**（原因同上：O-K / X-K 同元素对并列）。
4. 若要 100% 消歧，需要在这条规则后对"同元素对内部"再做一层裁决（规范形/规范编号，见 `T8_RULE9.md`）。

## 1. 规则实现

在规则 1~8 的 key 后追加：

```
key += ( -|CAT(comp_i) ∪ CAT(comp_j)|,
         tuple(sorted(rank(c) for c in CAT(comp_i) ∪ CAT(comp_j))) )
其中 rank: 聚=0, 散=1, 动=2（越小越优先）
```

- 第一项：结合后的大类数，越多越优先；
- 第二项：大类集合按 聚>散>动 的优先级编码后字典序比较
  （例如 {聚,散}=(0,1) 优于 {聚,动}=(0,2)；{聚}=(0) 优于 {散}=(1) 优于 {动}=(2)）。

实现：`t10_rule9c.py`（模拟+统计）、`t10_trace.py`（残余分歧定位）。

## 4. 结论与建议

- 该优化版规则 9 **已经把歧义压到极低**（T≤7 完全确定；T=8/9 约 0.08%~0.09%；大锅仍有少量）。
