# T18-D · 骨架承载的信息维度设计（属性 / 呈现 / 能力）

> 目标：把 T18 骨架体系转成游戏设计语言——每一块骨架是"器官原型"，融合与桥接是"连接方式"，
> 三种维度（数值属性、地图呈现、能力）由「骨架形态 × 元素 × 连接方式」共同决定。

---

## 1. 数据结构总览

### 1.1 物质 = 结构卡（Substance Card）

```
SubstanceCard {
  id, formula,
  skeleton_blocks: [Block],          # 6 级中间态骨架块（38 形态库中）
  fusion_edges: [FusionEdge],        # 0 级同类三价键：块内加固 / 块间融合
  bridges: [Bridge],                 # 二价连接层：X/W/A 桥与链段
  caps: [Cap],                       # 一价终端层：C/L/F 端帽
  decorations: [2价/1价 其余],
  attributes: {mass, hp, strength, ...},
  presentation: {silhouette, seams, ...},
  abilities: [Ability],
  slots: {used, free}
}
```

### 1.2 骨架块 Block

```
Block {
  elements: {O:2, P:1},      # 三价元素组成
  size: 3,                    # 原子数
  topology: "triangle" | "chain" | "clique" | "dimer" | "singleton" | "ring_k",
  bonds: [(i,j,mult)],        # 块内三价-三价键
  geometry: "3-三角形" | "链-3" | "二聚体" | ...
  stubs: 每原子剩余键数       # 可接二价/一价的接口
  fusion_sites: 可参与 0 级融合的原子
}
```

### 1.3 三种连接方式（决定呈现与能力的大方向）

| 连接 | 化学来源 | 机械含义 | 呈现 | 属性倾向 |
|---|---|---|---|---|
| **融合 Fusion** | 0 级同类三价键（O–O/P–P/K–K） | 两块骨架"长在一起"，成为更大的骨架块 | 两个形状合并成一个大形状（内部有接缝） | 质量/HP/强度相加并 +10%，接口变刚性 |
| **S 刚桥**（短键） | 聚素参与：X（晶）2 价，或聚素侧 | 刚性焊接 | 两块紧贴、共享一条边 | 耐久↑、机动↓ |
| **C 铰桥**（角键） | 动素参与：W（流）2 价 | 关节/铰链 | 两块角对角接触、可转动 | 柔性↑、机动↑、耐久↓ |
| **L 软桥**（长键） | 散素参与：A（气）2 价 | 长距离弹性系带 | 两块隔一格、由细线相连 | 距离↑、浮力↑、机动↑、耐久↓↓ |
| **端帽 Cap** | 一价 C（冰）/L（电）/F（焰） | 末端尖端 | 形状末端的尖刺/光点 | 攻击/传感/冷/电/火 |

> 多重键 = 接口加粗/加固：每多 1 根键，连接强度 +50%，呈现为更粗的平行线。

## 2. 属性维度（数值）

### 2.1 元素基础系数（可直接做成表）

每 1 个原子对属性的贡献（0~4 分制，游戏内可再乘系数）：

| 元素 | 质量 | 耐久(HP) | 强度 | 柔性 | 抗性/免疫 | 能量 | 机动 | 感知 | 攻击 |
|---|---|---|---|---|---|---|---|---|---|
| 秩 O（聚,3价） | 3 | 3 | 1 | 0 | 2 | 0 | 0 | 1 | 0 |
| 晶 X（聚,2价） | 4 | 4 | 2 | 0 | 3 | 0 | 0 | 0 | 1 |
| 冰 C（聚,1价） | 1 | 1 | 0 | 2 | 1 | 2 | 1 | 1 | 1 |
| 势 P（动,3价） | 3 | 1 | 4 | 1 | 0 | 2 | 1 | 0 | 2 |
| 流 W（动,2价） | 2 | 1 | 1 | 3 | 0 | 1 | 3 | 0 | 1 |
| 电 L（动,1价） | 1 | 0 | 1 | 2 | 1 | 3 | 1 | 2 | 2 |
| 沌 K（散,3价） | 3 | 2 | 2 | 1 | 2 | 1 | 1 | 1 | 1 |
| 气 A（散,2价） | 1 | 0 | 0 | 2 | 1 | 0 | 2 | 0 | 0 |
| 焰 F（散,1价） | 2 | 0 | 1 | 1 | 0 | 2 | 0 | 0 | 4 |

### 2.2 结构加成（骨架块层面）

| 结构 | 加成 |
|---|---|
| 环（三元环、4~5 元 2 价环） | 耐久 ×1.2，抗性 +2（封闭结构难破坏） |
| 链/长链 | 机动 +2，伸展距离 +1 格/原子 |
| 团（4 原子完全图，如 O3P） | 耐久 ×1.3，强度 +2，质量 ×1.1 |
| 星（3 价原子连 3 个原子） | 强度 +2，作为枢纽（可挂 3 个部件） |
| 孤立三价原子 | 柔性 +2，能力槽 +1（可植入） |
| 二聚体（2 原子） | 质量 ×0.9，锚点/配重 |
| 同类三价多重键 | 每多 1 键：强度 +1，耐久 ×1.1 |
| 多重桥键（2~3 根） | 连接强度 ×(1+0.5×额外键数) |

### 2.3 属性公式（示例可直接实现）

```
质量 mass = Σ元素质量
耐久 HP   = 10×Σ(元素耐久) + 20×骨架块数 + 15×融合次数 + 30×真桥数
           ×(结构加成) × (0.8 if 有 L 软桥)
强度 STR  = Σ(元素强度) + 2×3价原子数 + 5×多重键总数
柔性 FLX  = Σ(元素柔性) + 3×C 铰桥数 + 2×L 软桥数
抗性 RES  = Σ(元素抗性) + 2×环块数 + 3×晶桥数
能量 EN   = Σ(元素能量) + 2×电/焰端帽数
机动 MOV  = Σ(元素机动) + 3×C 铰桥数 + 2×L 软桥数 − 1×S 刚桥数
感知 SEN  = Σ(元素感知) + 2×电端帽数
攻击 ATK  = Σ(元素攻击) + 3×焰端帽数 + 2×冰端帽数
能力槽 slots = Σ(块)人数?   # 见 §4.2
```

**示例**：`O3P` 骨架（4 原子完全图：3 O + 1 P，块内无 0 级融合）
mass = 3×3+3 = 12；HP = 10×(3+3+3+1)+20×1 = 120×团加成1.3 ≈ 156；
STR = (1+1+1+4)+2×2=11；RES = 2+2+2+0 + 2(团)=8；MOV = 0+1=1。
→ "高耐久、低机动的核心团块"。

## 3. 呈现维度（地图上的形状与连接视觉）

### 3.1 骨架块的地图形态

| 块形态 | 地图呈现 | 尺寸 |
|---|---|---|
| 单原子 | 一个小六边形（宝石/种子） | 1 格 |
| 二聚体 | 两格哑铃/双联 | 2 格 |
| 三元链 | 三格折线（可弯） | 3 格 |
| 三元环 | 三角环（中空） | 3 格 |
| 4 原子团（如 O3P） | 三角形实心块 | 4 格 |
| 12/28 原子大骨架 | 大型多边形/团块（占地图数格到数十格） | n 格 |

### 3.2 连接方式的呈现

| 连接 | 视觉 | 地图效果 |
|---|---|---|
| **融合** | 两个形状合并为一个大形状，交界处有"接缝线" | 占格取并集；周长减少；形成更大的整体（如两个三角合并成菱形/沙漏） |
| **S 刚桥（晶/聚）** | 两块共享一条边，边缘加粗 | 刚体：整块作为一个单位移动/受击 |
| **C 铰桥（流/动）** | 两块只在一个角接触，接触点画铰链符号 | 可绕角旋转：肢体/翻盖/夹钳 |
| **L 软桥（气/散）** | 两块隔一格，中间一条细线（可画成弹簧/膜） | 可拉伸、拖拽、浮空；受击时只牵动不传导 |
| **端帽（冰/电/焰）** | 末端小尖/光晕：蓝=冰、黄=电、红=焰 | 攻击/感知/状态附加的像素标记 |
| **多重键** | 平行线加粗（2~3 根） | 连接更粗壮/更稳固的视觉 |

### 3.3 呈现规则（可直接写进引擎）

1. **融合不新增占格**：融合后总占格 = 两块并集（重叠格不重复算）；轮廓 = 并集轮廓；面积守恒、周长下降。
2. **刚桥(S) = 共享边**：两块必须贴边；移动时整组同步。
3. **铰桥(C) = 角接触**：两块只共享一个顶点；可绕该点旋转 60° 的倍数。
4. **软桥(L) = 隔一格**：两块间隔 1 格；中间格永久为空（化学长键要求）；可画成弹簧/丝带。
5. **端帽**：画在单键末端，颜色由元素决定（冰蓝/电黄/焰红）。
6. **大骨架**：多个融合块 + 桥的组合，其总轮廓即"体型"；体型尺寸 = 占格数 → 决定碰撞体积/地图碰撞箱。

## 4. 能力维度（Emergent Abilities）

### 4.1 能力的三层来源

**(a) 骨架形态能力**

| 形态 | 能力标签 |
|---|---|
| 环 | 容器（储存/护甲/封闭腔体） |
| 链 | 肢体（伸展/抓取/摆动） |
| 星（3 价枢纽） | 分叉器官（一拖三：肢/翼/触手） |
| 团（完全图） | 堡垒核心（高 HP、防破坏） |
| 孤立三价 | 控制器/种子（可植入、可改造） |
| 二聚体 | 锚/配重/关节头 |

**(b) 元素能力**

| 元素 | 能力 |
|---|---|
| O 秩 | 秩序·修复：每回合自修复 5% HP |
| X 晶 | 护甲·免疫：物理抗性 +30%，免疫一次破坏 |
| C 冰 | 相变·冷冻：可冻结接触物、变硬/变脆切换 |
| P 势 | 力量·冲击：近战伤害 ×1.5，可推动物体 |
| W 流 | 流动·机动：可变形通过窄缝、游泳/滑行 |
| L 电 | 电荷·信号：远程感知、麻痹/脉冲 |
| K 沌 | 混沌·抗性：免疫随机负面、可随机变异获得临时能力 |
| A 气 | 气体·浮空：可漂浮、产生气流推动 |
| F 焰 | 燃烧·热：持续灼烧、点燃、熔融 |

**(c) 连接方式能力**

| 连接 | 能力 |
|---|---|
| 融合 | 器官合并：两块能力池合并；HP 相加并 +10%；可形成"复合器官"（如心脏+肺） |
| S 刚桥（晶） | 刚性结构：装甲板、支撑梁、固定武器；被击时全身受力 |
| C 铰桥（流） | 关节：旋转、爬行、开合（夹钳/翻盖/腿） |
| L 软桥（气） | 软连接：鞭击、拖曳、浮空系留、远程抓取 |
| 端帽（冰/电/焰） | 末端武器/传感器：冰=冷冻尖刺、电=电击触角、焰=喷火口 |

### 4.2 能力槽（Ability Slots）

```
能力槽 = Σ 每个骨架块的自由 stub 数
       + 1 × 孤立三价原子数
       − 2 × 融合次数          # 融合占用接口
       − 1 × 每条桥的"占用接口"
```

- 融合 = 消耗接口换"合并能力"；
- 桥 = 用接口换"连接能力"；
- 剩余 stub 可挂：端帽（武器/传感）、额外肢体、器官模块。

### 4.3 涌现示例（用真实骨架组合）

**① 秩序守卫（坦克型）**
- 骨架：O₃ 三角（环块）+ 2 个 X 晶桥（S 刚桥）+ 3 个 C 冰端帽。
- 属性：mass 9+2×4=17；HP ≈ (10×9+20×1)×1.2(环) + 30×2(真桥) ≈ 204；
  RES 高（环+晶），MOV 低。
- 能力：环=护甲腔；晶桥=刚性装甲板；冰端帽=冷冻尖刺；被动"修复"（O 秩）。
- 呈现：三角形躯干 + 两侧刚性装甲翼 + 顶点三根冰刺。

**② 流动猎手（敏捷型）**
- 骨架：P 星（3 价枢纽）+ W 链段（C 铰桥连成肢体）+ L 电端帽（触角）。
- 属性：STR 高（P）、MOV 高（W/C 铰桥）、EN 中（L 端帽）。
- 能力：3 条可旋转鞭状肢体（C 铰桥）+ 电击触角（L 端帽）+ 高速滑行。
- 呈现：中心 P 核 + 三条不同方向折叠的长肢，末端黄色电点。

**③ 混沌浮游体（奇特型）**
- 骨架：K₃ 三角（环块）+ 3 个 A 气桥（L 软桥）+ 3 个 F 焰端帽（或 A 端帽不可，用 F）。
- 属性：RES 高（K）、MOV 中、ATK 高（F），质量小（A）。
- 能力：漂浮（A 软桥）、随机变异（K）、喷焰（F 端帽）、软连接拖拽。
- 呈现：紫色三角核心 + 三条细长弹性丝线连到浮空小气囊（A），丝线末端红焰。

### 4.4 设计指南（涌现性）

1. **"核心-肢体-末端"三件套**：环/团做核心，链/铰桥做肢体，1 价端帽做末端；
   三件套的每种组合都是一个新器官/生物。
2. **融合是"器官合并"的语法**：两个同元素骨架块融合 → 复合器官（更大、更强、能力池合并），
   如"两个 O₃ 三角"融合 → 六元环/大三角形 → 从"护甲"升级为"堡垒"。
3. **桥决定运动方式**：S=刚体/装甲/固定炮台；C=关节/腿/钳；L=触手/鞭/浮空/系留。
4. **端帽决定攻击/感知**：冰=控制、电=传感/麻痹、焰=输出。
5. **平衡锚点**：mass 由原子数决定（越大越慢）；HP 由环/团/融合决定；机动由 C/L 桥决定；
   攻击由端帽/焰决定；抗性由 K/环/晶决定。
6. **能力槽是稀缺资源**：融合与桥都消耗接口——这就是"结构 vs 能力"的取舍，
   自然形成"装甲重但少能力 / 轻盈但功能多"的生态位。
