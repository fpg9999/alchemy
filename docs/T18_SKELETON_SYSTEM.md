# T18 · 骨架体系总成果（整合版）

> 本文把 T9~T17 的结构研究整合成一套**可直接用于游戏设计**的骨架分类体系。
> 数据与脚本均在 `alchemy/`（详见文末索引）。

## 0. 一句话总结

**三价元素（秩 O / 势 P / 沌 K）构成"骨架层"；二价元素（晶 X / 流 W / 气 A）是"连接层"；一价元素（冰 C / 电 L / 焰 F）是"终端层"。**
骨架由 **45 种基础形态**（3+7+35）和 **0 级同类键融合规则**共同决定；终态骨架只能由该物质自己的 6 级中间态骨架块（38 形态库）经 0 级同类三价键加固/融合得到。

## 1. 三层价数角色（定义性，全部 84,225 种物质 0 例外）

| 层 | 元素 | 每原子键数 | 角色 |
|---|---|---|---|
| 骨架层 | 秩 O / 势 P / 沌 K（3 价） | 3 | 骨架节点：成环/链/星/团，提供分支与枢纽 |
| 连接层 | 晶 X / 流 W / 气 A（2 价） | 2 | 桥/链段/支臂：可把骨架连起来，也可自身成链/环 |
| 终端层 | 冰 C / 电 L / 焰 F（1 价） | 1 | 端帽：终点、尖刺、触角、能量端头 |

## 2. 45 种骨架库（概念层）

### 2.1 无三价元素：3 种（175 种物质，≤7 原子）
1. **二聚体**（2 价–2 价双键 / 1 价–1 价单键）
2. **纯二价小环**（3~5 元）
3. **双端帽链**（1 价端帽 + 1~5 个 2 价原子链）

### 2.2 只有一种三价元素：7 种模块（7,814 种物质）
单原子 / 单键二聚体 / 双键二聚体 / 三键二聚体 / 三元链 / 三元环（全单键）/ 三元环（含一条双键）。
（终态分子中三价连通块仍然只有这 7 种，最大 3 原子——与 T10 一致。）

### 2.3 两种或三种三价元素：35 种中间态形态（+3 孤立原子 = 38 形态库）
来自 T8 的 6 级结束状态：35 种多原子形态（{O,P}7 + {O,K}7 + {P,K}7 + {O,P,K}14），另加 3 个孤立单原子。
代表性：O2P、OP2、O3K、O3P、OP4K、O3P5K、O4P7K2（13 原子最大）等。

> 45 = 3 + 7 + 35。它们对应"构建块/中间态"，不是终态分子的全部三价连接形态。

## 3. 终态骨架的形成定理（T17）

三价–三价键只可能出现在两个周期表距离：

| 两端 | 距离 | 级别 |
|---|---|---|
| 不同三价元素 | **6** | 第 6 级（最先） |
| 同种三价元素 | **0** | 第 0 级（最后） |

因此三价骨架**严格两阶段**形成：

1. **6 级**：异类三价键形成，得到若干**骨架块**（必属于 38 形态库）；6 级子过程只依赖元素计数 → 这些块是该物质**自身元素向量的内禀属性**。
2. **0 级**：同类三价键形成，只能做：**块内加固**（改变块形状）+ **块间融合**（把多个块连成更大骨架）。

**定理（分类方式的核心）**：终态三价骨架 = 该物质自身 6 级骨架块 + 0 级同类三价键的加固/融合；**不需要二价桥参与骨架连接**。
- 若 6 级时没有单原子块，终态骨架的历史分解中就不会有单原子；
- T15 的 695 种"库外新形态"全部含 O–O / P–P / K–K 同类键——这些正是 0 级融合/加固键；
- 抽样 1,120 个物质：终态三价连通块**100% = 自身 6 级块之并**（0 反例）。

## 4. 装饰层统计（84,225 种物质）

- **1 价原子**：73.5% 接在三价骨架上、26.5% 接在二价链上、12 个原子在 C₂/F₂/L₂ 中彼此成对。
- **2 价原子**：约 27.6% 是"真桥"（两端不同三价骨架）；其余为链段（T+W 128,922）、带端帽支臂（O+T 33,331 等）、终端双键（同一三价 ×2，51,991）、二价自身链/环（W+W 40,145）、二价二聚（12）。
- **严格全桥分子**：24,807 / 84,225（29.5%）；**所有一价都接三价的分子**：57,327（68.1%）。

## 6. 分类方式的使用流程

```
物质（分子式/结构）
  → ① 算 6 级中间态骨架块（38 形态库，仅依赖元素向量）
  → ② 标记 0 级同类三价键（块内加固 / 块间融合）
  → ③ 得到终态三价骨架（单类 7 种 / 双类 54~55 种 / 三类 145 种 / 库外 695 种）
  → ④ 标记二价连接层（真桥/链段/支臂/终端双键/自聚）与一价终端层
  → ⑤ 输出物质"结构卡"（骨架块 + 融合图 + 桥/端帽清单）
```


## 7b. 超级大分子验证（108~346 原子）

- 7 个超大分子（108/140/156/215/217/258/346 原子）：**终态三价连通块 = 自身 6 级块之并，7/7 成立**；
- 6 级块大小仍 **≤13**（与 T5 的 13 上界一致）；
- **修正**：之前报"38 库命中 0"是脚本 bug（WL 指纹用错空边集）。正确提取后，超大分子的 6 级块
  共 6 种形态，**全部在 38 形态库内**（P2K、O1P3K1、O1P4K1、O2P3K1、O3P5K1、O4P7K2）；
- 结论：分类逻辑（自身 6 级块 + 0 级融合）与 38 块字典在超大分子上均成立；
  45 库目前证据支持为完整的 6 级块字典。
