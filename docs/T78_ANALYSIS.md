# T78 独立分析：九元素三轴介质箱（main / nogate / nochem）

**一句话结论**：三条轴（质量→重力、物态→碰撞、温度→恒素）在 240 分钟内**全部跑通且方向正确**，但 T78 是一个"碎片化 + 重力分层 + 恒素贫化"的**非收敛**系统：终态 3,922 分子 / 607 种分子式 / 810 个目录外新物质 / 78% 双原子碎片，与 T62 的 LF+OXCPWKA 双组分不动点正好相反；恒素门控把反应压进 ρ≥0.4 带并提高了单次判定效率（0.546% vs 0.441%），但相对"接触点本来就集中在高 ρ 带"是二阶效应；报告里最刺眼的 ρ0.6 桶 rate=14.6% 是**小样本 + 模式混杂 + 早期时间窗**的三重假象，不是门控响应曲线。

### 1.2 物态轴 → 碰撞模式：成立，且与化学强耦合

`mode_counts`（= 全部有效判定，和 = attempts）：

| 臂 | 穿过（气-气 0.18） | 游泳（0.45） | 黏附（0.60） | 阻挡（0.80/0.90/1.00） |

### 1.3 温度轴 → 恒素场：方向成立，但"相关性"要小心解读

ρ 场随时间的均值 / 分位（time_series 与 t=239 快照 200 格）：

| 臂 | t=0 | t=50 | t=100 | t=150 | t=200 | t=239 mean±std | t=239 p10 / p50 / p90 | min / max |
|---|---|---|---|---|---|---|---|---|
| main | 0.525 | 0.415 | 0.310 | 0.272 | 0.278 | **0.280±0.167** | 0.074 / 0.261 / 0.512 | 0.030 / 0.818 |
| nogate | 0.525 | 0.369 | 0.258 | 0.241 | 0.240 | 0.242±0.170 | 0.057 / 0.197 / 0.459 | 0.023 / 0.843 |
| nochem | 0.525 | 0.588 | 0.607 | 0.623 | 0.640 | **0.649±0.113** | 0.503 / 0.655 / 0.782 | 0.372 / 0.918 |

用快照重新构造"脚本自己的恒素目标"（`update_rho` 的 star 项，连续温度按 1.75 分界重算，不抄脚本输出）：

| 臂 | star 均值 t=0→239 | r(star, ρ) t=100 / t=239 | MAE | 热格 ρ / 冷格 ρ（t=239） | 顶 6 行 ρ / 底 6 行 ρ（t=239） |
|---|---|---|---|---|---|
| main | 0.582 → **0.280** | 0.927 / **0.957** | 0.066 | 0.562 / 0.174 | 0.330 / 0.255 |
| nogate | 0.582 → 0.235 | 0.924 / 0.956 | 0.061 | 0.620 / 0.149 | 0.263 / 0.224 |
| nochem | 0.582 → **0.649** | 0.934 / **0.979** | 0.035 | 0.738 / 0.432 | 0.653 / 0.639 |

（热格/冷格 = 快照中只含热分子 / 只含冷分子的恒素格；此口径与 Lead 报告里 r=0.957/0.955/0.976 可复现一致，说明两套独立实现互相对上。）

结论与告诫：
- **热物质让 ρ 升高**这条成立：热格 ρ 是冷格 ρ 的 1.7–3.2 倍；main 顶部 6 行 ρ 0.330 > 底部 6 行 0.255。nochem 顶/底几乎持平（0.653/0.639）但热格/冷格仍差 0.31——富集是**格级**的，不是简单的"上热下冷"梯度。
- **r(star,ρ) 有同义反复成分**：ρ 在定义上就是逐格朝 star 松弛（`v += 0.30*(star-v)`），所以高 r 只证明"场实现了自己的目标"，不是独立验证。真正独立的证据是两条：(a) 热格 vs 冷格的 ρ 差；(b) nochem 中**粒子级热/冷贡献恒定**（热 0.283 / 冷 0.117，全程不变），而按格平均的 star 均值从 0.582 升到 0.649——说明浮力把热分子送进**稀疏格**，抬高的是"按格平均"的 star，这是"温度+浮力"耦合成空间富集的直接证据，而不是温度组成变了。

main 27 格 top：轻·气·温 1,650；轻·气·热 619；轻·气·冷 508；轻·液·冷 230；重·气·冷 206；中·固·冷 111；中·液·冷 99；中·气·冷 91；轻·固·冷 79；重·液·冷 58。

**关键修正（本报告与"格分布 = 生态位分化"读法的主要分歧）**：三条轴取自**互不相交的价层**——质量只由三价 O/K/P 决定，物态只由二价 X/W/A 决定，温度只由一价 F/L/C 决定；`molecule_attrs` 对"缺层"分子把该轴值取 0.0，而 0.0 恰好落在极端档（质量→轻、物态→气、温度→冷）。T78 终态 78% 是双原子碎片，普遍缺 1–2 层。因此：
- 轻·气·温 42.1% 不是"大量中等质量的气态温热物质"，而是**缺轴碎片**被规则推进这个格（CF/L2 是 轻·气·温，LF 是 轻·气·热，WA 是 轻·气·冷、OK 是 重·气·冷）；
- χ²=2 万的巨大不均匀度主要是"碎片化 + 缺轴"的算术结果，**不宜直接读作 27 格行为表里的 27 种生态位被差异化占用**；
- 顺带：初始投料本身 26/27 格、χ²=1,004 就不均匀（中·气·热 243），所以"占满 27 格"也不是化学独有的成就。

## 2. 恒素门控：main vs nogate

### 2.1 计数与效率

| 指标 | main | nogate | 差 |
|---|---|---|---|
| 有效判定 attempts | 2,443,020 | 3,457,932 | **−29.4%** |
| complete / incomplete | 13,329 / 0 | 15,249 / 1 | −12.6% |
| 判定转化率 complete/attempts | **0.546%** | 0.441% | +23.7%（相对） |
| none（过门控但解析为无反应） | 245,502（10.05%） | 821,710（**23.76%**） | −57.9% 占比 |
| inert（未过门控） | 2,114,494（86.55%） | 2,486,803（71.92%） | — |
| capped（过门控但 na>20） | 69,695（2.85%） | 134,169（3.88%） | — |

门控的净效应：**砍掉近 3 成接触判定，把"白判"（none）从 24% 压到 10%，单次判定效率 +24%**；但总反应数反而少 12.6%，因为 nogate 的判定基数大。门控是"提纯器"，不是"反应放大器"。

### 2.2 反应地理（按接触点 ρ 十分位分桶）

| ρ 桶 | main reactions / attempts / rate | nogate reactions / attempts / rate |
|---|---|---|
| 0.0 | 3 / 625 / 0.48% | 69 / 4,387 / 1.57% |
| 0.1 | 87 / 5,746 / 1.51% | 456 / 18,040 / 2.53% |
| 0.2 | 391 / 14,165 / 2.76% | 874 / 13,385 / 6.53% |
| 0.3 | 1,223 / 25,899 / 4.72% | 2,192 / 40,203 / 5.45% |
| 0.4 | 4,514 / 1,268,828 / 0.36% | 7,082 / 2,918,677 / 0.24% |
| 0.5 | 6,925 / 1,126,461 / 0.61% | 4,407 / 462,351 / 0.95% |
| 0.6 | **185 / 1,271 / 14.56%** | 165 / 821 / 20.10% |
| 0.7 | 1 / 24 / 4.17% | 5 / 65 / 7.69% |
| 0.8–1.0 | 0 / 1 / 0 | 0 / 3 / 0 |

集中度：main 的 50% 反应落在 **1 个桶**、80% 在 2 个桶、90% 在 3 个桶、95% 在 4 个桶；nogate 是 50% 落 2 个桶、80% 3 个桶、90%/95% 4 个桶。ρ≥0.4 的反应占比 main **87.2%** vs nogate 76.5%；ρ≥0.3 为 96.4% vs 90.8%。反应点加权 ρ：main 0.438 / nogate 0.395（判定加权 0.443 / 0.409，场均值 0.280 / 0.242）→ 反应发生在场均值 **1.56× / 1.63×** 的 ρ 处。

**ρ0.6 桶 rate=14.6% 的异常（Lead 点名项）——三重原因，不是门控响应曲线**：
1. **样本量**：0.6 桶只占 main 判定的 0.05%（1,271/2.44M），0.7 桶只有 24 次判定；0.8+ 桶个位数。rate 的置信区间极宽。
2. **时间窗**：ρ≥0.6 的富集区只存在于**早期**（ρ 场均值 0.525→0.27；ρ_p90 从 0.551 降到 0.51 以下）。这些判定几乎全来自 t<60 的高温富集相，那里分子种类/接触模式与终态完全不同。
3. **模式混杂（主因）**：桶率 = E[mult·ρ | 桶]，而桶内**接触模式组成**差别极大——ρ0.4/0.5 两桶被气-气"穿过"（mult 0.18）灌满（占 97%+ 的判定），ρ0.6+ 桶里阻挡/黏附（mult 0.8–1.0）占比高，加上早期大分子"能 complete"的概率本身高。**门控概率与模式乘子、物种组成在同一个桶里纠缠，现有数据（无 per-mode attempts）无法分离**。所以 §2.1 的"intention-to-treat"式比较（总转化率、none 占比、ρ 加权、集中度）才是有意义的门控证据；单桶 rate 不可用。

另一点：0.4–0.5 两桶吃掉 main 97.9%、nogate 97.5% 的判定——这本身说明**接触采样（密度²）已经把接触点锁在高 ρ 带**，门控能做的只是带内的过滤，所以 gains 是二阶的。

## 3. nochem 纯物理基线 vs main：化学改变了什么

| 指标 | main（化学） | nochem（纯物理） |
|---|---|---|
| 分子数 | 1,793 → **3,922**（+118.7%） | 1,793 → 1,793 |
| 平均原子数 | **4.65** | 10.16（= 初始） |
| distinct 分子式 | 607 | 120（= 初始） |
| 2 原子分子 | 3,058（**78.0%**） | 0 |
| top4 份额 | CF/LF/L2/WA = 66.0% | L2A2/X3CW3KA/CKF2/LKF2 = 19.3% |
| ρ 终态 mean±std | 0.280±0.167（CV **0.596**） | 0.649±0.113（CV **0.174**） |
| 结束 y（轻/中/重） | 3936.5 / 2330.6 / 91.4 | 3979.4 / 2080.6 / 17.0 |
| 纵向三分（底/中/顶） | 12.6% / 3.7% / 83.7% | 39.7% / 10.8% / 49.6% |

**化学是否改变分层方向？没有。**两臂都严格"轻顶重底"，nochem 的重分子甚至贴底更彻底（y=17.0）。化学改变的是**幅度与形态**：它把群体质量分布推向轻端（main 终态轻 80.4% vs nochem 36.4%），于是顶带份额 83.7% vs 49.6%、中带被清空到 3.7%，形成"顶部气团 + 底部残渣"的两相结构。

**化学是否降低恒素不均匀度？没有，反而相反。**绝对离散 std 更大（0.167 vs 0.113），**相对离散 CV 大 3.4 倍**（0.596 vs 0.174），下尾 p10 从 0.503 掉到 0.074。化学把 ρ 场从"接近中性、平缓"推成"整体偏低 + 空间差异更大"。

机制（用快照重算）：化学把热分子（1 价富集）消耗成冷产物——粒子级热贡献 0.283→0.211、冷贡献 0.117→0.289——恒素目标 star 从 0.582 降到 0.280，ρ 场随之整体下降；nochem 因为组成不变（热/冷贡献恒 0.283/0.117），star 只是因浮力把热分子送到稀疏格而按格平均抬高到 0.649。**ρ 场没有消耗项**：main 的 ρ 下降不能读作"反应耗竭了恒素"，只是温度组成改变后场跟着换了目标值。

判定数一路涨（N 增长 + 密度），成功反应却从 115/min 掉到 13–28/min，单次转化率掉 ~85 倍。nogate 同心（t=239：21,505 判定 / 4 complete）。**化学在 240 分钟内进入"很热闹但没有反应"的准稳态**。

### 4.3 产物：自由碎块偏小、偏轻

- 每次成功反应平均产 **2.47** 个产物；`events` 中产物平均 **4.29** 原子（2–14），而反应物平均 **5.07** 原子 → 产物比反应物更小，是净碎片化；
- `events` 产物质量档：轻 6,824 / 中 1,650 / 重 1,414（68.9% / 16.7% / 14.3%）；
- 终态：main 78.0% 是 2 原子分子、平均 4.65 原子（初始 10.16，分子数 ×2.19、平均尺寸 ÷2.19）；nogate 79.2% / 4.11 原子；nochem 0% / 10.16；
- 终态 top：CF 1,093（27.87%）、LF 607（15.48%）、L2 552（14.07%）、WA 337（8.59%）、OK 173（4.41%）、PK 121、OP 68、XA 62、XWA 31。

"产物多为轻分子"的直接解释：**CAP=20 的产物是"自由碎块"**——一次碰撞把两个中等分子拆成 2–5 个更小的盐/端帽分子，原子数守恒但分子数几乎翻倍；碎片往往只剩 1–2 个价层（如 CF 只有一价+三价? 实为缺层），于是被分到轻/气/冷等极端档（§1.4）。唯一边界例外是 19–20 原子产物（见 §5）。

## 6. 与 T62 的对比：为什么 T78 不收敛

| 维度 | T62（等量价数，收敛） | T78 main（本实验） |
|---|---|---|
| 投料 | 同一 batchA、九元素等量 + 价数等量 | 同 batchA 缩放到 1,793 分子 / 18,222 原子 / 120 种 |
| 温度协议 | **1000°C → 0°C，1000 min/阶段（−1°C/min）**，0°C 后二次投放 | **T_REACT 恒 1000**（温度轴只驱动 ρ，不参与反应判定），240 min，无二次投放 |
| 空间 | 稀薄气体 DSMC，无重力 | 2D 2000×4000、重力 GRAV=80、分层两相、反射壁 |
| cap | 40（对照 60） | 20 |
| 判定转化 | **12,085,845 complete（99.40%）** | 13,329 complete（**0.546%**） |
| 终态 | **LF 15,264（44.3%）+ OXCPWKA 15,241（44.2%）**，43 种（B 阶段 94.0% 纯度） | CF 1,093（27.9%）+ LF 607（15.5%）+ L2 552（14.1%）+ WA 337（8.6%），**607 种**，OXCPWKA 仅 2 个 |
| 新物质 | — | 810 个目录外 |

**最有效的一条对照**：T78 终态就是 T62 的**高温爆裂相**。T62 在 t=0/1000°C 的组成是 OK 1,498 / PK 1,418 / CF 1,270 / L2 1,239 / LF 1,209 / OP 1,137，t=10/990°C 是 LF 5,156 / CF 5,050 / L2 3,980 / OK 3,892 / WA 3,276 / XA 2,782；T78 240 分钟后仍停在这一族双原子盐的混合里（CF/LF/L2/WA/OK/PK）。T62 的 LF+OXCPWKA 收敛发生在 900°C→0°C 之间（700°C 时才双双破万，t=1000 才各约 1.5 万）。**T78 缺的不是九元素或等量价数，而是那段降温窗口。**

不收敛的机理（五条，按重要性）：
1. **没有退火就没有选择压**。T62 的收敛由 1000→0°C 的冷却驱动（低能不动点被逐步选中）；T78 把 T_REACT 钉死在 1000，等于永远停在"爆裂/洗牌"相，只会在双原子盐附近来回重排。
2. **重力分层把反应物隔开**。两相之间只剩薄界面（中带 3.6% 粒子承担 15.3% 反应，每粒子强度 5×顶部），顶部气团与底部残渣不接触；反应通量靠界面补充，随时间自熄（complete/min 115→28）。
3. **碎片化自限**。78% 终态是双原子、75% 接触是"穿过"（mult 0.18），单次判定转化率仅 0.546%（T62 为 99.4%）——反应被自己的产物"熄火"。
4. **ρ 门控只做局部化**。87.2% 反应压在 ρ≥0.4 带，贫 ρ 的底部几乎无化学；且 ρ 无消耗、无产物反馈，富集带被反复利用而没有新鲜反应物补进来，反应带无法扩张。
5. **cap=20 + 开放组合空间**。19–20 原子终端类占终态 8.8%，810 个目录外新物质说明组合空间没有被"目录化"收敛；到最后一分钟仍在发现新物种。

⇒ **"不收敛"是"无退火 + 重力分层 + 门控局部化 + 碎片化"的动力学结果，不是九元素/等量价数本身的性质**；T62 的收敛是"退火 + 整理 + 全混合"的产物。

## 7. 诚实局限与下一步

### 局限（每条带数字）

1. **单 seed，且三臂立即分岔**：t=0 首分钟 main 39 complete vs nogate 79 complete，两条轨迹从第一步就不同；main/nogate 比较的是**不同状态**，不是同态 A/B 反事实。所有"门控效应"都带轨迹分岔的混杂。
2. **恒素无消耗/无反馈**：ρ 只因温度组成改变而变（star 0.582→0.280 vs nochem →0.649），不能读成"化学耗竭恒素"；富集带可被无限复用，这会让"门控定位反应"被高估。
3. **桶率不可分解**：ρ0.6 桶 14.6% 与 0.4 桶 0.36% 并列是模式乘子/物种/样本量混杂（§2.2）；脚本未记录 per-mode attempts，无法给出真正的门控响应曲线。
4. **events 截断 4,000**：模式富集只覆盖 t=0…39（main）/0…21（nogate），不能外推到全时段；"模式→反应"的定量结论要标早期样本。
5. **2D 反射壁 + 无横向混合**：main 79.8%、nochem 70% 粒子挤在上下 100 px 内，中带近空——分层幅度有相当部分是**边界压缩**artifact，真实三维/更大世界里更可能是梯度而非两相；且 `DAMP_X=0.5` 让体系没有横向对流。
6. **三轴对碎片退化**（§1.4）：三轴取自不相交价层，缺层取 0 被推到极端档；78% 双原子产物缺 1–2 层，27 格分布/档名对碎片语义失真，χ² 主要反映这条。
7. **CAP=20 边界**：capped 2.85%（main）/3.88%（nogate）；19–20 原子终端分子占终态 8.8%、占新物质 38.0%。
8. **DSMC / 速率松弛近似**：K_RATE=1600 的空间格随机配对、浮力做速率松弛、碰撞不做刚体冲量——是介质箱近似，不是动力学。
9. **时长不足**：240 min vs T62 的 1000 min；末期 distinct 仍从 1,008（t=50）降到 607 且仍发现新物质，只能说"准稳态 + 缓慢换血"，未达定态。
10. **单介质**：只跑了 中·气·温（2.0/1.0/1.75），三轴在其它 26 个介质格的方向未验证。

### 下一步（按优先级）

1. **多 seed ×3–5 复算** §1/§2 的主结论（尤其门控 24% 效率提升和界面强度 5×），排除单 seed 偶然。
2. **加退火对照**：T_REACT 1000→0 线性降温（240 或 1000 min），检验 T78 是否出现 LF+OXCPWKA；这是把"不收敛"归因到协议而非系统的**判决实验**。
3. **cap 对照 20/40/60**：T62 经验是 cap 只改边界长尾不改格局；若 T78 的 810 新物质/344 终端分子随 cap 消失，则"新物质爆发"部分是 cap=20 的边界产物。
4. **补计数**：`e_attempt[mode][ρbin]` + 不截断 events，才能把 门控 / 模式乘子 / 物种 三者从桶率里分离。
5. **初始 ρ 梯度**（左 0.2→右 0.8）：检验"化学被恒素场空间定位"是否比"被接触密度定位"更强。
6. **给 ρ 加消耗**（每 complete 局部 ρ×0.98）：检验富集带是否被耗尽、反应带是否迁移；这是"恒素作为资源"的最小闭环。
7. **关重力 / 三维 / 更宽世界**：把分层效应与边界压缩 artifact 分开。
8. **改用可分离指标**：报告"缺层率"（缺 1/2/3 个价层的分子占比）后再解释 27 格，避免把轴退化当成生态位分化。
