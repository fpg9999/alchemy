## 0. 一句话结论（v2 变更点）

1. **温度用整数 `T`（度）**，不做 `/(2N)` 归一：`T = n_电×1 + n_焰×2`，冰=0°、电=1°、焰=2°。跨分子直接用整数度比较。
2. 密度、粘性、温度**全部按整物质元素计数**，骨架内不再计算。
3. 温度传导效率：`η = (1−ρ̂) · (T+1)/(T+4)`（整数 T 的有界饱和形式；等价于 `(T+1)/(T+1+T_ref)`，`T_ref=3°`）。
4. 低密度 = 自由体积大 = 导热好；高密度低温 = 保温（用户确认默认方向）。
5. 温度×粘性派生能力 = **热黏合效率** `η_ad = σ̂·exp(−((T−T\*)/W)²)`，`T*=4°`、`W=3°`；三态：冷固型/热塑型/熔流型。
6. 传导优先规则按 `η_j^p`（p=2）分配通量；环境 `η_env=0.35`、`T_env=2°` 也参与。

## 1. 温度定义（整数度）

| 元素 | 中文 | 温度 |
|---|---|---|
| C | 冰 | **0°** |
| L | 电 | **1°** |
| F | 焰 | **2°** |
| O/X/K/A/P/W | 其余 | 0° |

```
T°(molecule) = n_L + 2·n_F                  # 整数，单位 °A
N  = 原子数
D  = 3·n_O + 2·n_K + 1·n_P                  # 密度原始值
S  = 3·n_X + 2·n_W + 1·n_A                  # 粘性原始值
ρ̂ = D/(3N) ∈ [0,1]，σ̂ = S/(3N) ∈ [0,1]      # 仅用于效率公式的比值（不是温度的归一）
```

示例：

| 分子 | N | T° | ρ̂ | σ̂ |
|---|---|---|---|---|
| `OXC` | 3 | 0 | 0.333 | 0.333 |
| `L2` | 2 | 2 | 0.000 | 0.000 |
| `F2` | 2 | 4 | 0.000 | 0.000 |
| `O3F3` | 6 | 6 | 0.000 | 0.000 |
| `O3X3`（全粘性） | 6 | 0 | 0.500 | 1.000 |
| `X3F4`（粘+焰） | 7 | 8 | 0.429 | 1.000 |
| G13 `O3X4CP16W5LK5A3F2` | 40 | 5 | 0.292 | 0.292 |

- **整数 T 的语义**：T 是“这个物质常态下能向外提供的温度总量（度）”。大分子因元素多可以 T 更高；比较时直接用 T 差（ΔT 也是整数度起步）。
- 动态温度 `τ`（状态量）用**浮点度**表示，初始 = T°，会向 T° 回归（见 §4）。

> 旧口径（F=3/L=2/C=1、按骨架）全部废弃；27 格阈值 `(10,16)/(6,11)/(3,6)` 需按新温度刻度重标定（确认后执行）。

## 2. 温度传导效率 η（密度 × 温度，整数 T 版）

### 2.1 公式

```
η = (1 − ρ̂) · (T + 1) / (T + 1 + T_ref)          T_ref = 3°（默认，可标定）
clamp 到 [0, 1]
```

- `(1−ρ̂)`：自由体积比例（导热通道）——密度越高，通道越少，越保温。
- `(T+1)/(T+4)`：**有界饱和**的热激发因子。`T=0` 时 1/4（低温仍能传一点，保证“反向吸热”可行）；`T=2` 时 1/2；`T=4` 时 5/8；`T=8` 时 3/4；`T→∞` 趋近 1。
  - 为什么不用 `/(2N)`：你说温度用整数 T，所以用**全局参考温度** `T_ref=3°` 做饱和，而不是按每个分子自己的原子数归一。
  - `T_ref` 越小，温度影响越陡；越大，温度影响越平缓。默认 3° 让 0~8° 覆盖主要变化区间。

### 2.2 默认值实例

| 分子 | T° | ρ̂ | η |
|---|---|---|---|
| `F2` | 4 | 0.000 | **0.625** |
| `L2` | 2 | 0.000 | 0.500 |
| `O3F3` | 6 | 0.000 | 0.700 |
| `OXC` | 0 | 0.333 | 0.167 |
| `O3X3` | 0 | 0.500 | 0.125 |
| 纯 `O12` | 0 | 1.000 | **0.000**（完全保温） |
| G13 | 5 | 0.292 | 0.472 |

（`O3F3` 精确值：`(1−0)·(6+1)/(6+4)=0.700`。）

### 2.3 设计理由与旋钮

- 低密度 → 自由体积大 → 通道多 → 易传；高密度低温 → 通道少且不活跃 → 保温。这是你确认的默认方向。
- 温度影响是**饱和型**：从 0° 到 4° 提升明显，再往上收益递减，避免大分子“T 很大所以无限导热”。
- 旋钮：`T_ref`（3°）、若想更陡可改 `(T+1)/(T+1+T_ref)` 的幂次；想“稠密导热好”则把 `(1−ρ̂)` 换成 `ρ̂`（当前不采用）。

## 3. 接触传导与优先规则

### 3.1 接触导率

```
κ_ij = κ0 · sqrt(η_i · η_j) · g_geo        κ0 = 0.35 /tick
g_geo：共边 1.00 / 共顶点 0.85 / 隔格 0.70 / 跨骨架桥 0.60
环境：κ_iE = κ0 · sqrt(η_i · η_env)         η_env = 0.35，T_env = 2°（可按群系配）
```

`sqrt(η_i·η_j)`：两端都要“传得动”，任一端为 0 则完全隔绝；再乘几何因子（距离/连接类型）。

### 3.2 热流与温度更新（整数 T 的度制）

```
q_ij = κ_ij · (τ_i − τ_j)                  # 单位：度·tick⁻¹（τ 为浮点动态温度）
q_iE = κ_iE · (τ_i − T_env)

C_i = N_i · (1 + ρ̂_i) / 4                 # 热惯性（原子数×密度；/4 使量级与 κ 匹配，可标定）
τ_i ← τ_i − (Σ_j q_ij + q_iE)/C_i
τ_i ← τ_i + λ · (T°_i − τ_i)              # 向常态温度回归，λ = 0.03
τ_i ← clamp(τ_i, 0, T°_i + 10)            # 允许少量过冲，上限防爆
|Δτ_i| ≤ 1.5° / tick                       # 单步限幅，防振荡
```

- `λ=0.03`（按你的“听你的”采用推荐）：物质是**恒温源**，会持续把温度往外送/从外吸，回到常态温度，因此热流长期存在。
- 度制说明：因为 T 是整数度、热量用“度”计量，**大分子热惯性大**（C 随 N 增长），所以大分子温度变化慢，小分子容易被加热/冷却——这符合“大物质稳定、小分子敏感”的直觉。

### 3.3 优先规则

```
w_ij ∝ η_j^p        p = 2
q_ij = w_ij · κ_ij · (τ_i − τ_j)        # 仅对 τ_i > τ_j 的邻居方向
```

- η 越高，分到的外放通量越大 → **优先传给传导效率更高的物质**（η 0.8/0.5/0.2 → 权重 0.64/0.25/0.04）。
- 环境永远作为候选参与分配；方向由 Δτ 决定，邻居更热则自动反向吸热。
- `p→∞` 退化为“只认 η 最高的一个邻居”的硬优先；`p=1` 是普通扩散。默认 2 兼顾优先与稳健。

## 4. 温度 × 粘性派生能力：热黏合效率 η_ad

### 4.1 公式（整数 T 版）

```
η_ad = σ̂ · exp( −((T − T*) / W)² )          T* = 4°，W = 3°，clamp [0,1]
```

- `σ̂`：粘性（胶点数量/强度）——**线性放大**；没有粘性就没有黏合。
- 高斯窗口：T 太低 → 分子链段冻住、接触面只能点接触（**脆**）；T 太高 → 热运动破坏界面、吸附解吸（**熔流失黏**）；**T≈4° 的热塑态**黏合最强。
- 半宽 `W=3°`：约 `T∈[2°, 7°]` 有实质黏合；`W` 越小，热塑窗口越窄、越“挑环境”。
- 峰值 `T*=4°` 对齐“电元素 1°、焰元素 2°”的中间带：两电（2°）到两焰（4°）附近最适合热塑黏合。

### 4.2 三态（新属性档）

| 温度档 | T 范围（默认） | 名称 | 行为含义 |
|---|---|---|---|
| 冷 | `< 2°` | **冷固型** | 键强高但脆；能固定结构，断裂后不易重接（结晶胶/刚玉胶） |
| 温 | `2° ~ 7°` | **热塑型** | 可反复熔接/自愈、可重排；**器官边界、复制、愈合**的主要来源 |
| 热 | `> 7°` | **熔流型** | 能润湿铺展但不能持键；只帮扩散/传热，不帮粘合 |

### 4.3 接入涌现（键强乘子）

```
m_ij = 1 + 0.6 · sqrt(η_ad_i · η_ad_j)      范围 1.0 ~ 1.6
w_ij ← w_ij · m_ij
```

- 热塑型分子之间界面更牢（利于 L2 组装体稳定、L3 边界器官）；冷固型低温区牢但“断后不重接”（损伤修复率低）；熔流型几乎无加成。
- `η_ad` 不是第 10 个操作，而是“黏（C）”操作的温度调制派生量；`η_cond` 同理是“传/移”体系的被动输运派生量。

## 5. 与 9 操作能力的关系

| 派生量 | 来源维度 | 性质 | 是否进 9 操作评分 |
|---|---|---|---|
| `η_cond` | 密度 × 温度 | 被动输运（介质属性） | 否，独立派生标量 |
| `η_ad` | 粘性 × 温度 | 界面结合调制（黏的温度窗口） | 否，键强乘子 |
| 温度档（冷/温/热） | 温度 | 三档标签 | 可进属性卡/27 格展示 |

9 操作（撑/锁/黏/分/捕/断/蓄/移/传）仍是主动能力唯一口径，避免能力体系膨胀（你已确认按推荐）。
