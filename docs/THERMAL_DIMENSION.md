## 0. 一句话结论

1. **温度**改为按整分子元素计数：`T° = n_电 × 1 + n_焰 × 2`，冰=0°、电=1°、焰=2°；归一化 `θ = T° / (2N) ∈ [0,1]`。
2. **密度、粘性、温度全部按整物质（所有原子）计数**，骨架内不计（`skeleton_units` 只保留几何成员信息）。
3. **温度传导效率**由密度与温度合成：`η = 0.5·(1−ρ̂)·(1+θ)`——低密度（自由体积大）+ 高温（激发强）→ 更容易传热；高密度低温 → 保温。
4. 物质**优先**把温度传给 η 更高的对象（软优先：按 `η_j^p` 分配通量；环境也是候选，自带 `η_env`）。
5. **温度 × 粘性**派生能力 = **热黏合效率** `η_ad = σ̂ · exp(−((θ−θ*) / w)²)`：黏性提供“胶点”，温度提供“可动窗口”，太冷发脆、太热解吸，中间热塑态最强。

下面给出完整定义、公式、默认参数、逐条理由、以及需要你拍板的 5 个点。

## 1. 温度的新定义（用户口径）

### 1.1 元素温度表

| 元素 | 中文 | 角色 | 温度 |
|---|---|---|---|
| C | 冰 | 聚·1 价 | **0°** |
| L | 电 | 动·1 价 | **1°** |
| F | 焰 | 散·1 价 | **2°** |
| O / X | 秩 / 晶 | 聚·3/2 价 | 0°（中性） |
| P / W | 势 / 流 | 动·3/2 价 | 0°（中性） |
| K / A | 沌 / 气 | 散·3/2 价 | 0°（中性） |

即：**只有一价元素带温度**（冰/电/焰 = 0/1/2）；三价、二价元素不对温度做直接贡献。

### 1.2 分子温度

```
T°(molecule) = n_L + 2·n_F          （整数度，单位 °A）
N  = 分子原子数
ρ  = 3·n_O + 2·n_K + 1·n_P          （密度，原始值）
σ  = 3·n_X + 2·n_W + 1·n_A          （粘性，原始值）
```

归一化（用于所有效率/判据公式，进入 [0,1] 区间）：

```
ρ̂ = ρ / (3N)
σ̂ = σ / (3N)
θ  = T° / (2N)      # 0°→0，纯焰→1（纯焰分子全部原子是焰，2N/2N=1）
```

- `θ` 是**常态温度**（内禀物性），不是环境温度。
- 动态温度 `τ`（见 §4）才是状态量，会向 `θ` 回归。
- 示例：
  - `F2`：T°=4，N=2，θ=1.00（最热）
  - `L2`：T°=2，N=2，θ=0.50
  - `OXC`：T°=0，N=3，θ=0.00（最冷）
  - `O3F3`：T°=6，N=6，θ=0.50
  - `O3X4CP16W5LK5A3F2`（G13，40 原子）：T°=1+2×2=5，θ=5/80=0.0625

### 1.3 与旧口径的差异

| 项 | 旧（2026-11-19 前） | 新（本文） |
|---|---|---|
| 温度权重 | F=3、L=2、C=1 | **F=2、L=1、C=0** |
| 范围 | 0 ~ 3N | 0 ~ 2N |
| 零点 | C 也有温度（1°） | C=0°，纯聚/动/散大分子可为 0° |
| 计算对象 | 整分子（但 `skeleton_units` 有逐骨架副产物） | **整分子唯一口径**，骨架不再算属性 |

→ **旧的 27 格阈值 `(10,16)/(6,11)/(3,6)` 必须重标定**（温度轴整体换刻度）；这一步放在你确认后执行。旧数据 `data/biomes/` 里的属性字段也要按新口径复算。

## 3. 温度传导效率 η（密度 × 温度）

### 3.1 公式

```
η(ρ̂, θ) = η0 · (1 − ρ̂)^a · (1 + θ)^b        η0 = 0.5，a = 1，b = 1
clamp 到 [0, 1]
```

- `ρ̂ ∈ [0,1]`：归一密度 = 密实填充比例；`1−ρ̂` = **自由体积比例**（热量可走的“通道”）。
- `θ ∈ [0,1]`：归一常态温度 = **热激发强度**（载流子/热运动活跃度）。
- 两者相乘：**通道 × 激发**。`η0=0.5` 使理论上限恰为 1（ρ̂=0、θ=1 时 0.5×1×2=1）。

单调性（有意为之）：

```
∂η/∂θ  = η0(1−ρ̂)  ≥ 0     温度越高越易传
∂η/∂ρ̂  = −η0(1+θ)  ≤ 0     密度越大越保温（自由体积少）
```

### 3.2 默认值下的实例

| 分子 | N | ρ̂ | θ | η |
|---|---|---|---|---|
| `F2` | 2 | 0.00 | 1.00 | **1.00**（最高，稀薄高温） |
| `L2` | 2 | 0.00 | 0.50 | 0.75 |
| `OXC` | 3 | 0.33 | 0.00 | 0.33 |
| `O3F3` | 6 | 0.00 | 0.50 | 0.75 |
| `O3X4CP16W5LK5A3F2` | 40 | 0.29 | 0.06 | 0.38 |
| 纯 `O12`（致密冷） | 12 | 1.00 | 0.00 | **0.00**（全保温） |

### 3.3 为什么这样设计（理由与可调性）

- **密度管“能不能走”**：低密度分子原子松散、自由体积大，热量有通道；高密度紧堆像保温层。这与“密度=3O+2K+1P”的既有语义一致（O/K/P 都是“聚/散/动”里的大价数堆积元素）。
- **温度管“有多想动”**：常态温度越高，分子内部热运动越强，越容易把能量递给邻居。
- `a, b` 是标定旋钮：`a>1` 让“保温”更极端；`b>1` 让“热”更重要。默认 1/1 最线性、最好解释。
- 若你希望**稠密=导热好**（金属直觉），把 `(1−ρ̂)` 换成 `ρ̂^a` 即可，一行开关；见 §8 待确认问题 2。

## 4. 接触传导与“优先传给效率更高的物质”

### 4.1 接触导率

```
κ_ij = κ0 · sqrt(η_i · η_j) · g_ij          κ0 = 0.35 /tick（默认）
```

- `sqrt(ηi·ηj)`：两端都要“传得动”，取几何平均（任一端 η=0 则完全隔绝）。
- `g_ij` 几何因子（按摆放关系，取自内核 `place`/几何模块）：
  - 共边相邻 **1.00**
  - 共顶点相邻 **0.85**
  - 隔一格（长键 L 型）**0.70**
  - 跨骨架桥（不同骨架单元之间）**0.60**
- 环境（`env`）作为**无限热库**参与：`κ_iE = κ0·sqrt(η_i·η_env)`，默认 `η_env = 0.35`，`θ_env` 为环境常态温度（默认 0.35，可按群系配置 0.15~0.60）。

### 4.2 状态量与更新

- 每个分子有动态温度 `τ_i ∈ [0,1]`（初始 = `θ_i`，即常态温度）。
- 每 tick 热流（能量单位，非温度单位）：

```
q_ij = κ_ij · (τ_i − τ_j)                    # τ_i>τ_j 时 i 主动放热给 j
q_iE = κ_iE · (τ_i − θ_env)
```

- 温度更新（容量越大变化越慢）：

```
C_i = 1 + ρ̂_i                                # 热惯性：密度高、原子多 → 变化慢
τ_i ← τ_i − (Σ_j q_ij + q_iE) / C_i
τ_i ← τ_i + λ · (θ_i − τ_i)                  # 向常态温度回归，λ=0.03
τ_i ← clamp(τ_i, 0, 1)
```

- `λ>0` 的含义：物质是**恒温源**（内部化学平衡不断把它拉回常态温度），所以热流可以长期存在，不会一次就凉透；这正是“常态温度”作为物性的意义。若你要“最终与环境平衡、物性消失”，令 `λ=0` 即可。

### 4.3 优先规则（“优先传给传导效率更高的物质”）

两种等价表达，推荐实现第二种（连续、无抖动）：

1. **硬优先**：每 tick 选出 η 最高的邻居 `j*`，其分得 60% 的外放通量，其余 40% 按 η 比例分给其他邻居；环境永远是一个候选。
2. **软优先（推荐）**：按 `η_j^p` 加权分配通量，`p = 2`：

```
w_ij = η_j^p / Σ_k η_k^p          （k 遍历邻居 + 环境，仅取 τ_i>τ_k 的方向）
q_ij = w_ij · κ_ij · (τ_i − τ_j) · (#方向归一)
```

   - p=1 是普通扩散；p=2 时“高 η 邻居”获得明显更大份额（η 0.8/0.5/0.2 → 权重 0.64/0.25/0.04），即**优先**，但不会只认一个邻居导致僵化。
   - 方向天然正确：只有 `τ_i>τ_j` 才向它放热；若邻居更热则反过来。
   - 若你希望硬性二值优先，`p→∞` 即可退化到 argmax。

### 4.4 稳定性

- 每 tick 单分子 `|Δτ| ≤ 0.15`（限幅，防振荡）。
- 成对交换用同一 `q_ij` 同时更新两侧（守恒，不重复计）。
- 温度场用 `τ` 而非 `T°` 参与传导；`T°` 只作为物性与命名。

## 5. 温度 × 粘性派生能力：热黏合效率 η_ad

### 5.1 公式

```
η_ad(σ̂, θ) = σ̂ · exp( − ((θ − θ*) / w)² )        θ*=0.45，w=0.28，clamp [0,1]
```

- `σ̂`：粘性（胶点数量与强度）——**线性放大**，没有粘性就没有黏合。
- 高斯窗口：温度太低，链段锁死、只能点接触（脆）；温度太高，界面解吸、热运动破坏结合（熔流失黏）；**中间热塑态**黏合效率最高，峰在 `θ*=0.45`。
- `w=0.28`：窗口半宽，约 `θ∈[0.17, 0.73]` 有实质黏合；`w` 越小，热塑窗口越窄、越“挑环境”。

### 5.2 三态（可直接作为新属性档）

| 温度档 | θ 范围 | 名称 | 行为含义 |
|---|---|---|---|
| 冷 | < 0.18 | **冷固型** | 键强高但脆；能固定结构，断裂后不易重接（结晶胶、刚玉胶） |
| 温 | 0.18 ~ 0.68 | **热塑型** | 可反复熔接/自愈、可重排；**器官边界、复制、愈合**的主要来源 |
| 热 | > 0.68 | **熔流型** | 能润湿铺展但不能持键；只能瞬时接触、帮扩散，不帮粘合 |

### 5.3 接入涌现（键强乘子）

界面键强度加一个黏合乘子（不改原有能力矩阵，只做温度调制）：

```
m_ij = 1 + 0.6 · sqrt(η_ad_i · η_ad_j)          范围 1.0 ~ 1.6
w_ij ← w_ij · m_ij
```

- 效果：热塑型分子之间界面更牢（利于 L2 组装体稳定性、L3 边界器官）；冷固型在低温区牢但“断后不重接”（损伤修复率低）；熔流型几乎不加成。
- 与 9 操作的关系：`η_ad` **不是第 10 个操作**，而是“黏（C）”操作的温度调制派生量；同理 `η_cond` 是“传（L）/移（W）”体系的被动输运派生量。

## 6. 与现有 9 操作能力的关系（不冲突的边界）

| 派生量 | 来源维度 | 性质 | 是否进 9 操作评分 |
|---|---|---|---|
| `η_cond` 温度传导效率 | 密度 × 温度 | 被动输运（介质属性） | 否，独立派生标量（参与环境/热流） |
| `η_ad` 热黏合效率 | 粘性 × 温度 | 界面结合调制（黏的温度窗口） | 否，作为键强乘子 |
| 温度档（冷/温/热） | 温度 | 三档标签 | 可进 27 格/属性卡展示 |

- 9 操作（撑/锁/黏/分/捕/断/蓄/移/传）仍是**主动能力**的唯一口径，`η_cond`/`η_ad` 只是“介质/界面”的被动属性，避免能力体系膨胀。
- 若你希望把它们升级为第 10/11 项能力，也可以（见 §8 问题 5）。

## 8. 需要你拍板的 5 个点

1. **温度归一化**：用 `θ=T°/(2N)`（推荐，便于跨分子比较）还是直接用整数度 `T°` 作为温度？
2. **密度—导热方向**：默认“**低密度=导热好、高密度=保温**”（自由体积逻辑）。你若认为稠密应导热好（金属直觉），我改成 `ρ̂^a`（一行开关）。
3. **常态温度是否需要回归**：`λ>0`（推荐）表示物质是恒温源、会持续放热；`λ=0` 表示最终与环境平衡、物性只在初期起作用。
4. **热黏合窗口**：峰温 `θ*=0.45`、窗口 `w=0.28` 是否合适？是否要拆成两种能力（冷固胶 / 热塑胶）而不是一个窗口曲线？
5. **派生量是否升级为能力**：`η_cond`/`η_ad` 保持“派生属性”（推荐，不破坏 9 操作体系），还是升级为第 10/11 项显式能力？
