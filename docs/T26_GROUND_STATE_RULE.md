# T26 · 能量门槛 e=1 + 结构性限制（分子内键型弛豫）

> 条件：键能 S=3、C=2、L=1；每根键断开+重连只需释放 **1** 单位能量。
> 结构性限制（本次补充）：**反应只在单个分子内部发生；键的原子对与多重度不变；只允许键型降级。**
> 统计脚本：`t26_ground_state.py`；数据：`t26_ground_state.json`。

## 1. 规则

### 能量层（e=1）
单根键释放量 = `w_旧 − w_新 ≥ 1`，因此允许的键型变化只有：
- **S → C**（释放 1）
- **S → L**（释放 2）
- **C → L**（释放 1）

不允许：任何"升级"（L→C、C→S）、同级不变（释放 0）。

### 结构层（本次补充的限制）
1. **单分子内反应**：只在一个分子内部发生，不与其他分子交换原子或键；
2. **连接图不变**：键的原子对（哪些原子相连）与键的多重度不变，只改变键的类型；
3. **只降不升**：键型只能沿 S→C、S→L、C→L 降级；
4. 结果必须仍可摆放（几何合法）。

## 2. 直接结果：每个分子有唯一的"基态键型"

对每一根键，按其两端元素类别查"允许键型"，取最弱（w 最小）的那个为基态：

| 元素对类别 | 允许键型 | 基态（最终） |
|---|---|---|
| 聚-聚 | S | **S** |
| 动-动 | C | **C** |
| 散-散 | L | **L** |
| 聚-动 | S, C | **C** |
| 聚-散 | S, L | **L** |
| 动-散 | C, L | **L** |

**规律**：同类元素对保持自己的键型；跨类元素对最终取"较弱一方的键型"（聚-动→C，聚-散→L，动-散→L）。

所以任何分子（原子连接图固定）在自然环境中都会**唯一地**松弛到基态键型：
- 聚-聚键保持 S；动-动保持 C；散-散保持 L；
- 聚-动键：S→C；聚-散键：S→L；动-散键：C→L。

## 3. 为什么"没有新物质"

- 分子式（原子组成）不变；
- 原子连接图（谁和谁成键、多重度）不变；
- 改变的只是键型/几何形态。

按本项目"物质 = 分子式"的目录约定：**没有产生任何新的分子式，也没有新原子组合**；
发生的是同一物质的"键型形态变化"（可理解为物质在自然环境中的老化/松弛）。

> 注意：如果严格到"键型不同 = 不同物质"，那么任何改变键型的反应都会产生"新物质"，
> 此时唯一能不产生新物质的规则就是"完全不反应"。所以必须采用"物质 = 分子式 + 连接图"的约定。

## 4. 统计（≤8 原子，3,931 种物质）

| 指标 | 数值 |
|---|---|
| 总键数 | 29,808 |
| 可降级键（S/C 未到基态） | **10,442（35.0%）** |
| 含至少一根可降级键的分子 | **3,721 / 3,931（94.7%）** |
| 已处于基态的分子 | 210（5.3%） |
| 总能量释放潜力 | **14,450 单位** |

→ e=1 下几乎所有含跨类键的分子都会发生 1~2 次键型降级，然后到达基态；
由于每个键最多降 2 级、能量单调下降，**必然终止**。

## 5. 例子（基态方向）

| 物质 | 反应 | 释放 |
|---|---|---|
| `OK` | 3 根 S → L（聚-散） | 6 |
| `CF` | 1 根 S → L | 2 |
| `LF` | 1 根 C → L | 1 |
| `XA` | 2 根 S → L | 4 |
| `C2A` | 2 根 S → L | 4 |
| `C2W` | 1 根 S → C（聚-动） | 1 |
| `CPA` | 2 根 C → L | 2 |

## 6. 稳定性论证

1. 每根键的键型等级有限（S=3、C=2、L=1），只降不升；
2. 每次反应 E 至少下降 1，E 有下界 ⇒ 反应次数有限，**必然停止**；
3. 停止条件：所有键都已是各自元素对的基态，或几何上无法再降；
4. 因此环境趋向稳定，且**不产生新分子式/新物质**。

## 7. 实现伪代码

```
for molecule:
    for each bond (i,j,mult):
        allowed = 该类元素对允许的键型集合
        ground  = 允许键型中 w 最小者
        if w(current) - w(ground) >= 1 and 几何可放置:
            change bond type to ground (或逐级 S->C->L)
            释放 w(current)-w(ground)
    # 产物：分子式不变、连接图不变、键型为基态
```

## 8. 与之前版本对比

| 版本 | 反应范围 | 新物质 | 稳定性 |
|---|---|---|---|
| T25 纯能量（无结构限制） | 任意 S→L/L 键重连 | 可能有新分子式 | 终止，但骨架被破坏 |
| T24 端帽 + e=2 | 只有端帽 S→L | 少（96.2% 已知） | 终止、骨架保留 |
| **T26 分子内键型弛豫 + e=1** | **分子内任何跨类键降级** | **无新分子式** | **终止，必然到基态** |
