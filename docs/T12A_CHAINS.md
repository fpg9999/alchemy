## 1. 定义与算法

### 1.1 单步反应

沿用项目权威口径：`R(A,B)` 把 A、B 的原子合并投锅，按规则 1~9 逐根贪心成键；所有原子键数填满且每个产物分子可用 `pot_v2.embed_all2` 严格摆放才成功。产物 = 分子式多重集。

**关键定律（T11）**：结果只由总向量 `vA+vB` 决定。故引擎用 `F(v)`（向量→产物多重集）缓存，既省算力，也是幂等性的理论根源。

### 1.2 链语义

状态 = 当前分子多重集，只跟踪“载体”分子 X（其它分子视为副产物/旁观者）。每步：

```
P_n = F(vX_n + vR)          # X_n 与试剂 R 投锅
X_{n+1} = pick(P_n)         # 从产物中按策略选下一载体
```

总向量每步严格增加 vR，因此链**单向增长**，不存在真正的状态回环；但载体序列（大小有限：元素子集有分子封顶）可以出现**有限周期 = 振荡**。

### 1.3 两种模式

| 模式 | 定义 | 本报告用途 |
|---|---|---|
| (a) 固定试剂链 | 试剂 R 固定，X_{n+1}=pick(F(X_n+R)) | §3 链长/饱和统计 |
| (b) 自由模式 | 每个载体 X 记录“与任一试剂 R 反应后可选的下一步分子 Y” | §4 载体转移图/振荡 |

载体选择策略：`max`（最大分子，平局取字典序小者，默认）、`min`、`first`、`random`。

### 1.4 终止方式

| 终止 | 含义 |
|---|---|
| FAIL | 投锅失败：价数配不平（剩键）或产物摆放失败/超出搜索预算 |
| INERT | `F(X+R)=={X,R}`：完全不反应（惰性） |
| STABLE | 下一载体 = 当前载体：载体不动点，产物混合稳定 |
| CYCLE | 载体序列回到更早载体：振荡（周期≥2） |
| OVERSIZE | 投锅总原子数超过 `--max-atoms`（保护性截断） |
| MAXSTEP | 达到步数上限 |

### 1.5 参数与近似

- `--max-steps=24`、`--max-atoms=30`、`--embed-budget=100000`、策略 `max`。
- 摆放校验是**有预算的**（`embed_mol2(max_nodes=...)`）。超预算记为 FAIL，这是保守近似：极少数真正可摆放的大分子会被判失败（详见 §9 局限与 bug 记录）。
- 链统计中所有“产物”均已通过 `pot_all.simulate` + 预算内 `pot_v2.embed_all2` 双重校验。

## 2. 幂等性：产物全部再投锅是否不变？

### 2.1 证明草稿（定义直接推出）

**命题 F 幂等**：若 `F(v)=P`（成功），则把 P 的全部原子重新投锅仍得 P。

证明：逐条拆开。

1. `simulate` 的输入只是一袋原子（元素多重集），输出的成键过程只依赖元素计数向量；T11 的全量数据（15,400 对无三价 + 5,075 对交叉 + 435 对聚素）已验证：总向量相同 ⇒ 结果相同。因此可把一次反应写成函数 `F(v)`。
2. 产物 P 的原子总向量仍是 v（反应只成键、不改变元素计数）。
3. 把 P 全部再投锅，输入向量仍是 v ⇒ 按 1 得 `F(v)`，即 P 本身。∎

**推论（单分子自复现）**：若 P 中某分子 m 的向量为 v_m，则 m 单独投锅得 m。（目录 82,961 条“一锅自复现”即此性质。）

**失败的处理**：失败时没有产物，故“再投锅”无定义；失败是**吸收态**：同一投料无论原子顺序/分解方式如何都失败（数据验证见 2.2）。

### 2.2 数值验证

- 测试向量 **127** 个（随机向量、目录物质、种子×试剂、已知不相容对、奇价数），覆盖成功 97 个、失败 30 个。
- 成功向量中，产物再投锅 === 原产物：**97/97**。
- 同一投料把原子表随机打乱后重新 simulate：结果不变 **97/97**。
- 每个产物分子单独投锅 = 自身：**97/97** 个向量通过（共 209 次单分子检查）。
- 同总向量的另一种分子对分解：结果相同 **23/23**。
- 失败例（应保持失败）：`O2XC2LAF`（剩键/价数奇偶）；`O2XWKF`（剩键/价数奇偶）；`OWA`（剩键/价数奇偶）；`OCF`（剩键/价数奇偶）；`OXC2P2LKF2`（剩键/价数奇偶）。

结论：幂等性在定义层成立，数值上 100% 通过；这是“一锅反应不动点”与“反应只由总向量决定”的同一枚硬币的两面。

## 6. 有趣现象

### 6.1 自催化（产物含投入物之一）

**单步反应中未发现自催化**：扫描 58564 对（≤4 原子池）+ 自由模式 133342 对，产物含投入物之一的**非惰性**反应为 0。

原因（结构性）：产物中若出现与投入物 A 同式的分子且反应非惰性，A 必须与 B 发生跨分子键；而 simulate 只加键不断键，A 的原子最终若仍单独成 A 分子，就不可能曾与 B 成键——于是 B 只能独立反应成自身，整锅退化为惰性 `{A,B}`。因此“A+B→A+…（B 被转化）”在单步内被“只加键不断键 + 每原子价满”排除；真正的自催化只能在**多步循环**中出现。

**多步催化/自催化（循环尺度，A 每轮再生）**：

- 催化剂 `C2`（跨类）：`C2 + O2 → O2C2`；`O2C2 + A3 → C2 + O2A3`；每轮净：`O2A3`；20 轮后副产物 `O2A3×20`
- 催化剂 `C2`（跨类）：`C2 + O2C2 → O2C4`；`O2C4 + A2 → C2 + OCA×2`；每轮净：`OCA×2`；20 轮后副产物 `OCA×40`
- 催化剂 `C2`（跨类）：`C2 + O2C4 → OC3×2`；`OC3 + A2 → C2 + OCA2`；每轮净：`OC3 + OCA2`；20 轮后副产物 `OC3×20 + OCA2×20`

## 7. 规律清单

1. **向量决定律**：`R(A,B)=F(vA+vB)`，与分子式、原子顺序无关（数值：同向量不同分解结果相同）。
2. **幂等律**：成功反应的产物全体再投锅复原原产物；失败是吸收态。
3. **单向增长律**：固定试剂链每步总向量增加 vR（单调），链必须终止于有限步；链长上界 = 该元素子集上的物质数（有限封顶的直接推论）。
4. **快速饱和律**：链平均 1~4 步内达到不动点/惰性；载体尺寸的每步平均曲线迅速走平（图 `t12a_saturation.png`）。
5. **增长-饱和律**：单产物增长链可线性长大，但在 14~17 原子附近自然停止（下一步 simulate 开始分裂成多个产物，净增长中断）；更长的复合链可达 30 原子，但最终仍落回惰性小分子混合。
6. **截断而非封顶**：链统计中 30 原子是保护阈值 `--max-atoms`，与元素子集分子封顶（最大 97）无关；自然封顶远小于目录封顶。
7. **惰性主导**：固定试剂链中 INERT 占 79.6%——多数“投料对”根本不反应（原样返回），这是链快速停止的主要原因。
8. **循环需副产物**：单产物链不可回环；允许副产物时 2-环由催化剂 A 反复再生，每轮净反应固定、副产物线性累积，可无限延续。
9. **振荡有限**：载体序列周期出现（CYCLE 终止），因元素子集分子封顶 + 总向量单调，周期状态数有限。

- 已知近似 / 局限：
  1. **试剂抽样**：链统计用全池 3931 个 natoms≤8 物质的分层随机抽样 1000 个（全部 natoms≤4 的 242 个 + 其余随机），并在 §3.6 用**全池 3931** 复算了单产物增长链。抽样比例 25%，结论按此口径陈述。

  4. **种子去重**：29 聚素 + 175 无三价名单共 204 条，其中 6 个纯 X/C 物质同时属于两名单（C2、X2、XC2、X2C2、X3、X3C2）；按向量去重后 198 个唯一种子。
