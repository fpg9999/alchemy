**强度 Ⅰ/Ⅱ/Ⅲ**：`s = Σ 元素权重 × (该元素占比) × 2.0 + 家族签名加成`，阈值 `≥2.4→Ⅲ / ≥1.2→Ⅱ / ≥0.5→Ⅰ`。

## 4. 小分子形态（m01664）

小分子没有多器官，形态 = **元素字形 + 键带**：

- 秩O 三角形、势P 圆形、沌K 正多边形（角数随 K 数增多）、晶X 尖六边形、流W 圆角六边形、气A 虚线六边形；
- 冰C 菱形、电L 小圆点、焰F 小三角形（端帽形态）。
- 键带用 S/C/L 三色粗细区分（短键刚性、角键铰接、长键软连），重键画平行线。

例：`OXC` = 三角(秩)+菱形(冰)+六边(晶)，C 角键把三者折成一个钩状体 → **晶态·刚性 小分子·三原子折线体「结晶·致密」**；
`F2` = 两个小三角以 L 长键相连 → **晶态·松散 双原子体「分解·荧光」**；`O2X2` = 两个三角 + 两个六边交替 → 短链体。

## 5. 与"器官/物种"的关系

- 器官（骨架块）→ 长出具体形态（28 库之一）→ 该形态的标签决定它偏向哪些能力；
- 物种卡上并列显示：**器官编号 / 元件组成 / 实际长成的形态 / 该器官主能力 / 还能长成的另 2 种形态**；
- 物种名 = `状态·软硬 + 生命类 + 主体形状 + 「top2 能力」`。

## 6. 局限（未决）

- 3 种可长成形态是按"元素组成 + 块编号旋转"选的，还没有和**实际几何位置**（哪个器官朝外/受力）耦合。
- 刚性/松散/粘性仍是暂行规则（小分子页用键型占比），等正式分类规则上传后替换 `t71_abilities.softness()`。
- 能力强度阈值是手工标定的，样本换成小分子后需要重新校准。
- 形态是程序化线稿，还没有做质感/光影统一。
