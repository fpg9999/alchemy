# 相分类规则（PHASE RULE）

> 定稿：2026-11-17（第二版：取消第四相，并列改用元素优先级裁决）
> 实现：`alchemy/phase.py`　测试：`tests/test_phase.py`

---

## 1. 规则

物质由三个价数层构成，每层恰好三个元素，因此可以做成三条**并列、互不冲突**的轴：

| 轴 | 三元组（按优先级排列） | 取值 |
|---|---|---|
| **骨架** skeleton | 秩 O > 沌 K > 势 P | 秩 / 沌 / 势 |
| **状态** state | 晶 X > 气 A > 流 W | **固 / 液 / 气** |
| **能量** energy | 冰 C > 焰 F > 电 L | 冰 / 焰 / 电 |

**判据**：该层三元素里**原子数最多者**决定该轴取哪个相。

**并列裁决**：最大值被多个元素同时取得时，按**元素优先级**取值：

```
聚素（O / X / C） > 散素（K / A / F） > 动素（P / W / L）
```

这就是反应规则 9 的 `RULE9_PRIORITY = O > X > C > K > A > F > P > W > L`
（见 `pot_v4.py` / `alchemy/core/reactor.py`），**直接复用，不另定一套**。

**全零**：该层三元素都为 0 时同样走这条裁决（等价于"三者全并列"），
所以每个物质在每条轴上**永远有确定取值**。

于是：

- **没有第四相**。原设计"并列 → 抵消 → 第四相"已被这条裁决取代；
- 物质空间 = 3 × 3 × 3 = **27 型**；
- 每条轴只依赖元素计数向量 → 纯函数、与结构无关、可缓存。

## 2. 为什么"和反应规则一致"是对的

反应引擎的贪心 key 在完全并列时用规则 9 裁决；这里在"该层元素数并列"时用同一条优先级，
意味着**相分类与反应规则偏好同源**：更"聚"的物质在反应里更容易先成键，也更优先决定自己的相。
两条规则不会互相打架，也不会出现"反应规则认为是 A、相分类认为是 B"的矛盾。

## 3. 全目录实测（84,225 条）

### 3.1 单轴分布

|---|---|

| 能量 | 冰 47.82% · 焰 28.66% · 电 23.52% |

三主相都落在 23%~48% 之间——没有退化相，也没有一相独大。

**没有空型**，对做图鉴分类很友好（每一型都能找到足够样本）。

前几名：

|---|--:|--:|
| 势 / 固 / 冰 | 5,853 | 6.95% |
| 秩 / 固 / 冰 | 5,629 | 6.68% |

| 势 / 气 / 冰 | 4,579 | 5.44% |
| 沌 / 气 / 冰 | 4,034 | 4.79% |

### 3.3 并列裁决有多重要

| 轴 | 靠裁决得出取值的物质 |
|---|--:|
| 骨架 | 769（0.91%） |
| 状态 | 18,660（**22.15%**） |
| 能量 | 24,740（**29.37%**） |
| 至少一条轴靠裁决 | 38,986（**46.29%**） |
| 三条轴全部无并列 | 45,239（53.71%） |

**结论：这条裁决规则是承重规则，不是边缘情况。** 46% 的物质至少有一条轴靠它定值。

### 3.4 结构性后果：动素永远不会赢得并列

并列时各元素胜出的次数（全目录）：

| 轴 | 并列 → 胜出者 |
|---|---|
| 骨架 | 秩 593 · 沌 1 · **势 0** |
| 状态 | 晶 10,284 · 气 4,383 · **流 0** |
| 能量 | 冰 10,321 · 焰 4,308 · **电 0** |

原因很简单：三条轴各自是"一聚 + 一散 + 一动"，任何并列只要含动素，就必然也含优先级更高的
聚素或散素，动素永远排在后面。

**所以 势 / 液 / 电 只会由"严格多数"产生，绝不会由裁决产生。**
这是可预测的、也是可解释的（动素是"连接/运动"元素，本来就该是少数派），
但如果设计上希望液/电更常见，只能靠调整物质构成，不能靠改裁决顺序。

## 4. 对现有五个群系的后果（重要）

按物种数统计：

| 群系 | 状态分布 | 能量分布 | 骨架分布 |
|---|---|---|---|
| T55 纯聚素 | 固 9 | 冰 9 | 秩 9 |
| T57 29聚素 | 固 4 | 冰 4 | 秩 4 |
| T63S4 K滴定 | 固 11 · 气 3 | 冰 11 · 焰 3 | 沌 8 · 秩 6 |
| T62B 等量价数 | 固 38 · 气 5 | 冰 36 · 焰 6 · 电 1 | 秩 22 · 势 20 · 沌 1 |
| T59B 三价最多 | 固 50 · 气 15 · **液 2** | 冰 54 · 焰 11 · 电 2 | 势 57 · 秩 10 |

**问题：这五个群系几乎没有"液"，气也很少。**

- 46 种候选物质里：固 42 种、气 4 种、**液 0 种**；
- 121 种并集里：流（W）主导的只有 2 种（1.7%）。

原因不是规则，而是**投料比例**：这五组实验里流素 W 的含量偏低，且平局时晶 X 会赢。

**若要做液体/气体地形，需要单独设计投料**——提高 W 的占比（并让 W 严格多于 X），
而不是改裁决顺序。全目录整体其实有 27.99% 的"液"，说明物质空间里液体是充足的，
只是这五组配比没采到。

## 5. 一个需要你确认的约定

**"该层元素全为 0" ≠ 物理推断，而是约定。**

例如 `LF`（电 + 焰）、`CF`、`OK`、`F2` 都没有二价原子，状态轴三票全 0，
按规则裁决成 **晶 X → 固**。46 种候选里有 **8 种**属于这种情况。

这在实际使用中通常没问题（双原子盐当固体是合理的），但它严格来说是"规则约定"而非"物质属性"。
如果要改，两个备选：

1. **保持现状**（全零 → 聚 → 固）：简单、确定、无遗漏。（当前实现）
2. **标记为"无二价层"**：仍然给 固，但额外打一个 `state_from_convention=True` 标记，
   便于以后玩法上区别对待（例如"这类物质可被炼金术直接当反应物"）。

实现里已经保留了区分能力：`phase_of()` 返回的 `axes[key]['tie']` 为 True 且
`counts` 全为 0 时，就是"约定值"。

## 6. 用法

```python
import alchemy.phase as F

F.phase_of("OXC")
# {'skeleton': 'O', 'state': 'X', 'energy': 'C',
#  'id': 'O/X/C', 'names': ('秩','固','冰'), 'label': '秩·固·冰', ...}

F.phase_id("O2XP2WK2A2")     # 'O/A/C'  -> 秩·气·冰
F.phase_names("LF")           # ('秩','固','焰')  状态轴靠"全零→聚"约定
F.agree_axes("OXCPWKA")       # 3  -> 三条轴都发生过并列裁决

F.distribution(["OXC", "LF"])              # 27 型分布
F.distribution(["OXC", "LF"], axis="state")  # 单轴分布
```

# 附：v2 方案（循环压制 + 第四相）

> 2026-11-17 第二版。实现为 `mode="cycle"`（默认），v1 保留为 `mode="hierarchy"`。

## A.1 规则

1. 该层原子数**严格最多**者胜出；
2. **两两并列**（恰好两个同为最大值）→ **循环压制**：

```
聚 > 散 > 动 > 聚        （聚压散、散压势、势压聚）
```

3. **三者全等** → **第四相**（`〇`，名字待定，占位为"无相"）。

循环压制是石头剪刀布式三循环，**没有绝对高低**：动素可以赢聚素（势压秩、流压晶、电压冰）。
这是它与 v1 层级制（聚>散>动，动素永远赢不了并列）的根本区别。

## A.2 全目录对比（84,225 条）

| 轴 | v1 层级 | v2 循环（全零=第四相） | v2 循环（全零=无该层） |
|---|---|---|---|
| 骨架 | 秩32.4% 沌31.7% 势35.8% | 秩31.5% 沌31.7% 势36.4% ｜第四相0.30% | 同左 ｜第四相0.10% 无层0.21% |
| 状态 | 固41.4% 气30.6% 液28.0% | **固29.4% 气30.6% 液33.5%** ｜第四相6.42% | 同左 ｜**第四相1.68% 无层4.74%** |
| 能量 | 冰47.8% 焰28.7% 电23.5% | **冰28.7% 焰28.7% 电28.6%** ｜第四相14.02% | 同左 ｜**第四相2.01% 无层12.00%** |

**v2 最大的好处：三主相变得几乎均匀。**

- 状态轴极差从 13.4 个百分点缩到 **4.1**；
- 能量轴极差从 24.3 个百分点缩到 **0.1**（几乎完美三分）；
- 液从 28.0% → **33.5%**、电从 23.5% → **28.6%**、固从 41.4% → 29.4%，
  不再被"聚优先"压成一边倒。

**v2 的代价：必须处理第四相。** 状态轴 6.42%、能量轴 14.02%（全零也算第四相时）。

## A.3 第四相的一个关键拆分

三元素全等有两种来源，必须分开：

| 来源 | 状态轴 | 能量轴 | 骨架轴 |
|---|--:|--:|--:|
| 真·三者等量（>0） | **1.68%** | **2.01%** | 0.10% |
| 该层全零（没有这一层的元素） | 4.74% | 12.00% | 0.21% |
| 合计（= 字面"全相等"） | 6.42% | 14.02% | 0.30% |

**结论：所谓"第四相"里，82% 其实是"该层没有元素"，不是"三者制衡"。**
例如 `LF`（电+焰）根本没有二价原子，把它叫"第四相"很别扭。

因此 `absent_mode` 提供三种处理：

| `absent_mode` | 该层全零时 | 适用 |
|---|---|---|
| `"fourth"`（默认） | 也算第四相 `〇` | 严格按"全相等→第四相"的字面读法 |
| `"poly"` | 按聚优先裁决（v1 约定） | 保证每个物质都有完整三相，便于玩法 |
| `"none"` | 记为"无该层" `—` | **推荐**：把"缺席"与"制衡"彻底分开 |

## A.4 对候选物质的影响（46 种，v2）

状态分布从 v1 的「固 41 · 气 5 · 液 0」变成「固 20 · 液 6 · 气 5 · 第四相 15」。

- **液从 0 变 6**：因为 `X+W` 并列时动（流）压聚（晶），终于有了液体；
- **第四相 15 种**：其中多数是"该层全零"（如 `LF` `F2` `CF` `L2`），
  换成 `absent_mode="none"` 就变成"无该层"而不是"第四相"。

工作表 `data/biomes/candidates/_union.csv` 同时给出两列：
`相型`（默认规则）与 `相型_无层单列`（`absent_mode="none"`），
外加 `第四相来源` 列标明是"全零"还是"等量"。

## A.6 虚态（第四相）的定义

### 一句话

**虚态 = 不占据空间的相。** 它悬浮在空间里，不与任何实体产生力学互动（固液可从它穿过），
但**仍然参与化学反应**。

### 为什么它是"相"而不是"没相"

把物态轴理解成**空间占位强度**的四个梯度，四相就自然成一列：

| 相 | 空间占位 | 力学互动 | 位置 | 典型表现 |
|---|---|---|---|---|
| **固** | 强（排他、不可压缩） | 极强（刚性支撑、阻挡） | 固定 | 晶体、矿石、地形 |
| **液** | 中（排他、近乎不可压） | 强（黏性、表面张力、浮力） | 流动 | 水、泥浆、熔融物 |
| **气** | 弱（排他、**可压缩**） | 弱（碰撞、压力、阻力） | 自由 | 雾、烟、大气 |
| **虚** | **零（不排他）** | **无** | 无位置概念 | 幽灵、场、灵质 |

所以"虚"不是"没有相"，而是占位强度轴的**第 4 个档位（= 0）**。

### 气与虚的区别（核心问题）

| 维度 | 气 | 虚 |
|---|---|---|
| 是否占据体积 | 是（**会被排开**、可被压缩） | **否**（可与固体占据同一格） |
| 穿过它时的感受 | 有阻力、有浮力 | **完全无阻**，也不产生浮力 |
| 压力 | 有（可推动物体、可被抽走） | **无** |
| 反应触发方式 | **接触/碰撞** + 恒素注入 | 不碰撞 → 只能靠**共位/重叠** + 恒素注入 |
| 物态可变性 | 固定（物态由组成决定，**不随温度变化**） | 固定（同上） |
| 重力/分层 | 有（密度分层、上浮） | 无（不受重力） |
| 容器 | 可密封约束 | **不可容纳**（穿透一切） |
| 可见性 | 半透明可见（雾/烟） | 不可见；只能靠反应痕迹或特殊感知发现 |

**最硬的一条判据：是否占有体积。**
固体丢进气里会被气排开一部分（有阻力、有浮力）；丢进虚里什么都不会发生（既不减速也不上浮）。
用这条就能在实现上明确分开两者，不需要靠"看起来像不像"。

**第二条判据：反应怎么触发。**
气态反应靠碰撞（现有粒子引擎 `t55_kinetic_env.py` 就是这个模型）；
虚态**不参与碰撞**，所以它的反应必须由"共位"规则触发——同一格里存在虚态物质与实体，
就判定一次反应。这也是为什么"它不与物质互动，但仍能反应"在实现上是自洽的。

### 实现要点（给引擎）

1. 碰撞检测跳过虚态（不参与动量交换、不参与 capped 计数）；
2. 反应判定用"共格"而不是"接触"（格子重叠即视为接触）；
3. 地图生成时虚态**不占格**，应作为区域的**附加层**（overlay），而不是地形块；
4. 采集/搬运：物理手段无效，只能靠化学（反应）或炼金术捕获。

### 虚态的两个来源（可作子标签，不改变主分类）

| 来源 | 含义 | 例 |
|---|---|---|
| **层全零** | 根本没有二价连接层，只有骨架 + 端帽（"裸核"） | `OK` `LF` `CF` `F2` `L2` |
| **非零全等** | 晶/气/流三种连接等量，无主导模式（"三相均势"） | `OXCPWKA` `OXCPWK` `O2XP2WK2A2` |

两者按决定同归虚态；数据里已记录区分（`_union.csv` 的 `第四相来源` 列）。
若要给虚态做次级玩法（裸核更"实"、均势更"空"），这两个来源是现成的切分点。

# 附二：概念族 = 骨架力学形态（刚体 / 胶体 / 软体 / 晶体）

> 2026-11-17。三价层不再决定"生命形式"，改为决定骨架的**力学形态**。

## B.1 依据：三价主导元素决定骨架键型

三价元素分属聚/散/动，而骨架键是**跨类**成键，允许键型互不相同。实测（1500 条抽样，
只统计三价-三价骨架键）：

| 主导 | S 短键 | C 角键 | L 长键 |
|---|--:|--:|--:|
| 秩 O(聚) | **60.2%** | 25.6% | 14.2% |
| 沌 K(散) | 19.7% | 22.0% | **58.2%** |
| 势 P(动) | 24.1% | **61.8%** | 14.2% |
| 第四相 | 33.3% | 33.3% | 33.3% |

**这是结构必然**：秩(O) 是唯一"跟另两个三价元素都能成 S"的（O-K 允许 S|L、O-P 允许 S|C）；
沌(K) 唯一两边都允许 L；势(P) 唯一两边都允许 C。每个主导元素恰好是它两个配对的**公共键型**。

## B.2 映射

| 相 | 主导 | 骨架键型 | 力学表现 |
|---|---|---|---|
| **刚体** | 秩 O(聚) | S 短键 60% | 硬、不弯、受击只断 |
| **胶体** | 沌 K(散) | L 长键 58% | 松散、分散、可吸附悬浮 |
| **软体** | 势 P(动) | C 角键 62% | 铰接、可弯、形变不断 |
| **晶体** | 第四相 | 三键各 1/3 | 对称、无主导机制（稀有种） |

# 附三：二维表定稿（2026-11-17 修订）

概念轴不再只是"外观"，而是给物质一套**物理属性**：硬度 / 密度 / 黏聚 / 是否受重力。
体积固定为 1 m³ 单位方块，所以"质量"直接等于密度。

## C.1 概念 ↔ 物理属性

| 概念 | 硬度 | 密度 | 黏聚 | 受重力 | 一句话 |
|---|---|---|---|---|---|
| **刚体** | 高 | **最高** | 极强 | 是 | 硬而致密，不弯只断 |
| **晶体** | **最高（脆）** | 高 | 强但脆 | 是 | 有序、易解理、稀有 |
| **胶体** | 低 | 中 | 中（可塑） | 是（缓慢） | 黏滞、可塑、吸附 |
| **软体** | 中（颗粒硬） | 低 | **极低（松散）** | 是（会塌落） | 松散、流动、无定形 |

## C.2 定稿二维表

| 概念＼物态 | 固 | 液 | 气 | 虚 |
|---|---|---|---|---|
| **刚体** | **金属、岩石**<br>硬、重、承重 | **液态金属**<br>高密度，沉底 | **气湖/沉气**<br>成块、有界面、不混合 | **力场**<br>吸引/排斥；引力场、磁场 |
| **晶体** | **宝石、水晶**<br>最硬、解理 | **卤水/盐泉**<br>液态晶体种子，干涸成矿 | **晶尘/钻石尘**<br>有序棱角微粒悬浮 | **虚晶**<br>裂玻璃质感、特殊效果 |
| **胶体** | **泥土、杂项**<br>软、可塑 | **蜂蜜、泥浆**<br>高黏，流动极慢 | **雾、烟、霾**<br>无序微粒悬浮 | **减速域**<br>穿过即减速 |
| **软体** | **沙子、沙砾**<br>松散、塌落 | **水**<br>低密、易流 | 空气、清风<br>自由流动 | **无特殊效果**<br>平凡虚质，可直接穿过 |

## C.3 分层（把密度变成可见的地层）

同一竖直空间里，物态相同的物质按密度自然分层：

- **液**：液态金属（最底）→ 泥浆/蜂蜜 → 水 ≈ 液晶（最上）
- **气**：重气（积于盆地）→ 雾烟 → 空气（最上）
- **固**：不流动，但破坏后会按粒子的"概念"决定塌落行为——
  软体固（沙）会流沙式塌落，胶体固（泥土）缓慢塌陷并保持形状，刚体固（岩石）不塌，
  晶体固（宝石）碎裂成有棱角的块。

## C.4 虚态四格 = 四种"场"

虚态不占空间、无碰撞，所以它只能是**场**。四个概念相正好对应四种场作用：

| 虚态 | 作用 | 机制 | 备选 |
|---|---|---|---|
| **刚体·虚** | **施力** | 对物体施加矢量力（吸引/排斥）；引力场、磁场即此 | — |
| **胶体·虚** | **耗散** | 标量阻尼：穿过即减速，不改变方向 | — |
| **软体·虚** | **无作用** | 无任何特殊效果，与其他软体物质一样平凡；可穿过、仍可反应 | — |
| **晶体·虚** | **感知** | 不改物理，改观感与状态：画面裂玻璃、空间感错乱、特殊增益 | — |

虚态只有 **刚体（力场）/ 胶体（减速域）/ 晶体（虚晶）** 三种带特殊效果，
**软体是无效果的那一种**——虚态里的"默认背景介质"。

四者构成"施加力 → 耗散力 → 无作用 → 扭曲感知"的阶梯。

## D.3 能量轴与恒素无关

**能量元素只影响真实温度，不影响恒素密度，也不引起物态相变。**
反应门槛由恒素密度决定（见附五），与能量相无关。所以：

- "冰相物质能冻结中间态"这个说法**不成立**——冻结化学要靠降低局部恒素密度，不是降温；
- 能量相的玩法定位是**现象层**：热（燃烧/灼烧/高温）、冷（结霜/冻伤/低温）、
  电磁与光（导电/发光/磁性/信号）、惰性（绝缘/绝热）。

## D.4 对候选群系的提醒

46 种候选物质里 **无属性 20 种（43%）**、冰 19、焰 5、电 2。

原因还是配比：九元素等摩尔产物往往没有 1 价端帽，能量轴三元素全零 → 无属性。
所以现有五个群系在能量上是"大部分惰性"。若要做"火山区/冰原/雷暴区"，
需要专门设计含大量 F / C / L 的配比。

## D.5 虚态软体的定稿（2026-11-17）

**虚态软体 = 无任何特殊效果**，与其他软体物质一样平凡：
可穿过、不占空间、不施加任何场作用，但仍可参与化学反应。
它是虚态里的"默认背景介质"——虚态只有 **刚体（力场）/ 胶体（减速域）/ 晶体（虚晶）** 三种带特殊效果的，
软体是"什么都没有"的那一种。

# 附五：恒素（Element E）——第十种元素

> 2026-11-17 定稿。恒素的一切都**单独讨论**，不进入三轴分类。

## E.1 本体

| 项 | 内容 |
|---|---|
| 位置 | 元素周期表**最中心** |
| 价数 | **0 价** |
| 特殊作用 | **影响周期表距离规则**（具体形式待定） |
| 是否参与反应 | **否** |
| 是否适用三轴 | **否**——它没有概念族/物态/能量之分，不进入 64 型 |

## E.2 它在化学里的角色：打破能垒

**这个世界的物质没有"不饱和"状态——所有物质的价数都是填满的。**

两个饱和分子要发生反应，必须先从外部**注入恒素**，用它打断已经形成的键
（相当于现实化学里的"克服活化能垒"）。断键之后重新成键，刚被借用的恒素
**逸散回空间**。

所以恒素是"**借出—归还**"，不是被消耗：

```
注入恒素  →  打断旧键  →  重组  →  新键形成  →  恒素逸散回空间
        （净消耗 = 0）
```

## E.3 守恒与分布

- **总量守恒**：任何过程都不产生/消灭恒素；
- **区域浓度不同**：有的地方富集，有的地方稀薄；
- 所以恒素不是"燃料"（不会被烧掉），而是**化学活跃度**：
  ρ_E 高的地方化学在跑，ρ_E 低的地方化学冻结。

支撑这条守恒的是一个可验证的定理：**完全饱和态的总键级 = Σ价数 / 2**，
只由元素组成决定，与排列无关（全目录 84,225 条实测 **84,225/84,225 成立**）。
因此任何完全反应前后的净成断键数相抵 → 净恒素收支恒为 0。
这也解释了"**把完全反应的产物重新升温到 1000 度，结果不变**"：
端点是净恒素中性的**不动点**，没有可动的欠价数，再借多少恒素也没用。
反应停止是**规则限制**（到达不动点），与温度/恒素量无关。

## E.4 世界的循环

既然总量守恒、净消耗为 0、而浓度有差异，那么"循环"指的就是
**恒素在空间中的重新分布**：

```
高富集 → 化学剧烈 → 扩散稀释 → 化学冻结 → 重新富集 → 再次活跃
```

所以"要不要提供稳定获取恒素的手段"这个问题，正确的提法是：
**什么机制让恒素重新富集？**（而不是"从哪开采"，因为没有任何物质储存恒素）

候选：

1. **地质泵**：深处恒素富集，缓慢向外渗流（最自然，不破坏守恒）；
2. **恒素透镜**：虚态晶体一类物质把稀薄区的恒素聚拢（设定上的奇迹物质）；
3. **主动浓缩**：文明/生命用技术或生物过程浓缩恒素（最有玩法价值）；
4. **大爆炸残余**：一次性库存，只出不进（不适合长期循环）。

## E.5 相变不由温度决定

- **物态只由组成（X/A/W）决定**；
- 物质**不会因为加热而熔化、不会因为冷却而结冰**；
- 要改变物态，只能改变组成 → **必须发生化学反应**；
- 推论：物质表是**静态**的——一张表管到底，不需要随温度变化。

## E.6 真实温度还剩什么作用（待定）

真实温度仍然存在（由能量元素驱动），但不驱动相变。它可能影响：

- 燃烧/灼烧/冻伤等**伤害与状态效果**；
- 光照、颜色、视觉表现；
- **反应速率**（是速率，不是门槛——门槛归恒素）；
- 生物的生存条件。

> 这一项还没定，是能量轴落地前需要补的一块。

## E.7 对已有实验的重新解读

| 实验参数 | 重新理解 |
|---|---|
| `T0=1000`、`T_end=0` | **恒素密度从高稀释到近零**（不是 1000°C） |
| "退火" | 恒素场的稀释过程 |
| 反应停止 | **到达不动点**（规则限制），不是"冷了所以停" |
| 再加热 1000 | 完全反应端点**不变**（E.3 的定理） |
| T58 的大量物种 | **不是"未饱和"**（不存在不饱和），而是被 cap 截断、碰撞稀疏导致的**未反应**；这些分子依然是饱和的 |
| 亚稳物 | 也是**饱和**的，只是不是它自己组成的**不动点**（所以会自分解到不动点） |
