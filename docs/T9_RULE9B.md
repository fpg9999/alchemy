# 规则 9（用户方案）验证：按“结合后大类更多”裁决——能消歧吗？

> 日期：2026-11-12　工作目录：`G:\AI work\deepseek\work1\alchemy`
> 待验证规则（用户提出）：
> **若规则 1~8 仍并列，则优先选择「结合之后分子式包含的大类（聚/动/散）更多」的那一对分子结合。**

---

## 0. 结论

1. **有效但不够**：该规则大幅减少了并列歧义（T=6 完全消除；T=7/8/9 减少约 46%~82%），
   但**没有完全消除**。
2. **残余歧义的具体形态**：剩下的分歧都发生在「并列候选对的**大类并集数相同**」时——
   例如两个 C-A 对、多个 W-K 对、O-K 对、X-K 对，它们结合后都只含 2 个大类，
   规则无法再区分，后续仍可能出现两种产物分子式多重集。
3. 若目标是**完全消歧**，需要在这条规则之后再补一条"对同一大类并集内的候选做规范裁决"
   （例如之前提出的规范决胜：按加键后状态的规范形/规范原子编号选最小者），
   或在游戏定义里接受这 ~0.3%~0.8% 的残余歧义。

---

## 1. 规则实现

在规则 1~8 的 key 之后追加一项：

```
key += ( -|CAT(comp_i) ∪ CAT(comp_j)| , )
```

其中 `CAT(x)` = 组分 x 中出现的元素大类集合（聚/动/散），
`|·|` = 并集的大类数量（1~3）。该值越大越优先（即取负值后越小越优先）。

实现：`t9_rule9b.py`（穷举并列 DFS）、`t9_rule9b_rand.py`（随机并列重跑）、
`t9_rule9b_randscan.py`（随机采样统计）。

---

## 2. 验证结果（T=3..9，全部 9 元素投料）

用"每个投料随机并列跑 10 次，产物分子式多重集若出现 >1 种则判为仍有歧义"统计
（基线 = 规则 1~8；新规则 = 规则 1~8 + 用户规则 9）：

| T | 偶价数投料 | 基线歧义 | 加用户规则 9 后歧义 | 残余比例 |
|---|---|---|---|---|
| 3 | 73 | 0 | 0 | — |
| 4 | 267 | 0 | 0 | — |
| 5 | 609 | 0 | 0 | — |
| 6 | 1,561 | 9 | **0** | 0% |
| 7 | 3,123 | 41 | **22** | 0.70% |
| 8 | 6,582 | 123 | **22** | 0.33% |
| 9 | 11,938 | 240 | **89** | 0.75% |

（T=9 基线 240 为随机采样估计；早前 t7 穷举 DFS 给出 ≥200，量级一致。）

- **T≤6 完全消除**（9 → 0）。
- T≥7 仍有残余（约 0.3%~0.8%），且**大锅例子 T=29、T=33 仍然歧义**
  （各自仍能跑出 2 种产物分子式多重集）。

---

## 3. 残余歧义的具体例子

### 3.1 T=7：`C1 L1 A3 F2`（向量 `[0,0,1,0,0,1,0,3,2]`）

- 两种结果：`CAF + LA2F` 或 `CA2F + LAF`
- 首次并列（第 0 步）：**3 个 C-A 候选对**，结合后大类并集都是 `{聚,散}`，**大类数都是 2**
  → 用户规则 9 完全无法区分。

### 3.2 T=8：`W1 L1 K5 A1`（向量 `[0,0,0,0,1,1,5,1,0]`）

- 两种结果：`K2A + WLK3` 或 `LK3A + WK2`
- 首次并列（第 0 步）：**5 个 W-K 候选对**，大类并集都是 `{动,散}`，大类数都是 2。

### 3.3 T=8：`C1 L1 K3 A2 F1`（向量 `[0,0,1,0,0,1,3,2,1]`）

- 两种结果：`CK2AF + LKA` 或 `CKA + LK2AF`
- 首次并列：**3 个 C-K 候选对**，大类并集都是 `{聚,散}`，大类数都是 2。

### 3.4 T=29：`O8 C7 W2 K4 A3 F5`

- 两种结果：`… O2KAF, O2WKF, O4WK2A2` 或 `… O2KAF, O2KAF, O4W2K2A`
- 首次并列（第 0 步）：**32 个 O-K 候选对**，大类并集都是 `{聚,散}`，大类数都是 2。

### 3.5 T=33：`X10 W9 K6 F8`

- 两种结果：`… X3W3K2, X3W3K2, X4W3K2` 或 `… X3W3K2, X7W6K4`
- 首次并列（第 0 步）：**60 个 X-K 候选对**，大类并集都只有 `{聚,散}`，大类数都是 2。

**共同点**：所有残余分歧的并列对都是**同一元素对**（C-A、W-K、C-K、O-K、X-K 等），
因此"结合后大类数"完全相同，规则 9 在该步失效；后续不同并列选择仍可能导向不同产物。

---

## 4. 为什么 T≤6 能完全消除、T≥7 不行

- 用户规则 9 能在**大类数不同**的并列中做出裁决（例如一个候选结合后含 3 大类、另一个只含 2 大类）；
  这会在后续步骤剪掉一部分导致"另一种产物"的分支。
- 但 T≤6 的 9 个歧义例子恰好都靠这种后续剪枝**收敛到唯一结果**；
  T≥7 的投料中，仍有并列对**大类数完全相同**，剪不掉全部分支，因此残余分歧出现。
- 本质上：用户规则是"大类层面"的粗粒度裁决，而残余分歧来自**同一元素对内部的对称选择**，
  需要更细（元素级/原子级/规范形）的裁决才能完全消除。

---

## 5. 建议

若目标只是"大幅收敛、定义简单"：
- 采用用户方案（大类数）作为规则 9，可把歧义压到 ~0.3%~0.8%（T≤9 实测），
  且 T≤6 完全确定；大锅仍有少量歧义，需要文档注明。

若目标是"完全消歧"：
- 在用户规则 9 之后再加一条**规范决胜**（如 `T8_RULE9.md` 的规范形方案）：
  即先按大类数裁决，剩余并列再按加键后状态的规范形（或规范原子编号）选最小者；
  这样理论上完全确定（已在前一轮对 T≤9 全量验证：置换不变性 0 失败）。
- 或者：用户规则 9 只作为"便宜的前置裁决"保留，最终用规范形兜底。
