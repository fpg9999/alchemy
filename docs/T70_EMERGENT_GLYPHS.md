# T70 生成式形状语言（骨架 / 桥梁 / 端帽）

> 目的：放弃 T68/T69 里"手工给每种骨架指派固定多边形"的做法，改成**一条规则族**：
> 图形由骨架块的数据（元素计数、邻接度数、键角）与桥/端帽的数据（元素、链长、多重键）通过函数生成。
> 于是同类骨架看起来"像同一种东西"（规律），每个个体又各不相同（涌现），而且参数是连续的，不会出现手绘的僵硬感。

## 1. 骨架块：超公式晶核

对每个 6 级骨架块（38 库里的一个形态，共 115 个实例），记：

- `n` = 原子数，`nO / nP / nK` = 三价元素计数，`deg[]` = 每个原子的键度和
- 对称瓣数 `m = 3 + nK`（纯 P 退化时 `m = 2`）
- 圆润度 `n1 = 0.42 + 1.55·(nP/n) + 0.30·(nO/n)`（P 越多越圆，O/K 越多越锐）
- 两向锐度 `n2 = 0.75 + 0.85·(nO/n) + 0.55·(nK/n)`，`n3 = 0.75 + 0.85·(nP/n)`
- 个体指纹 `wob = 0.030 + 0.022·frac(hash(label))`，整体旋转 `rot = 0.62·2π·frac(hash)`
- 相位 `ph` 由最大度数决定

外轮廓（极坐标，θ 从 0 到 2π）：

```
r(θ) = ( |cos(mθ/4)|^n2 + |sin(mθ/4)|^n3 )^(-1/n1) / 1.35
       × [ 1 + wob·cos((m+3)θ + ph) + 0.55·wob·cos((2m+1)θ - 0.7ph) ]
```

- 第 1 项是**超公式**：`m` 决定几重对称，`n1` 决定"星形↔圆形"，`n2/n3` 决定两个方向的锐边。
- 第 2 项是**有机扰动**：只由哈希种子决定（每个骨架块独一无二），幅度很小，让轮廓不像机器刻的。
- 内部用同一条 `r(θ)` 缩半径 3~4 次叠画 = 生长纹；从瓣尖向内画"晶脉"，亮度按度数。

因此：纯 O 块 = 三重对称、尖端锐利；纯 P 块 = 二重、圆润近圆；纯 K 块 = 3+K 重多角；
O+P 块有两种对称叠加；O+P+K 块最复杂。**同一元素组合的块风格一致，不同组合一眼可辨**。

## 2. 桥梁：按桥原子序列分段生成

- **晶 X = 焊核**：钝三角 + 三条放射焊纹 + 两侧焊板；多重键 `m` 越大，三角越厚、焊纹越多。
- **流 W = 双股编织腱**：两条正弦股交叉，交叉次数 = 链长；外面套一层浅色腱鞘。
- **气 A = 褶皱薄膜**：横向展开的手风琴幕（褶数 = 链长），两条长边贴着两侧骨架。
- **多元素桥**：沿同一条轴线分段（W–A–W 就是 腱–膜–腱），段间打"结"，读作组合接头。

## 3. 端帽触肢：按一价原子生成

- **冰 C = 冰晶尖刺**：一根主冰锥 + 两对侧刺（层数 = 2），浅蓝晶体填充。
- **焰 F = 飘带**：渐宽的软带 + 正弦起伏（波数 2），暖色。
- **电 L = 螺旋丝**：双股螺旋（圈数随链长），紫色。
- 尺寸 = 所连骨架块半径的 0.30 倍；位置用骨架轮廓的射线交点，沿元的原始朝向外伸。

```bash
python t70_render.py      # 生成上面 4 张图
```

依赖：`t70_glyphs.py`（生成器）、`t68_shapes.py`（画布/配色/家族）、`t69_pieces.py` + `t69_draw.py` + `t69_bodies.py`（示例分子的排版与装饰位置）、`t8_forms.json`（38 库）。

## 7. 局限（未决）

- 二维平面无法表现"薄膜的面"：气 A 只能画成侧看的褶幕，读起来像一排折片。
- 骨架块之间的空间关系仍沿用 T69 的骨架级排版，没有按桥长重新解算；示例图不是严格布局图。
- 端帽数量多时（G24 有 7 个一价端帽）仍会显得拥挤，尚未做朝向避让。
- 未做元素/骨架的动画或参数滑块；若需要，可以把这个生成器接成交互页面。
