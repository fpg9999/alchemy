## 1. 方法与口径

### 1.1 集合 S

- 从 `t4_catalog_all_validated.json` 的轻量索引 `t4_catalog_index.json` 取 natoms ≤ 8 的记录，按分子式去重；逐条与目录的 `atoms` 字段核对元素向量（0 缺失、0 不一致）。
- natoms 分布：

| 3 | 64 |
| 4 | 160 |

| 6 | 630 |
| 7 | 1,073 |

- |S| = 3,931 ≥ 3,000，按任务口径**不扩展**到 natoms≤9/10（若扩展：≤9 为 6,486 个物质、约 2.1×10⁷ 对；≤10 为 10,233 个物质、约 5.2×10⁷ 对，计算量各增 2.7×/6.8×，本任务不需要）。
### 1.2 反应定义

- R(A,B)：把 A、B 的全部原子拆开投锅，按规则 1~8 逐根贪心成键；成功需所有原子价数填满、且每个产物分子经 `pot_v2`/`t12b_embed` 严格校验可在六边形格上摆放；任一不满足则整锅失败。产物按分子式多重集记录。
- `t12b_embed`：从 `pot_v2.embed_mol2` 复制并加状态（ok / fail / timeout）与节点上限 `CAP=300,000`；超时向量记录为「未判定」，再用 3×10⁶、1.2×10⁷ 节点上限复核（结果见 §3.1）。
- 已知定律（本任务再次验证）：**反应结果只由总向量 vA+vB 决定**。因此只需计算全部唯一总向量，再把 7.73M 对映射到结果；§5 用 50 个等价类独立复算验证该定律。
- 每对的记录格式：`t12b_shards/pairs_XXXXX.jsonl`，每行 `[i, j, ridx]`（i≤j 为 S 下标，ridx 指向唯一向量结果），共 10,000 对/片；汇总见 `t12b_pairs.jsonl`。

### 1.3 试跑测速与全量耗时

- **试跑**：随机抽 2,000 个总向量测速 → `pot_all` 2.0 ms/向量、`pot_v3` 3.3 ms/向量（未加 embedding 上限）；又抽 5,000 个向量（约全量的 1/130）测 embedding 尾部 → 发现大分子图回溯很慢（个别 >6 s），据此加节点上限并把超时单列，避免误判。
- **全量**：656,343 个唯一向量，16 进程分块计算，`pot_all` 口径 **570 s**（含 embedding 校验）；`pot_v3` 对照 410 s；timeout 高上限复核 570 s（282 个向量，246 个判定为可摆）；分析 23 s。

### 1.4 运行环境

- 16 进程 multiprocessing；唯一向量 656,343 个；分析脚本 `t12b_analyze.py`。

> 注意：任一合法物质的价数总和 = 2×键数，必为偶数；因此**两个合法物质混合后的总价数一定为偶数**。本数据中奇数价数对 = 0，即**不存在「价数奇偶」导致的失败**——全部失败都来自贪心的动力学截断或几何限制。

跨元素规律（要点）：

- **无三价元素的体系 0 失败**：三价原子数=0 的 15,400 对全部成功（与 T11 的「无三价 175 内部 0 失败」一致）。

- **最不相容的是「两种不同三价元素 + 高 3 价占比」的组合**：PK、OK 两元素集合失败率最高（4.65%）；按大类看，仅含「动+散」（不含聚）的对失败率 2.75%，高于「聚+动」2.19% 与「三大类齐全」1.74%。
- **O 的存在显著提高惰性/单产物**（见 9.2），X 的缺席/出现对多产物比例影响最大；W（流，2 价）与 A（气，2 价）同时缺失时失败率最低——它们是最常见的「剩余原子」元素。
- **元素越多越倾向复分解**：集合越大，单产物比例越低、多产物越高；纯大类内的对小分子更容易原样返回（惰性）。

## 12. 规律清单

1. **总向量定律**：对 7.73M 对按总向量分组（656,343 类，99.6% 的对落在含 ≥2 对的类里），抽 50 类 390 对独立复算，类内结果完全一致 → 二元反应只取决于元素计数总和，与投料分子形式无关。
2. **成功占绝对多数（98.2%）**，失败仅 1.78%。合法物质的价数总和必为偶数，故两个合法物质混合的总价数**必为偶数**——本数据奇价数对 = 0，**不存在价数奇偶导致的失败**；全部失败来自贪心动力学截断或几何限制。
3. **「剩键」失败有统一结构**：11,450 个剩键失败向量的终态 100% 是「恰好 1 个 2 价原子（X/W/A）完全未成键、其余原子全饱和」，即贪心把某个 2 价原子晾在一边。另 2,279 个向量是「产物图摆不出」。
4. **失败率随三价原子数上升**（0 三价 → 0%；12 三价 → 9.3%）；最不相容的是「两种不同三价元素」（PK / OK 两元素混合 4.6%）。O、K 是主要「不相容」来源，W、A 是最常见的剩余原子（2 价）。
5. **单产物 = 严格向量加法**：1,061,160 对单产物全部满足 vC=vA+vB（0 违例），不存在催化/取代式单产物反应。
6. **多产物是常态（76.3%）**：2×不同（交换）最多（1.96M 对），其次 3 产物（1.37M）、2×同种（归中/歧化 6,751 对）；最多的一对可产出 8 个分子。
7. **惰性与尺寸负相关**：T=8 时 45% 惰性，T=16 时仅 1.6%；大混合物几乎必然复分解（86% 多产物）。惰性王是小分子/二聚体（L2、F2、LF、C2…），它们同时也是化合枢纽。
8. **产物守恒**：产物总原子数恒等于投料原子数（0 违例）；单产物对产物原子数=两投料原子数之和。
9. **口径稳健**：规则 9 只改变约 0.4% 的对的结果（其中仅 1 个向量改变成功/失败），不改变任何宏观比例结论（§11）。
10. **目录小缺口**：212 种合法产物分子式未收录于 ≤16 目录（目录 embedding 预算 40 万节点所致），本任务用更高上限复核确认其可严格摆放——这是对既有目录的一个补充发现。
