## 3. 上一版猜想 D 的反例与更正

**原猜想 D**：每组件 `rem≥2` 原子数 ≤3。（已被推翻）

**反例**：投料 `[1,2,3,6,2,6,2,0,8]`（O1 X2 C3 P6 W2 L6 K2 A0 F8），第 7 根键后，
一个 6 原子组件的组成为 `O(rem0) K(rem0) P×4(rem2)`，`rem≥2` 原子数 = **4**。
（k=3 的穷举只覆盖 O/X/K，P 类原子未参与，所以旧穷举没发现；这也说明 3 元池与全池的常数不同。）

**修订后的观察**：
- 随机/爬山搜索得到 `max h = 4`（未超过）；全 9 计数各 ≤3 穷举 `max h = 3`；
- 更稳健的量是"额外键容量" `Σ(rem−1)`（见 §4）。

## 4. 新的不变量候选 E：`Σ(rem−1) ≤ 4`

定义 `ex(C) = Σ_{i∈C, rem_i>0} (rem_i − 1)`。含义：组件内所有活跃原子"多余一根"的键容量之和。

**观察**：
| 对象 | max ex |
|---|---|
| 反例 `[1,2,3,6,2,6,2,0,8]` | **4** |
| OXK42 / 全 9 97 族 / 97 族×2 | 3 / 3 / 3 |
| 全 9 计数各 ≤3 穷举（131071 组） | 3 |
| 爬山搜索（T≤240、放大族） | 从未超过 4 |

**动力学公式**（对证明有用）：
- 同组件加键：`ex' = ex − 2 + d`，其中 d = 端点在加键后 rem 变 0 的个数（0/1/2），故 `ex' ≤ ex`；
- 跨组件合并：`ex' = ex_A + ex_B − 2 + d`（d 为两端回 0 的个数），故 `ex' ≤ ex_A + ex_B`。
  只有当合并两端都恰好 rem=1（d=2）时，`ex` 才可能"相加"而不减少。

因此证明 E 的关键是：**限制"两端都 rem=1 的跨组件合并"不能把多个组件的 ex 累加超过 4**。
这是比上一版 D 更具体的攻击点（D 的失败正是因为忽略了 4 个同元素的 rem=2 原子可以同处一个组件）。
