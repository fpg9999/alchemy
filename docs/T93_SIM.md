## 摘要

在 T87 连续重力 + 非对称三素力的环境世界上，构造「**核心（24×C3K3F2 固态惰性团簇）+ 壳内食物（C2K2/CKF2 各 40）+ 冷壳（OXC/X2C2/C2 环带 300 或 OXC+OP 双层 390）+ 壳外攻击浴（360 个富 F/O 分子）**」的三段结构，并新增一个只用于度量与展示的粗网格热场 τ（80×55，κ∝√(ηiηj)，显式差分，边界向 T_env 松弛）。9 条臂覆盖「无壳对照 / 重·固·冷 OXC 壳 / 轻·气档 C2 壳 / 轻·固·冷 X2C2 壳 / 20°C 冷环境 / 双层 OXC+OP / 无攻击浴自组装 / T87 重力 G=0.30 / 低重力 G=0.02」；主臂取微重力 G=0。

结论三条：

1. **冷壳确实能大幅降低「外来分子—核心」接触，并把核心存留从 45.8% 提高到 87.5%~100%**：无壳对照 600 拍内核心 24→11、外来-核心相邻对累计 3202；OXC 单层降至 1326（−58.6%），C2 层 275（−91.4%），X2C2 层 937（−70.7%），双层 OXC+OP 降到 172（−94.6%），核心存留 24/24；外来分子到核心中心的最近距离从 2.83 格拉大到 3.0~6.32 格，`foreign_within2` 从终态 2（历史最大 13）降到 0~3。
2. **「保温」只是瞬态延迟，不能维持低温**：以核心质心 3 格内的 τ_core 计，单层 OXC 相对无壳的峰值温差只有 **33.0°C**（t≈100），双层 OXC+OP 峰值 **48.6°C**（t≈200），C2 层 12.8°C；到 600 拍末分别衰减到 4.9 / 14.8 / 6.2°C，所有臂内部都升到 302~325°C（T_env=400°C）。升温到 300°C 的时间只被推迟约 30~90 拍（无壳 500 拍，OXC 530，双层 590）。**在「薄壳 + 纯扩散、无热容」的口径下，冷壳起不到持续保温作用。**
3. **隔绝有效但代价高**：外壳把大部分攻击分子挡在核外，同时**自己被化学消耗**（OXC 300 个初始壳分子到 600 拍只剩 17 个 id 存活，按分子式统计的「当前屏障」也只有 28 个；C2 层剩 161/300，双层 390→47）。壳粘住大量攻击分子（外来-壳接触累计 2.7 万~11.1 万次），并因「壳-浴」反应被分解；**真实重力 G=0.30 下重壳直接沉底，核心被吃光（24→1）**；G=0.02 也不足以维持环带（壳质心从 55 行漂到 87.8 行，覆盖扇区只剩 5.6%）。双层隔热最好、核心 100% 存活，但寿命也最短之一（390→47）。

一句话：**「C 类低温分子在外围形成冰壳」在规则上可以形成并显著隔绝外来接触，但在这个无热容、带化学活性的点粒子模型里，它既不能持续保温，也会被环境浴化学吃掉；只有在低重力/支撑表面且时间有限的条件下才成立。**

## 1 问题与判据

用户问题：能否用 C（冰素，低温）类低温分子在多分子生命外围形成冰壳保护膜，实现

- ① **保温**：外界高温（400°C 浴）下内部仍低温；
- ② **隔绝/阻挡外来分子**：内部反应继续、外部接触反应不发生。

对应可判据（本报告口径）：

| 问题 | 指标 | 「成立」的阈值（事前设定） |
|---|---|---|
| 壳是否形成/维持 | 壳分子当前屏障数、36 扇区角覆盖 `cov_angular_f` | ≥0.8 且 600 拍末不明显下降 |
| 保温 | 核心质心 τ_core(t)，与无壳对照的差 Δτ_core | 600 拍末 Δτ_core ≥50°C |
| 隔绝 | 外来-核心接触累计 `contacts_foreign_core`、外来到核心最近距离 `foreign_min_r`、`foreign_within2` | 相对无壳对照降 ≥1 个数量级，核心存留 ≥80% |
| 内部反应继续 | `react_in`（反应质心 R≤8） | 全程 >0 |
| 外部接触反应不发生 | `react_out` 与外来-核心接触是否被壳截断 | 外部反应不转化为核心侵蚀 |

## 3 模型与实验设计

### 3.1 世界与引擎

- 世界 **160×110**，环面边界（引擎语义），seed=**20261123**（单 seed）。
- 引擎：`t87_env_asym.AsymWorld`（→ t86 TriWorld → t85 ResolveWorld → t84 SkelWorld → t83 World）。
  - 8 邻域移动；每拍 `update_rho → 逐分子重力 → 非对称三素力 → 布朗 → react_phase → rebuild_locks`；
  - 反应为 2~4 分子组，`resolve(mds, Tamb)` 返回 none/incomplete/complete/decomp；
  - `p_react=0.010`（T87 默认 0.012），`cap=26`，`brown_p=0.12`（T87 默认 0.04；本实验把 400°C 热浴的热运动折算为更高的布朗率，属于建模选择，见 §7）；
  - 重力：`gacc += grav·mass`，整数部分逐格下移（被占时按质量比 0.75/概率 0.65 交换），单拍最多 3 步；**引擎没有终端速度，gacc 线性累积**。
- 核心中心 `CORE_CENTER=(55,80)`（世界中部），核心判定/冻结区 `CORE_ZONE=8`（Chebyshev）。
- 分区半径：内部 R≤8、壳体带 8<R≤13、外部 R>13；ρ_E 采样带 in 0~12、out 16~40。

### 3.2 初始三部分（每臂同构，只变壳/浴/重力）

### 3.3 热场 τ（新增，仅度量与展示）

- 粗网格 **80×55**（block=2，即 W//2×H//2；取 W//4 时 1~2 格厚的壳会被空格 η_env 稀释，故按复核意见改细）。
- 每格 η = 该格内分子 η 的均值；空格 η_env=0.35。分子 η：

  η = (1−ρ̂)·(T_deg+1)/(T_deg+4)，ρ̂=(3n_O+2n_K+n_P)/(3N)，T_deg=n_L+2n_F，clamp[0,1]

  （N=原子数；与 `docs/THERMAL_DIMENSION.md` 一致。典型值：OXC N=3, T_deg=0, ρ̂=1/3 → η=0.167；C2 η=0.25；C3K3F2 η=0.469；OP η=0.083。）
- 边系数 κ_ij = 0.35·√(η_i η_j)，只取 4 邻居；显式差分 `τ_i += dt·Σ_j κ_ij(τ_j−τ_i)`，`dt = 0.5/max_i Σ_j κ_ij`（保证稳定）。
- 边界格（i=0/54 或 j=0/79）额外向 T_env 松弛：`τ += 0.3·(T_env−τ)`，每拍。
- 初值：**距核心 >13 格的格心 = T_env（外部热浴），其余 = 20°C**；所有臂同一初值剖面，只有壳分子不同。
- τ **只用于度量与展示**（`tau_core/tau_in/tau_shell/tau_out/tau_edge`），**不写回 `resolve` 的 Tamb**：反应温度语义仍是 T87 的「Tamb=T_env 常量 + ρ_E gate」。若把 τ 再喂给 resolve 就是双重计温，本实验明确不做。
- 采样桶（按网格中心到核心中心的世界距离）：core ≤3、in 3~7、shell 7~12.5、out 12.5~32、edge 边界格。
- 口径限制：本热场**没有热容/潜热/相变项**，是纯扩散场；τ 的升温速度由 κ 与边界松弛决定，不含分子热容。

### 3.4 反应政策与血统（关键建模假设）

1. **核心惰性表面假设（沿用 T90 主体语义）**：核心分子只在「同时含外来攻击血统（`bath_lineage`）」的组里参与反应；核心与内部食物/内部产物之间的反应被抑制。理由：resolve 给出 `C3K3F2+C2K2→[C2K2F2,C3K3]`，若允许，核心会被自己的食物迅速溶解，与 T90「主体稳定、食物-食物缩合生长」矛盾。
2. **血统追踪**：`bath_lineage` = 初始 360 个浴分子 id + 它们参与反应生成的后代 id。`foreign` 判定 = 该血统；内部产物（如食物缩合产物）记为 `other`，不参与「外来攻击」统计。
3. **产物落点修补**：`_apply_group` 求得反应质心距离 d；若 d>R_INTERIOR（膜外反应），置 `_spawn_min_r=8`，覆写的 `_find_footprint` 只允许在膜外找空位（T85 原来的质心 ±10 扫描会把壳上反应的产物丢到膜内，造成「产物瞬移穿膜」的假象）。膜内反应不设限。
4. 反应分类钩子：group 质心到核心中心距离 ≤8 记 `react_in`，8~13 记 `react_shellzone`，>13 记 `react_out`；含核心分子记 `core_involved`；同时含核心+外来记 `core_attack_react`（核心被侵蚀）；含壳+外来记 `shell_bath_react`（壳被消耗）。

### 3.6 指标定义

- `core_n`：**存活且距核心中心 Chebyshev≤8 的 C3K3F2 分子数**（冻结种子 + 内部新生成/并入者）。`core_by_element`：这些分子的原子组成。
- `core_retention` = core_n_final / 24。
- 壳「当前屏障」按**分子式**统计（`shell_formula_n`）：活着的壳式分子且距核心中心 5~18 格——避免「反应替换 id 后同式再生」被误记为损失；同时保留按 id 的 `shell_alive` 作「原始壳分子存活数」。
- `cov_angular_f`：以核心中心为极点分 36 个 10° 扇区，环带 5~18 格内有壳式分子的扇区比例（另有 `coverage4/8`：核心边界格是否被壳占，薄壳时多为 0，故报告以角覆盖为主）。
- `contacts_foreign_core / _shell`：逐拍统计「外来血统—核心」「外来血统—壳」的 8 邻接对（4 个正向方向计一次），累计。
- `foreign_within2`：距核心格 ≤2 格的外来血统分子数；`foreign_min_r`：外来血统分子到核心中心的最小距离（穿透深度）。
- `react_in / react_shellzone / react_out`：反应质心到核心中心距离分档的累计次数。
- `rho_in / rho_out`：ρ_E 场在 R 0~12 / 16~40 的平均；`gate = 0.15+0.85ρ_E`。
- `tau_core / tau_in / tau_shell / tau_out / tau_edge`：τ 场分桶均值。
- `warm_delay_core300`：τ_core 首次 ≥300°C 的拍号；`shell_loss = 300 − shell_alive_final`（按 id）；`shell_escape`：原始壳分子仍存活但漂出环带（距核心 >18 格）的数量。

- 单层 OXC 的保温时长约 100~200 拍：Δτ_core 33.0°C（t100）、31.9°C（t200）、20.1°C（t300）、11.3（t400）、4.9（t600）。
- 双层 OXC+OP 的峰值 48.6°C（t200），到 t600 仍有 14.8°C——是全部臂中最好的，但仍远低于「维持低温」；且 t600 绝对温度 302.5°C，离 T_env 只差 97.5°C。
- C2 层最薄效应（12.8°C 峰值）：C2 的 η=0.25 高于 OXC 的 0.167（C2 不含 O/K/P，ρ̂=0）；η 越高 κ 越大，隔热越差。
- 结论：**按事前判据「600 拍末 Δτ_core ≥50°C」，所有臂都不满足；保温只在前 100~200 拍有 13~49°C 的延迟效果。** 图见 `images/t93_thermal.png`。

### 4.3 隔绝：接触、穿透深度与存留

- 无壳对照：外来-核心接触 3202，核心 24→11（8 次核心-外来反应），外来最近距离 2.83 格，`foreign_within2` 历史最大 13。
- 有壳臂：接触降到 1326（OXC）/275（C2）/937（X2C2）/172（双层）/225（20°C 环境）；核心存留 87.5%~100%；C2 与双层 0 次核心-外来反应；外来最近距离 3.0~6.32 格，穿透深度被推远。
- `foreign_within2` 终态：无壳 2（最大 13）→ 有壳 0~3（最大 2~4）；双层最小（终态 0、最大 2，最近距离 6.32 格）。
- **壳的「当前屏障」数**（按分子式）终态：OXC 28、C2 217、X2C2 91、双层 87、20°C 51、自组装 112；无壳 0。C2 层的角覆盖 0.944、OXC 0.25——C2 壳在几何上最完整，OXC 壳到 600 拍已被消耗到只剩 1/4 扇区覆盖。
- 因此「隔绝」的强弱顺序（按外来-核心接触）：**双层（172）< 20°C 环境（225）< C2（275）< X2C2（937）< OXC（1326）≪ 无壳（3202）**；但这一顺序与「壳寿命」相反（C2 剩 161，OXC 剩 17，双层 47）。

### 4.4 反应：内部继续，外部接触反应被挡在壳上

- 内部反应（质心 R≤8）在所有臂都持续发生：无壳 22 次、OXC 32、C2 23、X2C2 39、双层 40、自组装 27——**内部反应没有因壳而停止**；壳内食物 C2K2/CKF2 的缩合（`C2K2+CKF2→C3K3F2`）也在发生（`grown_core` 无壳 1、其余 0~1，食物 80→6~30，说明大部分食物在 600 拍内被消耗/反应掉，T90 式「核心增生长大」没有在这个尺寸下复现）。
- 壳带反应（8<R≤13）：无壳 45（无壳时该带只是普通浴区）vs 有壳 107（OXC）/36（C2）/86（X2C2）/92（双层）——**有壳臂在壳带发生更多反应，因为壳本身是反应界面**（`shell_bath_react` OXC 110、X2C2 112、C2 52、双层 53）。
- 外部反应（R>13）：无壳 109 vs 有壳 318（OXC）/131（C2）/373（X2C2）/303（双层）——外部反应率反而更高，因为「外来分子 + 壳分子」在壳面上反应（壳是反应物）；这些反应消耗的是壳，不是核心。
- 结论：**「外部接触反应不发生」严格说没有做到——反应发生了，但发生在壳上而不是核心上。** 核心-外来反应：无壳 8 → OXC 2 / C2 0 / X2C2 1 / 双层 0 / 低重力 6 / 真实重力 14。图见 `images/t93_react.png`。

### 4.5 壳自身：消耗、吸附、重力

1. **化学消耗**：`shell_alive` 300→17（OXC，94.3% 损失）、→161（C2，46.3%）、→52（X2C2，82.7%）、→42（20°C 环境）、双层 390→47（87.9%）；`shell_bath_react` 110/52/112/110/53 次；壳-浴接触 2.7 万~11.1 万次。壳的「当前屏障」按分子式统计比按 id 高（如 OXC 28 vs 17），说明部分壳物质被反应后又生成了同式分子，但净量仍骤降。
2. **壳粘住攻击分子**：OXC-O2/OP/OK 的 pair_w≈+0.51（弱吸）、OXC-OCF2≈+0.67，浴中的 A=3 分子（O2/OP/OK）对壳有非对称吸引力 F≈7.5，所以壳表面会聚集攻击分子（`contacts_foreign_shell` 巨大），这既「挡」了核心，也**加速了壳的消耗**——是负面机制。
3. **重力坍塌**：
   - G=0.30（T87 真实重力）：壳质心从 55 行沉到 **108.5 行**（世界底部），角覆盖 **0.000**；核心 24→**1**，核心-外来反应 14，外来-核心接触 7220。重壳（OXC mass=3.0）在 `gacc+=0.30·mass` 下约 30 拍就沉底。
   - G=0.02（低重力）：壳质心 55→87.8 行，角覆盖 0.056，`shell_escape=36`；核心 24→16，核心-外来反应 6。**因引擎没有终端速度，gacc 线性累积，600 拍内低重力壳仍漂出环带**。
   - 主臂 G=0（微重力/支撑表面假设）壳质心 55→62.1（OXC）、55→55.7（C2）、双层 55→58.5，基本维持。
4. **无浴自组装**：没有攻击浴时，壳仍从 300 缓慢反应重构到 109 个 id/112 个当前屏障（角覆盖 0.639），说明壳-壳/壳-内部产物反应本身就会消耗壳；「初始环带 + 壳内自粘（OXC-OXC 的 pair_w=1.667）维持」是当前口径下最接近「自发成壳」的形态。

### 4.6 单层 vs 双层 vs 轻壳

- **双层 OXC+OP**：隔热最好（峰值 48.6°C，终态 14.8°C），隔绝最好（接触 172、最近距离 6.32、核心 100%），但外膜 OP 被大量消耗（390→47）。OP-OP 的 pair_w=2.0 是强自粘，OP 与 OCF2 的 w≈+0.41、与 OXC≈+0.51，并没有让外膜长期成层——OP 自身也参与反应。**双层可行但寿命最短之一。**
- **C2 单层**：几何覆盖最好（0.944）、核心 100%、接触 275，但它是「气」档分子（见 §7 不一致），且 η 较高、保温最差（12.8°C 峰值）；若按物态语义「气不挡人」，它的阻挡只能来自占格规则，不能当作物理证据。
- **X2C2 单层**：居中（接触 937、覆盖 0.667、核心 95.8%），但壳消耗也快（→52）。
- **OXC 单层**：初始最密（300 填满 8.2~12.4 环带），但 600 拍后只剩 17 个原始分子，角覆盖 0.25——**它在前 100~200 拍最有效，然后被环境吃掉**。

## 5 机制解释

### 5.1 为什么保温只是瞬态

τ 场是**纯扩散、无热容**的：内部初始 20°C，外部边界 400°C，壳层的低 η 只把 κ 降为 √(0.167·0.35)/√(0.35·0.35)≈0.69（单层）或更低（双层），相当于把热扩散系数降低 30%~50%。核心半径只有 ~2 格、到边界只有 ~10~15 格，扩散时间尺度很短；且壳只有 2~4 格厚。因此 τ_core 在 100~200 拍内就被追平。若要有持续保温，需要：更厚的壳（多层、厚度 ≫ 扩散长度）、更低的 η（更致密/更重元素）、或热容/相变机制（本模型没有）。

### 5.2 为什么壳被化学消耗

resolve 在 400°C（与 20°C 结果相同，温度不改变这些配对）给出大量「壳-浴」放热/复分解式结果，例如 `OXC+O2→[O3XC]`、`OXC+OP→[O2XCP]`、`OXC+OCF2→[O2XC2F2]`、`OXC+X2AF2→[OAF,X3CF]`；`OXC+F2`/`OXC+CF` 为 incomplete（净不变）。壳分子一旦与攻击分子相邻，就有 p_react·gate·mult 的概率被替换为产物，壳物质被「化学吃掉」。同时 OXC-OXC 自粘（pair_w=1.667，仅 d=1）使壳成网，但也让壳表面持续暴露给浴。

### 5.3 为什么壳粘攻击分子

三素力是非对称的：`F_on_j = K_A·A_i·decay(d,r_att_i) − K_R·R_j·decay(d,r_rep_j)`，吸引力大小取决于**施力方**的 A。浴中的 O2/OP/OK 的 A=3，对壳（A=2）的吸引力约 7.5（d=1），远大于壳自身 A=2 对外 5.0 的吸引；因此壳表面会富集这些高 A 攻击分子（`contacts_foreign_shell` 巨大），这既「挡」了核心，也**把敌人拉到壳上**，加速壳消耗。

### 5.4 壳与核心之间没有强粘附

pair_w（锁判定用 Jaccard）在 C3K3F2–OXC 上只有 d=1 时 +0.118、d=2 时 +0.059，远低于锁阈值 1.0；非对称力上核心对壳的吸引（F_on_shell = 2.5·A_core = 2.5，d=1）也不足以把壳拉紧。因此**壳不是「长在核心上」的，而是「初始环带 + 壳内自粘」维持的**；一旦壳被消耗/重力拉走，环带就散了。这正是文档要求说明的降级口径：本实验实现的是「初始环带 + 粘附维持」，不是「自发生长闭合的冰壳」（无浴自组装臂给出了 300→109 的自然重构，但没有自发闭合到核心周围的新证据）。

### 5.5 重力

`gacc += grav·mass` 对 OXC（mass=3.0）是 0.90/拍（G=0.30），30 拍就累积 27 步，壳沉底；G=0.02 时 0.06/拍，600 拍累积 36 步，足以漂出 8~12 环带（`shell_escape=36`）。引擎没有终端速度/支撑力，所以**微重力或支撑表面是这套冷壳成立的必要环境条件**。主臂取 G=0 是「微重力/支撑表面」假设，不是 T87 的真实重力语义。

## 6 结论（逐条回答）

1. **壳是否形成/维持？**
   - 初始环带可以放置成密壳（300 个 OXC 填满 8.2~12.4 环带，角覆盖 1.0）；但**不能长期维持**：600 拍后 OXC 角覆盖 0.25（当前屏障 28 个）、C2 0.944（217 个）、X2C2 0.667（91 个）、双层 0.583（87 个）。壳被壳-浴反应消耗，且壳-核心间没有强粘附锁（pair_w≈0.12），不会自发包覆核心。→ **降级口径：初始环带 + 粘附维持，不是自发生长的冰壳。**
2. **保温？** 只有瞬态延迟：单层 OXC 峰值 Δτ_core=33.0°C、双层 48.6°C、C2 12.8°C；600 拍末只剩 4.9/14.8/6.2°C，内部仍 302~325°C。**不满足「外界高温下内部仍低温」的持续保温判据。**
3. **隔绝？** 有效：外来-核心接触从 3202 降到 172~1326（双层 −94.6%，C2 −91.4%，OXC −58.6%），核心存留从 45.8% 提到 87.5%~100%，外来最近距离从 2.83 推到 3.0~6.32 格。**但这是「用壳被消耗换来的」**：壳-浴反应 52~124 次、壳-浴接触数万次，壳自身损失 46%~94%。
4. **内部反应继续、外部接触反应不发生？** 内部反应全程继续（22~40 次）；外部接触反应**没有消失，而是转移到了壳上**（外部反应 109→131~373，壳带反应 45→36~107），核心-外来反应从 8 降到 0~2。严格判据「外部接触反应不发生」不成立，成立的弱版本是「外来分子与核心的接触/反应被大幅截断」。
5. **负面结论**：壳会粘住攻击分子（高 A 的 O2/OP/OK）；壳同时挡住内部食物外流/外部食物进入（食物 80→6~30，T90 式生长未复现）；双层隔热最好但寿命最短之一；真实重力 G=0.30 直接毁壳（核心 24→1），G=0.02 也不够（角覆盖 0.056）；C2 的「气」物态语义与占格阻挡不一致，不能把 C2 的阻挡当作物理证据。

## 7 局限与模型不一致

1. **核心惰性假设**：核心与内部食物/产物之间的反应被人为抑制（否则 `C3K3F2+C2K2→[C2K2F2,C3K3]` 会溶核）。这是一个建模选择，不是内核规则；如果放开，核心存留会显著下降（quick 早期未加政策时 12→7）。
2. **C2 气态 vs 占格阻挡**：C2 的物态档是「气」（state=0），但 t83/t84 的碰撞只按占格判定，气态不穿透。C2 壳的阻挡效果只能说明「占格规则下气档分子也挡人」，不能作为「气态冰壳能挡分子」的物理证据。这个不一致在 T93_STATIC 的静态分析中应单独讨论。
3. **τ 场没有热容/潜热/相变**：纯扩散，升温速度由 κ 决定；真实冰壳的熔化潜热、热容、辐射都会改变保温结论。τ 只用于度量，不改变 resolve 的 Tamb（避免双重计温）。
4. **重力无终端速度**：`gacc` 线性累积，G=0.02 在 600 拍内仍会漂移；真实微重力下还有支撑/对流/布朗等。
5. **产物落点修补不完整**：只限制「膜外反应产物不落膜内」；膜内反应产物可以落在膜外（物理上允许），但会让「壳内物质外流」统计偏保守。
6. **单 seed、单分辨率**：seed=20261123 一条；τ 网格 80×55；壳初始环带由随机角度采样，存在放置抖动。
7. **「壳」按 id 与按分子式两套口径**：`shell_alive`（id）会把「消耗后同式再生」误记为损失，`shell_formula_n`（分子式）是「当前屏障」；两者都在 JSON 中，报告同时给出。
8. **无浴自组装臂**只说明「已放置的环带会自然重构」，不能证明「从无壳初始条件自发形成壳」。
9. **brown_p=0.12** 是 400°C 热浴的建模选择（T87 默认 0.04），会同时加快壳与浴的混合；若改回 0.04，隔绝效果会更弱、壳寿命可能更长，未做敏感性扫描。
