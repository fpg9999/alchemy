# 能力系统：v3 三项数值 + v4 九项次级三阶（附 512 历史口径）

> 定稿：2026-11-18（v3/v4 现行口径）　实现：`alchemy/ability.py`　测试：`tests/test_ability.py` 26 项、全仓库 `tests/run_all.py` 124 项全通过
>
> **当前口径（§0：v3 + v4）**：能力轴为**类别辐条（聚 / 散 / 动）**，
> 能力是**三项可量化数值**；v4 再把每个主方向拆成 **9 项次级能力 × 三阶（低/中/高）**。
> 不再有 512 个离散状态，512 体系整体**冻结**为历史接口。
> 权重默认取价数（环号）：`[聚]=3O+2X+1C`、`[散]=3K+2A+1F`、`[动]=3P+2W+1L`。
>
> 本文「附」描述的 **512 体系**是 v2 及更早的口径，保留作历史与对照；
> `ability_of()` / `distribution()` / `catalog_combos()` 仍可调用，但默认流程已不再使用。

## 0. v3 + v4：能力 = 三项数值 + 九项次级三阶（当前口径）

### 0.1 v3：三个主方向 = 三项数值

| 能力轴 | 周期表辐条 | 组成 | 默认权重 |
|---|---|---|---|
| **聚** | 聚素轴 | O / X / C | 3 / 2 / 1（= 价数） |
| **散** | 散素轴 | K / A / F | 3 / 2 / 1 |
| **动** | 动素轴 | P / W / L | 3 / 2 / 1 |

与物性（径向：密度/粘性/温度）**几何垂直**，互不污染。

`ability.scores("OXC")` → `{'poly': 6.0, 'scatter': 0.0, 'move': 0.0}`，
并给出每个元素在该轴内的**贡献占比**（连续，不裁断）。

### 0.2 v4：九项次级能力 × 三阶（默认输出）

每个主方向下，**每个元素掌管一个次级能力**（共 9 个），每个次级能力用**两个阈值**切成三阶。

| 主方向 | 次级能力（元素） | 阈值（上界） |
|---|---|---|
| **聚** | 结构支撑（O）、刚性（X）、粘合（C） | (6,12) / (2,6) / (1,2) |
| **散** | 分化（K）、吸附（A）、切割（F） | (3,12) / (2,6) / (1,2) |
| **动** | 储能（P）、移动（W）、信号（L） | (6,12) / (2,6) / (1,2) |

**三条硬规则（2026-11-18 晚定）**：

1. **只有三阶**：低 / 中 / 高。**"无"并入"低"**——没有该元素与该元素极少不再区分；
2. **不做能力组合**：不枚举组合、不生成组合 ID、不互相折算；
3. **所有能力并存且互不影响**：9 项各自给数值与档位，缺一项不影响其他项。

其他约定：

- 次级能力名取自 `docs/T71_ABILITIES.md` 的"材料层能力"表，与项目既有命名一致
  （T71 整体已被 v3/v4 取代并加历史横幅，但 9 项次级能力的**命名**仍沿用该表）；
- 权重沿用 `CATEG_W`（= 价数），所以 **主能力值 = 三个次级能力值之和**，口径自洽；
- 档位规则：`≤ t1 → 低`（含 0），`≤ t2 → 中`，否则 `高`；
- 次级阈值由全目录**非零样本**的 33% / 67% 分位数定标（非零样本才能反映真实梯度）；
- 主方向的三阶阈值：`聚 (6,13)`、`散 (6,12)`、`动 (6,13)`。

#### 实测分布（全目录抽样 6,000）

| 主方向 | 低 | 中 | 高 |
|---|--:|--:|--:|
| 聚 | 36.4% | 33.1% | 30.4% |
| 散 | 38.2% | 29.7% | 32.1% |
| 动 | 33.2% | 33.8% | 33.0% |

主方向三阶基本均分。**次级能力则明显偏向"低"**，这是"无并入低"的必然结果：

| 次级能力 | 低 | 中 | 高 |
|---|--:|--:|--:|
| 结构支撑 O | 65.0% | 16.2% | 18.8% |
| 刚性 X | 60.1% | 27.5% | 12.4% |
| 粘合 C | 78.0% | 12.2% | 9.8% |
| 分化 K | 51.9% | 29.7% | 18.4% |
| 吸附 A | 61.4% | 26.2% | 12.4% |
| 切割 F | 78.7% | 11.9% | 9.4% |
| 储能 P | 62.5% | 17.2% | 20.3% |
| 移动 W | 59.6% | 25.9% | 14.5% |
| 信号 L | 78.6% | 11.8% | 9.6% |

一价元素（C/F/L）"低"占近 79%——因为约一半的分子完全没有一价端帽。

## 附：v2 512 历史口径（已冻结，仅作对照）

> 以下 A~D 是 v2 及更早的 **512 体系**，已被 §0 的 v3/v4 取代并**冻结**：
> 不再作为默认流程，只保留 `ability_of()` / `distribution()` / `catalog_combos()` 作历史对照接口。
> **现行口径请只看 §0。**

### A. 规则（v2 512）

**沿用"最多原子主导"**，但**并列最多时不再裁断，而是记为复合能力**。
每条轴（价数层）提供一个能力维度，每维度 **8 种情况**：

| 类别 | 种数 | 情况 |
|---|--:|---|
| 单元素主导 | 3 | 该层三元素中只有一个是最大 |
| **双元素主导** | 3 | 恰好两个并列最大（**保留，不裁决**） |
| 三元素主导 | 1 | 三者全等且 > 0 |
| 无主导 | 1 | 该层三元素全为 0 |

3 + 3 + 1 + 1 = 8/轴 → 三维复合 **8³ = 512**。

#### 1.1 三条轴的 8 种情况

| 轴 | 单主导 | 双主导 | 三合 | 无 |
|---|---|---|---|---|
| 三价 | 秩 O / 沌 K / 势 P | 秩沌 OK / 秩势 OP / 沌势 KP | 三合 | 无 |
| 二价 | 晶 X / 气 A / 流 W | 晶气 XA / 晶流 XW / 气流 AW | 三合 | 无 |
| 一价 | 冰 C / 焰 F / 电 L | 冰焰 CF / 冰电 CL / 焰电 FL | 三合 | 无 |

双主导的书写顺序固定按轴内元素顺序（O→K→P / X→A→W / C→F→L）。

#### 1.2 与旧分类的关系

| | 旧（T74 口径） | 新（本模块） |
|---|---|---|
| 并列最大 | **裁断**（按优先级取一个） | **复合**（记为双主导/三合） |
| 每轴情况数 | 3（+ 裁决） | **8** |
| 复合空间 | 27 | **512** |

合并信息不丢失：双主导、三合都是独立情况。

### B. 全目录实测（84,225 条，v2 512 口径）

#### 2.1 每轴的 8 种情况分布

| 三价轴 | 占比 | 二价轴 | 占比 | 一价轴 | 占比 |
|---|--:|---|--:|---|--:|
| 势 P | 35.8% | 流 W | 28.0% | 冰 C | 23.6% |
| 沌 K | 31.7% | 气 A | 25.4% | 焰 F | 23.5% |
| 秩 O | 31.5% | 晶 X | 24.5% | 电 L | 23.5% |
| 秩势 OP | **0.6%** | 晶流 XW | 5.6% | 焰电 FL | 5.1% |
| 无 | 0.2% | 气流 AW | 5.2% | 冰焰 CF | 5.1% |
| 三合 | 0.1% | 晶气 XA | 5.0% | 冰电 CL | 5.1% |
| 秩沌 OK | **0.001%** | 无 | 4.7% | 无 | 12.0% |
| 沌势 KP | **0.001%** | 三合 | 1.7% | 三合 | 2.0% |

**关键差异**：双主导在二价/一价轴上很常见（各约 5%），但在**三价轴上几乎不存在**
（秩势 0.6%，秩沌与沌势各只有 1 条）。
原因：三价元素只有三种，且在分子里数量少，很难恰好并列。

#### 2.2 512 种里实际出现多少

| 范围 | 出现的复合能力 | 占比 |
|---|--:|--:|
| 全目录 84,225 条 | **308 / 512** | 60% |
| 32 个群系（219 种分子式） | **89 / 512** | 17% |
| 46 种候选物质 | **34 / 512** | 7% |

**结论：512 是理论空间，实际可见空间远小于它。**
32 个群系加起来只用到 89 种；末位大量组合（尤其含三价双主导的）永远不会出现。

### C. 收紧方案（v2 讨论记录，已作废）

> **已定（2026-11-18）：采用 A 全量 512，不再收紧。** 下表保留作记录。
> **后续（v3/v4 定稿）**：512 整体冻结为历史接口，不再作为默认输出；收紧与否已不影响现行流程。

| 方案 | 三价轴取值 | 空间 | 说明 |
|---|---|--:|---|
| **A 全量** | 8 种 | 512 | 保留全部理论组合 |
| **B 去极罕见** | 6 种（去 秩沌 / 沌势） | **384** | 只去掉各 1 条记录的两种 |
| **C 只留单主导** | 4 种（秩/沌/势 + 无） | **256** | 三价轴不做复合 |
| **D 每轴都精简** | 二价/一价也只留 5 种（去三合） | 4×5×5 = 100 | 最省，但丢掉三合 |

按实测，**B 方案几乎无损**（去掉的两种各只有 1 条记录），能把空间压到 384；
若想让能力表更好维护，**C 方案（256）**也够用——因为 32 群系只用到 89 种。

### D. 用法（512 历史接口，冻结但可调用）

```python
import alchemy.ability as AB

AB.ability_of("OXC")["id"]              # 'O|X|C'
AB.ability_of("OXC")["label"]           # '秩|晶|冰'
AB.ability_of("OXCPWKA")["id"]          # 'ALL|ALL|C'   （三价、二价都三合）
AB.ability_of("O2X2P2W2K2A2")["id"]     # 'ALL|ALL|NONE'

AB.distribution(forms)                  # 512 种分布
AB.distribution(forms, axis="state")    # 单轴 8 种分布
AB.catalog_combos(forms)                # {'n_present': 308, 'n_total': 512, 'empty': [...]}
```
