## 3. 主规范：T75 方块世界（已采用）

### 3.1 核心规则

**每个三价连通骨架 = 地图上的 1 个单位正方形方块**；分子 = 若干方块组成的**多格骨牌（polyomino）**。

方块内部的区分（不再画元素字形）：

| 位置 | 含义 |
|---|---|
| 外框颜色 / 内部纹样 | 骨架家族（纯秩三角、纯势圆、纯散五角、秩势拱、秩散盾、势散圆角方、秩势散六边） |
| 右上小方点 | 该骨架由几个 6 级块融合而成（1~2） |
| 底部文字 | 块形态（38 库公式，如 `OP4K`） |
| 顶部小字 | 该骨架的三价原子数 |

### 3.2 方块之间怎么连（都画在共用边上）

| 连接 | 图形 |
|---|---|
| 晶 X 桥 | 共用边上短粗的浅灰焊块（最硬，两块直接咬死） |
| 流 W 桥 | 跨边的细长椭圆肌腱（可拉伸、可弯） |
| 气 A 桥 | 沿共用边的淡青细长薄膜（隔空软连） |
| 融合（0 级同类键） | 同一骨架内两块 6 级块的焊纹（几条斜刻纹） |
| 一价端帽 | 方块**外缘**的小方钉：冰 C 三角钉 / 焰 F 方钉 / 电 L 细圆钉 |

### 3.3 与内核的接口

本层需要的输入只有骨架分解：`alchemy.attrs.skeleton_units(atoms, edges)` 已给出
`members` / `bridge_members`（桥同时属于两侧）/ `size`，
足以驱动"每骨架一个方块 + 共用边上的桥"这套画法。

> 2026-11-19 复核：`skeleton_units` 只能驱动**抽象层**。上游 `t75_tiles.py` 实际还需要
> 原子坐标 `place`、家族与 38 库块形态匹配、融合对、支臂/端帽角色（即 `t68_data.json` 的结构），
> 因此「内核直接出图」还缺一层适配器（150~250 行，见 `docs/INTAKE_R2.md` §4.4）。

### 3.4 尚未实现

方块嵌入（BFS 四邻接排版）、方块绘制、桥/融合/端帽绘制 —— 上游已有实现
（`t75_tiles.py` / `t75_render.py`），内核侧暂不重复实现。
