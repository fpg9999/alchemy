# T22 · 自然环境端帽交换（修正版：端帽包含 2 价端帽双键）

> 修正：端帽不只是一价原子；**最外侧以双键挂在骨架上的 2 价原子（X/W/A 端帽双键）也算端帽**。
> 脚本：`t22_natural_caps2.py`、`t22b_verify.py`；数据：`t22_natural_caps2.json`、`t22_verified.json`。

## 1. 修正后的定义

物质的端帽集合 `Cap(M)`：
- **1 价原子**（C/L/F）：容量 1（一根键）；
- **2 价原子**（X/W/A）且两根键都连到同一个原子上（双键端帽）：容量 2；
- 其余原子 = 骨架。

端帽的"键数量" `K(M) = Σ容量`（1 价记 1、双键端帽记 2）。

**规则**：若 `K(A) = K(B) = K`，则
```
A + B → A' + B'
A' = S(A) + Cap(B)，B' = S(B) + Cap(A)
```
骨架保持不拆；新端帽按大锅规则重连（可单键挂、双键挂；容量 2 的端帽甚至可以
一根单键挂两个骨架原子，从而**由端帽变成桥**）。

## 4. 新增现象（相比仅 1 价端帽）

1. **端帽种类扩展到 X/W/A**：晶/流/气也可以做端帽（双键形式），端帽集合从 {C,L,F}
   扩到 {C,L,F,X,W,A}；因此同 K 的交换组合数量大增（新分子式 3,225 → 7,359）。
2. **端帽↔桥的角色转换**：容量 2 端帽重连时可以选择"双键挂同一原子"（仍是端帽）
   或"两根单键挂两个原子"（变成桥）。后者会改变骨架连通（把两个骨架原子连起来/成环），
   而骨架内部键不拆——这是"端帽交换"带来的一种**骨架级连接变化**。
3. **混合端帽**：产物端帽多重集可以是 1 价+2 价混搭，出现"双端帽结构"（两个 2 价端帽）
   等新形态。
4. **纯端帽分子（无骨架）**：如 X₂、A₂、C₂、CF 等二聚体，全部原子都是端帽；
   交换即整体交换原子集合，只能重新组合成端帽间的小分子（如 X₂↔CL 只交换不变化），
   部分组合会失败（价数配不平）。
5. 守恒与可逆性不变：
   - **骨架守恒**：骨架原子/键/元素组成不变；
   - **K 守恒**：只有 K 相同的物质反应；
   - **可逆**：交换两次回到原物质（`A+B ⇌ A'+B'`），且同端帽多重集时只发生端帽位置异构。

## 5. 与三层模型的关系

- 自然反应依然只动"最外层"：1 价端帽 + 2 价双键端帽；
- 但 2 价端帽可以转化为桥 → 相当于允许"端帽层"临时侵入"连接层"；
- 骨架层（38 库 + 0 级融合）仍不变；二价连接层的内部桥/链不动（除非它原本是端帽双键）。
