# T89 群系里的"类生命"候选：能自主移动 / 生长 / 分裂 / 驻留的分子团簇

> 2026-11-20。回答用户 m03544："查找其中类似生命，能自主行动的物质或分子团簇"。
> 数据 = T88 六个元素子集群系（B3_OFL / B3_OXC / B4_OXKF / B5_OXKAF / B6_OXCKAF / B9_all9），
> 规则 = T87（连续重力 + 非对称分子间力 + 骨架占格 + resolve 完全/不完全反应）+ 10°C 恒温平台 400 拍。
> 只看恒温阶段 t≥400 拍；跟踪帧每 25 拍一帧（`AsymWorld.frames`）。

## §0 摘要

1. **六个群系里都能找到"能动的团簇"**：B4 起共 **86 个 mover**（满足"持续 ≥4 帧、尺寸 ≥4、速度 ≥0.06 格/拍、直线度 ≥0.25"），占各群系分子 **1.2%~7.9%**；B3 两个三元素群系几乎没有——整个群系已经并成一个巨型团（76%/84% 分子），只剩它在原地缓慢蠕动。
2. **最好的"类生命"候选**：B9_all9 里一个 **13 个 CF 分子**的团，t=575~675 持续 5 帧沿一个方向漂移：净位移 7.4 格、速度 0.110 格/拍、直线度 0.67（持续朝一个方向，不是来回抖）。它没有边界、没有内部结构、没有繁殖，只是被"非对称力 + 重力"推着走的一段临时聚集体。
3. **生长与分裂事件大量存在但都是"并合/破碎"**：178 次生长、17 次分裂（B9），几乎都发生在体积 ≤64 的团上；尺寸越大越少见，且没有一次是"子团独立存活并继承特征"。
4. **结论**：在这个规则宇宙里，"自主行动"存在（非对称力导致动量不守恒，团簇可以自驱动），但**没有生命**——没有自我维持、没有边界、没有遗传/复制、没有能量代谢；运动是外力（非对称力 + 重力 + 边界反射）下的持续漂移，寿命大多只有 2~10 帧（50~250 拍）。

## §1 判据

| 类别 | 判据（恒温阶段 t≥400，25 拍/帧） |
|---|---|
| mover（自主移动团） | 持续帧数 ≥4；平均尺寸 4~64 个分子；速度 ≥0.06 格/拍；直线度（净位移/路径）≥0.25 |
| growth（生长） | 同一 track 内 n_max ≥ 1.5×n_min，且 n_max ≤ 64 |
| division（分裂） | track 结束后一帧，末质心 10 格内出现 ≥2 个子团，尺寸合计 0.6~1.6×原团 |
| colony（驻留大团） | n_mean ≥ 80、持续 ≥6 帧、速度 <0.05（在原地反应，不迁移） |
| life_score | `min(1,frames/8)·min(1,n_mean/10)^0.5·min(1,speed/0.12)·straight`（0~1，仅用于排序） |

> 说明：尺寸上限 64 是为了排除巨型沉积团——它的质心会因为内部重组而缓慢漂移，会被误判成"移动"。

## §3 最佳候选（B9_all9，CF 团）

- 尺寸：13 个分子（7~20 波动），t=575→675（5 帧）
- 路径 11.0 格，净位移 7.4 格，速度 **0.110 格/拍**，直线度 **0.67**
- 方向：**下沉**（dx=+2.8、dy=+6.8；dy 正=向下）
- 平均 A（聚素吸引力）=1.02、R（动素排斥力）=1.53、质量=0.46
- 主要成分：CF、CF、CF

形态：一条持续朝右下方向的漂移轨迹（图中绿圈起点、红圈终点），中途有一次小的方向修正，但整体朝同一方向。它被上方/左侧的团簇持续"推"和"吸"，本质是**净力不为零的受力漂移**，而非自主推进。

## §4 形态与规律

1. **能动的都是小团（4~20 个分子）**：mover 平均尺寸 5~13；>40 的大团几乎不动（被重力压在沉积层里，且被四周团簇约束）。
2. **方向约 1/3 上、1/3 下、1/3 横**：上浮/横向部分无法用重力解释，只能来自非对称力（A 吸 B 而 B 斥 A 时的净差）——这正是 T87 规则想观察的现象。
3. **速度 0.06~0.13 格/拍**，与尺寸没有单调关系（r≈−0.003）；质量/吸引力越大反而略慢（r≈−0.2）。
4. **没有稳定的"个体"**：mover 平均只持续 5~8 帧（125~200 拍），随后因并合/分裂/沉积而消失；尺寸稳定（±25%）的持续 mover 在 T87 全域里只有 3/1,243。
5. **分裂事件**（17 次）都是大团被撞碎或反应后重排，没有一次产生"可独立生存的子团"。

## §5 诚实判断

- **"自主行动"成立**：确实存在不受重力解释的持续移动团簇（B6、B9 最明显），这是非对称力 + 边界反射的必然结果。
- **"类似生命"不成立**：没有边界（团簇是开放集合，随时并入/脱离）、没有遗传（无模板）、没有代谢（能量从粘附锁/合成里来但无受控循环）、没有自我维持（寿命 125~200 拍）、没有复制。它更像"洋流里的絮团"，而不是"能自主行动的个体"。
- 若用户想要"更接近生命"的候选，需要考虑的方向：给团簇加**边界/表面层**（表面分子与内部不同）、加**模板**（某物种催化自身合成）、加**能量开关**（粘附锁需要持续供能才能维持），这些都还没做。
