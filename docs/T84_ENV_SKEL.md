## 1. 模型改动（相对 T83）

### 1.1 骨架格占位

- 每个分子由 k 个"6 级中间态骨架块"组成：`k = len(attrs.skeleton_units(atoms, edges))`；
  没有三价骨架的分子（如 K2、A2、F2、CF）记 **1 块**；
  目录外产物没有 `place`，按目录统计的**平均 8.08 原子/骨架**估算 `k = round(natoms/8.08)`。
- footprint 形状：k=1→1×1，k=2→1×2，k=3→1×3，k=4→2×2，更大取近似方阵（`skel_shape`）。
- 占格是**真实占位**：网格里每个 footprint 格都登记 owner；移动要求全部 k 格为空且在界内；
  接触/反应按"任两格 4 邻接"判定；粘附锁仍按相邻格 w≥1 记录。
- 投料 k 分布（按分子数）：1 块 6,796、2 块 6,511、3 块 1,320、4 块 125 → **平均 1.65 块/分子**。

### 1.2 温度曲线

```
T(t) = 10 + 990 · exp( −4.5 · t / 1199 )      (t = 0..1199 拍)
```

| t | 0 | 200 | 400 | 600 | 800 | 1000 | 1200 |
|---|---|---|---|---|---|---|---|
| T(°C) | 1000 | 477.4 | 230.6 | 114.2 | 59.2 | 33.2 | **21.0** |

要更接近 20°C 或更低，只需改曲线渐近值/时间常数（例：渐近 10°C、k=4.6 → 19.7°C；
渐近 5°C、k=4.4 → 16.8°C），不必改动力学。

### 1.3 其余物理（沿用 T83）

- 三轴：质量档 → 重力（轻 −0.55 / 中 0 / 重 +0.60，行号向下为正）；
  物态 → 迁移率（气 1.00 / 液 0.60 / 固 0.25）；
  温度档 → 恒素场（热格富集、冷格稀薄，10×20 网格，反应门控 gate=0.15+0.85ρ）。
- 三素力：`w = Att − Rep`（聚素=吸引、散素=覆盖半径、动素=排斥；κA=2.5、κR=0.5），
  力的方向决定移动方向，`p = STATE_MOB[state] · min(1, 0.25+0.75·|F|)`。
- 反应：相邻格对，`p = p_react(0.01) · MODE_MULT[物态对] · gate`；
  `MODE_MULT` 气-气 0.18 / 气-液 0.45 / 液-液 0.60 / 含固 0.80~1.00；cap=26。

## 6. "只有合并没有断键分解"是什么意思（回答用户问题 3）

本实验每对相邻分子做的事是：

```
total = vec(A) + vec(B)                 # 把所有原子放进一个集合
prods = complete_products(total)        # 规则 1~11 的 F(v)：确定性的"完全反应"
```

这里的"完全反应"有两层含义：

1. **组合层面**：A、B 的全部原子被放入同一个集合，重新按规则 1~11 成键；
   产物可以是 1 个、2 个甚至多个分子——所以"合并后变小/裂成两个"**是允许的**，
   只要总元素向量不变。
2. **操作层面**：`complete_products` 只会**贪心加键**，从不执行"断键"这个动作；
   它是在空图上重新长出一个满足规则的结构，而不是把反应物拆开。
   因此没有"一个分子自己断裂成碎片"（单分子自发分解）这条通道。

真正会"断键"的是另一个引擎入口 `natural_engine.resolve(mols, T)`：
当 `T < Σc`（温度低于接触集合的总键能）时，`complete` 不被触发，才会进入
**不完全反应**：选出最不稳定的一类键，每对断 1 根，再按规则 1~11 重新连回去
（可能产生多产物、分解），或者判定 none。

T82/T83/T84 的模拟都**直接调用 `complete_products`**，所以：

- 有"合并 + 整体重排"；
- 有"合并后裂成 2 个产物"（产物数 >1）；
- **没有**"单分子自发断裂/低温断键重排"这条通道。

如果要让"断键分解"真正出现，下一步应当把反应改成 `resolve([mi, mj], T_env)`，
并让温度真的降到键能以下（本模型里 `T < Σc` 才会切换通道）；这会是 T85 的方向。

## 7. 诚实局限

1. 点粒子动力学 + k 格 footprint：分子内部的原子不参与碰撞，只有 footprint 占格；
2. footprint 形状是紧凑多边形（1×2/1×3/2×2…），与骨架真实形状无关；
   第 i 个骨架块画在第 i 格，块间桥用虚线示意，不是真实 bridge 原子位置；
3. 目录外产物按 8.08 原子/骨架估算 k，没有结构信息（灰块）；
4. 团簇统计按格 8 邻接，footprint 使相邻分子更容易被判为同一团（1,205 偏高）；
5. 反应仍用 `complete_products`（无断键/自发分解，见 §6）；
6. 单 seed；温度曲线是给定函数，不是能量守恒下的自洽降温；
7. 与 T83 不可直接比较反应数（世界尺寸与占格都变了）。
