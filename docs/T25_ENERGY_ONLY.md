# T25 · 只保留能量限制（去掉端帽与单对交换限制）会怎样

> 条件：键能 S=3、C=2、L=1；反应中每有一根键断开并重连，必须释放 2 单位能量。
> 不再限制"只动端帽"、也不再限制"每次只交换一对端帽"。
> 统计脚本：`t25_energy_only.py`；数据：`t25_energy_only.json`。

## 1. 规则在纯能量下退化成一个简单定律

单根键断开+重连的释放量 = `w_旧 − w_新 ∈ {−2,−1,0,1,2}`；要 ≥2，唯一可能是：

**旧键 = S（3）、新键 = L（1）**。

于是"去掉端帽/单对限制"后，规则自动变成：

> **自然反应 = 把 S 键改造成 L 键**（每改一根释放 2，恰好达标）。
> C 键永远不能改（C→L 释放 1 < 2，C→更弱不存在）；
> L 键也不能改（已是最弱）；
> 只有 S 键可以被"拆掉重连成 L"。

这就是一条**单向的"S→L 弛豫"定律**：世界中的短键只会变成长键，不会反向。

## 2. 什么键可以被改造

- 旧 S 键要求键两端至少一端是 **聚**（S 只对含聚的组合开放）；
- 新 L 键要求至少一端是 **散**（L 只对含散的组合开放）；
- 因此**同一对原子**上能完成 S→L 的，只有 **聚–散** 原子对；
- 若"拆一根 S、在別处成一根 L"（允许原子重排、分子间重连），则只需：断的每根是 S、成的每根是 L。

## 3. 统计（≤8 原子、3,931 种物质）

| 指标 | 数值 |
|---|---|
| 总 S 键 | 9,362 根 |
| 其中"聚–散"S 键（可直接 S→L） | **4,008 根（42.8%）** |
| 冻结 S 键（聚-聚 / 聚-动，无法直接变 L） | 5,354 根 |
| C 键 | 11,194 根（完全冻结） |
| L 键 | 9,252 根（完全冻结） |
| **含至少一根可转换 S 键的分子** | **2,018 / 3,931（51.3%）** |
| 只有冻结 S、无 S→L 可做的分子 | 1,020（25.9%） |
| 无 S 键的分子 | 893（22.7%） |

→ 在纯能量规则下，**约一半分子会自发弛豫（S→L）**，另一半已经是稳定态。

## 4. 会发生的反应形态

1. **分子内弛豫**：同一分子里的 聚–散 S 键变长成 L 键（几何上把两个原子拉开到距离 2）。
   分子式不变、骨架形状变松——这是**结构异构化**。
2. **分子间重连**：断 A 的 S 键、在 B 上成 L 键（或两分子碎片互换），可改变分子划分。
   这类反应可能改变每个分子的分子式（产生新分子式），但每一步仍必须是 S→L。

## 5. 稳定性与终点

- 每次反应 E 下降 2×n（n 根键），E 有下界 ⇒ **必然终止**；
- 终点 = **没有可改造的 S 键**的体系：
  - 要么没有 S 键（22.7%），
  - 要么 S 键全是"冻结 S"（聚-聚 / 聚-动，25.9%）；
- S 键数量只减不增（新键只能是 L）⇒ 环境单调"变软"，不会振荡、不会循环。

## 6. 问题：骨架会被"溶解"

这是去掉端帽限制后的真正后果：

- S 键正是骨架层的主要连接（S 短键构成骨架的紧凑部分）；
- 纯能量规则允许骨架内的 S 键（只要涉及 聚–散 对）被改成 L 键；
- 于是 **T18/T17 的骨架结构会逐步松弛、解体**，最终世界里的物质变成"以 L 键为主的松散结构"；
- 这虽然能量上稳定、且终止，但**破坏了骨架分类体系**，也不符合"自然环境中物质保持可识别形态"的设计目标。

## 7. 结论

| 限制 | 结果 |
|---|---|
| 只保留能量规则 | 退化为"S→L 单向弛豫"；约 51.3% 分子会变松；终止且稳定，但**骨架被破坏**，产生大量结构异构体；分子式层面基本不新增（除非分子间重连） |
| 再加"只动端帽" | 保护骨架，反应稀少（T24：反应率约 1.6%，96.2% 产物已知） |
| 再加"每次只交换一对端帽" | 反应更稀少、更局部、更容易可视化 |

**建议**：以 T24 的"只动端帽 + S→L + 每根键释放 2"为基础，保留骨架不受破坏；
"纯能量无限制"版本可作为特殊环境（高温/催化/长时间地质作用）下的"物质老化/软化"机制，
而不是常规自然反应。
