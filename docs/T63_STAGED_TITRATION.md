## 0. 一句话结论

**只投入 29 种纯聚素（O/X/C）退火 → 每次补一种"大量单质"（先 1 价焰 F2、再 2 价气 A2、最后 3 价沌 K2）继续退火**，体系呈现教科书式的**逐级价数滴定**：
每一次投放都把上一阶段的终态**整体熔断、完全换代**（top20 保留数为 0），产物家族依次为

## 1. 实验设计

### 1.1 用户要求（2026-11-17）

> "先只用聚素物质，第一次退火之后加入大量的焰单质（焰-焰）进行第二次反应实验，退火后加入大量的气单质进行第三次实验，退火后加入大量的沌单质进行第四次实验。"

解读为**四阶段单质滴定**：

1. 阶段 1：只投聚素（O/X/C 的 29 种物质），完整退火 1000 → 0°C；
2. 阶段 2：0°C 后"整理归档"（保留全部终态分子，不过滤），投入大量 **F₂（焰-焰）**，重置 1000°C 再退火；
3. 阶段 3：同样整理后投入大量 **A₂（气-气）**，再退火；
4. 阶段 4：同样整理后投入大量 **K₂（沌-沌）**，再退火。

投放顺序 = **1 价（F）→ 2 价（A）→ 3 价（K）**，正好对应元素角色表（§2.1：F 端帽、A 连接层、K 骨架/长键），见 HANDOFF §2.1。

### 1.2 "其他变量自行调节"的部分

| 变量 | 取值 | 理由 |

| 阶段 1 投料 | T57 全部 29 种纯聚素，9,002 分子 / 38,532 原子（平均 4.28） | 直接复用 T57 已验证的纯聚素设计（面积模型 `A∝n_atoms`、数量 `∝1/A`） |
| 每次投放量 | 8,000 分子 = **16,000 原子**（F2/A2/K2 各 8,000） | 约等于阶段 1 原子数的 42%，足以"改写配方"又不变成长时间的稀释 |
| 环境尺寸 | **L = 30000**（T57 用 10000、T59/T62 用 60000） | 20,000~28,000 分子量级下，保持碰撞频率与 cap 压力平衡的中间值 |
| cap | `max_reaction_atoms = 40` | 沿用 T59/T62 口径，便于横向对照 |
| 阶段温度程 | 每阶段 1000 分钟，线性 1000 → 0°C | 与 T55/T57/T59/T62 完全一致 |

| 无化学对照 | 阶段 1 单独跑 500 分钟（`t63_control_s1.json`） | 验证碰撞计数充足（≥500 次/分子） |

## 2. 阶段 1：29 种纯聚素熔体（1000 → 0°C）

| 阶段 | v3（O/P/K） | v2（X/W/A） | v1（C/L/F） | v3:v2:v1 |

- 占比先被推向极端（阶段 2 一价过半、阶段 3 二价最大），**阶段 4 后回弹到接近 1:1:1**——与 T62"等量价数 → 稳定双组分"的结论互相印证：1:1:1 价数是本体系的强吸引子，多投的那 16,000 个 3 价原子恰好把它补平。

### 6.3 物种完全换代：top20 保留数 = 0

| 跃迁 | 上一阶段分子式 | 新阶段分子式 | new | retained | lost |

## 7. 与 T57 / T59 / T62 的对比

## 8. 机理讨论

### 8.1 结果与元素角色表完全一致

HANDOFF §2.1 的元素角色：F = 1 价端帽、A = 2 价连接层、K = 3 价骨架/长键。T63 的产物序列逐字验证了这张表：

- **F 阶段**：`OCF2`（O 被两个 F 端帽盖住）、`O2X2C2F2`（F 封端的大分子）、`X2`（无 F 可挂的 X 自配对）；
- **A 阶段**：`XCF`/`OAF`（A 挤进原 F 的位置，形成桥连三元组）、`O2A3`（A–A 桥连）、`X2C2`；
- **K 阶段**：`OK` 三键（3 价 K 与 3 价 O 的强配对）、`O2X3C3K3A3`（K–A–O 复合盐）、含 K 巨型（K 骨架 + A/F 填缝）。

### 8.2 为什么每次都能"完全换代"

两个条件同时满足：

1. **投放量足够大**：16,000 原子 ≈ 阶段 1 的 42%、阶段 2 的 29%，且是"同一价数类别"的过量，会打破原有价数平衡；
2. **1000°C 复热**：完全反应判定 `T ≥ Σc` 在 1000°C 下几乎总成立（T35 全加和阈值只有 1~24），所以每次复热都会**把全部旧分子拆成原子级再重组**——旧终态没有"记忆"。

对比 T62 第二阶段只"提纯"不"洗牌"：T62 的 batchB 是 120 种混合分子（80,027 原子），与旧底物元素配比接近，复热后重组仍收敛到同一不动点；T63 每阶段是"单一价数类别过量"，配比被强制改变，所以必然换代。

### 8.3 F₂ 为什么会在 K 阶段再生

- 在前三阶段，F 的 1 价被 O/X/C 的悬空价"吃满"（阶段 2 F 家族占 88.6% 原子）；
- K 是 3 价，与 O（3 价）形成 **O≡K 三键**（`OK`，6 价全填），把 O 从含 F 分子中抢走；
- 失去宿主的 F 只能两两配对 → **F₂ 单质再生**（6,521 个分子 = 13,042 个 F 原子 = 全部 F 的 81.5%）；
- 这是价数规则的必然结果：**更强/更高价的配对（K–O 三键）会把弱端帽（F）挤回单质**。

### 8.4 终态价数回弹 = T62 吸引子的再次出现

T62 的结论是"价数 1:1:1 → 双组分等摩尔不动点"。T63 从 1:1:1（阶段 1 投料）出发，被三次滴定推到极端，最后又回到 **32.4 : 35.1 : 32.5**——偏差 <3pp。这说明：

- 价数 1:1:1 不是 T62 的偶然，而是**体系层面的吸引子**；
- "逐级加单质"可以看作对这个吸引子的**往复滴定实验**：加 1 价 → 偏 1 价；加 2 价 → 偏 2 价；加 3 价 → 回正。

### 8.5 巨型的两个成因

1. **K 的高连接度**：3 价 + 长键 L，单个 K 可挂 3 个方向，K/A/O 复合盐（`O2X3C3K3A3`）就是 14 原子骨架；
2. **cap=40 的边界**：巨型恰好卡在 39/40 原子（7 种巨型全是 39 或 40 原子）——它们不是"长到 40 就停"，而是"合并超过 40 被弹性截断"，所以 40 是观测上限而不是化学上限（与 T59/T62 的 cap 巨型同理）。

---

## 9. 结论

1. **逐级单质投放 = 逐级价数滴定**：F₂ → A₂ → K₂ 三次投放依次把体系改写为"F 端帽 / A 桥 / K 骨架"三类终态，每阶段完全换代（retained=0）；
2. **产物家族严格对应元素角色**：F 端帽、A 连接层、K 骨架，与 §2.1 角色表逐字一致；
3. **F 会被更高价配对挤回单质**：K 阶段 O≡K 三键形成后，81.5% 的 F 以 F₂ 形式再生——"单质再生"是价数规则的直接推论；
4. **终态价数回弹到 ~1:1:1**，再次印证 T62 的等量价数吸引子；
5. **capped/巨型只在 3 价 K 阶段出现**（0.435%，24 个 39/40 原子巨型，<1%），说明 3 价元素是巨型堆积的直接驱动；
6. **纯聚素熔体不动点稳定**：阶段 1 与 T57 在 L 放大 3 倍后仍复现 OXC ~80.8%。

### 下一步建议

1. **cap60 高保真对照**（同投料/种子，仅 cap 40→60）：验证 K 阶段巨型是否与 T59/T62 一样是 cap 边界产物；
2. **反向滴定**：K₂ → A₂ → F₂ 顺序投放，检验"顺序是否可交换"（价数滴定是否路径依赖）；
3. **低温窗口**：T0≈12°C 下重复四阶段，看中间产物（F 端帽/A 桥小分子）能否被"冻结"保存；
4. **多次循环**：四阶段后再投一轮 F₂，检验体系是否回到阶段 2 的终态（可逆性/迟滞）；
5. **元素角色定量化**：把"F 端帽率、A 桥接率、K 骨架率"做成随投放量变化的曲线，得到价数滴定的"滴定曲线"。
