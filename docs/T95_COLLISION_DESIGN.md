## 0. 要解决的实现问题

代码实测（非猜测）：

1. **平移不推挤**：`alchemy/t84_env_skel.py:147-169` 的 `_try_move` 要求平移后 footprint
   所有目标格为空；任一格被其他分子占用 → `n_blocked += 1; return False`。
   团簇内部邻居互相占着对方的目标格，所以团簇几乎无法整体平移。
2. **多格团簇不落**：`alchemy/t87_env_asym.py:112-149` 的 `_gravity_step` 要求整段
   footprint 下方全空才下落；只有“单格移动者 + 单格阻挡者 + 重压轻 + 概率”才交换。
   → 多格团簇既不能沉、也不能推，钉在生成位置 = 观察到的“悬浮不动”。
3. **键锁限制重排**：`alchemy/t83_env_axes.py:296-303` 的 `_lock_ok` 要求与锁邻居的
   位移不超过 `lock_r=2`。
4. **反应原地生成**：`_apply_group` 在质心 `_spawn` 产物，团簇在原地长大、占地越来越多。

结论：“悬浮”是规则实现层的钉住，不是力平衡。T95 把它们改成可推挤、可落下、
可被碰撞打散的动力学。

## 2. 冲突决策链（核心算法）

当分子 A 想沿方向 n 前进 1 格，目标格被分子 B（或 B 所在团簇）占据：

1. **团簇化**：把锁连通分量当作刚体 `C`，质量 `M = Σ m_i`、速度 `v = 质心速度`、
   粘附能 `W = Σ 锁邻接对的净吸引力`。
2. **接近判据**：`v_rel = (v_A − v_B)·n`；若 `v_rel <= 0`（互相远离）→ 不处理，正常移动。
3. **动量预算**：
   - 推动者：`J_A = M_A·max(0, v_A·n) + max(0, F_A·n)·dt`
   - 抵抗者：`J_B = M_B·max(0, −v_B·n) + J_stick(B) + J_floor`
     - `J_stick(B)` = B 与锁邻居的净吸引力之和（越粘越难推）
     - `J_floor` = 若 B 下方/前方有地面支撑，加上静摩擦项 `μ·M_B·g`
4. **质量下限**：`M_A >= M_min_ratio · M_B`（仅作硬门槛，不是唯一判据）
5. **解算条件**：`J_A > J_B` 才推动；否则计 `n_push_fail`。
6. **一维冲量**（沿 n，恢复系数 e）：
   ```
   v_A' = (M_A v_A + M_B v_B − M_B e (v_A − v_B)) / (M_A + M_B)
   v_B' = (M_A v_A + M_B v_B + M_A e (v_A − v_B)) / (M_A + M_B)
   ```
7. **网格落地**：A 前进 1 格；B 按 `v_B'` 累积位移，>=1 格时后退 1 格（同拍最多 Kmax 个
   分子参与链）。先试后写：整条链的目标格先做占用检查，全部通过才统一提交 cell 变更，
   保证元素守恒与 footprint 一致。
8. **能量损耗**：每拍 `v *= (1 - gamma)`；`|v| <= Vmax`。

P1（第一阶段）：只对**单格分子**实现链式推挤（团簇=单格时自然退化为旧行为+推挤）。
P2（第二阶段）：多格团簇整体速度场、团簇间碰撞、被推散（锁断裂留给后续版本）。

## 3. 受力来源

- 三素力：`AsymWorld.force_on(mid)`（T87 的非对称版本）→ 团簇求和。
- 重力：`G_GRAV * mass`（T87 常量；T94 的 `grav` 参数化版本沿用）。
- 粘附：`W` = 锁邻域净吸引力和（`three_su.pair_force` 的 w）。
- 地面支撑：世界底部边界内一格视为支撑，静摩擦计入 `J_floor`。

## 4. 数据与不变量

- 每个活动分子新增字段：`vx, vy（格/拍）, px, py（累积位移）`；团簇质心速度每拍重算。

  mover 计数、内外接触计数、元素守恒断言、运行时间（目标 < 旧实现 2×）。
