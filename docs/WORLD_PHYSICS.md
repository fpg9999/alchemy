# 世界物理规则（终版）

> 2026-11-20 定稿。对应实现：`examples/lattice_sim.py`（默认参数即本页规则）。

## 一、三条轴的分工

| 轴 | 来源 | 作用 |
|---|---|---|
| **质量** | 三价层特征值平均（O=3 / K=2 / P=1） | **决定沉降** |
| **聚 / 动 / 散** | 三类元素特征值之和 | **决定分子间力** |
| **物态** | 二价层特征值平均（X=3 / A=2 / W=1） | **只决定玩家能否穿过**，不参与物理 |
| **温度** | 一价层特征值平均 | 未接入（预留给恒素富集） |

**要点**：物态已完全退出物理判定。固/液/气不再影响流动、沉降或相互作用。

## 二、力的规则

对分子 i 与 j（距离 d，作用半径 D = max(D_i, D_j)，dn = d/D）：

```
dn < 0.3      ：斥力，从 −R_j 线性回到 0      ← 被对方的动素推开
0.3 ≤ dn < 1  ：引力，三角峰在 dn=0.65 达 +A_i ← 被自己的聚素拉动
dn ≥ 1        ：0
```

**非对称**：`k_ij = A_i − R_j ≠ k_ji`。

三个和到四个值的转化：

```
A = A_max · S_聚/(S_聚+K)          A_max = 10, K = 8
R = R_max · S_动/(S_动+K)
D_att = D_min + (D_max−D_min)·(0.5·s + 0.25·a)
D_rep = D_min + (D_max−D_min)·(0.5·s + 0.25·m)
D_min = 0.5, D_max = 3.0
```

## 三、每个 tick 的决策链

```
① 沉降（质量 > 0）
   下方空         → 下沉
   下方更轻       → 推下去（推不动就交换）
   已平衡         → 不动

② 铺平（质量 > 0，静止时）
   只在"侧列下方更少"时侧移（沙堆式平衡）
   平衡后不再移动

③ 分子间力 + 惯性
   目标空位       → 移动
   目标被占       → 必须同时满足：
                    · 保序（水平自由；垂直只允许重的往下、轻的往上，等重不限）
                    · 交换后总势能更低
                 否则不动
```

## 四、关键机制

| 机制 | 作用 |
|---|---|
| **重力按列累积** | 下方分子承担上方全部重量（水压） |
| **推开链** | 重的可把轻的整条链推下去 |
| **保序交换** | 允许流动但禁止破坏分层 |
| **能量规则** | 交换必须降低势能 → 消除"两个分子来回换位"的振荡 |
| **平衡侧移** | 消除液面永不停歇的侧滑 |

## 五、观测到的世界性质

| 性质 | 数值 |
|---|---|
| 静止世界比例 | **100%**（44/44 世界完全静止） |
| 同种分子邻接率 | **72.4%**（随机约 40%，富集 1.8 倍） |
| 分层相关性 r(质量, 高度) | 0.50 ~ 0.61 |
| 每 tick 移动分子比例 | **0%** |

**世界会自行冻结在局部能量最低点。** 化学聚集在冻结前已完成。

## 六、冻结 = 潜力

冻结不是终点，而是**亚稳态**：

- 任何能量注入（反应、恒素交换）都会打破平衡
- 一旦打破，分子间力会重新驱动分子运动
- 系统会再次寻找新的能量最低点

**"大多数世界静止，但保有流动起来的潜力"** —— 这正是当前规则的设计目标。
