# T23 · 自然环境「稳定化」反应规则（不产生新物质 + 尽量少反应）

> 【注意：早期版本因公式字符串 bug 导致 R1/R3 比例虚低；修正后 R1=62.61%、R3=15.68%，说明"白名单"规则本身并不够严格，应以 T24 的键能规则为准。】
>
> 目标：给自然环境下分子间反应设计一套规则，使
> ① 不产生任何新物质（产物必须都是世界里已经存在的物质）；
> ② 反应尽可能少，物质趋于稳定。
> 脚本：`t23_stability_rules.py`；数据：`t23_stability_rules.json`。

## 1. 推荐规则（三条，按严格程度递进）

### 规则 I：已知物质守恒律（基础）
一次自然反应（端帽交换）**只有当两个产物分子式都已经存在于世界物质集合中**（大锅目录/已发现集）时才允许发生；否则两个物质只是"相遇但不反应"。

- 效果：**不产生新物质**；
- 反应率（≤8 原子样本，100,435 对同 K 对）：**778 对 = 0.77%**，即 99.2% 的相遇不反应。

### 规则 II：稳定化律（推荐）
在规则 I 基础上，再要求反应后"端帽失配能" E 严格下降：

```
E(分子) = Σ(每个端帽的键型与其元素偏好键型不一致的个数)
偏好键型：聚系端帽→S（短键）、动系端帽→C（角键）、散系端帽→L（长键）
允许反应 ⇔ 产物都已知 且 E(A')+E(B') < E(A)+E(B)
```

- 效果：**不产生新物质**，且 E 是有界非负整数、每次严格减小 ⇒ **反应必然终止**，
  系统收敛到"局部稳定态"（任何进一步交换要么产物未知、要么 E 不下降）；
- 反应率：**188 对 = 0.19%**（约为规则 I 的 1/4）。

### 规则 III：端帽惰性/异构律（最保守）
在规则 I、II 之上，再要求两端端帽多重集完全相同（只可能交换端帽位置）：

- 效果：物质组成完全不变，只有端帽位置异构（同一分子式）；
- 反应率：≈ 规则 II 的子集（进一步更少），环境几乎"冻结"。

> 若希望自然界"几乎不反应"，可用规则 II；若要"绝对冻结"，用规则 III。
> 规则 II 已经能在 99.8% 的相遇中保持不反应，同时保留少量"自发趋于稳定"的演化。

## 2. 为什么这样能"趋于稳定"

- E 只减不增、有下界 ⇒ 不存在循环（这是关键：规则 II 自然排除了端帽交换的可逆来回）；
- 产物必须在已知集合内 ⇒ 新物质只能由大锅（高能反应）产生，自然环境只是"整理/退火"；
- 允许的反应都是"把端帽从不匹配的骨架移到更匹配的骨架" ⇒ 直观解释为**降低表面能/退火**。

## 3. 数据（≤8 原子、含骨架的 3,931 种物质，同 K 抽样 100,435 对）

| 规则 | 会反应的对数 | 占比 |
|---|---:|---:|
| R0（只要求 K 相同） | 100,435 | 100% |
| R1（产物都已知） | **62,881** | **62.61%**（修正后） |
| R2（同端帽多重集） | 11,027 | 10.98% |
| **R3（产物已知 + E 下降）** | **15,752** | **15.68%**（修正后） |

## 4. 允许的稳定化反应示例（R3，全部产物都在大锅目录）

| 反应 | 端帽失配能 E |
|---|---|
| `O2X2P4 + O4W2K2 → O2P4W2 + O4X2K2` | 2 → 0 |
| `O2L4 + X2P2 → O2X2 + P2L4` | 2 → 0 |
| `P2W2K4 + X2P2 → X2P2K4 + P2W2` | 3 → 1 |
| `C4K2A2 + O2X2 → X2K2A2 + O2C4` | 1 → 0 |
| `O2X2W2 + P4K2A2 → O2X2A2 + P4W2K2` | 2 → 1 |
| `O2P4A2 + W2K2A3 → O2P4W2 + K2A5` | 2 → 0 |

## 5. 被阻止的反应示例（规则 II 下不反应）

| 反应 | E 变化 | 阻止原因 |
|---|---|---|
| `X2P2W3 + X2K2A3 → …（原样）` | 2 → 2 | E 不变 |
| `O2X2C2F2 + P2W2L2F2 → O2X2L2F2 + C2P2W2F2` | 3 → 3 | E 不变 |
| `O2WA + O2WA3 → O2A2 + O2W2A2` | 2 → 3 | E 上升 |
| `P2W2A4 + O2X4 → X2P2W2A2 + O2X2A2` | 1 → 2 | E 上升 |

## 6. 实现细节

1. **端帽识别**（修正版）：
   - 1 价原子（C/L/F）→ 端帽，容量 1；
   - 2 价原子（X/W/A）且两根键都连同一原子（双键端帽）→ 端帽，容量 2；
   - 每个物质的端帽键数 K = Σ容量。
2. **K 相等判定**：只有 K 相等的两物质才进入自然反应判定。
3. **端帽交换**：骨架固定不动；新端帽重连按大锅规则（可双键挂或单键挂，1 价挂单键）。
4. **产物检查**：两个产物分子式都在"已知集合"（大锅目录，或当前世界已发现物质）；
5. **稳定化判定**：比较 E 前后值，严格下降才允许反应；
6. 反应后结构还要做一次几何合法性检查（若失败则视为不反应）。

## 7. 设计参数建议

- **已知集合**：用大锅可产出目录（84,225 条）作为"世界物质库"；可扩展为"已发现集合"以鼓励探索。
- **E 的权重**：目前"失配 1 点"；可改为按键型强弱加权（如 L 不匹配扣 2），调节反应方向偏好。
- **反应概率**：若想让自然反应更稀有，可在规则 II 上再乘一个活化概率 p（例如 5%），
  则有效反应率 ≈ 0.19%×p（p=0.05 时约万分之九）。
- **稳定态判定**：当某物质与同 K 的所有已知物质交换都不满足规则时，它就是自然稳定物质；
  自然环境下会逐步"吸附"到这些稳定物质上。
