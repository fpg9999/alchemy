# T11B · 反应循环研究（允许副产物）

> 定义修正：**循环 = 起点物质 A 最终被重新产出**，中间步骤可以产生副产物。
> 例：`A+B=C`（单产物），`C+D=A+E`（A 重新出现，E 为副产物）——这种循环**存在且大量存在**。

## 0. 结论

- 真 2-环（A→C→A，两步都是真反应）：**2432 个**（按无向去重；含方向则倍）。
  - 分类：聚素内 **112**、无三价内 **2031**、跨类 **289**。
- 真 3-环：188,723 个（聚素内 2,147、无三价内 145,473、跨类 41,103）。
- 环很常见，**A 在这类循环中扮演催化剂**：循环净反应里 A 被消掉（重新生成），只把其它物质转化。
- 之前的"循环不可能"结论只适用于**每一步都是单产物**的严格链；一旦允许副产物，守恒不再禁止循环。

## 1. 三类 2-环示例（净反应式）

### ① 无三价内：C2 催化（最典型）
```
第1步  C2 + X2      → X2C2
第2步  X2C2 + A2    → C2 + 2 XA
净反应  A2 + X2     → 2 XA          （C2 被再生，可循环使用）
```
再如：`C2+X2→X2C2; X2C2+A2→C2+2XA`、`C2+A3→C2A3; C2A3+W3→C2+3WA` 等。

### ② 跨类：C2 催化，把 聚素 与 散素/动素 连接
```
第1步  C2 + O2X2C4  → 2 OC3 + X2
第2步  X2 + C2A2    → C2 + 2 XA
净反应  O2X2C4 + C2A2 → 2 OC3 + 2 XA     （C2 被再生）
```
更简单的跨类：`C2+O2→O2C2; O2C2+A3→C2+O2A3`，净反应 `O2+A3→O2A3`。

### ③ 聚素内：O2C2 催化
```
第1步  O2C2 + C2  → O2C4
第2步  O2C4 + O2  → 2 O2C2
净反应  C2 + O2 → O2C2      （O2C2 被再生）
```

## 3. 规律总结

1. 循环的存在条件（向量层面）：设循环 A→C→A，
   第一步 vA+vB = vC+ΣE1；第二步 vC+vD = vA+ΣE2 ⇒ 副产物总量 = vB+vD。
   只要系统里存在能承载 vB+vD 的副产物组合，就有循环。
2. 因为反应结果只由总向量决定，循环与具体分子式无关，只与总组成有关——同一总组成的不同物质对共享同一循环。
3. 典型模式：**小分子 A 先与伙伴 B 合并成 C，C 再与 D 反应把 A 挤出**（吸收-释放），A 净再生。
4. 这类循环是真正的"催化"：A 不被消耗，可反复使用；净反应只发生在 B 与 D 之间。
5. 越小的物质（1~4 原子）越容易当催化剂（因为它们的向量小、容易在第二步被重新挤出）。
