# T62 独立验证报告（守恒 / 等量性 / 对照 / 自洽）

> 验证对象：T62 九元素两阶段实验（三/二/一价等量投料）。
> 验证脚本：`t62_verify.py`（独立实现，不 import 项目化学模块，自行解析分子式/价数/结构合法性）。
> 结果数据：`t62_verify.json`（含全部输入文件 SHA256、逐项实测值、容差与 overall）。
> 运行：`python t62_verify.py`（默认读取 `t62_*`；可用 `--a/--b/--control/--a_hf/...` 覆盖）。
>
> **结论：overall = PASS。PASS=57、FAIL=0、PENDING=0、SKIP=0、INFO=2；7 组检查全部通过。**

  stateA 总数/组成与结果一致（48 种结构）。

  终态 N=51,937、原子 230,046；逐元素 == A 终态 + batchB；stateB 总数/组成与结果一致（47 种结构）。
- **质量平衡**：B 原子 == A 终态原子 + batchB 原子 == B 终态原子（逐项相等）。
