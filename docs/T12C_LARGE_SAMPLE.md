### 1.2 反应计算

- 对每个采样对 (A,B)：把 A、B 的全部原子投入大锅，用 **pot_v3（规则 1~9）** 逐根贪心成键；
- 反应成功 = 所有原子剩余键数=0，且**每个产物分子**都能用 `pot_v2.embed_mol2` 在六边形格上严格合法摆放；
- 产物记为排序后的分子式多重集；记录产物个数、最大分子原子数、耗时。
- **总向量去重优化**：反应结果只取决于元素总向量 vA+vB，故按唯一总向量只计算一次再回填到各对；本次 10000 对只有 9977 个不同总向量。
- 采样随机种子固定（`20261113 + layer*7919`），结果可复现（`t12c_run.py`）。
- 口径说明：正式模拟器为 pot_v3（规则 1~9，规则 9 = 元素优先级决胜）；任务接口里的 `pot_all`（规则 1~8）在 400 个随机小投料上与 pot_v3 **400/400 结果相同**（规则 9 只在残余并列时起作用，实测 T≤9 无残余并列）。

### 1.3 性能与预算

- 全样本累计单核时间：simulate ≈ 6414s，embedding ≈ 16841s（含 8M 重试）；主采样 18 进程墙钟 **11.7 分钟**（实测），重试阶段另用 **11.4 分钟**（实测）。
- 大分子 embedding 是主要瓶颈：97 原子单分子约需 3M 节点/≈19s，140 原子单分子需 8M 节点/≈25s。因此主采样对每个产物分子设 3,000,000 节点预算，超预算记为「摆放失败」。
- **embedding 重试**：对 131 个 3M 预算失败的总向量用 8,000,000 节点预算重试，发现 **9 个其实可摆放**（6.9%，占全部样本 ≤0.1%），其中包括 140 原子新纪录分子；其余仍记为「摆放失败」并计入 §4.1。

## 6. 总向量决定律与碰撞率

### 6.1 定律

反应结果只取决于元素总向量 vA+vB（原始目录中每个物质无论结构如何，拆开后只剩元素计数）。因此「不同物质对、相同总向量 ⇒ 反应结果完全相同」。

### 6.2 碰撞统计（分层精确枚举 + 全目录抽样）

|---|---|---|---|---|---|---|
| L1(2-8) 全层 | 3931 | 7724415 | 655965 | 624401 | 7692851 | 99.591% |

| 全目录随机抽 1,999,977 对 | 84,225 | 3,546,883,200 | 样本内 1,925,027 | - | - | 样本内碰撞对占比 3.748% |

补充：随机两个物质对总向量相同的概率（二阶矩估计）≈ **3.923e-08**；全目录无序对总数 3,546,883,200。

**解读**：小原子数层（L1 全层 772 万对）里，不同物质对共享同一总向量很常见（碰撞率见上表）；原子数越大，总向量空间越大、碰撞率急剧下降。全目录随机对之间「撞总向量」的概率极低，但**小分子之间**的碰撞是「同总向量定律」最常被观察到的场景。

### 6.3 100 组「同总向量、不同物质对」独立验证

- 从分层精确枚举中抽 100 组（每组至少 2 个不同物质对，覆盖 L1/L2/L3/L4），对每对**用其自身目录原子顺序**独立跑 pot_v3（不共用缓存），比较产物分子式多重集；另用规范顺序 + 随机打乱顺序各跑一次。
- 结果：**100/100 组完全一致**；打乱原子顺序后仍一致 100 组；其中反应成功 100 组、失败 0 组（同组内成功/失败也一致）；embedding 通过 97、失败 3 组。

### 6.4 采样内碰撞

- 本次分层的 10000 个采样对按总向量分组得 9977 组，其中 23 组含 ≥2 对；组内结果（按缓存）全部相同 = True。
- 采样碰撞率（(对数-不同总向量数)/对数）=0.230%；大原子数层的总向量空间大，所以这个数字比 L1 精确值低很多。

### 6.5 单产物 = 严格向量加法（数据验证）

- 若投料总向量恰好等于目录中某物质 C 的分子式向量，则反应结果应为**单产物 C**。本样本中总向量命中目录物质的对有 **363** 个，违反（失败或产物不是 C）**0** 个。
- 这说明「单产物化合」没有催化/取代：A+B→C 当且仅当 vC=vA+vB。

### 7.4 跨元素规律总结

1. **失败**：物质对的奇价失败恒为 0（目录物质价数和恒偶）；真正的失败只有两类——偶价剩键（罕见，纯大类 3/435≈0.7%、纯异大类 36/900=4%）与产物摆放不合法（大原子数 L3/L4 的主要失败形式）。
2. **哪种元素组合最容易失败**：失败率与「元素数/原子数」强相关——5~6 元素聚动散子集、总原子数 ≥65 的组合失败率最高（主要是摆放失败）；单元素出现与否的失败率差异很小（1.5%~2.3%），说明**没有某个元素单独导致失败**（不过含 K/含 O 的混合略高）。
3. **哪种组合最容易单产物化合**：单产物要求总向量恰好等于某个合法分子式；元素子集 OXPWLF、CPWLKA、OXLKA 等（小分子、5~6 元素）单产物率最高（23%~31%）；大原子数对也可能单产物（L4 层 12 例，包括 140 原子新纪录），因为两个大分子可以严格相加成一个大分子。
4. **惰性**：只在同大类内部出现（纯大类 69/435≈15.9%），异大类纯物质对从不惰性（0/900）；整体随机样本中惰性率随原子数上升而消失。
5. **大投料 → 碎片化 + 偶发超大分子**：大总向量多数被贪心拆成大量小分子（二聚体/小环/小链），产物个数随投料增大而增加；但特殊配比下会出现超大单分子（本样本最大 140 原子，见 §5.4 新纪录）。
6. **大类对称性**：聚/动/散 内部统计逐项相同，三个「异大类纯物质对」统计也逐项相同——这是三种键图同构（三角格子）的直接体现。

## 9. 局限与口径说明

1. **模拟器口径**：使用正式模拟器 `pot_v3`（规则 1~9）；任务接口提到的 `pot_all`（规则 1~8）在随机小投料上与 pot_v3 一致（400/400），差异仅出现在规则 1~8 残余并列时，实测极少。
2. **embedding 节点预算**：主采样每分子 3,000,000 节点（≈20s 上限）；对失败者用 8,000,000 重试，131 个失败总向量中 9 个其实可摆放（含 140 原子新纪录）。剩余「摆放失败」可能仍有个别实际可摆放（需更大预算），因此 §4.1 的「摆放失败」是真实失败数的上界（误差 ≤1% 的样本）。
3. **采样偏差**：各层内均匀抽对（不同公式优先），但 L3/L4 条目少（937/327），对中会重复使用同一公式；大分子对的总原子数可达 194，模拟/校验成本高，故 L4 层样本相对较少（2,000 对）。另外目录中纯大类物质只有 90 种，随机对几乎抽不到纯组合，故对「纯大类/双大类」另做了 4,005 对的专门抽样（§7.2b）。
4. **总向量碰撞率**：小层用**全枚举精确值**（L1/L3/L4 全层），L2 用 3,000 条公式子集精确值；全目录用 200 万随机对抽样估计，结论是「随机大对撞向量概率极低、小分子对撞向量常见」。
5. **产物尺寸封顶**：4~9 元素子集的目录 >16 原子部分为搜索下界（非完备），因此「超过目录最大」不能直接判为新物质；1~3 元素子集目录完备，未见超封顶。本采样发现的 108/140 原子分子都是**反应产物**（不在目录内），已用 pot_v2 严格校验可摆放。
6. 反应结果与物质具体结构无关（只由元素总向量决定），故「不同物质对相同总向量」的复跑是对「实现确定性 + 总向量定律」的双重验证（见 §6.3）。
