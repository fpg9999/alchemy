# T16 · 终态骨架能否拆成「45 库骨架」+ 直接融合键？

> 检验对象：T15 的 695 种"终态新骨架"（不在 45 库中的三价连通块）。
> 库：7 种单类型模块（单原子/二聚体1·2·3键/三元链/三元环全单键/含双键）+ 35 种 T8 多三价形态 = 42 个形态 key（45 中的 3 个"无三价"骨架没有三价组件，不参与）。
> 脚本：`t16b_decompose.py`；数据：`t16_decompose.json`。

## 1. 结论

- **平凡意义上：可以。** 45 库包含"单原子"，而单原子是合法骨架模块；因此任何终态三价骨架都可以写成
  「若干库骨架块（大量单原子 + 少量小模块） + 块与块之间的直接键（融合键）」，
  不需要二价元素做桥。
- **非平凡意义上（要求骨架块 ≥2 原子）：部分可以。**
  - 695 种新形态中，**150 种（21.6%）能被库骨架块完整覆盖**（没有剩余顶点）；
  - 其余 545 种只能部分覆盖，覆盖率分布大约 **60%~95%**（少量低至 30%~50%）；
  - 也就是说，很多大骨架确实由若干库块"拼"成，但拼接方式（融合键形成的环、长链、密集连接）
    本身构成了 45 库之外的新形态。

## 2. 具体拆解示例

| 终态骨架 | 大小 | 覆盖 | 拆法（库骨架块 + 融合键） |
|---|---|---|---|
| `O3P` | 4 | 3/4 | **OOO 三元环**（单类型模块）+ **P 单原子** + 3 条 O–P 融合键 → 组成 4 原子完全图 |
| `O2CK` | 3 | 2/3 | **O–O 单键二聚体** + **K 单原子** + O–K 双键/单键（融合） → 三角形 |
| `O3KA2` | 4 | 2/4 | **O–O 二聚体** + O,K 单原子 + 融合键 |
| `CP2K3` | 5 | 3/5 | **K–P–K 三元模块** + P,K 单原子 + 融合键 |
| `O2K4` | 6 | **6/6** | **KOK + OKK** 两个三元模块，融合键闭合为 6 元环 |
| `O2P2K2` | 6 | **6/6** | **POK + OKP** 两个三元模块 |
| `O4K2` / `O4P2` | 6 | **6/6** | **OKO + OKO** / **OPO + OPO** 两个同型模块 |
| `O2K6` | 8 | 6/8 | **3 个 K–K 单类型二聚体** + 2 个 O 单原子 + 融合键 |
| `O2P6` | 8 | 6/8 | **3 个 P–P 二聚体** + 2 个 O 单原子 |
| `O5P5K2` | 12 | 11/12 | **POKOP + OKOO + PP** 三个库块 + 单原子/融合键 |

## 3. 对分类的修正

- 你的直觉是**对的**：终态"新骨架"主要就是"库骨架（含单原子）之间直接相连（无二价桥）"；
- 但不能说"终态形态 = 若干个完整 45 骨架的简单拼装"：融合键可以把小模块连成新的环、长链、
  完全图，形成 45 库无法列举的新结构；
- 正确做法是把骨架分类升级为两层：
  1. **骨架库（45 种）**：单类型 7 模块 + 多三价 35 形态（+ 无三价 3 形态）；
  2. **融合规则层**：哪些骨架的哪些"挂键/原子"可以互相直连，连成环/链/密网——
     这一层才是终态形态多样性的来源（对应"二价桥"之外的直接三价–三价、三价–原子融合）。
