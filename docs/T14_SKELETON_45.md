# T14 · 「45 种骨架 + 二价桥 + 一价端帽」假说的检验

> 对象：目录全部 **84,225 种物质**（`t4_catalog_all_validated.json`）
> 脚本：`t14_verify_skeleton_hypothesis.py`、`t14b_bridge_stats.py`、`t14c_roles.py`
> 数据：`t14_summary.json`、`t14c_summary.json`

## 0. 你的 45 = 3 + 7 + 35 是否成立？

| 层 | 数目 | 来源 | 含义 |
|---|---|---|---|
| 无三价元素 | **3** | T9（175 种物质） | 二聚体 / 纯二价环 / 双端帽链 |
| 只有一种三价元素 | **7** | T10（7,814 种） | 单原子、1/2/3 键二聚体、三元链、三元环（全单键/含双键） |
| 两种或三种三价元素 | **35** | T8（38 − 3 个孤立单原子） | 6 级（三价元素彼此结合）结束时的组件形态库 |
| **合计** | **45** | | |

**但必须说明：这 45 种是"概念/构建层"的分类，不是终态分子里三价原子子图的全部形态。**
在终态分子里，三价诱导子图的连通块形态数（按基团精确规范化）为：

| 三价元素种类 | 终态分子中的连通块形态数 | 最大连通块 |
|---|---|---|
| 单一种（O / P / K） | 各 **7**（与 T10 完全一致） | 3 |
| 两种（KO / OP / KP） | **54 / 55 / 54** | ≤ 28 |
| 三种（KOP） | **145** | ≤ 28 |

原因：T8 的 35 种是"6 级刚结束时"的骨架（活跃原子还剩 1~2 根键）；终态分子还会继续成键
（0 级同类键 + 与二价/一价原子成键），所以三价原子之间的最终连接形态远比 35 种丰富。

## 1. 价数角色的检验（全部 84,225 种物质）

- **价数恒成立**：0 个原子违背「键数 = 价数」。所以 3 价 = 骨架节点（最多 3 条边）、
  2 价 = 链节点（恰好 2 条边）、1 价 = 端点（恰好 1 条边）在定义上是必然的。

### 1.1 一价原子（C/L/F）的邻居
| 邻居价类 | 原子数 | 占比 |
|---|---:|---:|
| 三价原子 | 155,930 | 73.5% |
| 二价原子 | 56,201 | 26.5% |
| 一价原子 | 12 | ≈0% |

→ 一价元素**基本是端帽**，但 26.5% 接在二价（链端），且 C₂、F₂、L₂ 三个二价体系里
一价原子彼此成对（12 个原子），并非端帽。

### 1.2 二价原子（X/W/A）的角色
| 角色 | 原子数 | 说明 |
|---|---:|---|
| 一个三价 + 一个二价 | 128,922 | 链/桥的延伸段 |
| **两个不同三价（真桥）** | **105,908** | 连接两个骨架 |
| 同一个三价原子 ×2（双键） | 51,991 | 终端双臂/端帽式 |
| 两个二价（二价链/环） | 40,145 | 二价自身的链/环 |
| 一价 + 三价 | 33,331 | 带端帽的支臂 |
| 一价 + 二价 | 22,834 | 链端点 |
| 两个一价 | 18 | 二价被两个端帽夹住 |
| 同一个二价 ×2（双键二聚） | 12 | 二价二聚体 |

→ **只有约 27.6% 的二价原子是"真桥梁"**；其余是链段、支臂、端帽式双键、或二价自身的二聚/环。

### 1.3 分子级严格检验（含三价的分子）
- 所有二价原子都恰好是"纯桥"的分子：**24,807 / 84,225（29.5%）**
- 所有一价原子都接在三价骨架上的分子：**57,327 / 84,225（68.1%）**

## 2. 结论：假说的正确表述

**不能简单说"所有物质 = 45 骨架 + 二价桥 + 一价端帽的固定结构"，但存在一个正确的三层框架：**

1. **三价层（骨架/概念层）**：3 价原子的相互连接形成"骨架块"。
   - 在**反应中间态（6 级结束）**，骨架块恰有 38 种（35 种多原子 + 3 个孤立原子）——即你说的 35 种；
   - 单三价体系另有 7 种基本模块（T10）；
   - 无三价体系有 3 种（T9）；
   - **但终态分子中的三价连通块是这些的"继续生长版"**：单三价仍只有 7 种（≤3 原子），
     两/三三价体系则分别有 54~55 / 145 种连通形态，最大到 28 个三价原子。
2. **二价层（连接层）**：2 价原子最多 2 条键，可做
   - 真桥（两端不同三价骨架）≈27.6%；
   - 链段（接三价/二价）或带 1 价端帽的支臂；
   - 或自身成二聚体/小环（无三价体系的基础形态）。
3. **一价层（终端层）**：1 价原子基本是端接（73.5% 接三价、26.5% 接二价），
   少数二价体系里彼此成对（C₂/F₂/L₂）。

**关键修正**：
- 45 种是"骨架/构建块"的字典，不是终态分子三价连接的全部形态；
- "固定结构"不成立：二价链段落可以很长（连接层带来无限/半无限组合），
  真正让物质集有限的是**各元素子集的分子尺寸封顶 + 几何可摆放性**，而不是 45 种骨架本身；
- 无三价物质的 3 种形态是独立的基础类（没有三价骨架可挂）。
