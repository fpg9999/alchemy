# T36 · 同时包含「38 库多三价骨架」与「7×3 库单三价骨架」的物质

> 问题：是否存在一种物质，既含 38 库中的多三价元素骨架，又含 7×3 库中的单三价元素骨架？
> 数据：全部 84,225 种物质（`t4_catalog_all_validated.json`）；
> 脚本：`t36_both_skeletons.py`（精确组件）、`t36b_both_relaxed.py`（允许 38 骨架是更大组件中的子块）、`t36c_render.py`（绘图）；
> 图：`images/t36_both_skeletons.png`。

## 1. 判定口径

- **多三价骨架（38 库）**：一个三价组件含 ≥2 种三价元素，其形态匹配 T8 的 38 形态库（实际只有 35 个多原子形态；3 个单原子形态不属于多三价）；
- **单三价骨架（7×3 库）**：一个三价组件只含 1 种三价元素，其形态匹配 7 种单元素骨架（单原子、单键二聚、双键二聚、三键二聚、三元链、三元环全单、三元环含一单双）；
- 两种骨架可以是分子中的**两个分离的三价组件**（由二价/一价装饰层连接），也允许 38 骨架是更大三价组件中的子块（去掉同元素键后匹配）。

## 2. 结果：确实存在

| 统计口径 | 数量（占 84,225） |
|---|---:|
| 同时包含两类骨架（单三价骨架含单原子） | **12,268（14.6%）** |
| 同时包含两类骨架且单三价骨架为多原子（二聚/链） | **2,192（2.6%）** |
| 要求 38 骨架是**独立完整组件** | 9,869 |
| 其中单三价骨架为多原子的 | **153** |

### 单三价骨架的形态分布（多原子部分）
| 形态 | 出现次数 |
|---|---:|
| 单键二聚 | 1,543 |
| 双键二聚 | 589 |
| 三元链 | 65 |
| 三元环（全单/一单双） | **0（本目录未发现共现）** |
| 单原子（平凡情形） | 13,975 |

### 可与单三价骨架共现的多三价骨架（38 库中只有 7 种）
`OK3、O3K、O3P、PK3、P3K、OP3、OP4K`

其余 28 种多三价形态（更大的骨架，如 O3P5K2、O4P7K2 等）在目录中**没有**与单三价骨架同时出现。

## 3. 具体案例

### 案例 A：`O5X3KA`（10 原子，最小案例之一）
- 多三价骨架：**O3K**（38 库）；
- 单三价骨架：**O–O 单键二聚**（7 库）；
- 其余 X3、A 是装饰层，把两个骨架连起来。

### 案例 B：`O5X3PA` / `O5X3PW`
- 多三价骨架：**O3P**（38 库）；
- 单三价骨架：**O–O 单键二聚**。

### 案例 C：`OP5W3A` / `OXP5W3`
- 多三价骨架：**OP3**；
- 单三价骨架：**P–P 单键二聚**。

### 案例 D：`OWK5A3` / `OXK5A3`
- 多三价骨架：**OK3**；
- 单三价骨架：**K–K 单键二聚**。

### 案例 E：`OCP7W2KA2`（14 原子）
- 多三价骨架：**OP4K**（6 原子）；
- 单三价骨架：**PPP 三元链**（7 库）；
- 其余为 W2、K、A2、C 等装饰。

### 案例 F（放宽口径）：`C2P6KAF3`（13 原子）
- 单三价骨架：**P=P 双键二聚**；
- 多三价块：KPPPP 组件中去掉 P–P 同元素键后得到 **P3K** 子块（38 库）；
- 这说明双键二聚 + 38 骨架的组合主要以"融合块"形式出现，而不是两个独立组件。

## 5. 为什么只有少数组合？

1. **原子预算限制**：多三价骨架越大，消耗的三价原子越多；在 ≤16 原子目录里很难再留出独立的单三价组件 + 装饰层；
2. **几何/价数限制**：两个骨架要由二价/一价装饰层连接，且必须可摆放；
3. **单三价骨架的稳定性**：单三价组件中只出现了二聚/链，未出现三元环（环可能更不稳定/更容易被融合）；
4. **大骨架的"吸收"效应**：更大的 38 形态往往把同元素的三价原子吸进同一个组件（0 级融合），难以再单独形成单三价组件。

## 6. 结论

**存在，而且不止一例。** 在全部 84,225 种物质中：
- 含两类骨架的共有 **12,268 种**（14.6%）；
- 排除"单原子"这种平凡单骨架后，仍有 **2,192 种**；
- 其中 **153 种**满足"38 骨架为独立完整组件 + 单骨架为多原子"的严格口径；
- 但组合不是任意的：38 库中只有 7 种小骨架能与 7×3 库共现，单骨架也只出现二聚/链（无三元环）。
