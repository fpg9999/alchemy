## 1. 正式规则 9（已写入 `HANDOFF.md` §5）

> **规则 9（元素优先级决胜）**：若规则 1~8 仍完全相同，则看"结合之后的分子式"
> （两个分子的元素组成相加）里各元素的数量，按以下优先级比较：
> **秩(O) > 晶(X) > 凝/冰(C) > 沌(K) > 气(A) > 焰(F) > 势(P) > 流(W) > 电(L)**。
> 先比秩元素数量（多者优先），相同则比晶元素数量，再比凝/冰，依次类推。

- 完整 key（字典序最小优先）：
```
( -周期表距离, -(rem_i+rem_j), 族组合序号, cross, 分子内距离,
  min(size_i,size_j), -max(size_i,size_j),          # 规则5
  -并集种类数,                                      # 规则6
  自身种类数和, min(自身种类), max(自身种类),       # 规则7
  -(总剩余键和), -min(总剩余键),                    # 规则8
  *(-结合后各元素数，按 秩>晶>冰>沌>气>焰>势>流>电) ) # 规则9
```
- "凝"按项目元素表理解为"冰(C)"。
- 规则 9 之后若仍有完全并列（同一元素对、结合后元素计数完全相同），取候选顺序中的第一个（确定性）。
  实测 T=3..9 全部投料无残余歧义（`T12_RULE9E.md`）。

## 2. 正式实现：`pot_v3.py`

- `pot_v3.simulate(atom_list, rng=None)`：规则 1~9 的完整模拟器；
  返回格式与 `pot_all.simulate` 一致（`[{"atoms":[...], "edges":[(a,b,mult),...]}, ...]`），失败返回 `None`。
- 几何可实现性判定继续用 `pot_v2.embed_mol2` / `pot_v2.validate_place`（未改动）。
- 用法示例：
```python
import pot_v3, pot_all, pot_v2
atoms = pot_all.vec_to_atoms((9, 10, 0, 0, 0, 0, 23, 0, 0), pot_all.ORDER)  # O9X10K23
mols = pot_v3.simulate(atoms)
for m in mols:
    place = pot_v2.embed_mol2(m["atoms"], m["edges"])
    ok, msg = pot_v2.validate_place(place, m["atoms"], m["edges"])
    assert ok, msg
```
- 自检案例（`python pot_v3.py`）：
  - `O3+F+A2+W` → **O2WA + OAF**
  - `X1+W1+L1+K2+F1` → **WKF + XLK**
  - `O9X10K23` → **O9X10K23**
