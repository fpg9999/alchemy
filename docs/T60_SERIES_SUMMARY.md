## 0. 系列一句话

从 T55 到 T59，我们把"炼金术化学规则"从静态大锅反应推进到**可运行的 2D 粒子环境**：
单质投料 → 高温完全反应退火 → 温度阈值窗口 → 面积/数量模型 → 九元素随机物质库 → 两阶段连续实验；
同时把完全反应引擎加速 3.6~6.3 倍、把环境从 400000² 缩小到 60000²。核心发现：

1. **1000°C 相对 T35 阈值（Σc 1~24）等同无限高温**：几乎所有反应在高温段完成，终态主要由
   "完全反应 F + 元素配比"决定，而不是初始分子大小/面积/数量；
2. **元素与价数配比是终态结构的配方**：
   - 等比例 O/X/C → 99.5% `OXC`（T55）；
   - 价数比 3<2<1 + 散素 → 同价跨类双原子盐 `CF`/`XA`/`OK`（T56）；
   - 全部 29 聚素 + 面积模型 → `OXC` + `OX2C`（T57）；
   - 九元素随机投料 → 937 种终态（T58，动力学+cap 冻结）；
   - 三价最多的 120 种物质两阶段 → 43/67 种结构，`CF`/`O2XP2WK2A2`/`OXCPWK` 等主导（T59）；
3. **面积/截面只是动力学旋钮**（T57 证明），**温度窗口、cap 上限、环境大小决定能否"退火干净"**；
   T59 cap60 高保真对照显示 cap40 的 43/67 种结构与 top30 中的 19 个巨型分子主要是人工边界，
   真正稳定核心只有 9~13 种（`CF`、`O2XP2WK2A`/`O2XP2WK2A2`、`OXCPWK`、`L2`、`LF`、
   `O4X2P5W2K3A2`、`O3XP4WK3A`、`OXCPWKA`、`OCPKA`）；
4. **算法优化让大分子反应成为可能**：`fast_pot` 与 pot_v4 规则 1~11 逐字等价（27,315 向量审计
   0 差异），F 加速 3.6~6.3×，支撑 cap60 下 59/60 原子大分子的生成与反应。

### 2.3 T57：全部 29 种聚素 + 面积模型

- 设定：全部 29 种纯聚素（2~9 原子）均投入，9002 分子/38532 原子；面积 ∝ 原子数、
  数量 ∝ 1/面积（面积越大数量越少）；面积加权碰撞截面；L=10000；1000→0°C；
- 结果：终态 **12,054 分子 / 38,532 原子 / 4 种分子式**：`OXC` 9,746（80.9%）、

  让环境偏向大分子；**面积/截面是动力学旋钮，不改变 F+配比决定的热力学终态**。
- 低温窗口（T0=12°C）才保留大分子：平均 4.09、26.3% ≥5 原子、18 种分子式、7 种新物质。

1. **温度尺度**：T35 全加和阈值对聚素/小分子只有 1~24；1000°C 在前 98% 时间等同"无限高温"，
   完全反应主导；冷却窗口只有最后几十度，因此自然环境的"低温化学"需要把温度放到 0~20°C 级。
2. **终态 = F(v_total) 的热力学不动点 + 元素配比**：T55 的 OXC、T56 的 CF/XA/OK、
   T57 的 OXC+OX2C、T59 的 CF/O2XP2WK2A2/OXCPWK 都由总元素计数向量决定；
   初始分子大小/面积/数量只影响到达速度（T57 直接证明）。
3. **价数比例是配方**：3 价多 → O/P/K 骨架丰富（T59）；3 价少/一价多 → 同价盐（T56）；
   等比例 → OXC（T55）。
4. **区域大小 + 碰撞频率 + cap 决定"退火是否干净"**：T58 大区域+碰撞稀疏+cap20 → 937 种
   动力学冻结组成；T59 缩小区域+cap60 → 9/13 种真正稳定核心。
5. **大分子反应可行**：fast_pot 加速后 cap60 出现 59/60 原子大分子；cap40 的 39/40 巨型堆积
   是人工边界。
6. **稳健物质层级**：`CF`/`WA`/`LF`/`L2`（跨 5~6 次实验）> `O2XP2WK2A2`/
   `O4X2P5W2K3A2`（跨 4 次）> 其余；双原子盐与三价骨架分子是环境里最稳定的"硬核"。
