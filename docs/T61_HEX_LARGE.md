# T61 · T59 最后两次实验的全部大分子：六边形棋盘格严格摆放

> 对象：T59 两阶段实验的**第一阶段 A** 与**第二阶段 B**（最后两次实验）终态中，
> 所有原子数 ≥5 的"大分子"物质（按结构去重、跨两阶段合并）。
> 全部结构使用 `pot_v2.embed_mol2` 在六边形棋盘格上做**严格摆放**并通过
> `validate_place` 校验（S/C/L 键型合法、L 键中点格必须为空、无重复占格）。
> 数据：`t61_hex_layouts.json`；图：`images/t61_hex_*.png`。

---

## 0. 一句话

T59 两阶段终态共有 **66 种不同结构的大分子物质**（≥5 原子）：**9 种中等大分子（5~18 原子）+
57 种 39/40 原子巨型分子**；其中 36 种同时出现在 A/B 两阶段、3 种仅 A、27 种仅 B。
**66/66 全部找到严格六边形棋盘格摆放**（62 个直接搜索成功；4 个 39/40 原子巨型通过
随机原子重排 + 加强搜索在 37~57 秒内成功）。

## 2. 六边形棋盘格摆放方法

- 使用 `pot_v2.embed_mol2(atoms, edges, max_nodes=2,000,000)` 做严格回溯摆放：
  - 每个原子占一个六边形格；
  - 键型由端点元素对允许集合决定：**S 短键（共享边）、C 角键（共享顶点）、L 长键（隔一格）**；
  - L 键中点格必须为空；
  - 摆放完成后用 `pot_v2.validate_place` 严格复核（无重复格、键偏移合法、L 中点空）。
- 62 个结构直接成功；4 个 39/40 原子巨型（`O8X6CP13W4K6A2`、`O5X3C2P14W4LK5A2F3`、
  `O8X6P13W4K6AF`、`O8X5P13W4K5A4`）在固定搜索顺序下失败，改用**随机原子标号重排**
  （`embed_mol2_perm_seed0`，max_nodes=1.5M）后成功，每个耗时 37~57 秒；结果已回映射原原子编号。
- 坐标：`place` 为轴向坐标 `(q,r)`；绘图用项目既有 flat-top 六边形映射
  `center=(1.5·s·q, √3·s·(r + q/2))`（`t8_render_forms.center_of`）。

## 5. 说明与局限

1. 本图只含 **T59A/T59B 主实验**（最后两次实验）的大分子；cap60 高保真对照
   （T59A_hf/T59B_hf）是补充实验，未混入。
2. "大分子"取 **原子数 ≥5**；若把 2 原子双原子盐也计入，会显著增加图量且与"大分子"语义不符。
3. 66 种结构全部严格可摆放；4 个巨型分子需要随机重排搜索才找到解，说明其摆放空间较窄，
   但不代表化学上不可能。
4. 巨型分子数量少（每种 1~2 个），图中数量标签可看出它们是 cap40 边界层的少数产物；
   cap60 对照下只余 3 个 59/60 原子巨型。
5. 图由 `t61_render_hex.py` 读取 `t61_hex_layouts.json` 绘制；重跑可复现。
