## 1. 二元反应的定义与口径

把物质 A、B 一起投锅（恒素触媒忽略）：全部原子拆开，按规则 1~8 逐根成键；
反应成功 = 所有原子价数填满且每个产物分子能合法摆放。产物为分子式多重集（可为 1 个、2 个或多个）。

**关键性质：反应结果只取决于「元素计数向量之和」 vA+vB**（与原来是什么分子无关）。

## 2. 基本定律（由定义直接推得，且数据全部验证）

1. **可交换**：R(A,B)=R(B,A)。

2. **总向量决定一切**：vA+vB 相同 ⇒ 反应结果完全相同。
   例（无三价内部）：`A2+W2` 与 `WA+WA` 总向量都是 2W+2A，结果都是 `2 WA`；`A2+X2` 与 `XA+XA` → `2 XA`。

3. **单产物 = 严格向量加法**：A+B→C 当且仅当 vA+vB 恰好等于某个物质 C 的向量；此时产物就是 C。
   推论：**不存在催化/取代**（A+B→A+C 会要求 vC=vB ⇒ C=B），也不存在「单向转化」。

4. **单产物链不可回环，但允许副产物时有循环**：若每一步都只产出单一物质，则 A+B→C 要求 vC=vA+vB（向量严格变大），
   因此不可能回到 A。**但**若允许副产物（A+B→C+E；C+D→A+F），循环就存在——见 `T11B_REACTION_CYCLES.md`：
   真 2-环 2,432 个（聚素内 112 / 无三价内 2,031 / 跨类 289），其中 A 被重新产出，扮演**催化剂**。

5. **失败=不相容**：两个各自合法的物质混合后，可能因价数无法配平而整锅失败（聚素内 3 对；交叉 129 对）。

6. **反应等价类**：把投料对按总向量分组，同一组结果必相同；这是给「反应性质」分类的自然坐标。

## 4. 聚素 29 的全部二元反应结果

完整表：`t11_binary_ju.json`。要点：

- **惰性对（原样返回）87 个**，如：`O2+O2`、`C2+O2C4`、`X2+X3`、`O2C2+O2X2` 等 → 混合不反应。
- **单产物（化合）40 个**，全部是严格向量加法，例如：
  `C2+O2→O2C2`、`O2+X2→O2X2`、`O2+X3→O2X3`、`O2X4+X3→O2X7`、`OC3+OX3C→O2X3C4`。
- **多产物（复分解）305 个**，典型模式：
  - 归中/对称歧化：`C2+O2C4→2 OC3`、`O2+O2X2→2 O2X`、`C2+O2X2→2 OXC`、`O2C4+X2→?`…
  - 交换重组：`C2+O3C5→O2C4+OC3`、`C2+OX2C→OC3+X2`、`O2+O2X3→O2X+O2X2`。
- **失败（不相容）3 对**：`C2+OXC`、`C2+O2XC4`、`O2C4+XC2` → 混合后价数配不平，整锅失败。

## 5. 无三价 175 内部 与 交叉 29×175

- 无三价 175 内部：15,400 对**全部成功**，没有失败（只有 2价/1价，价数总能配平）；
  惰性 1,473、单产物 449、多产物 13,478。多产物远多于聚素，说明「复分解」在无三价体系非常常见。
- 交叉 29×175：5,075 对，成功 4,946、**失败 129**（全部涉及含 O 的聚素物质，O 三价 + 低阶元素配比失衡）；
  惰性 97、单产物 604、多产物 4,245。
- 等价类现象非常明显：无三价内部 3,439 个不同总向量中 3,043 个类含多对（同一总组成不同分子对 → 结果相同）；
  交叉部分 3,158 类中 1,460 类含多对。这验证了「总向量决定一切」。

## 6. 反应性质独特的物质（专题）

### ① 惰性王：C2、L2、X2C2、X2
- `C2`（冰₂）：与 70 个伙伴混合后完全不变（惰性最多），但也能与 50 个伙伴化合、2 个伙伴不相容。
- `L2`（电₂）：惰性 57；`X2C2`（晶₂冰₂）惰性 54 且几乎不参与单产物（仅 8），是多产物型「反应惰性体」。
- `X2`（晶₂）：惰性 48，但单产物 77（最多）——既是惰性对象又是「化合枢纽」。
### ② 不相容王：O3XC（秩₃晶冰）
- `O3XC` 失败 26 次（最多），单产物 38、多产物 111、惰性 0：它几乎不与其它物质「和平共处」，
  混合时经常整锅失败或强制重组。
- `O2X`（秩₂晶）失败 16、单产物 47；`O3XC3` 失败 16；`O2` 失败 15。O 的存在显著提高「不相容」概率。
### ③ 化合枢纽：O2、X2、XA、OX3C
- `O2`：单产物 69（与含 X/C 的物质大量加成），失败 15，惰性 0：非常「活泼」。
- `X2`：单产物 77 为全库最高：`X2 + 任意含 X/C 物质` 常直接生成对应多一个 X 的化合物。
- `OX3C`：单产物 53、失败 0：是「温和加成剂」。

### ④ 连续反应：增长链与合成网络
- 无三价内部最长单产物增长链 1 步：['A2', 'C2', 'C2A2']
- 交叉最长链 2 步：['O2', 'C2', 'O2C2', 'O2C4']
- 聚素最长链仅 2 步：['O2', 'C2', 'O2C2', 'O2C4']（说明聚素的「化合增长」很快被惰性/复分解截断）。
- 从单质出发，聚素只有 8 种能靠单产物化合合成（O2C2、O2X2、X2C2、O2C4、O2X4、O2X6、O2X2C4 等），
  其余 19 种必须通过复分解/多步反应得到。
