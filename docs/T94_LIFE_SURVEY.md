# T94 · 生命综合调查：模型内能形成的「生命形式」与还差什么

> 日期：2026-11-24（夜）
> 设定：**现有规则**（不改 `alchemy/` 内核、不改规则 1~11 与三素公式）
> 试验场参数（用户指定新默认）：初始温度 **200°C**、终态 **0°C**（600 拍指数降温后平台）、接触反应概率 **p_react=1.0**、重力 **G=0.20**、环境耦合 **env_coupling=0.5**、cap=36、热值 `heat(C,L,F)=(-1,+1,+2)`
> 本文汇总今晚四个分支（A 自复制普查 / B 完美膜动态 / C 环境谱系 / D 文献梳理），并给出综合答案与待补规则。

---

## 0. 一句话结论

**在现有规则 + 新默认参数下，模型内能形成最接近「生命」的东西是一套分子组合，而不是一个能繁殖的个体：**
一个**高 A 惰性主体**（如 `O2` / `OK`）+ 一层**高 D 低 A 膜**（`PK` / `W2`，需 G≈0 悬浮）+ 一层**本地冷壳**（`O4XK2` / `O2X`，1~2 层）+ **食物**（`XA3` / `C2K2` / `CKF2`）；
它能在 200→0°C 窗口内**长大**（无膜对照主体原子 48→102，+212%）、**被膜保护**（G=0 时环境-主体接触与核心-环境反应均压到 **0**、角覆盖 0.92）、**自复制化学式**存在（2,596 个模板、24,708 组三体候选）；
**但它仍然不是生命**：复制只是「加和合成」（模板作用=0、无变异）、没有代谢闭环、没有稳定的空间区隔（壳靠初始环带+自粘维持、会被消耗且不会自修复）、没有选择压。**「还差一层膜」的问题已在 T93 部分回答（物理膜可行），今晚进一步确定：物理膜只在微重力/低重力成立，且在默认 G=0.2 下失效；化学意义上的「完美膜」在现有力场里不成立。**

### 1.2 温度与反应口径（重要）

- **反应温度**：`natural_engine.resolve(mds, T)` 的 `T` 是「局部温度」，不是环境温度。今晚统一用 `t94_config.local_T`（附近分子热值 + 0.5·T_env）。
- **p_react=1.0**：旧文档里的反应百分比（如 T93 的 22~40 次内反应）是旧 p_react 下的计数，**不可直接外推**；今晚所有报告都报**原始计数**。
- **重力 G=0.20**：落在 T93 的危险区（旧 G=0.30 时冷壳沉底、核心 24→1；G=0.02 时壳漂出环带）。这是今晚 B 分支的第一变量。

## 3. 分支 A：自复制普查（`t94_census.py` / `T94_REPLICATION.md`）

**方法**：不跑世界，直接对 84,225 条目录用 `natural_engine.complete_products`/`resolve` 做全量枚举（不改内核）。判据：`F(2·comp(A))` 恰为 2 个分子且两产物元素计数都等于 `comp(A)`，即 `A + B + C → 2A`。

| 项目 | 结果 |
|---|---|
| 模板 A（nA≤12，`F(2compA)=[A,A]`） | **2,596 个** |
| 其中有目录内食物拆分（nB+nC=nA） | **2,411 个**（185 个拆不出：目录无单原子分子、无 OX/OC/XC 异核双原子） |
| 三体候选组 | **24,708 组** |
| 复制保真度 2/2 | **2,594 / 2,596**（2 个 n=11 模板 `X3P2K6`、`X3P6K2` 保真 0/2：F(V) 是「规范骨架」的另一同组成分子，一次性规范化，不是可遗传变异） |
| 最小自复制形式 | **`A2F2 + A2 + F2 → 2 A2F2`**（4 原子；同温 `W2F2`、`X2F2`；二聚体 `A2`/`F2` 不在目录内） |
| 温度窗口 | 需 `T_env ≥ ((3+ec)Σc − Σheat)/ec = 7Σc − 2Σheat`；**T_env_min ∈ [26, 252]°C**；今晚窗口内 21,716/24,708 组有正窗口（其余需更高温）；窗口中位 22 拍、最长 204 拍；**0°C 平台 0 候选** |
| 二元催化 | **0 / 946,946**（无同分异构体 ⇒ `A+B→A+C`(C≠B) 不可能；198 例「放大」全是 A==B 同种对） |

**关键否证——模板作用=0**：对 80 个候选做 `F(compB+compC)` 直接计算，**80/80 等于 `[A]`**。也就是说产物完全由「总元素计数」决定，与模板 A 是否存在、骨架如何无关 —— 这不是模板复制，只是加和合成。又因「组成↔物种」双射，保真度恒为 2/2，**没有变异来源**。

**结论**：现有规则下存在「自复制化学式」（最简 `A2F2`），但不存在「自复制个体」；T79 的二元否定与 T94-A 的三体普查在机制上一致：**F 是组成函数，不是模板函数**。

### 4.2 六条结论

1. **微重力下「完美膜」成立**：`PK` 膜 + G=0 → 环境-主体接触 **0**、核心-环境反应 **0**、角覆盖 **0.92**、膜留存 89%；膜-环境接触仅 1,638（对 D>0 环境确有真实斥力，重膜臂为 82,287，差 50 倍）。
2. **默认 G=0.2 是首要杀手**：重膜（PK, mass=1.5）下沉、角覆盖归零、接触反超无膜（8,782 vs 6,542）；轻膜 W2/WA2 能维持环带（cov 0.67~0.78）但 envC 仍有 3,638~5,698，密封不足。
3. **自修复不成立**：膜 birth 20 vs death 84（140→74，净消耗 3.7×）；自修复路径 `O2 + P2K4 → 2OK + 2PK` 只在 T_local≥40°C 前段发生（共 5 次），降温平台后停止；主体原子 48→32（反而缩小）。
4. **化学不相容（O2 主体 + P 系膜）**：主体会被转成高 D 产物，原子 48→88/79（无膜对照 102）；`OK` 主体与 `PK` 惰性（归因损失 0）但同样沉降。
5. **自制造身体成立（今晚唯一强正结果）**：无膜对照靠 `XA3` 食物把主体原子 48→102（**+212%**），说明「主体 + 食物 → 更多主体」在 200→0°C、p_react=1.0 下成立。
6. **膜的物理结论**：没有化学键，只有力场 + 占格；G=0 时力场足够，G=0.2 时质量必须 ≈0（W2 mass=1.0）才能不沉，但轻膜也留不住（留存 38~85%、密封不足）。

## 7. 综合答案：模型内「最接近生命的东西」由什么组成

按「能长大 + 能被保护 + 有复制化学式 + 能在某些环境存活」四条筛选，今晚数据支持的最小组合：

```
主体：O2 或 OK（A=3，惰性、不易被膜反应）    —— 能靠 XA3/C2K2/CKF2 食物长大（48→102 原子）
膜  ：PK（A=0, D=3, mass=1.5）或 W2（mass=1.0）—— 需 G≈0；G=0.2 时改用 W2/WA2 但密封不足
壳  ：O4XK2 / O2X（本地冷壳，η=0.06~0.08）     —— 1~2 层，E2/E4 供给最足
食物：XA3（让主体长大）、C2K2/CKF2（T90 配方）
环境：E4（O/X/C，最安全）> E2/E3（可存活）> E1/E5/E6/E7（需膜）> E8（不可存活）
温度：200→0°C 窗口内有效；0°C 平台后自修复/复制窗口关闭
```

**但它不是生命**：复制是加和合成（模板作用 0）、无变异、无代谢闭环、无稳定隔室、无自修复、无选择压。用户设想的「完美膜」（强排斥 + 被主体吸引 + 可制造/修复）在现有规则下**只能部分实现**：微重力下力场膜成立（G=0：envC 0、coreER 0、cov 0.92），默认 G=0.2 下靠质量≈0 的轻膜只能部分维持；「由主体制造」只在高温前段有 5 次反应，「自修复」净消耗 3.7×。

## 8. 要「闭环」还缺的规则（模型扩展建议）

1. **模板依赖**：让 `complete_products` 的产物骨架依赖输入骨架（规则 10 真正生效），否则复制永远只是组成函数。
2. **同分异构体**：允许同一组成多骨架，才有变异与保真度差异；当前 comp↔物种双射是「无进化」的根因。
3. **可逆的膜-主体键**：T93 的 pair_w 只有 +0.118，锁阈值 1.0；需要一条「表面选择性粘附」规则（类似 T80 的不对称机制）。
4. **真正的催化位点**：E 恒素目前只参与 ρ_E 门控与「E 催化」名义，需要一个「不消耗、降低反应阈值」的显式机制。
5. **隔室化**：膜要被消耗 → 需要「A + food → A + M」的持续补膜反应（今晚自修复臂证明单靠随机反应不够）。
6. **持续能源**：温度梯度在 0°C 平台消失后一切停止；需要恒素场/化学势的持续驱动。

## 9. 模型内 vs 模型外

- **模型内可判定**：resolve 结果与温度窗口、pair-w 分类、膜覆盖率/留存、接触与反应计数、环境池的 D>0 占比与热值、10 臂守恒。
