# T70b 大分子整体图：一个分子 = 一个完整形体

> 针对"一个大分子看起来像多个零散东西拼凑"的问题，T70b 换了画法：**先造一个身体，再把结构画进身体里**。

## 1. 做法

1. **并集成一个身体**：把所有 6 级骨架块、二价桥、融合处先画进同一张蒙版（2× 超采样），
   取并集后用大半径形态学闭运算（降采样 + 高斯模糊 + 重阈值）把块与块之间的凹口填平，
   得到**一条光滑的连续外轮廓**——整个分子只有一个边界，不再按块描边。
2. **端帽长在体表**：冰刺 / 飘带 / 螺旋丝在身体轮廓确定之后再并入蒙版，成为体表的附肢；
   支臂画成体表伸出的触须。
3. **一个填充 + 一条外轮廓 + 一层内膜**：身体用纵向渐变填充（上浅下深），外轮廓深色一条，
   内侧再压一条很淡的"内膜"线，给身体厚度层次。
4. **结构画在体内**：每个骨架块 = 一个器官区（极淡家族色 + 一个器官核），
   桥 = 体内的骨纹（X 楔块 / W 编织 / A 膜褶）与贯穿的脉络线，融合处 = 几道焊纹。
5. **编号徽章**只标在器官旁（可关掉），元素字形与字母全部隐去。

结果：整张图读起来是"一只完整的生物/晶体"，内部的器官分区仍然能指出它由哪些骨架块组成。

## 3. 复现

```bash
python t70b_body.py     # 生成上面两张图
```

依赖：`t70b_body.py`（本模块：蒙版合成 + 平滑 + 整体渲染）、`t70_glyphs.py`（桥/端帽零件）、
`t69_bodies.py` + `t69_draw.py`（骨架级排版与几何）、`t68_shapes.py`（配色/画布）、`t68_data.json`（36 分子）。

## 4. 局限（未决）

- 身体轮廓是把块的外接形状平滑得到的，块数很多时会变成"一串珠子"，还没做更有机的形状生成。
- 只画 2D 投影，折叠关系（谁在谁前面）不可见。
- 器官核目前是按块大小等比例画的圆，没根据块形态变化。
- 未在身体表面加纹理/渐变光照；如果需要更"生物"的质感，可以加体表斑点、脊线、光照渐变。
