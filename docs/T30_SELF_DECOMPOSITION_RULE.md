# T30 · 不稳定物质的自分解规则

> 背景：大锅 = 完全自然反应 F（把任意元素向量完全重排为大锅产物）；
> 自然环境 = 不完全反应（T28/T29 的分解规则，会产生目录外的新物质）。
> 目标：给这些不稳定物质一条"自分解"规则，使它们在给定条件下能自分解成大锅可产出的物质。
> 脚本：`t30_self_decomp.py`、`t30b_prep_fig.py`、`t30_render.py`
> 图：`images/t30_self_decomposition.png`

## 1. 定义：稳定 / 不稳定

设 `F(v)` = 完全大锅反应（输入元素计数向量，输出产物分子集合）。
对物质 M，取其自身元素向量 `v_M`：

- **稳定物质**：`F(v_M) = {M}`（M 是自己元素向量的完全大锅产物，即 F 的不动点）；
- **不稳定物质**：`F(v_M) ≠ {M}`（M 不是完全大锅产物）。

> 目录中的 84,225 种物质都是 F 不动点（抽样 80/80 验证）；
> 自然环境下产生的新物质则不是（143/143 验证）。

## 2. 自分解规则

> **规则 S（自分解）**：当不稳定物质 M 满足触发条件时，执行一次完整大锅反应：
>
> ```
> M → F(v_M)
> ```
>
> 即把 M 的全部原子按大锅规则重新完全重排，得到一组大锅产物。
> 稳定物质（F 不动点）在任何条件下都不自分解。

### 触发条件（可任选或组合）

| 条件 | 说明 | 效果 |
|---|---|---|
| ① 完全反应场 | M 接触大锅 / 恒素 E / 高温 / 强扰动 | 立即自分解 |
| ② 时间条件 | M 在自然环境中存在足够长时间 | 一定会自分解（给定半衰期） |
| ③ 概率条件 | 每个时间步以概率 p 自分解 | p 可设为常数或不稳定度的函数 |
| ④ 不稳定度阈值 | `U(M) ≥ θ` 时才能触发 | 控制不同"不稳定程度"的物质 |

**不稳定度 U 的可选定义**（用于条件④/③）：
- 简单版：`U(M) = 0`（F 不动点）或 `U(M) = 1`（非 F 不动点）；
- 分级版：`U(M) = F(v_M) 的产物数 − 1`（产物越多越不稳定；样本中 U=1~7）；
- 也可用结构偏离度（M 与 F(v_M) 产物的键型差异）自定义。

## 3. 为什么它保证"所有不稳定物质都能分解"

1. `F(v_M)` 对任何元素向量都有定义，输出产物都是**大锅可产物质**（这是 F 的定义）；
2. 自分解产物是 F 不动点：把每个产物再单独投锅，仍得到它自己（验证 30/30）；
3. 因此一次自分解就把不稳定物质变为稳定集合；
4. 稳定物质再次遇到规则 S 时不反应（F({M})={M}）；
5. 所以**所有不稳定物质都能被"清空"**，自然环境中最终只剩下大锅可产出的稳定物质。

## 4. 数据验证

对 1,200 个随机分子对的自然反应产物中收集到 **143 种目录外新物质**：

| 验证项 | 结果 |
|---|---|
| 自分解后"完全转化为别的物质" | **143 / 143** |
| 自分解产物全部在大锅目录中 | **143 / 143** |
| 目录物质为 F 不动点（抽样 80） | 80 / 80 |
| 自分解产物再作用 F（抽样 30 种） | 30 / 30 仍为自身（一步收敛） |

产物个数分布：2 个 47 种、3 个 28 种、4 个 25 种、5 个 15 种、6 个 21 种、7 个 4 种、8 个 3 种
（即不稳定物质一次自分解通常裂成 2~8 个大锅产物）。

## 5. 示例

`XCP2WLK2A`（自然环境合并产生的目录外新物质）：

```
XCP2WLK2A  →  XWA + CL + PK + PK
```

- 4 个产物全部是大锅可产物质（F 不动点）；
- 再次施加规则 S，每个产物都不再变化；
- 因此该新物质只存在到触发条件满足为止，之后"消失"为一批稳定物质。

图：`images/t30_self_decomposition.png`（左：不稳定分子；中：触发条件；右：4 个稳定产物）。

## 6. 与"自然环境不完全反应"的衔接

```
大锅（完全反应）：任意元素 → F(v) → 稳定物质集合
自然环境（不完全反应）：稳定物质 → 分解规则 → 可能产生不稳定物质（新物质）
自分解规则 S：不稳定物质 + 触发条件 → F(v_M) → 稳定物质
```

三者形成闭环：
- 自然环境的"不完全"制造不稳定物质（丰富度/探索来源）；
- 一旦满足条件（进入完全场/时间到/概率命中），不稳定物质自动分解回稳定物质；
- 稳定集合不会反向变成不稳定（F 不动点）。

## 7. 参数建议

| 参数 | 建议 | 作用 |
|---|---|---|
| 触发方式 | 默认：接触完全反应场（大锅/恒素 E）立即触发 | 干净、可解释 |
| 自然环境半衰期 | 可选，例如按 U 分级：U 越大半衰期越短 | 让不稳定物质在自然界缓慢消失 |
| p（每步概率） | 0.01~0.1 每时间步 | 控制新物质寿命 |
| θ（U 阈值） | 1（所有不稳定）或 2（只让"很不稳定"的分解） | 控制分解门槛 |
| 产物检查 | 只要求产物是 F 输出（即大锅可产） | 不需要白名单 |

## 8. 边界情况

- **大分子目录不完整**（>16 原子）：用 `F(v_M) = {M}` 判断稳定，而不是查目录；
- 若某 M 在 `F(v_M)` 的多个产物中仍出现自己（部分不稳定），可视为"部分稳定"，
  需要更严格的规则（例如只把 M 从产物中剔除或视为稳定）；本次 143 种样本中 **未出现**这种情况；
- 自分解是"一次完成"的，不需要多步迭代（产物已是 F 不动点）。
