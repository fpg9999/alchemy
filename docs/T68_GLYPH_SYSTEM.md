# T68 大分子骨架的形状语言（元素字形 / 家族容器 / 连接语法）

> 任务：为每种骨架设定一种独特形状——单秩元素代表三角形、单势元素代表圆形、
> 单散素代表正方形（或更多角）；大分子里有多个骨架融合或用二价桥相连时，
> 设计连接方式把这些几何图形也连起来，并用图形呈现至少 30 个大分子 / 特大分子。
> 本文件定义"形状语言"本身；36 个分子的成品图册见 `docs/T68_GIANT_ATLAS.md`。
> 状态标注：**已验证** = 能用脚本复算复现；**推断** = 视觉约定，不影响化学数据。

---

## 1. 形状语言的三层结构

T18 已确定的三层价数角色（沿用，不重新定义）：

| 层 | 元素 | 价数 | 在骨架图中的职责 |
|---|---|---|---|
| 骨架层 | 秩 O、势 P、沌 K | 3 | 环 / 链 / 星 / 团，决定"骨架形状" |
| 连接层 | 晶 X、流 W、气 A | 2 | 桥、链段、支臂，决定"骨架之间怎么连" |
| 终端层 | 冰 C、电 L、焰 F | 1 | 端帽、尖刺，只做装饰封口 |

形状语言 = **原子字形（元素层）+ 家族容器（骨架层）+ 键型语法（连接层）** 三层叠加，
所以一个骨架图形同时携带三种信息，且不会退化成"一团彩色点"。

## 2. 元素字形（原子级别）

| 元素 | 字形 | 几何（s = 格子半尺度） | 读法 |
|---|---|---|---|
| 秩 O | 三角形 | 外接圆半径 0.60·s | 骨架原子，最锐利 = 秩序 |
| 势 P | 圆形 | 半径 0.50·s | 骨架原子，最饱满 = 势 / 能量 |
| 沌 K | 正多边形 | 角数 n = min(8, 3 + 骨架内 K 数)，内切 0.46·s | 骨架原子，K 越多角越多 = 混沌度 |
| 晶 X | 尖六边形 | 半径 0.52·s | 二价，刚性，S 短键为主 |
| 流 W | 圆角六边形 | 切角六边形近似 | 二价，铰接，C 角键为主 |
| 气 A | 虚线六边形 | 边长 0.52·s，虚线描边 | 二价，软连接，L 长键为主 |
| 冰 C | 小菱形 | 半宽 0.34·s | 一价端帽 |
| 电 L | 小圆点 | 半径 0.28·s | 一价端帽 |
| 焰 F | 小三角形 | 半径 0.34·s | 一价端帽 |

补充约定（**已验证**，`t68_shapes.py: atom_poly()`）：

- K 的角数按"同一骨架内 K 原子总数"取：1 K = 正方形，2 K = 五边形，3 K = 六边形，
  4 K = 七边形，5 K = 八边形封顶。例：`O2K3` 里的三个 K 都画成六边形，`OK2` 的 K 画五边形。
- 骨架原子高饱和 + 深描边；桥原子中饱和；一价端帽字形缩小并变浅；游离装饰最浅。
- 字形只编码"价数 / 层 / 家族"，不编码元素的具体化学性质；元素的化学性质仍由字母与颜色给出。

## 3. 骨架家族容器（骨架级别）

骨架的三价元素集合只有 7 种（`fam_key()`），每种给一个独特外轮廓 + 专属颜色，
让"这是哪一类骨架"在缩略图尺寸下也能一眼分辨（`t68_shapes.py: fam_shape()`）：

| 家族 | 三价集合 | 容器外形 | 38 库形态数 |
|---|---|---|---|
| 纯秩 | O | 三角形 | 1（O） |
| 纯势 | P | 圆形 | 1（P） |
| 纯散 | K | 正多边形（3+K 数边） | 1（K） |
| 秩势 | O+P | 拱形（三角 ∪ 圆的水滴形） | 7 |
| 秩散 | O+K | 盾形（三角 ∪ 方） | 7 |
| 势散 | P+K | 圆角方（方圆超椭圆） | 7 |
| 秩势散 | O+P+K | 六边形（最复杂的一类） | 14 |

容器只是**轮廓**：同一家族内不同骨架靠容器内部的原子字形、位置与键型区分，
所以同一家族的 7~14 个形态仍然一一可辨（见第 4 节 38 形态图鉴）。

## 5. 键型语法（键级别）

六边形棋盘格上两个相邻原子的相对位移决定键型（`pot_all.classify_offset()`，**已验证**）：

| 键型 | 几何含义 | 画法 | 化学性格 |
|---|---|---|---|
| S 短键 | 共享一条边（相邻格） | 实线，红 `#c0392b` | 刚性、最短，聚素 |
| C 角键 | 共享一个顶点（角接触） | 实线，绿 `#1e8449` | 可转动关节，动素 |
| L 长键 | 隔一格中点空 | 紫 `#6c3483` 虚线 + 中点半透空格 | 软、长，散素 |

- 每对元素最多 3 根平行键；多重键用平行线间距 0.16·s 表示（双键 2 线、三键 3 线）。
- L 键画在"中点空格"旁，并给中点半透空格占位六边形，读图时不会以为键断了。
- 骨架内部（三价-三价）的键用全饱和色；通向装饰层的键按类型上色但变淡变细，
  避免装饰层抢走骨架轮廓。

## 6. 骨架之间怎么连（连接语法，本图册的重点）

### 6.1 融合（0 级同类三价键）

两个 6 级骨架块之间如果出现**同一元素**的三价键（编码上属于 0 级键），判定为融合：

- 画法：两个容器轮廓"焊在一起"，键画成**深色双线焊条 `#34495e`**，中间加
  **橙色刻痕 `#e67e22`**，并在旁边标橙字「融合」。
- 实例（**已验证**）：G13 的骨架② `O2P8K2` = `OP4K ⊕ OP4K`，由 1 根 P–P 0 级键融合而成。
- 注意：0 级键只在价数未饱和时出现；稳定大分子价数基本已饱和，所以 36 个分子里
  只出现 1 根融合键（见 `docs/T68_GIANT_ATLAS.md` 第 6 节）。

### 6.2 二价桥（跨两个骨架的连接层）

桥原子 X/W/A 的键型决定桥的"机械性格"，图形上用三种不同附件表达：

| 桥型 | 桥原子 | 画法 | 力学读法 |
|---|---|---|---|
| S 刚性焊桥 | X 晶 | 骨架上贴小方焊板 + 红色实线 | 两骨架相对固定，硬焊 |
| C 铰接桥 | W 流 | 桥原子外套绿色圆环 + 实线 | 可绕骨架转动 / 折叠 |
| L 浮空软桥 | A 气 | 紫色虚线 + 中点空格六边形 | 两骨架隔空柔性相连 |

36 个分子里 114 条桥的分布（**已验证**，按桥的键型组合统计）：
S 刚性焊桥 9 条、C 铰接桥 45 条、L 浮空软桥 4 条、混合桥 56 条；
按键端计 S 63 / C 121 / L 44。混合桥（两端键型不同，如 X–W、X–A）最多，
说明真实稳定大分子更喜欢"一端硬一端软"的复合连接。

### 6.3 骨架上的装饰

| 装饰 | 定义 | 画法 |
|---|---|---|
| 一价端帽 | 一价原子直接接在骨架 / 链端 | 小字形 + 浅色 |
| 支臂 | 骨架 – 二价原子 – 一价端帽 | 从骨架伸出的短链，端部小字形 |
| 骨架内桥 | 同一骨架上两个原子之间的二价焊点 | 画在容器内部，橙色点 + 短弧线 |
| 游离二价 | 不与任何骨架相连的散块 | 最浅色，只作陪衬 |

36 个分子装饰层原子数（**已验证**）：支臂原子 126、骨架内桥原子 53、一价端帽 66、
游离二价 0。

## 7. 分子卡片怎么读

每张卡片（`images/t68_giants_*.png`，2 张 / 页，共 18 页）左侧是分子图，右侧是清单：

- 卡片头：编号 G13、分子式、来源实验阶段、原子数 / 骨架数 / 桥数、分子家族；
  右上绿框是稳定性复核结论 `F(v_M)={M}`（pot_v4 复核，**已验证**）。
- 右侧「骨架」列表：每个骨架给编号圆徽章 ①②③、家族图标、形态公式、家族中文名、
  原子数、6 级块数、38 库编号（#k），行尾是该骨架自身形态的迷你图。
- 右侧「桥」列表：每条桥给「桥k」椭圆徽章、桥原子公式、桥型、键数与类型。
- 「装饰层」：一价端帽 / 支臂 / 骨架内桥 / 游离二价 的原子数。
- 图内编号与面板编号一一对应：圆徽章 = 骨架编号，椭圆徽章 = 桥编号。

## 9. 局限与未决

- **推断（视觉约定，不是化学结论）**：K 字形"角数 = 3 + K 数"、7 家族外轮廓的具体几何、
  桥附件的形状（焊板 / 圆环 / 虚线）都是本图册新定的视觉规则，用于"每种骨架一种独特形状"，
  不改变任何模拟数据。
- **已回避的歧义**：同一家族的 7~14 个形态若只看外轮廓会难以区分，因此容器内必须画出
  原子字形与键型；缩略图（总览）尺寸下只保证家族 + 骨架数量可读，细节看卡片页。
- **未决**：0 级键（融合 / 加固）在稳定分子里极少，是否给 0 级键设计更丰富的图形语言，
  要等找到更多含 0 级键的稳定大分子样本再定。
- 骨架与桥的归属沿用 T68 数据构建时的规则（终态三价连通分量 = 骨架；桥 = 两端接不同骨架的二价连通块）；
  该口径与 T20 的九种二价存在形式一致，但"混合桥"是本图册为绘制方便做的合并分类。
