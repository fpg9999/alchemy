# T64 生态群系：12 个"元素社区"的退火—恒温实验

> 实验日期：2026-11-17；引擎：t55_kinetic_env（DSMC 粒子环境）+ pot_v4 反应规则；
> 报告文件：`docs/T64_BIOMES.md`；数据：`t64_biome_B01..B12_result.json`；
> 脚本：`t64_biomes.py`（实验）、`t64_analysis.py` / `t64_render.py`（分析出图）、
> `t64_verify.py`（独立验证）、`t64_hex_layouts.py` / `t64_hex_render.py`（结构图）。

## 0. 一句话结论

在"每个群系只放 3~9 种元素的双原子单质、1000°C 退火到 25°C、随后 600 分钟在 25°C 附近做日/季节浮动"的条件下，
**12 个群系全部收敛成特征鲜明的稳定物质群落**：纯族群系（B01/B02/B03）由单一三元分子占据 99% 以上；
混合群系沿着"配对双产物 → 多骨架簇合物 → 多组分生态系统"三种路径演化；其中 **B08 三骨架湖** 聚合出
十原子簇合物 `O2X2P2W2K2`（占 94.4%，平均 9.73 原子/分子），**B11 九元素大生态** 复现了 T62 的
`LF + OXCPWKA` 双组分生态，**B09/B10** 则形成三对双原子分子并各自长到 39 原子的巨型结构。
所有 12 个群系守恒、温度日程、判定、结构、对照全部通过（验证 102 项 PASS / 0 FAIL）。

**关键数字**：12 群系合计 59,714 分子 / 165,000 原子；总模拟 425.4 秒；
恒温段温度实测 15.56~35.71°C（日周期 ±8°C + 季节 ±3°C，理论 14~36°C）；
末温全部 22.25°C；无化学对照 min=706.5、fraction_ge_500=1.0。

## 1. 任务与设计

### 1.1 用户要求（2026-11-17）

> "一个生态群系就是在一个特定大小的空间里，只有特定几个元素组成的物质存在（至少 3 种元素且包含一种三价元素，至多 9 种元素），然后在经过一轮 1000° 高温退火到一个恒定的温度（具体温度你来定）之后形成的较为稳定的物质群落。温度会一直保持在一个中间值附近上下浮动，就和现实世界一样。现在请你尝试构建这样的生态群系，至少尝试构建十个群系并从中找出有特色的群系详细分析。"

### 1.3 温度日程（所有群系相同）

```
0 ~ 975 分钟     T(t) = 1000 - t                      （1°C/分钟，1000→25°C）
```

## 2. 方法

### 2.1 投料设计：双原子单质、等原子

每群系只投该元素的 `X2` 双原子分子，每元素原子数相等（2,000~4,000）：
`O2/X2/C2` 三键/双键/单键、`P2/W2/L2`、`K2/A2/F2` 同理。这样"群落"的化学计量由元素集合本身决定，
不预设任何产物偏好；同时保证单质种类少、初始状态干净，便于观察"从单质到群落"的全过程。

### 2.2 口径

- **终态种数**：`len(final_composition)`（终态存在的分子式数；`distinct_formulas` 是历史累计键，不采用）
- **平均聚合度**：终态总原子 / 终态总分子
- **capped**：合并后 >40 原子的弹性截断事件（不计入 complete/incomplete/none 三类判定）
- **家族**：聚素 = 只含 O/X/C；动素 = P/W/L；散素 = K/A/F；同时含 2 组以上 = 混合
- **单质残留**：分子式恰为 `e2` 的原子数；利用率 = 1 − 残留占比
- **新物质**：目录（84,225 条已知结构 + 29 种 + 9 种单质）之外的分子式
- **特色评分**：8 个维度（多样性/专一性/聚合度/最大尺寸/三价利用率/转化率/恒温活性/新物质数）
  在 12 群系内做 z-score，正向 z 值平方和；前 3 名优先取自不同主导维度

### 3.2 三种终态形态

**形态 I：单一三元分子统一（B01/B02/B03，纯族）**
每族三元素（3+2+1 价）恰好组成一个饱和三元分子：`OXC`/`PWL`/`KAF` 各占 99.3~99.4%，
平均 3.02 原子/分子，最大分子只有 8 原子。三价元素提供"双键 + 单键"两个配位，二价/一价元素分别以双键/单键封端：

```
OXC：  O = X        O 用双键连 X、单键连 C（O 三价填满）
       O - C         X 二价、C 一价各填满
```

**形态 II：配对双产物（B04~B07、B12）**
体系分裂成"一个含三价元素的饱和分子 + 剩余元素的饱和单质/小分子"，比例由价数配比决定（约 2:1）：

| 群系 | 主要产物 1 | 主要产物 2 | 机制 |
|---|---|---|---|
| B04 | OAF 66.2%（O=A + O–F） | X2 33.1% | O 与 A、F 完美配平后，X 无人配对只能成 X2 |
| B05 | OP 66.6%（O≡P 三键） | X2 33.1% | 两个三价互相饱和，X 剩余成 X2 |
| B06 | OK 66.5%（O≡K） | C2 33.2% | 同上，C 剩余成 C2 |
| B07 | OP 66.4% | X2C2 32.9%（C–X–X–C 链） | OP 后剩余的 X、C 组成四元链 |
| B12 | PK 66.3%（P≡K） | L2A2 33.1%（L–A–A–L 四元链） | 无氧生态，A 桥接两个 L |

**形态 III：多骨架簇合 / 多组分生态（B08/B09/B10/B11）**
元素数 ≥5、三价骨架元素 ≥2 时，体系不再分裂成小分子，而是形成多骨架簇合物或"多个小产物共存"：

- **B08（5 元素，3 种三价 + 2 种二价）**：94.4% 的原子进入十原子簇合物 `O2X2P2W2K2`，
  平均 9.73 原子/分子，是全部群系中聚合度最高的（全体均值 3.28）；
- **B11（9 元素）**：收敛为 `OXCPWKA`（42.3%）+ `LF`（42.1%）双组分，平均 4.30 原子/分子；
- **B09/B10（6 元素）**：没有统一大分子，而是三对双原子分子各占约 1/3（B09：CL/XW/OP；B10：CF/XA/OK），
  平均 2.06 原子/分子，但同时出现 39 原子巨型结构（占比极小）。

结论：
1. **多样性、新物质数、总事件数随元素数单调上升**（B11 最多：24 种、417 新物质、41,116 事件）；
2. **聚合度不是元素数的单调函数**：B08（5 元素）远高于 B09/B10（6 元素），因为 B08 恰好集齐

3. **最大分子尺寸由"骨架元素是否齐全"决定**：B09/B10/B11 都有 39 原子巨型（含多个 P 的骨架），

### 3.6 动力学：退火定型，恒温段缓慢重排

从 400 个时间点的时间序列看（B01 为例）：1000→25°C 的 975 分钟里，
分子数从 6,000 迅速坍缩到 ~3,980 并定型；进入恒温段后，25°C 下每 100 分钟仅有约 400~600 次碰撞
（B01 末段 events 增速 ≈3.5 事件/分钟），分子种类和数量基本不再变化。
12 群系恒温段事件合计仅占全程事件的一小部分，**终态产物主要在退火过程中定型**，
这与用户"退火后形成稳定群落"的设定一致；恒温浮动段只做缓慢的热重排（这也解释了为什么 B08/B11 的
终态在 25°C 下能保持 600 分钟不塌缩）。

### 4.1 B01 聚素平原（O+X+C，12,000 原子，L=17,000）

| 分子式 | 中文名 | 数量 | 占比 | 原子数 |
|---|---|---|---|---|
| OXC | 秩晶冰 | 3,957 | 99.42% | 3 |
| O2XC2 | 秩2晶冰2 | 6 | 0.15% | 5 |
| O2X2C4 | 秩2晶2冰4 | 3 | 0.08% | 8 |

结构：`O=X` 双键 + `O–C` 单键（O 三价填满，X 二价、C 一价各填满）。

**意义**：这是"聚素族生态"的基态；也说明低 T 下的终态由"最简饱和分子"决定，而不是由初始物种分布决定。

## 7. 温度与动力学观察

1. **退火决定终态**：1000→25°C 的 975 分钟里，体系从 6,000 个双原子分子演化到 1,500~7,300 个终态分子；
   进入恒温段后，25°C 的碰撞率只有高温段的 1/5~1/10，事件数增长极慢（B01 恒温段约 3.5 事件/分钟），
   终态组成基本不变
2. **恒定温度 25°C 的选择**：T57/T63 用的是线性降到 0°C 并结束；T64 需要"恒温 + 浮动"，
   因此选 25°C（室温）：既能保持"稳定群落"，又让恒温段仍有缓慢重排（不是完全冻结）
3. **浮动幅度**：日周期 ±8°C + 季节 ±3°C，实测 15.56~35.71°C，波动 20.15°C；
   在 600 分钟的恒温段里大致经历 ~2.5 个日周期、~0.67 个季节周期，足以观察"温度浮动是否改变群落"
4. **浮动的影响**：恒温段内各群系组成基本不变（capped 事件也集中在退火前中期），
   说明这些群系在 14~36°C 范围内是"耐受"的；更大浮动或更长时间可能触发重排，可作为下一步
5. **无化学对照**：B01 投料关闭化学跑 500 分钟，路径长度 min=706.5、中位 750.4、≥500 比例 100%
   （纯物理运移标定），与 T57/T59/T62/T63 的对照一致

### 8.2 局限

1. **温度取 25°C**：这是"室温"选择；若取 0°C 或 60°C，终态可能不同（T57/T63 的 0°C 经验显示更彻底的"最简分子"化）
2. **时间尺度**：恒温段 600 分钟只覆盖 ~2.5 个日周期；更长时间（如 10,000 分钟）可能让亚稳态重排
3. **空间都是均匀 2D 方形**：没有地形/边界/局部温度梯度；"生态"只是化学意义上的
4. **capped 现象**：B09/B10/B11 在退火前中期尝试合并 >40 原子被截断（capped 计数），
   不影响终态判定（<1%），但说明 cap 对"巨型结构"有边界效应
5. **单质投料**：只有一个初始条件（双原子单质等原子），没有检验投料比例变化的影响（T62 已从另一侧验证）

## 9. 结论

1. **12 个生态群系全部成功构建**，且都形成稳定、可复现的物质群落；三族纯系群系收敛为单一三元分子（99%+），
   混合群系收敛为"配对双产物 / 多骨架簇合物 / 多组分生态"三类形态
2. **价数结构 > 元素身份**：O/X/C、P/W/L、K/A/F 三组同价数元素给出完全同构的终态（B01/B02/B03）；
   B09（聚+动）与 B10（聚+散）镜像对称，B05/B06 双三价同构——说明"3+2+1"或"3+3"的价数搭配决定终态形态
3. **元素越多越不单调**：B11 最活跃、最多样；B08 聚合度最高；B09/B10 分裂成三对小分子——
   多样性、聚合度、稳定性由"骨架/桥/端帽元素"的搭配决定，而非简单的元素数量
4. **"生态核心"复现**：B11 复现 T62 的 LF+OXCPWKA 双组分，说明该双组分是 9 元素等原子比下的稳定吸引子
5. **温度浮动不破坏群落**：14~36°C 的日/季节浮动下，12 个群系的终态组成在 600 分钟内保持稳定
6. **工程可复用**：`t55_kinetic_env.py` 新增 `temp_schedule` 参数后，任何"退火+恒温浮动"实验都可直接复用；
   12 群系全流程（含 4 个引擎阶段）仅 425 秒

## 10. 下一步建议（T65）

1. **温度扫描**：T_mid 取 0/10/40/60°C，观察终态形态转变（尤其 B08 簇合物、B09/B10 配对物）
2. **浮动幅度扫描**：±8→±20°C、周期 240→60 分钟（快速昼夜），检验"生态耐受性"
3. **投料比例扫描**：同一元素集合，改变各元素原子数比（如 B11 的 9 元素非等量），寻找"非化学计量生态"
4. **多群系耦合**：把两个群系放在同一空间/相邻空间，观察物种迁移与融合（生态过渡带）
5. **更长时间**：恒温段延长到 10,000 分钟，观察亚稳态重排与"生态演替"
6. **空间异质性**：加入地形/边界/局部温度梯度，把"化学群落"变成"空间生态"
