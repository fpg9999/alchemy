# T21 · 自然环境反应：端帽交换（Cap Metathesis）

> 规则（用户定义）：两个物质的最外层原子（端帽，1 价原子）**数量相等**时，
> 双方脱掉全部端帽并交换给对方；骨架部分保持不动，新端帽与骨架按大锅规则重新连接。
> 分析脚本：`t21_natural_caps.py`、`t21b_verify.py`；数据：`t21_natural_caps.json`、`t21_verified.json`。

## 1. 形式化

物质 M 分解为：`M = 骨架 S(M) + 端帽多重集 Cap(M)`（端帽 = 1 价原子 C/L/F）。
规则：若 `|Cap(A)| = |Cap(B)| = k`，则

```
A + B  →  A' + B'
A' = S(A) + Cap(B)        （骨架 A 原位不动，接上 B 的端帽）
B' = S(B) + Cap(A)        （骨架 B 原位不动，接上 A 的端帽）
```

约束：
- 骨架内部键**不拆**（与用户规则一致：只交换端帽）；
- 端帽只能接在骨架的"游离键位"上；键型必须符合大锅规则；
- 每个产物需几何合法（可摆放）。

## 2. 统计（全部 3,931 种 ≤8 原子物质，端帽数分组 1~5）

| 5 | 63 |

| 两个产物都在目录 | 937 对 |
| 同端帽元素（只可能换位置/异构化） | 20,039 对 |
| 出现过的**全新分子式** | **3,225 个** |
| 出现过的已知分子式 | 135 个 |
| 几何上无法完成的重连 | 0（回退搜索全部找到合法挂点） |

> 即"大锅无法产生的物质"。我们随机抽 16 个新产物用 `pot_v2.validate_place` 严格复核，**16/16 合法**。

## 4. 规律与新现象

### 4.1 三条守恒律
1. **端帽数守恒**：只有 k 相同的物质才反应；k 是每分子的守恒量子数。
2. **骨架守恒**：每个分子的骨架原子、骨架元素组成、骨架键（含 0 级融合结构）完全不变。
3. **端帽层交换**：全局元素守恒，但端帽元素在两分子间互换——物质可视为 `骨架 ⊗ 端帽多重集`。

### 4.2 新现象 ①：大量"大锅不可能产生的物质"
- 121,953 对样本中出现 **3,225 个全新分子式**（超出大锅可产出集合）；
- 原因：大锅要求"全原子重排+每原子价数填满+可摆放"，很多"骨架+外来端帽"的组合
  虽然化学价数合法，却永远不会作为大锅产物出现（大锅的贪心重组会把它拆成别的组合）。
- 意义：**物质总目录 = 大锅产物 ∪ 自然端帽交换产物**，后者可能远大于前者；
  自然反应是"以现成骨架为模板的功能化机制"。

### 4.3 新现象 ②：可逆平衡（交换是对合）
- 交换两次即回到原物质：`A + B ⇌ A' + B'`，因为 A' 的骨架仍是 S(A)、端帽为 Cap(B)，
  与 B' 交换端帽后得到 S(A)+Cap(A)=A、S(B)+Cap(B)=B。
- 所以自然环境中的端帽交换形成**可逆平衡**：`A,B` 与 `A',B'` 共存时互相转化，净变化为零。
- 若两物质端帽元素多重集相同（20,039 对），交换只改变端帽的挂接位置 → **端帽位置异构化**。

### 4.4 新现象 ③：端帽置换网络
- 同 k 的多个骨架之间可反复交换端帽：端帽多重集在骨架间做置换；
- 可形成"端帽迁移网络"（与 T11 的催化循环不同：这里的循环不需要副产物，直接由端帽交换实现）；
- 平衡态由各骨架的端帽亲和性（几何/键型）决定。

### 4.5 新现象 ④：骨架族与端帽功能化
- 同一个骨架可以搭配任意端帽多重集（只要 k 相等且几何允许）→ 产生"骨架族"（同一骨架的多个物质）；
- 端帽决定末端功能（C 冰=冷冻/结构、L 电=电击/信号、F 焰=燃烧），
  于是自然反应 = "用现成骨架做**端帽功能化改造**"；
- 这为设计提供新的物质生成方式：大锅造骨架 → 自然环境交换端帽 → 功能化变体。

### 4.6 与三层模型的关系
- 自然反应只作用于**终端层（端帽）**；
- 骨架层（含 0 级融合）与二价连接层完全不动；
- 因此 T18 的骨架分类（38 库 + 融合）对自然反应产物依然完全适用——只是换了端帽。

### 4.7 反应性/选择性
- 端帽（1 价）与任何类别的原子都至少存在一种合法键型
  （聚-动 S/C、聚-散 S/L、动-散 C/L…），所以**几何上几乎总能挂上**：
  这使端帽交换成为自然界"高概率发生"的低能反应；
- 只在挂点被骨架/其他端帽占满、或长键中点冲突时需要回退；本样本 0 例失败。
- 选择性来自"端帽数 k 必须相等"以及端帽的键型几何位阻，而非元素种类。

## 5. 对游戏设计的直接结论

1. **新增一种基础反应类型**："端帽交换/功能化"（自然反应），与"大锅重排"并列；
2. 物质系统 = 骨架（机械/结构/能力基座）× 端帽（末端功能），
   可以在不改骨架的情况下大量派生物质（每个骨架 × 端帽多重集）；
3. 端帽交换可逆 → 可做"平衡/可逆反应"玩法（例如可逆染色、可逆武器化）；
4. 大锅造不出的"功能化变体"可作为稀有/自然产物（探索奖励）；
5. 反复端帽交换可形成"置换网络"，适合做化学反应网络/炼金图鉴的分支。
