# T75 方块世界：每个骨架 = 地图上的一个单位方块

> **历史口径提示（2026-11-19）**
> 本文的"硬度"已被内核 **密度 / 粘性 / 温度 → 3³ = 27 格**取代（见 `docs/TRAITS.md`、`alchemy/attrs.py`）；
> 外观权重 1.20 / 0.90 / 0.60 与内核 3 / 2 / 1 两套并存、无换算表，详见 `docs/INTAKE_R2.md` §4 / §6。
> 文中"硬度"请按旧口径阅读，**不要当作现行属性**。

> 用户 (m02325) 的新规则：
> ① 世界变成方块单位（类泰拉瑞亚）；每个物质由 1 个或几个单位方块拼成；
> ② 一个物质内**每一块骨架 = 地图上的 1 个单位方块**，所以骨架呈现必须是方块，方块内部可以做细节区分；
> ③ 取消"刚性/松散/粘性""高温/低温""固/液/气"这些类别，改成三个**数值属性**：
> 三价元素决定**硬度**、二价元素决定**粘性**、一价元素决定**温度**（温度只表示物质自身温度，与反应无关）。

## 1. 一个方块里放什么

每个三价连通骨架压缩成 **1 个单位方块**（正方形，边长 1 格），内部区分：

| 位置 | 含义 |
| --- | --- |
| 外框颜色 / 内部纹样 | 骨架家族（纯秩三角、纯势圆、纯散五角、秩势拱、秩散盾、势散圆角方、秩势散六边） |
| 右上小方点 | 该骨架由几个 6 级块融合而成（1~2 个） |
| 底部文字 | 块形态（38 库编号/公式，如 OP4K） |
| 顶部小字 | 该骨架的三价原子数 |

## 2. 方块之间怎么连（都画在共用边上）

| 连接 | 图形 |
| --- | --- |
| 晶 X 桥 | 共用边上短粗的浅灰焊块（最硬：两块直接咬死） |
| 流 W 桥 | 跨边的细长椭圆肌腱（可拉伸、可弯） |
| 气 A 桥 | 沿共用边的淡青细长薄膜（隔空软连） |
| 融合（0 级同类键） | 同一骨架内两块 6 级块的焊纹（几条斜刻纹） |
| 一价端帽 | 方块**外缘**的小方钉：冰 C 三角钉 / 焰 F 方钉 / 电 L 细圆钉 |

分子的形状 = 若干单位方块组成的**多格骨牌（polyomino）**。方块排布由骨架图 BFS 四邻接嵌入网格得到
（优先紧贴其桥接伙伴、整体紧凑）。

## 3. 三个数值属性

| 属性 | 来源 | 权重 | 公式 |
| --- | --- | --- | --- |
| 硬度 | 三价 O / P / K | 1.20 / 0.90 / 0.60 | `Σ 个数 × 权重` |
| 粘性 | 二价 X / W / A | 1.00 / 1.40 / 0.40 | `Σ 个数 × 权重` |
| 温度 | 一价 C / L / F | −2.00 / +0.50 / +3.00 | `Σ 个数 × 权重`（负=冷、正=热、0=常温） |

权重集中在 `t75_attrs.py` 的 `HARD_W / STICK_W / TEMP_W`，要整体调参只改这三张表。
卡片上除了数值还列出各元素的贡献（例如「硬度：秩O×3(1.2) + 势P×16(0.9) + 沌K×5(0.6)」）。

## 5. 说明与局限

- 方块的**内部纹样**表示家族；同家族方块外观一致，靠底部块形态文字与右上块数区分具体骨架。
- 目前多格骨牌的排布是 BFS 贪心嵌入，能保证每个分子都排成连通的方块组；分子很大（5~7 块）时会出现
  一些不规则的 2×N 形状，这是图形嵌入的近似，不是化学拓扑。
- 属性值与旧分类（刚/粘/松、固/液/气）不再并存：新规则只输出数值，旧的分类页保留作历史参考。
- 温度暂不含环境温度影响（规则说与反应无关，只看物质自身）。

## 6. T75b 改版：属性按**每个骨架**计算，桥不计入

用户 (m02416)：属性不是整个物质的，而是**每个骨架各算各的**：骨架用"它拥有的元素 + 连在它身上的元素"来算；
**用于连接两个骨架的二价桥只负责连接，不计入任何属性**。

实现（`t75b_attrs.py`：`skeleton_attrs(mol)`）：

| 属性 | 每个骨架取什么 |
| --- | --- |
| 硬度 | 该骨架自己的三价原子（秩O 1.2 / 势P 0.9 / 沌K 0.6 的权重和） |
| 粘性 | **挂在它身上**的二价原子（骨架内桥、支臂上的、端帽双键…；晶X 1.0 / 流W 1.4 / 气A 0.4） |
| 温度 | **挂在它身上**的一价原子（端帽；冰C −2.0 / 电L +0.5 / 焰F +3.0） |

注意：`role == "bridge"` 的原子（连接两个骨架的二价桥）**直接跳过**，既不进粘性也不进任何属性。
一个骨架若只有三价原子（别的二价都在桥上），它的粘性就是 0 —— 页面上会写"只有三价元素（桥不计）"。

呈现方式：
- 每块方块右下角三条小色条 = 这块骨架自己的 硬度(红) / 粘性(绿) / 温度(紫)；
- 卡片右侧逐骨架列表：`① OP4K   H 5.4  V 0.0  T +3.5`，下一行是参与计算的元素（如 `硬:秩1+势4+沌1`）。

图件：`images/t75b_rules.png`、`images/t75b_molecules.png`、`images/t75b_overview.png`。
复现：`python t75b_render.py`。
