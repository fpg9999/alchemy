# 三轴体系·最终结论（v4）

> 定稿：2026-11-18　实现：`alchemy/phase.py`　测试：**85 项全通过**
> **v4 判定规则**：严格多数者胜 → **两两并列走循环压制**（聚>散>动>聚）
> → **三者全等（含全零）归聚**。**永不产生第四相。**
> **v4 分类**：晶体并入刚体；虚与无属性不再存在。体系 = **3×3×3 = 27 型**。
>
> **与 `docs/MATERIAL_AXES.md` 的关系（2026-11-19 补注，两套体系分名并存、互不替代）**：本文件的「三轴」是
> **三轴判相（相态）体系**——3 价层 → 概念族（刚体/胶体/软体）、2 价层 → 物态（固/液/气）、1 价层 → 能量（冰/焰/电），
> 由 `alchemy/phase.py` 实现；`docs/MATERIAL_AXES.md` 的「**物质三轴**」是另一套体系——质量/物态/温度（按层平均 + 阈值）
> → 27 格行为表 + 浮力，由 `alchemy/attrs.py` 实现。两者**无换算关系**：本文件「27 型」指相态分类，不是 MATERIAL_AXES 的
> 27 格行为表（二者都恰好 3×3×3 而得名碰撞）。两套的「物态」都取自 2 价层，但语义不同（此处为相态命名 固/液/气；
> MATERIAL_AXES 的物态轴为 气/液/固 的碰撞语义 穿过/游泳/阻挡），以各自文档为准。

## 0. 一句话

**物质 = 三条正交轴（每轴三相）× 恒素场（独立于三轴）。**

```
3 价层 O/K/P → 概念族（刚体 / 胶体 / 软体）   —— 决定"是什么材质"
2 价层 X/A/W → 物态  （固 / 液 / 气）        —— 决定"如何占据空间"
1 价层 C/F/L → 能量  （冰 / 焰 / 电）        —— 决定"带什么能量"
```

**共 27 型**（全目录 84,225 条中 27 型全部有物质：最少 2,020 条、最多 4,609 条）。

## 1. 判定规则（v4）

```
轴(物质, 三元组):
    n = 该物质里三元组各元素的原子数
    1) n 严格最大者胜出
    2) 两两并列（恰好两个同为最大）→ 循环压制：聚 > 散 > 动 > 聚
    3) 三者全等（含三者全为 0）    → 按优先级取聚素
```

### 1.1 为什么是"混合"而不是纯层级

纯层级制（并列一律取聚）会让动素（势/流/电）**永远赢不了并列**，
导致物态轴被晶 X 吞掉（固 41%）、能量轴被冰 C 吞掉（冰 48%），
**"液"在五个候选群系里全部归零**。

混合规则只在"两两并列"这一档开一条循环通路，让动素能赢聚素：

| 两两并列 | 胜出 |
|---|---|
| 聚 vs 散 | 聚 |
| 散 vs 动 | 散 |
| **动 vs 聚** | **动** ← 这条救回了液 / 电 / 软体 |

而"三者全等"没有优势方可言，直接归聚兜底。

### 1.2 v4 分布（全目录 84,225 条）

| 轴 | 分布 |
|---|---|
| 概念族 | 软体 36.44% · 刚体 31.82% · 胶体 31.74% |
| 物态 | **固 35.86% · 液 33.54% · 气 30.60%** |
| 能量 | **冰 42.70%** · 焰 28.66% · 电 28.64% |

物态轴几乎完美三分（极差 5.3pp），能量轴冰仍偏高但电恢复到 28.6%。
三轴仍统计独立（两两 Cramér's V ≈ 0.03）。

### 1.3 与各版本的对比

| 版本 | 两两并列 | 三者全等 | 第四相 | 空间 | 固/液/气 |
|---|---|---|---|---|---|
| v1 层级 | 聚>散>动 | 聚>散>动 | 无 | 27 | 41.4 / 28.0 / 30.6 |
| v2 循环 | 循环 | 第四相 | 有（晶体/虚/无属性） | 64 | 29.4 / 33.5 / 30.6 |
| v3 层级 | 聚>散>动 | 聚>散>动 | 无 | 27 | 41.4 / 28.0 / 30.6 |
| **v4 混合** | **循环** | **聚>散>动** | **无** | **27** | **35.9 / 33.5 / 30.6** |

v4 = v3 的简洁性 + v2 的平衡性。

## 2. 概念族：刚体 / 胶体 / 软体

**晶体已并入刚体**（宝石、水晶、卤水等归入刚体这一大类）。

### 2.1 依据：三价主导元素决定骨架键型

三价元素分属聚/散/动，骨架键是**跨类**成键，允许键型互不相同。实测（1500 抽样，只统计三价-三价键）：

| 主导 | S 短键 | C 角键 | L 长键 |
|---|--:|--:|--:|
| 秩 O(聚) | **60.2%** | 25.6% | 14.2% |
| 沌 K(散) | 19.7% | 22.0% | **58.2%** |
| 势 P(动) | 24.1% | **61.8%** | 14.2% |

**结构必然**：秩(O) 是唯一"跟另两个三价元素都能成 S"的；沌(K) 唯一两边都允许 L；
势(P) 唯一两边都允许 C。每个主导元素恰好是它两个配对的**公共键型**。

### 2.2 三相

| 相 | 主导 | 骨架主导键型 | 力学表现 | 硬度/密度/黏聚 |
|---|---|---|---|---|
| **刚体** | 秩 O | S 短键 60% | 硬、不弯、受击只断 | 3 / **4** / 4 |
| **胶体** | 沌 K | L 长键 58% | 松散、分散、可吸附悬浮 | 1 / 2 / 2 |
| **软体** | 势 P | C 角键 62% | 铰接、可弯、形变不断 | 2 / 1 / **1** |

### 2.3 已排除的假设

- ❌ **"三价主导决定形状"**：实测 1000 抽样，团都占 73~84%、环数 1.38~1.56、骨架块数 2.0~2.2、原子数 13.5~13.7——三组几乎相同，形状与该轴无关。
- ❌ **"概念族决定生命形式（死物/植物/动物）"**：必然三等分，与"死物≫植物≫动物"的金字塔矛盾；生命改为三轴共同涌现。

## 3. 物态：固 / 液 / 气

空间占位强度的三个档位（"虚"已随第四相移除）：

| 相 | 空间占位 | 力学互动 | 位置 | 典型 |
|---|---|---|---|---|
| **固** | 强（排他、不可压缩） | 极强（支撑、阻挡） | 固定 | 岩石、金属、水晶、泥土、沙 |
| **液** | 中（排他、近乎不可压） | 强（黏性、表面张力、浮力） | 流动 | 水、泥浆、蜂蜜、液态金属 |
| **气** | 弱（排他但**可压缩**） | 弱（碰撞、压力、阻力） | 自由 | 雾、烟、空气 |

**液列按密度分层**：液态金属（底）→ 泥浆/蜂蜜 → 水（顶）。
**气列按结构有序度**：气湖（成块不混合）→ 雾烟（无序悬浮）→ 清风（自由）。

## 4. 能量：冰 / 焰 / 电

| 相 | 元素 | 含义 |
|---|---|---|
| **冰** | C | **冷**：降低真实温度 → 结霜、冻伤 |
| **焰** | F | **热**：升高真实温度 → 燃烧、灼烧 |
| **电** | L | **电磁与光**：导电、发光、磁性、信号传递 |

**能量轴只管"现象层"，不引起物态相变**（见 §6.3）。

> 碰撞/重力/恒素富集）是**不同体系、不同命名空间**。需要物理行为语义（上升/悬浮/下沉、穿过/游泳/阻挡、恒素稀薄/中性/富集）
> 时查 MATERIAL_AXES 的 27 格行为表；本节只用于相态/材质命名。

```
{概念形容词}{能量形容词}{物态名词}
 刚体→刚性  冰→低温    固→固体
 胶体→黏性  焰→高温    液→液体
```

## 6. 配套设定：恒素（第十元素）

### 6.1 本体

| 项 | 内容 |
|---|---|
| 位置 | 元素周期表**最中心** |
| 价数 | **0 价** |
| 作用 | **影响周期表距离规则** |
| 参与反应 | **否** |
| 适用三轴 | **否**（不进 27 型，单独讨论） |

### 6.2 机制：借出—归还

**这个世界没有"不饱和"物质——所有物质价数都填满。**

```
注入恒素 → 打断已形成的键 → 重组 → 新键形成 → 恒素逸散回空间
                                          （净消耗 = 0）
```

- 恒素**总量守恒**，不被消耗；
- 唯一变量是**区域浓度 ρ_E**：高 = 化学活跃，低 = 化学冻结；
- "获取恒素"的正确提法是**如何让恒素重新富集**。

支撑定理：**完全饱和态的总键级 = Σ价数/2**，只由组成决定（全目录 **84,225/84,225** 实测成立）。
因此完全反应净恒素收支恒为 0 → 端点是**不动点** → **重新升温到 1000 度结果不变**。
反应停止是**规则限制**，与温度无关。

### 6.3 相变不由温度决定

- 物态**只由组成（X/A/W）决定**；
- 物质**不会因为加热而熔化、不会因为冷却而结冰**；
- 要改变物态，只能改变组成 → **必须发生化学反应**；
- 推论：**物质表是静态的**，一张表管到底。

### 6.4 世界的循环

`高富集 → 化学剧烈 → 扩散稀释 → 化学冻结 → 重新富集 → 再次活跃`

富集机制候选：地质泵（最自然）／特殊晶体作为"恒素透镜"／文明主动浓缩／大爆炸残余（一次性）。

## 7. 周期表几何

**形状：以恒素为中心的三辐星形。** 三条辐条 = 聚 / 散 / 动，三层同心环 = 价数（1 价最内，3 价最外）。

```
同辐条距离 = |r₁ − r₂|        （沿辐条走，不经过中心）
跨辐条距离 =  r₁ + r₂        （穿过中心的恒素）
```

这解释 `ptable_dist` 的公式（同类 `|价差|`、跨类 `价数和`），也解释：

- **6 级（OP/OK/PK）是唯一"两层最外 × 跨辐条"**的组合 → 骨架最依赖恒素；
- **0 级（同种元素）不经过中心** → 理论上不依赖恒素。

图上标出的类别优先级（聚最优先、散次优先、动最后）与规则 9 的
`O>X>C>K>A>F>P>W>L` 同源。规则 1（11 条自然反应规则的第一条）= `ptable_dist` 降序，远的先成键。
