# T32 · 自然环境的完整循环：不完全反应 → 不稳定中间体 → 半衰期自分解 → 再次反应

> 循环：
> 1. 几个稳定物质发生**不完全反应**（规则 v2）；
> 2. 反应产生**不稳定新物质**（M 不是 F 不动点）；
> 3. 不稳定物质按半衰期自分解：`M → F(v_M)`（T30 规则），变成稳定物质；
> 4. 稳定产物再次参与不完全反应……
> 脚本：`t32_cycles.py`、`t32e_sim.py`、`t32g_prep.py`、`t32h_render.py`
> 图：`images/t32_full_cycle.png`、`images/t32_cycle_rules.png`

## 1. 四个真实示例（均为几何合法结构）

### 示例 A：三段链（自分解产物继续反应）
```
OX2C + KA2F + PL2F
  → OX2C + KA2F 反应 → OX2CKA2F（不稳定）
  → 自分解：OX2CKA2F → OK + CF + XA + XA
  → 再次反应：PL2F + CF + XA → CPF2 + L2 + XA
  → 稳定终态：OK、XA、CPF2、L2、XA
```
（PL2F 全程是旁观者；CF、XA 是自分解碎片，随后作为反应物）

### 示例 B：两段链（中间体衰变后收束）
```
OWF + CWK
  → 反应：OWF + CWK → OW2K（不稳定）+ CF
  → 自分解：OW2K → OK + W2
  → 稳定终态：CF、OK、W2
```

### 示例 C：碎片再组合（自分解产物成对反应）
```
LKF2 + CPLF
  → 反应：LKF2 + CPLF → CPL2KF（不稳定）+ F2
  → 自分解：CPL2KF → L2 + PK + CF
  → 再次反应：F2 + L2 → LF + LF
  → 稳定终态：PK、CF、LF、LF
```

### 示例 D：碎片再生 + 旁观者催化
```
OCPK + CA2F + WLF + X2CF
  → 反应：CA2F + X2CF → XCAF + XCAF（不稳定）
  → 自分解：XCAF → CF + XA
  → 再次反应：CF + XCAF → CF + XA + CF
  → 稳定终态：OCPK、WLF、XA、XA、CF、CF
```
（CF 被再生；OCPK、WLF 全程未参与，是"旁观者/催化剂"）

## 2. 随机模拟的统计（600 次，p_react=0.30，q_decay=0.30，最多 80 步）

| 结果 | 数量 |
|---|---:|
| 完全不反应（已稳定/键类不满足） | 571 |
| 发生 1 轮反应 | 26 |
| 发生 2 轮反应 | 3 |
| ≥3 轮反应 | 0 |
| 严格闭环（回到初态） | 0（样本中） |

- 链通常 **1~2 轮后进入稳定固定点**；
- 自分解产物高频小分子：**OP(6)、PK(5)、XA(4)、OK/CF/CL（各 2）**；
- 稳定终态高频：XA、OP、PK、CF、CL、L2、OK、LF、C2；
- 严格闭环 A+B→…→A+B 在 2 万+ 对/6 千对搜索中未发现（需要精确再生，极稀有）。

## 3. 更具体的规律

1. **链启动门槛**：大多数体系完全不反应（571/600）；需要"至少两个分子共享当前全局最不稳定类"才可能启动。
2. **链很短**：1~2 轮反应后即收敛稳定；没有出现 3 轮以上（随机参数下）。
3. **尺寸振荡**：不稳定中间体通常是"合并后的大分子"；自分解把它爆成多个小碎片；小碎片再组合成中等分子（如 A：8 原子中间体 → 4 个 2 原子碎片 → 3~4 原子产物）。
4. **碎片货币**：OP、PK、XA、OK、CF、CL、L2、F2、C2 等小分子反复出现在各轮中；CF、CL、LF 可被再生（示例 D 中 CF 失而复得）。
5. **旁观者惰性 = 催化剂/溶剂**：不含当前最不稳定类的分子全程不变（PL2F、OCPK、WLF 等），可设计为催化剂、容器、见证者。
6. **半衰期是节奏旋钮**：q 大 → 中间体一闪而过、链短；q 小 → 中间体积累，可被捕获或继续参与反应，链更复杂。
7. **反应概率是"沸腾度"旋钮**：p 高 → 链式反应频繁；p 低 → 偶发、稳定态主导。
8. **路径依赖**：全局最不稳定类决定"谁先动"；加入一个含更低距离键的分子会改变整条链（可做"触发剂"机制）。
9. **闭环稀有**：严格回到初态的闭环没有在样本中找到；循环在游戏里更像"开链"（反应→自分解→再反应）最终停在稳定集合。

## 4. 更具游戏性的示例

1. **半衰期捕获**：不稳定中间体只存在有限时间；玩家须在半衰期内采集/利用它（稀有材料、限时事件）。
2. **连锁爆米花**：一次反应 → 自分解 → 第二次反应，可做连锁爆炸/连击特效与音效节奏。
3. **碎片银行**：OP/PK/XA/CF/CL/L2 等小碎片在多轮循环中重复出现，可设计"碎片合成/回收"经济。
4. **惰性催化剂**：旁观者分子不参与但稳定存在，天然适合做"催化剂/容器/溶剂"道具。
5. **反应节拍器**：调整 q（半衰期）与 p（遭遇率）做出不同"节奏"的环境；极端参数可做"死寂区/沸腾区"。
6. **隐藏闭环**：真正的 A+B→…→A+B 闭环可以作为隐藏机制（永动炼金阵/时间循环遗迹）。
7. **链式迷宫**：不同初始组合/旁观者导致不同最终稳定产物，适合做"配方探索/分支解谜"。
8. **中间体武器化**：不稳定中间体作为临时 buff/炸药（半衰期后消失），用"时间"做资源。
