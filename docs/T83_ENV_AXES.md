# T83 九元素环境：三轴（质量/物态/温度）+ 三素力 + 骨架方块切片

日期：2026-11-20 ｜ 脚本：`t83_env_axes.py`（模拟）、`t83_render.py`（渲染） ｜ 结果：`t83_env_result.json`、`t83_slices.json` ｜ 图：`images/t83_slices.png`（+5 张单图）

## §0 摘要

在 T82 的基础上同时打开**质量/物态/温度三轴**与**三素相互作用力**，把 6,998 个九元素分子投进 240×160 的**方格硬边界世界**，初始 1000°C、900 拍冷却到 73.4°C，再以「每个分子占一个单位方格」的骨架方块渲染，截取 4 个 22×16 切片 + 1 个 13×9 原地放大，外加全环境密度图与恒素场 ρ 图。

结果：三轴全部生效且可读——

- **质量轴**：三档 y 均值 = 轻 33.0 / 中 79.2 / 重 111.6 行（H=160），轻上浮到顶、重下沉到底，分层清晰；
- **物态轴**：物态档占比 气 46.0% / 液 27.5% / 固 26.5%；含固反应占全部成功反应的 58.3%（固相更"粘"、接触时间更长）；
- **温度轴**：环境温度 1000→73.4°C 单调下降，恒素场 ρ 均值 0.549、标准差仅 0.043——热源退去后恒素场趋于中性均匀，门控（gate 0.15~1.0）仍让反应在 ρ 高处略微更易发生；
- **三素力 + 重力联合**：1,034 个连通团，最大团 **1,322**（21.7% 分子），86.7% 分子在 ≥3 的团里；顶部 10 行堆积 1,346 个分子（22.0%）形成"浮膜"，底部 10 行 686 个形成"沉降层"；
- **反应**：成功 5,199 次（尝试 37,946，成功率 13.7%），终态 2,032 种分子式、734 种目录外新物质，元素严格守恒（9 元素各 7,880~7,925 原子，总量 71,100）。

## §1 模型

### 1.1 世界与投料
- 方格 **240×160 = 38,400 格**，**硬边界**（非环面），每格最多 1 个分子，分子是点粒子（图标占 1 格）。
- 投料：`t62_loads.json` batchA（14,752 分子、120 种、9 元素等量、三/二/一价等量）按 `scale=0.47451` 放大到 target=7000 → 实际 **6,998** 分子，9 元素各约 7,900 原子。

### 1.2 三轴（每分子读目录骨架 → `attrs.molecule_attrs` → `property_of`）

| 轴 | 权重 | 档（低/中/高） | 行为 |
|---|---|---|---|
| 质量 | O 3 / K 2 / P 1，按层平均 | 轻/中/重 | `GRAV = -0.55 / 0.0 / +0.60`（行号增大=向下）加入竖直合力 |
| 物态 | X 3 / W 2 / A 1 | 气/液/固 | `STATE_MOB = 1.0 / 0.60 / 0.25` 乘迁移概率；气可被推挤交换（50%），固不可入 |
| 温度 | F 3 / L 2 / C 1 | 冷/温/热 | 恒素场 ρ 的局部源/汇 + 反应门控 |

### 1.3 三素力（T81 公式，见 `docs/THREE_SU_AXES.md`）
- 聚素 P=3O+2X+C、散素 Q=3K+2A+F、动素 S=3P+2W+L；A=P/n_att、B=Q/n_rng、D=S/n_rep（缺族=0）。
- r_att = 1+[Q≥10]+[Q≥20]，r_rep = 1+[Q≥15]+[Q≥30]。
- `Att = 2.5·√(A_iA_j)/3·J_att·F(d,r_att)`、`Rep = 0.5·√(D_iD_j)/3·J_rep·F(d,r_rep)`，J=元素组成 Jaccard，F 线性衰减；w=Att−Rep。
- w≥1 **粘附锁**（只锁相对位置、不生成化学键、不改分子式）；w≥0.2 弱接触；|w|<0.2 无作用；w≤−0.2 排斥。
- 本实验把三素力的合力向量 + 重力向量合成，决定每拍移动方向（8 邻域、1 格/拍），概率 `p = STATE_MOB[物态]·min(1, 0.25+0.75·|F|)`，另有 4% 布朗。

### 1.4 反应（规则 1~11，`natural_engine.complete_products`）
- 相邻 4 向、每对按 `p = p_react(0.01) · MODE_MULT[物态对] · gate` 触发；
- `MODE_MULT`：气-气 0.18、气-液 0.45、液-液 0.60、气-固 0.80、液-固 0.90、固-固 1.00；
- gate = 0.15 + 0.85·ρ；产物原子数 > cap=26 跳过；1 产物合并、2 产物各占一格、更多或无产物记失败；
- 温度轴不参与反应判定（按 MATERIAL_AXES 口径，温度只决定恒素在哪富集；此处用它驱动 ρ 场与门控）。
- 环境温度 `Tamb(t) = 25 + 975·exp(−3t/(ticks−1))`：1000°C → 73.4°C（900 拍）。
- 恒素场 ρ：10×20 网格；每拍邻域均值回归 0.15 + 向局部目标 0.35；局部目标 = 0.5 + 0.30·(热−冷)/n + 0.20·(Tamb−25)/975。

### 1.5 渲染
每个分子用目录 `place`（六边形轴向坐标）重绘骨架，**整体缩放到恰好 1 个方格内**；原子=方块（9 元素配色），键型 S 实线 / C 虚线 / L 点线；目录外产物画灰块（180 种）。格子叠在环境上，位置=分子真实占用的格子。

## §5 分析

1. **三轴同时生效、且空间可分辨**。质量轴给出 33/79/112 的强分层；物态轴改变迁移率与反应模式（含固 58.3%）；温度轴给出 1000→73°C 的单调降温与一个弱但可测的 ρ 场。三轴不是叠加成"均匀混合"，而是把环境切成"顶部浮膜 / 中间混合 / 底部沉降"三层。
2. **重力 + 三素粘附产生"边界堆积"**。顶部 10 行 22.0%、底部 10 行 11.2%，中间 140 行只占 66.8%；T82（无重力）时垂向是均匀的（行方差≈泊松）。这说明 T78 的"重力 → 分层"在方格 + 三素力的世界里同样成立，但**边界是硬墙**，堆积被放大。
3. **巨团是"沉降 + 粘附"的联合产物**：最大团 1,322（21.7%）、86.7% 在 ≥3 团；T82 无重力时最大团只有 43。重力把分子压到底/顶，粘附锁再把它们连成贯通网络——这是"宏观结构由三轴决定、接触层自组装由三素决定"的直接证据。
4. **反应地理跟随三轴结构**：顶部 2,394 次（浮膜内高接触）、底部 1,483（沉降层）、中部 1,322；含固反应占 58.3%，因为固相分子迁移率低、接触时间长。
5. **组成被"低温 + 门控"筛成小分子集合**：2,032 种终态、top 15 多为 3~8 原子（LKF2、L2A2、CKF2…），说明 900 拍冷却过程中大分子被拆/重组、最终落在低能量的小分子；734 种目录外新物质则是规则 1~11 的合法产物。
6. **与 T78 对照**：T78 用连续空间 + 恒素门控（无三素力、无物态碰撞、无硬边界）得到顶层反应集中 70.6%、双原子主导；T83 用方格 + 三轴 + 三素力得到"浮膜/沉降/巨团"结构。共同点是**分层与恒素富集的方向一致**，差异是 T83 的粘附力把分层放大成贯通团簇。

## §6 诚实局限

1. 分子是**点粒子**，图标按目录骨架绘制；图标统一缩放到 1 格，**大小不反映真实尺寸**。
2. 反应是**固定概率 p_react × 物态 × gate** 触发，未用 w 做门控（T81 的粘附强度只用于运动与锁）。
3. **只有合并、没有断键分解**（complete_products 口径），大分子一旦生成就稳定到 cap=26 为止。
4. 单 seed（20261120）；多 seed 只做了 T82 级别的稳定性观察，未在本参数集重复。
5. 硬边界造成顶部/底部堆积被放大（有限尺寸效应）；环面版本会不同。
6. ρ 场网格粗（10×20 = 24×16 格/格），温度轴只能给"弱场"。
7. 734 种产物不在 84,225 目录内 → 画灰块；它们的骨架未知。
8. 900 拍只冷却到 73.4°C（未到 25°C），降温过程仍在进行，终态不是平衡态。
