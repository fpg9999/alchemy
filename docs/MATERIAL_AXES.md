# 物质三轴：质量 / 物态 / 温度

> 定稿：2026-11-19　实现：`alchemy/attrs.py`　测试：`tests/test_attrs.py`（全套 123 项通过）
> 本文是物质分类的**权威定义**，取代此前的密度/粘性/温度、熵/物态等方案。

---

## 0. 一句话

**三个价数层各贡献一个轴，每个轴对应一套独立的游戏系统，每个轴切三档，构成 27 类物质。**

| 轴 | 价数层 | 属性 | 三档 | **决定的游戏系统** |
|---|---|---|---|---|
| **概念族** | 3 价 秩O / 沌K / 势P | **质量** | 轻 / 中 / 重 | **重力行为** |
| **物质族** | 2 价 晶X / 流W / 气A | **物态** | 固 / 液 / 气 | **碰撞判定** |
| **能量族** | 1 价 焰F / 电L / 冰C | **温度** | 冷 / 温 / 热 | **恒素富集** |

## 1. 取值与阈值

```
质量 = Σ(3价元素数 × 权重) / 3价原子数      权重 O3 / K2 / P1
物态 = Σ(2价元素数 × 权重) / 2价原子数      权重 X3 / W2 / A1
温度 = Σ(1价元素数 × 权重) / 1价原子数      权重 F3 / L2 / C1
```

取值范围 **[0, 3]**，是**强度量**（与分子大小无关）。

| 轴 | 阈值 (低/中, 中/高) | 低 / 中 / 高 占比 |
|---|---|---|
| 质量 | (1.67, 2.30) | 35.5% / 34.0% / 30.5% |
| 物态 | (1.70, 2.22) | 33.2% / 35.8% / 31.0% |
| 温度 | (1.50, 2.00) | 33.1% / 34.5% / 32.4% |

**缺失层不需要特判**：该层不存在时分子为 0，**0 必然落在最低档**——
质量=轻、物态=气、温度=冷。这正好符合语义：
没有骨架就最轻、没有桥就没有内聚所以是气、没有能量元素就是绝对零度。

## 3. 温度与恒素的关系

温度**不参与"是否反应"的判定**（那只由恒素浓度 ρ_E 决定），
而是决定**恒素在哪里富集**：

> **热物质富集恒素** → 局部 ρ_E 升高 → 周围反应活跃
> **冷物质稀薄恒素** → 局部 ρ_E 降低 → 周围反应冻结

这符合"恒素总量守恒、只有区域浓度变化"的设定：**热物质是恒素的浓缩器，冷物质是稀释器。**

## 4. 浮力：上升/下沉永远是相对的

```
物体重量 W = 质量 × 体积
介质浮力 B = 介质质量 × 体积
净力    F = B − W = (介质质量 − 物体质量) × 体积

F > 0 → 上升    F = 0 → 悬浮    F < 0 → 下沉
可托起的重量 ≤ F
```

**关键**：同一个轻固体，在重气体里上浮成浮空岛，在轻气体里照样落地。
这比"轻物必升"更有意思——**同一物体在不同环境行为相反**。

实现：`alchemy.attrs.buoyancy(object_mass, medium_mass, volume)`。

## 6. 实测（全目录抽样 6000）

- 27 格覆盖 **27 / 27**，每格 **2.7% ~ 4.5%**（162~273 个成员）
- 三对相关：r(质量,物态) = +0.034、r(质量,温度) = −0.002、r(物态,温度) = +0.016
- 每个质量区间内，固/液/气大致各占 1/3 → **同质量不同物态会互相穿插**

## 7. 被否掉的方案（历史）

| 方案 | 为什么被否 |
|---|---|
| **硬度** | 只对固体有意义，"硬度 × 液体"那栏只能生搬硬套 |
| **密度 + 粘性** | 两者都是"凝聚程度"的投影（r(粘性,物态) = −0.77），重复计同一件事 |
| **熵 / 物态 / 温度** | 只是把密度/粘性归一化，物理内核没变 |
| **活性** | 与恒素机制冲突：反应只由 ρ_E 判定 |
| **导电性** | 与 电L 的权能冲突 |
| **能力 512 离散状态** | 并列时裁断会丢信息；已改为两项数值（聚/散/动） |

**判据**：一条轴必须 (a) 对应一套独立游戏系统，(b) 在三种物态下都有明确交互差异。
