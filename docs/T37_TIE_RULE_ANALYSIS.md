# T37 · 大锅反应并列歧义与「中间态骨架内优先」规则检查

> **T39 更正（2026-11-15）**：本文的"不同骨架数"用了有 bug 的 `wl_key`（非同构不变量，
> 对称原子未规范破序），数字会虚增；用 `pot_all.mol_label` 复核后
> O5X3KA 4→2、O5X3PA 4→2，其余示例不变。T37/T38 的"并列导致 6 级块出库"实例
> 也已被 T39 证伪（真实反例是另一族 `O3P5K2`）。详见 `docs/T39_SKELETON_LIBRARY_VERIFY.md`。

> 背景：大锅贪心规则 1~9 在少数步骤会出现**完全并列的关键字**；不同的并列选择可能得到相同产物分子式、但**骨架结构不同**。
> 用户新增规则：并列时**优先结合「一开始形成的中间态骨架」内的原子**。
> 脚本：`t37_tie_analysis.py`、`t37b_branch.py`、`t37c_ambiguity.py`、`t37e_scan.py`、`t37f_stats.py`
> 数据：`t37_scan.json`

## 1. 10 原子示例确实存在歧义

以 `O5X3KA` 为例（T36 案例）：
- 大锅反应（其自身元素向量）产物仍是 `O5X3KA`，但并列选择会产生 **4 种不同的骨架结构**（分子式相同）；
- 默认按候选顺序取第一个，只是人为选定其中一种，不是规则上唯一确定。

### 歧义出现在哪里

`O5X3KA` 共 9 次并列。第一次并列在**最开始的第 6 级成键**：

```
K（1 个） 与 5 个等价的 O 原子 并列
key = (-6, -6, ..., cross=1, ...)
```

此时**还没有任何中间态骨架块**（第 6 级刚开始形成），所以新规则"优先同一中间态骨架内的原子"无从判断；这次并列直接决定了后续骨架的雏形。

- 第 6 级结束后才形成中间态骨架块；
- 之后确实有"块内优先"的并列（如最后的 O–O 0 级键），新规则能选中块内一对；
- 规则加入后：`O5X3KA` 的 4 种骨架结果降到 **2 种**，但**没有完全消除歧义**。

## 2. 新规则的实际作用范围（400 个物质抽样）

| 统计 | 数量 |
|---|---:|
| 有并列的分子 | 397 / 400 |
| 并列事件总数 | 2,482 |
| **中间态骨架形成之前**的并列 | **865（34.9%）** |
| 骨架之后、但没有"同块内"候选 | 1,552（62.5%） |
| 骨架之后、且有同块内候选（新规则可生效） | **65（2.6%）** |
| 骨架层面存在多解（分子式相同） | 236 / 400 |
| 加入新规则后仍存在多解 | **234 / 400** |

结论：
- 新规则只能作用于 **2.6%** 的并列事件；
- 大量并列发生在**骨架形成之前**（无块可判断）或**块间/非三价原子**（没有同块候选）；
- 因此加入该规则后，绝大多数骨架歧义仍然存在。

## 3. 残留歧义的来源分类

1. **骨架形成前的并列**：最早的第 6 级成键，原子之间完全等价（如多个 O 连同一个 K），没有"已有中间态骨架"可供优先；选择不同 → 后续骨架不同。
2. **骨架之后但没有同块候选**：并列双方分属不同骨架块，或涉及二价/一价原子；新规则无法比较。
3. **同块内仍并列**：即使同属一个块，块内多个原子等价（对称），需要更细的规则。

## 5. 如何才能真正消除歧义（建议的并列优先级）

建议把并列裁决明确成一条**完整的优先级链**：

1. **同中间态骨架块内优先**（用户新规则）：若块已形成，且并列双方中有同块的三价原子对，优先选它；
2. **否则按规范顺序**：例如按原子编号、元素序（O<X<C<P<W<L<K<A<F）、或坐标/距离排序，取第一个；
3. **可选：几何优先**：若反应物有实际摆放坐标，优先选择两原子在原料中距离更近/方向更自然的一对（这等于用原始几何破缺对称性）；
4. **可选：最小骨架/最对称**：枚举并列分支，选最终骨架规范序最小的一个（确定但计算量大）。

只加第 1 条不够；必须补充第 2 条（或几何规则）才能让结果**规则上唯一**。

## 6. 另一种可能的解释：把"一开始的中间态骨架"理解为"原料自身的骨架"

如果反应对象是**单个已有物质**（如 O5X3KA 自身投锅），
把"一开始形成的中间态骨架"解释为**该物质原本的三价骨架块**（O3K + O–O），
那么在最早的 K–O 并列中，可以优先选择与 K 同属 O3K 块的 O 原子，从而减少歧义。

但这仍有问题：
- 大锅反应通常只接收元素计数向量，不保留原料结构（除非特殊规定）；
- 即使保留，同块内多个等价原子仍会并列，需要 fallback；
- 对"元素混合物"投料，没有原料骨架可用。

## 7. 结论

- **10 原子示例确实存在骨架歧义**：4 种骨架、同分子式；
- 新规则「优先中间态骨架内原子」只能减少部分（4→2），**不能完全消除**；
- 400 个物质抽样中：397 有并列，236 有骨架歧义，加规则后仍有 234 个；
- 主要原因是**骨架形成前的并列**（865/2482）和**无同块候选的并列**（1552/2482）；
- 若要让大锅反应成为**定义良好的函数**，必须再补一条 fallback（规范顺序/几何/最小骨架）；
- 当前实现实际上已经在用"候选顺序取第一个"作为 fallback，只是没有写成显式规则；建议把这条显式化并向玩家说明。
