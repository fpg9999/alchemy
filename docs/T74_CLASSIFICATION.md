## 1. 固 / 液 / 气

看 **晶X / 流W / 气A** 的数量，最多者决定；并列时优先 **X > W > A**；三者相等取**固态**；三者都为 0 记作"晶态"。

## 2. 刚性 / 粘性 / 松散

看 **秩O / 势P / 沌K** 的数量，最多者决定；并列时优先 **O > P > K**（与固液气同一套优先级思路）；三者相等取**刚性**。

## 3. 高温 / 低温 / 导电

看**一价元素** 冰C / 电L / 焰F 的数量，最多者决定；并列时优先 **C > L > F**；三者都为 0 记作"常温"。

实现：`t74_rules.py` 的 `physical_state()` / `hardness()` / `thermal()`（`_pick()` 按优先级取最大）。

## 4. 有机 / 无机：按能力与结构判断（不看有没有端帽）

沿用 T71 的**结构门控生命度**（只有真的长出对应器官结构的能力才计分）：

| 生命度 | 判定 |
| --- | --- |
| ≥ 5.0 | 有机物（有机生命 / 拟生命） |
| 3.0 ~ 5.0 | **活性无机物** |
| < 3.0 | **无机晶体** |

`t74_rules.classify(mol)` 一次给出：状态、硬度、热电、类别、生命分、各元素计数。
