# T78 九元素三轴介质箱：质量→重力、物态→碰撞、温度→恒素富集

**一句话结论**：在 4×2 km² 的竖直「中·气·温」介质箱里投入 1,793 个等量价数的九元素分子跑 240 分钟，
新三轴（`docs/MATERIAL_AXES.md`）**全部可运行且方向正确**：轻分子浮到顶、重分子沉到底（轻/中/重 y 均值
3936.5 / 2330.6 / 91.4）；温度轴把恒素富集到热分子所在处（局部 ρ 与局部平均温度 r=0.957）；
恒素门控把 13,329 次成功反应中的 70.6% 压到顶部富集带，并产出 810 个目录外新物质——
但 **T78 不收敛**（无退火、温度固定反应温度 1000、持续可反应），与 T62 的「LF+OXCPWKA 双组分不动点」形成对照。

## 1. 设计：把三轴落到一个 2D 环境里

三轴（`alchemy/attrs.py`，按价数层平均）→ 三条物理规则：

| 轴 | 元素层 | 档 | 环境规则（本实验实现） |
|---|---|---|---|
| 质量 | 三价 O3/K2/P1 | 轻/中/重 | 竖直重力：向终端速度 `v_target=GRAV·(MED_MASS−mass)/MED_MASS` 松弛；`GRAV=80`、`K_RELAX=0.25`、`DAMP_X=0.5` |
| 物态 | 二价 X3/W2/A1 | 气/液/固 | 碰撞模式倍率 `MODE_MULT`：气-气 0.18（穿过）、气-液/液-气 0.45（游泳）、液-液 0.60（黏附）、气-固/固-气 0.80（阻挡）、液-固/固-液 0.90、固-固 1.00；同时决定布朗扰动 `SIGMA`=10/5/1.5（气最易动、固几乎不动） |
| 温度 | 一价 F3/L2/C1 | 冷/温/热 | 恒素场：每分子按热强度 `(t−1.75)/1.25`、冷强度 `(1.75−t)/1.75` 给所在 200×200 元胞注入/抽取；ρ 向邻域扩散、向 0.5 回归，截断 [0,1] |

**反应只由恒素浓度决定，温度轴不参与反应判定**（新口径）。因此反应温度固定 `T_REACT=1000`，
门控概率 `p = 物态倍率 × ρ^1.0`；通过门控且原子数和 ≤ `CAP=20` 才真正 `E.resolve([mi,mj], 1000)`。
`complete`/`incomplete` 且分子式标签排序改变 → 产物替换（中点 ±N(0,3) 抖动，速度取原子数加权平均 ×U(0.8,1.2)、随机方向）。

- 世界：W=2000 × H=4000（竖直，y=0 底），四面反射；介质固定 **中·气·温**（mass 2.0 / state 1.0 / temp 1.75），ρ 初值 0.5。
- 碰撞采样：8×16 网格（250×250 元胞），每元胞每分钟 λ=`K_RATE·Nc(Nc−1)/2/A·DT`（`K_RATE=1600`，DSMC 近似）。
- 投料：`t62_loads.json` batchA 的 120 个分子式按 0.122 缩放到 `target_mol=1800` → **1,793 分子 / 18,222 原子**；
  9 元素各 2,013~2,033 个原子（元素等量），三/二/一价原子各 1/3；初始覆盖 **26/27** 个 27 格。

### 3.3 物态轴 → 碰撞模式

`mode_counts` 与反应率：气-气对（穿过，倍率 0.18）贡献了绝大多数接触尝试（>90%），液-液（黏附 0.60）

### 3.4 温度轴 → 恒素场（关键验证）

- 终态 ρ：main 0.280±0.167（p10 0.074 / p90 0.526），nogate 0.242±0.170，**nochem 0.649±0.113（p10 0.503 / p90 0.785）**。
- 快照检验（200 格：格内粒子平均温度 vs 格 ρ）：t=239 时 **r=0.957(main) / 0.955(nogate) / 0.976(nochem)**；
  t=0 时无方差（ρ 均匀 0.5）→ **热处富集、冷处稀释的方向强成立**。
  但注意：ρ 的定义本身就是逐格朝「温度目标」松弛，r 有同义反复成分，属一致性检验而非独立验证；
  更强的独立证据是 **热格 ρ / 冷格 ρ = 0.562/0.174（main）、0.620/0.149（nogate）、0.738/0.432（nochem）**，
  以及 nochem 粒子级热/冷贡献全程恒为 0.283/0.117、而格均目标值从 0.582 升到 0.649——说明浮力把热分子
  送进稀疏格，空间富集由「温度+浮力」耦合产生，而不是温度组成变化。详见 `docs/T78_ANALYSIS.md` §1.3。
- 化学臂 ρ 反而下降（0.28/0.24）：热分子被消耗成冷产物（F/L 被并入小分子、热源减少），恒素平均浓度随之稀释；
  纯物理臂热分子留在顶部持续加热 → ρ 升到 0.649。热→富集 → 富集→更多反应 → 消耗热源，是一个**负反馈**。
- main vs nogate 的 ρ 差（0.28 vs 0.24）：两臂从 t=0 第一分钟即分岔（main 39 vs nogate 79 次 complete），
  比较的是**不同轨迹状态**，不宜作单因素因果归因（`docs/T78_ANALYSIS.md` §7 局限 1）。

### 3.5 恒素门控：把反应压到富集带

- main 反应 13,329 次，其中**顶带 9,415（70.6%）**、中带 2,036、底带 1,878；`reaction_y_hist` 40 桶的顶桶 7,731 次
  （反应极度集中在 y≈3900–4000）。nogate 顶带比例 57%（8,699/15,250），底/中带反应明显更多 → 门控把反应「关进」富集区。
- 门控的净效应（main vs nogate）：有效判定 −29.4%（2,443,020 vs 3,457,932）、成功反应 −12.6%（13,329 vs 15,249），
  但**单次判定转化率 0.546% vs 0.441%（相对 +23.7%）**、「过门控但无反应」none 占比 10.05% vs 23.76%、
  ρ≥0.4 富集区的反应占比 87.2% vs 76.5%、反应点加权 ρ 0.438 vs 0.395（臂均值 0.280/0.242）。
  即门控是「**提纯器**」而不是「反应放大器」：它砍掉近三成接触判定、把浪费的判定压下去，但总反应数因基数缩小而略降。
- 反应地理（按接触点 ρ 分桶，main）：ρ 0.4 桶 attempts 1,268,828 / reactions 4,514；ρ 0.5 桶 1,126,461 / 6,925；
  ρ 0.6 桶仅 1,271 / 185（rate 0.146，样本小、集中早期热区）；ρ≤0.3 的桶 rate 仅 0.005~0.047。
  → 反应几乎全部发生在 ρ≥0.4 的富集区，低温贫化区（ρ<0.3）几乎无化学。
- ⚠️ 诚实注：ρ 0.6 桶的高 rate（14.6%）**不能读作门控响应曲线**——它是「样本量 0.05% + 只存在于 t<60 早期热区
  + 模式混杂（0.4/0.5 桶 97.9% 的判定是 mult=0.18 的『穿过』，0.6+ 桶里阻挡/黏附占多数）」三重原因共同造成的假象；
  且脚本未记 per-mode attempts，无法分离。门控证据应引用上面的「转化率 / none 占比 / ρ 加权 / 集中度」四项。
  详见 `docs/T78_ANALYSIS.md` §2.2。

### 3.7 与 T62 的对照

T62（九元素两阶段、等量价数、1000°C 退火到 25°C）收敛到 **LF + OXCPWKA ≈ 1:1 等摩尔双组分**（A 88.5%/B 94.0% 分子）。
T78 同样等量价数、同样九元素，却**不收敛**：distinct 607、新物质 810、终态被双原子小分子主导。
最有效的一条对照（`docs/T78_ANALYSIS.md` §6）：**T78 的终态正是 T62 在 1000°C 的「高温爆裂相」**
（T62 t=0 组成 OK 1498 / PK 1418 / CF 1270 / L2 1239 / LF 1209；t=10 即 LF 5156 / CF 5050 / L2 3980…），
而 T62 的 LF+OXCPWKA 收敛发生在 **900°C→0°C 的降温窗口**（700°C 才双双破万）——T78 缺的正是那段退火。
机理（按重要性）：① 无退火→没有选择压，停在「爆裂/洗牌」相；② 重力分层把反应物隔开，反应靠两相间的薄界面
（中带 3.6% 粒子承担 15.3% 反应，单位粒子强度 14.24 vs 顶带 2.87）；③ 碎片化自限（78% 双原子、75% 接触是
「穿过」mult 0.18，单次判定转化 0.546% vs T62 99.40%）；④ 门控只做局部化、ρ 无消耗无反馈，反应带无法扩张；
⑤ cap=20 + 开放组合空间，末分钟仍在发现新物质。
→ **「收敛/不动点」是退火+整理+全局混合的产物，而不是九元素+等量价数本身的性质**；判决实验 = 给 T78 加 1000→0°C 退火。

## 4. 诚实局限

1. `incomplete` 基本恒 0（main 0、nogate 1）：T_REACT 固定 1000 时 `E.resolve` 几乎总给 complete；这不代表真实环境。
2. `CAP=20` 截断：产物原子数 ≤20，新物质集中在 17~20（19–20 原子占新物质 38.0%、终态 344 个 = 8.8%，
   属结构性终端——它们与任何伙伴再反应都 na>20）；大分子无法生长（69,695/134,169 次 capped）。
3. 单 seed（20261119）、单介质（中·气·温）、固定世界大小与 240 分钟；**且三臂从 t=0 第一分钟即分岔**
   （main 39 vs nogate 79 次 complete），main/nogate 比较的是不同轨迹状态，不是同态 A/B 反事实。
4. 碰撞为 DSMC 近似（同格随机配对），非真实刚体动力学；浮力/重力用速率松弛近似，未做作用力积分。
5. 恒素 ρ 只由温度轴贡献，**反应不消耗/不产生 ρ**（真实体系里应耦合），也不能读作「化学耗竭恒素」；
   这会让富集带被反复利用、高估门控的局部化效果。
6. `nochem` 臂的 `chem_off=29,782` 是「通过门控+cap 但化学关闭」的对，仅用于核对漏斗，不参与物理结论。
7. ρ 0.6 桶 rate 异常偏高（见 §3.5）未分解，属待查项；`events` 只保留前 4,000 个成功反应
   （main 覆盖 t=0…39、nogate t=0…21），模式富集结论只适用于早期样本。
8. 2D 反射壁 + 无横向混合（`DAMP_X=0.5`）：main 79.8%、nochem 上下 100 px 内合计 69.6% 的粒子挤在边界，
   分层「两相 + 空中间带」有相当部分是边界压缩 artifact，真实三维/更大世界更可能是梯度。
9. 三轴对碎片退化（见 §3.6 注）：27 格分布在碎片化体系里语义失真，属方法问题。
10. 只跑了「中·气·温」一个介质格，其余 26 个介质格的三轴方向未验证。

## 5. 下一步（按优先级，采纳 `docs/T78_ANALYSIS.md` §7）

1. **加退火对照（判决实验）**：`T_REACT` 1000→0 线性降温（240 或 1000 min），检验 T78 是否出现 LF+OXCPWKA；
   这是把「不收敛」归因到协议而非系统的判决实验。
2. **多 seed ×3–5 复算** §1/§2 的主结论（尤其门控 +23.7% 效率、界面强度 5×），排除单 seed 偶然。
3. **cap 对照 20/40/60**：T62 经验是 cap 只改边界长尾不改格局；若 810 新物质/344 终端分子随 cap 消失，
   则「新物质爆发」部分是 cap=20 的边界产物。
4. **补计数**：`e_attempt[mode][ρbin]` + 不截断 events，才能把门控/模式乘子/物种三者从桶率里分离。
5. **初始 ρ 梯度**（左 0.2→右 0.8）：检验「化学被恒素场空间定位」是否强于「被接触密度定位」。
6. **给 ρ 加消耗**（每 complete 局部 ρ×0.98）：检验富集带是否被耗尽、反应带是否迁移（恒素作为资源的最小闭环）。
7. **关重力 / 三维 / 更宽世界**：把分层效应与边界压缩 artifact 分开。
8. **改用可分离指标**：报告「缺层率」（缺 1/2/3 个价层的分子占比）后再解释 27 格，避免把轴退化当生态位分化。
