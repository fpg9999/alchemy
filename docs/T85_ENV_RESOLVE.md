# T85 九元素环境：更低质量阈值 + 10°C 恒温平台 + 完全/不完全反应

> 用户 m02870：降低质量阈值让更多物质下沉；温度降到一定值后恒温一段时间做进一步
> 完全/不完全反应，再终止；终态 ~10°C；切片渲染改为"同物质同色填满整格、相邻同物质
> 合并为大色块"。
> 运行：`python t85_env_resolve.py --W 320 --H 220 --target 7000 --ticks 1200
> --cool-ticks 650 --p-react 0.012 --out t85_env_resolve_result.json`，726 秒，
> seed=20261120。渲染：`python t85_render.py` → `images/t85_slices.png`。

## §0 摘要

- **质量阈值**：实验内覆盖为 `(1.20, 1.85)`（内核默认 `(1.67, 2.30)`，内核文件未改）。
  同一批 6,998 分子投料的三档占比：默认 **轻 36.4 / 中 35.7 / 重 27.9 %** →
  新阈值 **轻 19.3 / 中 24.4 / 重 56.3 %**，重档翻倍。
- **温度**：1000°C 指数冷却，650 拍后到达 **10°C**，之后 **恒温 10°C 保持 550 拍**
  （t=650→1200）；曲线 `T(t)=10+990·exp(−10·t/650)`（t≤650），此后恒 10.0。
- **反应**：改用 `natural_engine.resolve(pair, T)`（不再是 `complete_products`），
  同时出现 **complete / incomplete / none / self_decomp** 四类；累计 resolve：
  **complete 24,994 · incomplete 13,285 · none 11 · decomp 0**（incomplete 占 34.7%）。
- **终态**：N 6,998 → **14,436**，占用 **18,879 格（26.8%）**，**2,620 种**物质、
  目录外新物质 **896**，9 元素守恒 True；质量档 y 均值 **36.6 / 90.1 / 131.6**
  （H=220，行号越小越靠顶）；最大团 **6,416**（12,737 个分子在 ≥3 的团里）；
  ρ 0.392 ± 0.044；T=10.0°C。
- **切片**：A 顶部 **99.5% 填满的"浮膜凝胶"**（385 分子连成 1 团，平均只有 3.5 原子/分子）；
  B 平均密度 25.9%；C 稀疏 1.9%；D 大分子附近 9.7%（平均 8.7 原子、2.2 骨架）。
  同物质同色、相邻同物质不画边界 → 大色块（见 `images/t85_slices.png`）。

## §1 三处改动

### 1.1 质量阈值降低（只改实验脚本）

```
MASS_THRESH = {"mass": (1.20, 1.85),      # 默认 (1.67, 2.30)
               "state": (1.70, 2.22),     # 不动
               "temperature": (1.50, 2.00)}  # 不动
```

`ensure_type()` 里改为 `A.property_of(at, thresholds=MASS_THRESH)`；重力行为表不变
（轻 −0.55 / 中 0 / 重 +0.60，物态迁移率 气 1.0 / 液 0.60 / 固 0.25）。
内核 `alchemy/attrs.py` 未改。

### 1.2 温度：冷却 + 恒温平台

```
T(t) = 10 + 990·exp(−10·t/650)   (t ≤ 650)
T(t) = 10.0                       (650 < t ≤ 1200)
```

| t | 0 | 200 | 400 | 600 | 650 | 800 | 1000 | 1200 |
|---|---|---|---|---|---|---|---|---|
| T(°C) | 1000 | 55.6 | 12.1 | 10.1 | 10.0 | 10.0 | 10.0 | **10.0** |

冷却速率调大到 10（T84 是 4.5），是为了在 650 拍内真正落到 10°C，留 550 拍恒温平台
让不完全反应充分进行。

### 1.3 反应入口换成 resolve

`_try_react` 里构造分子 dict（atoms/edges/vec/c/formula/label），调用
`E.resolve([mi, mj], T)`：

- `complete`：`T ≥ Σc` 时把两分子的元素合并后按规则 1~11 完全重排（产物可以 1~3 个）；
- `incomplete`：`T < Σc` 后选全局最不稳键类，断 1 根再重连（产物可 2~3 个）；
- `none`：不反应；
- `self_decomp`：不稳定分子自分解（本实验里 0 次，因 T=10 < 多数分子 c）。

产物统一按"先移除两反应物、再在附近找 footprint 放置全部产物"处理；放置失败计
`n_react_fail`。

## §5 分析

1. **阈值确实生效**：同一投料下，重档从 27.9% → 56.3%，t=0 的 y 均值接近均匀
   （104.2/105.2/107.4），但 200 拍后就拉开到 77.9/95.2/110.7，终态 36.6/90.1/131.6
   ——重分子沉底、轻分子上浮，分层速度明显快于 T84（T84 终态 46.6/108.2/144.2）。
2. **但终态又"变轻"**：终态质量档 轻 56.8 / 中 16.1 / 重 27.2。原因是质量轴只由
   **O/K/P（三价元素）**决定——反应把三价元素搬进少数大分子，同时产出大量
   **不含 O/K/P 的双原子碎片（LF/L2/CF/CL/F2/XA…）**，这些分子的质量恒为 0，
   只能算"轻"。所以阈值只能改变"起始沉积倾向"，终态轻重由化学重排决定。若要让
   终态更沉，需要动质量轴定义（把更多元素算进质量）或改用连续浮力。
3. **不完全反应真的发生了**：恒温 10°C 后 incomplete 从 98 次/200 拍涨到
   10,265→13,285 次，占 resolve 的 34.7%；碎片化让 N 翻倍后又缓慢回落（15,010→14,436）。
4. **反应集中在顶部**：底 2,544 / 中 3,739 / 顶 6,531——顶部凝胶里分子挨得最密，
   反应概率 × 接触数最高，形成"顶部反应器"。
5. **粘附锁把轻碎片锁成巨团**：最大团 6,416 个分子，占全部 44%；密度图显示顶部
   一条深色带、底部一条深色带、中间稀疏。

## §6 诚实局限

1. 点粒子 + 骨架图标：footprint 占格是登记制，分子不是刚体。
2. resolve 只作用于相邻对（2 个分子），不处理三体以上接触；self_decomp 因此几乎不触发。
3. 多产物（>2）不设上限，导致 N 翻倍；这是"完全反应"在规则下的真实行为，但会放大
   碎片化，与 T83/T84 的"合并优先"不可直接比较。
4. 反应仍按固定 `p_react × 模式 × gate` 触发，未按 w 门控；cap=26 截断大分子。
5. 质量阈值只在实验内覆盖，内核默认仍是 (1.67, 2.30)。
6. 单 seed（20261120）；未做多 seed 统计。
7. 温度场仍是全局单一 T（Tamb），没有空间温度梯度；ρ 场 10×20。
