# 数值属性层：密度 / 粘性 / 温度 → 3³ = 27 格

> 更新：2026-11-18（第三轮）　实现：`alchemy/attrs.py`　测试：`tests/test_attrs.py`（113 项全通过）

---

## 0. 本轮改动

| # | 改动 | 旧 | 新 |
|---|---|---|---|
| 1 | 3 价轴决定的属性 | 硬度 | **密度** |
| 2 | 物性表达 | 数值 + 档位（无网格） | **每轴三档 → 3³ = 27 格** |

### 为什么把"硬度"换成"密度"

硬度与"固态"在概念上重合：**硬的必然是固体**，所以把硬度当成一条独立轴，
必然生出"刚性液体""刚性气体"这种不合理物质（目录里实测有 254 个"刚性液体"样本）。

密度与粘性、温度都独立：

| 例 | 密度 | 粘性 | 说明 |
|---|---|---|---|
| 水银 | 高 | 低 | 重但不粘 |
| 蜂蜜 | 中 | 高 | 不重但很粘 |
| 泡沫 | 低 | 中 | 轻但能挂住 |

而且密度对固/液/气**都适用**，不会像硬度那样让"没有三价元素的分子硬度恒为 0"
（`XA`、`F2`、`OK` 这类物质在旧方案下硬度只能是 0）。

## 1. 三轴 → 三属性

| 轴 | 价数层 | 属性 | 权重（每个原子） |
|---|---|---|---|
| **概念/骨架** | 3 价 秩O / 沌K / 势P | **密度** | O +3、K +2、P +1 |
| **物态/连接** | 2 价 晶X / 流W / 气A | **粘性** | X +3、W +2、A +1 |
| **能量/端帽** | 1 价 焰F / 电L / 冰C | **温度** | F +3、L +2、C +1 |

公式一律 `Σ 该层元素个数 × 权重`，作用于**整个分子的全部原子**。

**温度是热力学量**：0 = 绝对零度（无能量元素时可达），无负值。

### 1.1 两套坐标：径向给物性，角向给能力

周期表是以恒素为中心的三辐星，天然有两套互相垂直的坐标：

| 方向 | 周期表上是什么 | 决定什么 | 三条轴 |
|---|---|---|---|
| **径向** | 三层同心环 = 价数 | **物性** | 3价→密度 / 2价→粘性 / 1价→温度 |
| **角向** | 三条辐条 = 类别 | **能力** | 聚→聚能力 / 散→散能力 / 动→动能力 |

几何上垂直，所以两套数值不会互相污染——这也是"刚性液体"问题的根治方式：
把"硬度"换成与粘性、温度都独立的"密度"，并把物性与能力分到两个正交方向。

## 2. 阈值与 27 格

每轴按阈值切三档（低/中/高）：

| 属性 | 阈值 `(低/中, 中/高)` | 定标后占比（低/中/高） |
|---|---|---|
| 密度 | **(10, 16)** | 29.7% / 36.8% / 33.5% |
| 粘性 | **(6, 11)** | 31.2% / 32.1% / 36.6% |
| 温度 | **(3, 6)** | 29.8% / 31.6% / 38.6% |

定标样本：全目录 6,000 条随机物质（分子级），取 33% / 67% 分位数。

**三档组合 = 3×3×3 = 27 格**，编号 0~26，格式 `密-X|粘-Y|温-Z`。

### 27 格在目录里的分布（抽样 6,000）

**27 格全部有物质**（无空格）。最多的格 7.3%，最少的格 1.0%。

| 格 | 占比 |
|---|--:|
| 密-中\|粘-低\|温-高 | 7.3% |
| 密-高\|粘-低\|温-高 | 7.2% |
| 密-中\|粘-高\|温-低 | 6.0% |
| 密-低\|粘-高\|温-中 | 5.9% |
| 密-低\|粘-高\|温-低 | 5.4% |
| 密-中\|粘-高\|温-中 | 4.8% |

## 3. 实例

| 分子式 | 密度 | 粘性 | 温度 | 格 |
|---|--:|--:|--:|---|
| `OXC` | 3.0 | 3.0 | 1.0 | 密-低\|粘-低\|温-低 |
| `OXCPWKA` | 6.0 | 6.0 | 1.0 | 密-低\|粘-中\|温-低 |
| `O2X3C3K3A3` | 12.0 | 12.0 | 3.0 | 密-中\|粘-高\|温-中 |
| `OK` | 5.0 | 0.0 | 0.0 | 密-低\|粘-低\|温-低 |
| `XA` | 0.0 | 4.0 | 0.0 | 密-低\|粘-低\|温-低 |
| `F2` | 0.0 | 0.0 | 6.0 | 密-低\|粘-低\|**温-高** |

`F2` 是纯焰二聚：密度/粘性都为 0，只有温度高——这正是"密度对全部状态都适用"的体现。

---

## 4. 用法

```python
import alchemy.attrs as A

d = A.attrs_of("O2X3C3K3A3")
d["density"], d["stickiness"], d["temperature"]      # 12.0, 12.0, 3.0
d["dens_contrib"]                                    # {'O': 2, 'K': 3}

p = A.property_of(d)
p["cell"]                                            # '密-中|粘-高|温-中'
p["index"]                                           # 0~26

A.grid()                                             # 全部 27 格
```

## 5. 三层职责

| 层 | 由谁决定 | 状态 |
|---|---|---|
| **能力（数值）** | 三轴加权和 + 元素占比（`ability.scores`） | ✅ |
| **物性（27 格）** | 三数值 + 阈值分档（`attrs.property_of`） | ✅ |
| **外观** | T75 方块世界（`docs/APPEARANCE.md`） | 📄 仅记录 |

`ability.scores()` 与 `attrs.molecule_attrs()` 共用同一套权重表，不会出现两套口径。
