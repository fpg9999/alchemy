# 数值属性层：硬度 / 粘性 / 温度（第二轮修订）

> 更新：2026-11-18（第二轮）　实现：`alchemy/attrs.py`　测试：`tests/test_attrs.py`（96 项全通过）
> 上位规则来源：`docs/T75_BLOCK_WORLD.md`（取消离散分类，改为数值累加）

---

## 0. 第二轮的三处改动

| # | 改动 | 旧 | 新 |
|---|---|---|---|
| 1 | 粘性权重 | X 3 / A 2 / W 1 | **X 3 / W 2 / A 1** |
| 2 | 温度权重 | C −3 / L +1 / F +5 | **F 3 / L 2 / C 1**（**纯热值，无负值**） |
| 3 | 计算范围 | 每个骨架各算各的（桥不计入） | **整个分子一起算** |

**骨架概念保留**，但它的用途从"算属性"变成**只决定物质外观**（由 `skeleton_units()` 提供分解）。
**连接两个骨架的二价桥，同时属于它所连接的两个骨架**（不再被排除）。

> 语义影响：温度改成 F3/L2/C1 后不再有"冷"——冰只是**热值最低**。
> 因此档位标签从"冷/常温/热"改为 **低/中/高**。

## 1. 三条属性

| 属性 | 由哪一层决定 | 权重（每个原子） |
|---|---|---|
| **硬度** | 三价层 秩 O / 沌 K / 势 P | **O +3、K +2、P +1** |
| **粘性** | 二价层 晶 X / 流 W / 气 A | **X +3、W +2、A +1** |
| **温度** | 一价层 焰 F / 电 L / 冰 C | **F +3、L +2、C +1** |

公式一律是 `Σ 该属性对应元素的个数 × 权重`，**作用于整个分子的全部原子**。

权重集中在 `HARD_W` / `STICK_W` / `TEMP_W` 三张表，整体调参只改这里。

## 2. 骨架（外观层）

`skeleton_units(atoms, edges)` 返回骨架分解，规则：

- **骨架 = 三价原子的连通块**；
- **跨两个骨架的二价桥，同时记入两侧骨架**（`bridge_members` 字段）；
- 其余二价/一价原子归它挂着的骨架；
- 没有三价原子的分子返回空列表（如 `F2` `XA`），但**分子级属性照样存在**。

每个骨架单元附带自己的 `hardness / stickiness / temperature`（仅作参考，
不再用于分子属性；分子属性由 `molecule_attrs()` 独立计算）。

## 3. 阈值与分档

| 属性 | 阈值 `(低/中, 中/高)` | 定标后占比（低/中/高） |
|---|---|---|
| 硬度 | **(10, 16)** | 29.7% / 36.8% / 33.5% |
| 粘性 | **(6, 11)** | 31.2% / 32.1% / 36.6% |
| 温度 | **(3, 6)** | 29.8% / 31.6% / 38.6% |

定标样本：全目录 6,000 条随机物质（**分子级**）。阈值取 33% / 67% 分位数，三档大致均分。

## 4. 物性标签

```
硬-中/粘-高/温-低
```

| 分子式 | H | V | T | 物性 |
|---|--:|--:|--:|---|
| `OXC` | 3.0 | 3.0 | 1.0 | 硬-低/粘-低/温-中 |
| `OXCPWKA` | 6.0 | 6.0 | 1.0 | 硬-中/粘-中/温-中 |
| `O2X3C3K3A3` | 12.0 | 12.0 | 3.0 | 硬-中/粘-高/温-中 |
| `O2XP2WK2A2` | 12.0 | 7.0 | 0.0 | 硬-中/粘-中/温-低 |
| `O3XP4WK3A` | 19.0 | 6.0 | 0.0 | 硬-高/粘-中/温-低 |
| `F2` | 0.0 | 0.0 | 6.0 | 硬-低/粘-低/温-高（无骨架） |
| `XA` | 0.0 | 4.0 | 0.0 | 硬-低/粘-中/温-低（无骨架） |

## 5. 用法

```python
import alchemy.attrs as A

d = A.attrs_of("O2X3C3K3A3")
d["hardness"], d["stickiness"], d["temperature"]   # 12.0, 12.0, 3.0
d["hard_contrib"]                                  # {'O': 2, 'K': 3}
A.property_of(d)["label"]                          # '硬-中/粘-高/温-中'
d["skeletons"]                                     # 骨架分解（外观层）
```
