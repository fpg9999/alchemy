# T92 群系网格：全部 3/4/5 元元素子集的环境群系扫描

> 2026-11-21 夜。规则 = T87（连续重力 + 非对称三素力 + 骨架占格 + resolve 完全/不完全 + 10°C 恒温平台）。
> 目的：把 T88 的 6 个手选群系扩展为**全部组合**的扫描，回答"哪种元素组合会产生哪种群系"。
> 工具：`t92_biome_grid.py`（跑）、`t92_plot.py`（图）、`t92_stats.py`（统计）。

## 0. 摘要

- 枚举 9 元素的全部 3/4/5 元子集：`C(9,3)+C(9,4)+C(9,5) = 84+126+126 = 336` 个群系，每个跑一次小世界（160×110、700 分子、400 拍、降温 250 拍后 10°C 恒温 150 拍），共 1793 s。
- **集中度随元素数单调下降**：平均 HHI 0.056（3 元）→ 0.027（4 元）→ 0.018（5 元）；优势种份额最高 27.3%，**336 个群系里没有一个是 A 单主（≥30%）**，B 主辅 29、D 多主 307、C 双主 0。
- **终态种数几乎完全由投料池大小决定**（`feed_pool` vs `n_distinct` 的 Pearson r = **0.970**）：池越大，终态越多样，与元素种类关系不大。
- 质量分层普遍成立（重档平均 y ≈ 105–107 / 160，轻档 ≈ 45–62），但**重档占比与元素数无关**（三组均约 22%），单个群系可在 0~86% 间变化。

## 1. 方法

- 元素集合：`O X C K A F P W L`，枚举 size=3/4/5 的全部子集（按字典序）。
- 投料：`t88_biomes.build_feed(subset, n_mol=700, natoms_max=8)` —— 从 84,225 目录取"元素集合 ⊆ subset、2~8 原子"的分子式池，用 IPF 配平到子集内**元素份额相等**。
- 世界：`t87_env_asym.AsymWorld`，W=160、H=110（硬墙），ticks=400、cool_ticks=250（1000°C → 10°C 后恒温），cap=36、p_react=0.012、force_r=2、seed=20261120。
- 分类（沿用 T67/T88 口径）：优势种份额 ≥30% → **A 单主**；≥15% → **B 主辅**；前二合计 ≥50% → **C 双主**；否则 **D 多主**。
- 记录字段：n_final、cells_used、n_distinct、n_react、complete/incomplete/none、n_new、HHI、dominant/dominant_share/top2_share、top8、y_mean_mass、tiers_mass、clusters、band_react、mode_counts、rho_mean、conservation_ok、runtime。

## 2. 按元素数分组

| 元素数 | 群系数 | 平均 HHI | 中位 HHI | 平均终态种数 | 平均反应 | 平均重档 | A/B/C/D |
|---|---|---|---|---|---|---|---|
| 3 | 84 | 0.056 | 0.048 | 42 | 106 | 22% | 0 / 20 / 0 / 64 |
| 4 | 126 | 0.027 | 0.023 | 120 | 141 | 22% | 0 / 8 / 0 / 118 |
| 5 | 126 | 0.018 | 0.017 | 246 | 172 | 22% | 0 / 1 / 0 / 125 |
| 全体 | 336 | 0.031 | — | 148 | 146 | 22% | 0 / 29 / 0 / 307 |

## 3. 关键发现

1. **元素越多越"多主"**：3 元组里还有 20 个 B 主辅（如 `B3_FOX` OXF 27.3%、`B3_LOX` OXL 26.2%、`B3_KOX` OK 26.0%），4 元只剩 8 个，5 元只有 1 个。原因是投料池迅速变大（3 元 6~44 种，4 元 34~137 种，5 元 91~344 种），产物无法在 400 拍内收敛到少数物种。
2. **池大小 ≈ 多样性上限**：`feed_pool` 与 `n_distinct` 的 r=0.970（几乎是 1:1）；与 HHI 的 r=−0.585。`n_elem` 与 `n_distinct` 的 r=0.835，但它的作用基本是通过池大小传递的。
3. **反应强度与多样性弱相关**：`n_react` vs `n_distinct` r=0.344、vs HHI r=−0.044。5 元群系平均反应 172 次 vs 3 元 106 次，但组内方差很大（5 元中 2.9s 的稀疏群系到 8s 的高反应群系并存）。
4. **不完全反应占主导**：多数长跑里 incomplete ≈ 1.5~4× complete（如 `B3_FOX` complete 403 / incomplete 1478；`B3_FKX` 432/1229）。10°C 远低于多数分子对的 Σc，接触主要走"断键重连"而非完全重排。
5. **分层与元素集无关**：重档 y 均值集中在 105~110（世界高 110，即紧贴底壁），轻档 45~62；`B3_AOW`、`B3_ACO` 等无 X 的组合重档占比可达 84~86%（因为池内只有重分子），反之含大量 X（固/液）的池轻档多。
6. **最集中与最分散**：最集中 `B3_CFL`（池仅 6 种，HHI 0.168，优势 CL 19.0%）；最分散 `B5_AKLPW`（池 258 种，HHI 0.0061，终态 287 种）。3 元组的极端（`B3_FOX` 27.3%）是 336 个里最接近"单主"的。

## 4. 与 T88 对照

| 维度 | T88（6 个手选群系） | T92（336 个全扫） |
|---|---|---|
| 规模 | 2,500 分子 × 800 拍 | 700 分子 × 400 拍 |
| 收敛程度 | B3 两组能到"主辅"甚至单主边缘（如 OXC 28.6%） | 全部 ≤27.3%，无单主 |
| 结论 | 元素少→纯化抱团，元素多→多主 | 同一趋势，但小世界/短时间只会停在"多主" |

→ T92 用于**趋势与分类**（哪种元素组合偏集中/偏分散），绝对分类以 T88 的长跑为准。想在小世界里看到单主，需要增加 ticks 或减少池（只投该池的前几名物种）。

## 5. 局限

- 单 seed；700 分子/400 拍的小世界，未达长期收敛；A 单主门槛（30%）在此规模下几乎不可达。
- 投料按元素等份额配平，未探索"不等量投入"（T86 的三价富集是另一方向）。
- 分类阈值（30/15/50%）是人为约定；`top2_share` 已记录，可换阈值重分类。
- 未按群系区分温度/重力参数（全部用 T87 默认 G=0.30、KA=2.5、KR=0.5）。
- 目录外产物（每个群系 0~400 种）占终态种数的一部分，未区分"目录内/外"多样性。

## 6. 复现

```bash
cd alchemy
python t92_biome_grid.py --sizes 3 4 5 --n-mol 700 --ticks 400 --cool-ticks 250 \
    --out t92_biome_grid.json
python t92_plot.py     # -> images/t92_biome_grid.png + t92_biome_summary.json
python t92_stats.py    # -> 控制台统计（本文件的表格来源）
```

单群系复现（任选其一）：
```bash
python t92_biome_grid.py --sizes 3 --quick      # 只跑 84 个 3 元子集
```
