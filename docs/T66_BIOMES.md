## 0 一句话结论

10 个群系与 T65 一一对应（同元素集、同原子数、同温度日程），但投料从"全双原子单质"改为"约 37.5%~60% 原子以化合物/骨架构筑、其余为单质"：**终态组成余弦相似度 10/10 对 ≈ 1.0000（最小 0.9999），头号产物 8/10 对相同**——初始化学形态被退火"抹平"；但**路径差异显著**（capped 平均少 980 次、净事件少 19.8%），说明终态由元素配比与温度路径决定，而到达终态的碰撞/合并轨迹依赖于初始形态。

## 1 任务与设计

### 1.1 用户要求

原文（m01888）："不一定要投单质，其他的物质也可以。再来十组"。

含义：沿用 T64/T65 的"生态群系"框架（特定空间、特定元素集合、1000°C→恒温退火+恒温浮动），但底物不再局限于双原子单质，可以是"其他物质"（化合物/骨架分子）。本轮设计目标由此确定为：

1. 验证 **初始化学形态（单质 vs 化合物）是否改变生态群系终态**；
2. 若终态相同，量化"路径记忆"（事件数、capped、瞬时新物质、运行时间）；
3. 给出 ≥10 个群系并挑选特色群系详细分析（沿用 T64/T65 口径）。

### 1.2 设计原则

* **成对对照**：E01~E10 与 T65 C01~C10 的元素集、每元素原子数、L、温度日程、cap、蓄水池、种子基值全部一一对应，**唯一变量是初始化学形态**；
* **化合物 + 单质混合**：每个群系投入 1~5 种目录内稳定化合物（天然盐/端帽/多元素骨架），其余原子以双原子单质补足——既满足"投其他物质"，又使初始体系偏离大锅平衡（游离单质会与盐反应），避免"种子即终态、体系静止"的平凡结果；
* **精确配平**：每元素原子数 == T65 对应值（3500/3500/3500/3500/3000/3000/2500/2400/2100/2000），由 `t66_biomes.py` 在生成 design 时用 `build_templates` 逐元素自检，配平不成立直接报错；
* **化合物可用性校验**：`build_templates` 先查 `substances.json`，否则用 `complete_products(parse_formula(...))` 按同 formula 选取；本轮逐条验证过 73 个投料分子式。教训：`PL`、`X2K` 无法生成（P–L 不是大锅稳定产物，P 仍余 2 价），已剔除；
* 种子 = 20261129 + 序号；E01 另跑 500 分钟无化学对照；本轮不做六边形严格摆放。

## 2 方法

### 2.1 引擎与投料

* 模拟引擎同 T57/T63/T64/T65：`t55_kinetic_env`（2D DSMC 粒子环境）+ `natural_engine`（规则 1~11 大锅反应/自分解）+ `fast_pot` 加速；
* 本轮沿用 `temp_schedule` 自定义温度日程（T64 起引入，向后兼容），恒温段浮动实现"现实世界温度波动"；
* 判定：每次碰撞调用 `E.resolve`，分 complete / incomplete / none，合并后原子数 > cap 记 capped（弹性截断，不进入三类判定）；
* 化合物投料模板：`build_templates` 按 formula 建分子并记录元素原子；design 阶段逐群系校验"逐元素原子数 == atoms_per_element"，不通过即抛错（本轮 10/10 通过，见 t66_verify 设计合规 9 项）。

### 2.2 分析口径

* 终态种数取 `len(final_composition)`；`distinct_formulas` 是历史累计键（见 caveat）；
* 组成余弦：终态各分子式分子数占比向量的余弦（1=完全一致）；
* 特色评分：8 维 z-score（有效物种数/头号占比/平均原子/最大原子/三价利用率/单质转化率/恒温活性/新物质数）正向平方和，主导维去重取前 3；
* 与 T65 对照：逐群系 E0x vs C0x 的组成余弦、top1 是否相同、capped/事件/新物质差值。

### 2.3 独立验证

`t66_verify.py` 独立实现（自写分子式解析、价数表、结构合法性、温度逐分钟复算），11 组 89 项 PASS，详见 §9。

## 4 逐群系结果

### 4.1 E01 双盐平原（O P X W）

* 投料：OP×1750 + XW×1750 + 游离 O2/P2/X2/W2 各 875（化合物占比 50.0%）；
* 终态 top5：OP 3359（49.8%）、XW 3349（49.7%）、O6X4P4W6 6、O6X3P4W6 4、XW2 3；
* 结构：OP = O≡P 三键；XW = X=W 双键；O6X4P4W6 为多环巨型（19 原子）；
* 与 T65 C01 对照：余弦 1.0000、top1 相同；capped 2,250 vs 4,247（少 1,997），净事件 12,471 vs 15,360；
* 特色：**出现了 40 原子巨型 O10X11P16W3（1 个）与 39 原子 O5X15P11W8（1 个）**——capped 边界产物，T65 C01 最大 39 但 giant 数量不同；≥19 原子巨型 26 个/569 原子。

### 4.2 E02 双盐配位谷（O K C L）

* 投料：OK×1750 + CL×1750 + 游离 O2/K2/C2/L2 各 875；
* 终态：OK 3455（49.7%）、CL 3441（49.5%）、C2 16、L2 16、O3L3K2 9；种数 6、max 8；
* 结构：OK = O≡K 三键；CL = C–L 单键；
* 与 C02 对照：余弦 1.0000、top1 相同、capped 0/0；净事件 10,788 vs 13,514；
* 特色：最"干净"的群系之一（6 种、max 8），种子几乎直接就是终态，但仍发生 1.08 万次净事件（盐与游离单质的可逆交换）。

### 4.3 E03 四元盐台地（P X A L）

* 投料：XPLA×1750 + 游离 P2/X2/A2/L2 各 875；
* 终态：XPLA 3459（98.9%）、L2 17、X2P2A2 6、XP2A2 4、X3P2A 4；mean 4.00；
* 结构：XPLA = X=P 双键 + P–A 单键 + A–L 单键（P 用 3 价：双键+单键；A 用 2 价；L 用 1 价）；
* 与 C03 对照：余弦 1.0000、top1 相同、capped 0/0；净事件 10,641 vs 13,956；
* 特色：**专一性最高（top1 98.9%，z=+1.6）**——单一四元盐几乎独占，残余只有 L2 与少量杂合中间体。

### 4.4 E04 盐晶原（K A F X）

* 投料：KAF×1750 + 游离 K2/A2/F2 各 875 + X2×1750；
* 终态：XKF 3448（66.2%）、A2 1724（33.1%）、X3K2 9、XK2F4 9、A2F2 7；种数 9、max 7；
* 结构：XKF = X=K 双键 + K–F 单键；A2 = A=A 双键；
* 与 C04 对照：余弦 1.0000、top1 相同、capped 0/0；净事件 12,308 vs 13,649；
* 特色：种子 KAF + X2 在退火中重排为 XKF + A2（K 由"KAF"转移到"XKF"），说明**化合物内部键也会被重排**，但产物与单质播种一致；散素 A2 占 33% 残留。

### 4.5 E05 聚动盐林（O X C P W）

* 投料：OXC×1500 + OP×750 + XW×750 + 游离 O2/X2/C2/P2/W2（O2 375、X2 375、C2 750、P2 1125、W2 1125）；
* 终态：OP 2915（39.8%）、XW 2915（39.8%）、C2 1473（20.1%）、XC2W2 5、X2C2W 3；种数 18、max 39；
* 与 C05 对照：余弦 1.0000、top1 不同（E05 OP vs C05 XW，但两者计数几乎相等：OP 2915/XW 2915 vs C05 XW 2844/OP 2823，属"互换"）；capped 1,009 vs 7,313（少 6,304！）；
* 特色：capped 降幅最大的群系；巨型 O8X11C2P12W6（39 原子×1）；说明早期已有 OXC/OP/XW 盐时，退火前期的大合并路径被大幅削减。

### 4.6 E06 盐骨架麓（O P K X A）

* 投料：OP×1000 + OK×1000 + PK×1000 + XA×1500 + 游离 O2/P2/K2 各 500 + X2/A2 各 750（化合物占比 60.0%，本轮最高）；
* 终态：O2X2P2K2A2 1455（94.8%）、XA 21、OK 14、O2X2P2K2A 13、XA2 6；mean 9.77（最高）、max 19；
* 结构：O2X2P2K2A2 = 两个 O–P–K 三元环经 P–X–A–A–X–P 桥缝合的十原子封闭簇（O–P 单键、O=K 双键、P–K 单键、P–X、X–A、A–A）；
* 与 C06 对照：余弦 1.0000、top1 相同；capped 3 vs 12；净事件 17,812 vs 22,402；
* 特色：**平均聚合度最高（9.77 原子/分子，z=+2.5）**——即使初始是 2~4 原子盐，体系仍能"攒出"十原子簇，且专一性 94.8%；incomplete 判定 30,565 次（10.9%，最高，属正常：小盐之间多次碰撞未达完全反应阈值）。

### 4.7 E07 六元盐坡（O X C P K A）

* 投料：OXCPKA×1250 + 游离 O2/X2/C2/P2/K2/A2 各 625；

* 特色：种子 OXCPKA 就是 T65 C07 的终态主产物（94%），但初始"半化合物"仍带来 1.8 万次净事件——游离单质与盐的交换在持续进行。

### 4.8 E08 七元盐湖带（O X C P W L K）

* 投料：OXCPWK×1200 + 游离 O2/X2/C2/P2/W2/K2 各 600 + L2×1200；

### 4.9 E09 八元盐雨林（O X C P W L K A）

* 投料：OXCPWKA×1050 + 游离 7 种单质各 525 + L2×1050；

### 4.10 E10 九元盐穹顶（9 元素）

### 第 1 名：E10 九元盐穹顶（特色分 10.88，主导维度：恒温活性）

* 机制：单质播种时体系必须先"元素→盐"成键，早期大量小分子反复合并，容易冲过 40 原子边界（capped）；化合物播种把成键步骤提前到 t=0，退火早期直接进入"盐+游离单质"交换，大合并路径减少；

### 6.3 结论

1. **终态由元素配比 + 温度路径决定，初始化学形态几乎不改变终态组成**（10/10 对余弦 ≥0.9999）；
2. 初始形态改变的是**到达终态的路径**：capped/净事件/瞬态新物质/运行时间；
3. 因此"生态群系"的"物种组成"是可复现的吸引子，而"演替过程"有形态记忆——这为后续"播种成熟群落 vs 裸元素"的生态学对比提供了基线。

## 10 结论

1. **初始化学形态记忆 ≈ 0（组成层面）**：同元素集、同原子数、同温度日程下，化合物播种与单质播种的终态组成余弦 10/10 对 ≥0.9999，top1 8/10 相同，2 处不同仅为计数几乎相等的产物互换；
2. **路径记忆显著（动力学层面）**：化合物播种使 capped 平均减少 980 次、净事件减少 19.8%、瞬态新物质减少 50 种；方向是"提前成盐 → 早期大合并减少"；
3. **例外 E09**：种子本身是 7 原子大骨架（OXCPWKA）时 capped 反增（746 vs 1），说明"路径记忆"取决于种子尺寸而非"是否化合物"；
4. **生态群系框架的可复现性**：T64→T65→T66 三轮中，相同元素集/温度日程的群系终态组成稳定复现（T65 C10 与 T64 B11 余弦 1.0；T66 与 T65 余弦 1.0），"生态群系"可以视为由元素配比 + 温度日程定义的**吸引子**；
5. **工程启示**：若想让生态群系"更像自然演替"（早期经过元素态→低聚→盐），应投单质；若想直接得到"成熟群落"并节省计算，可投化合物——终态相同但路径不同、capped 差异大。

## 11 下一步建议（T67 候选）

1. **种子尺寸梯度**：同元素集、同温度日程，播种 2/3/4/7/10 原子种子 → 检验 E09 的 capped 反增是否随种子尺寸单调；
