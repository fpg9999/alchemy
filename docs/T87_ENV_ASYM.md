## §0 摘要

- **规则**：①取消质量档位，改为连续重力——每拍竖直速度累加 `G·mass`，质量越大下沉越快
  （`G=0.30`：mass=3 → 0.9 格/拍，2 → 0.6，1 → 0.3，0 不动）；②分子间力改为**非对称**、
  且不用匹配度 J——A 对 B 的力与 B 对 A 的力分开算，`F_on_B = K_A·A_A·F(d,ratt_A) − K_R·R_B·F(d,rrep_B)`，
  `F_on_A = K_A·A_B·F(d,ratt_B) − K_R·R_A·F(d,rrep_A)`（A=聚素吸引力、R=动素排斥力、r=散素覆盖半径）。
- **结果**（1400 拍，t=600 到 10°C 后恒温 800 拍）：N 7,000 → **14,290**，占用 19,822 格（28.2%）；
  1,718 种、1,703 个目录外新物质；resolve 调用：complete 31,925 / incomplete 30,995 / none 67；
  9 元素守恒；沉积层最大团 **6,046**（78.6% 分子在 ≥3 团里）。
- **分层**（质量档 y 均值，世界高 220）：轻 **101.3** / 中 **197.0** / 重 **198.7**（t=0 时三档都在 106）。
  连续重力把中等质量的也压到底部，只剩无质量/极轻分子留在上方——比 T86 的档位重力更极端。
- **团簇运动**：每 25 拍跟踪一次（56 帧），共 3,101 条 track（1,243 条持续 ≥6 帧）；
  按判据（速度≥0.06 格/拍、直线度≥0.25、n≥5）得到 **160 个 mover（约 25.7% 分子）**，
  方向分布 **上浮 51 / 横向 48 / 下沉 61**；其中**尺寸稳定（±25%）的只有 3 条**。
  小团（3~10 分子）动得最快（均值 0.06~0.08、p90 ~0.11~0.13 格/拍），大团（>100）慢且多数钉在沉积层。

## §1 规则改动

### 1.1 连续重力（取消质量阈值）

```
每拍:   gacc_i += G_GRAV * mass_i          # mass_i ∈ [0,3]，连续值（O3/K2/P1 按层平均）
        steps = int(gacc_i); gacc_i -= steps
        重复 steps 次：footprint 整体下移 1 行；被占时
          - 单格分子之间且 mass(下方) < 0.75·mass(自己) → 以 0.65 概率交换（重者下沉）
          - 其它 → blocked
```
质量 3 → 0.9 格/拍、2 → 0.6、1 → 0.3、0 → 0。这样"只要有质量就会被重力拉、质量越大越快"，
不再有轻/中/重三档的突变。

### 1.2 非对称分子间力（去掉匹配度）

```
A_i  = 聚素吸引力均值（O=3,X=2,C=1，按聚素原子平均，0~3）
R_i  = 动素排斥力均值（P=3,W=2,L=1，按动素原子平均，0~3）
ratt_i, rrep_i = 散素点数和 Q 决定的覆盖半径（1/2/3，排斥落后 1.5 倍点数）

F_on_j (由 i 施加) = K_A·A_i·F(d, ratt_i) − K_R·R_j·F(d, rrep_j)
F_on_i (由 j 施加) = K_A·A_j·F(d, ratt_j) − K_R·R_i·F(d, rrep_i)
K_A=2.5, K_R=0.5, F(d,r)=1(d=1), (r+1−d)/r(1<d≤r), 0(d>r)
```
关键点：**两项力不对称**——A 的吸引力大时会把 B 拉过来，同时 B 的排斥力又把自己往外推；
同一对分子 `F_on_i ≠ −F_on_j`，内部动量不守恒，团簇因此可能整体被"推着走"。

### 1.3 其它（沿用 T86）

骨架占格（k 个骨架占 k 格）、状态迁移率 `STATE_MOB={气1.0,液0.6,固0.25}`、粘附锁（w≥1，
距离≤2）、resolve 反应（完全/不完全/none）、2~4 分子同时反应、cap=36、恒素场 ρ 10×20、
温度 `T(t)=10+990·exp(−10·t/600)`（t≥600 恒 10°C）。

## §4 团簇运动分析（自主移动能力的搜索）

方法：每 25 拍对占格网格做 8 邻接连通分量（size≥3），记录质心/包围盒/平均质量/A/R；
帧间按质心距离≤6 格、尺寸比 0.5~2.0 贪心匹配成 track；只统计恒温阶段（t≥600）。

- **track 总数 3,101**（≥6 帧的 1,243 条）。
- **mover 判据**：帧数≥6、n≥5、平均速度≥0.06 格/拍、直线度（净位移/路径）≥0.25。
  满足者 **160 个**，覆盖约 **25.7% 分子**；方向：**上浮 51 / 横向 48 / 下沉 61**。
- **尺寸稳定（track 内 n 变化 ≤±25%）的只有 3 条**——多数"团簇"在反应并合/分裂中变形，
  因此下面的形态只能作为"该类运动的样本"，不是永久个体。
- **速度 vs 尺寸**（全部 961 条 ≥6 帧 track）：
  | 尺寸档 | 均值（格/拍） | p90 |
  |---|---|---|
  | 3-4 | 0.078 | 0.133 |
  | 5-9 | 0.063 | 0.109 |
  | 10-19 | 0.054 | 0.095 |
  | 20-49 | 0.061 | 0.095 |
  | 50+ | 0.093 | 0.136 |
- **相关性**（961 条）：速度与尺寸 r=−0.003、与平均质量 r=−0.234、与 A r=−0.134、
  与 R r=−0.164、与 (A−R) r=0.054 —— 速度主要不是由尺寸/质量决定；**质量越大越慢**（沉积）。
- **方向与尺寸**：下沉团平均 n≈23，上浮/横向团平均 n≈13（方向按垂直分量 dy 判定；dx=水平、dy=垂直，正=向下） —— 大团下沉，小团更自由地向上/横向漂。
- **代表案例**（`images/t87_mover.png` 三行）：
  1. **上升团**：14.5 个分子（LF/LF/OGPW3KF6），t=700→925，净上移 **4.1 格**，速度 0.067 格/拍，
     直线度 0.27，A=1.54、R=1.04、质量 0.52。
  2. **横向团**：14.5 个分子（LF），t=700→925，净位移 **4.1 格**（水平 dx=-4.1，几乎不上下），速度 0.081，直线度 0.34，
     A=2.12、R=1.22，质量 1.71。
  3. **下沉团**：32.7 个分子（OK），t=1025→1150，净位移 3.4 格（垂直下沉 3.0 格），速度 0.072，直线度 0.36。
- **最快样本**（尺寸不稳定，但运动明显）：117 个 OK 分子 v=0.124、直线度 0.38、净上移 5.9 格；
  128.6 个 OK 分子 v=0.102、净上移 5.2；108.8 个 X2AF2 分子 v=0.091、净左移 6.0。
- **沉积主体**：最大团 6,046 个分子（78.6% 分子）作为整体几乎不动（速度 0.059 但净位移仅 1.9 格），
  只在内部进行反应与重排。

## §6 规律与讨论

1. **连续重力 = 全域分选**。由于质量是连续值且无阈值，中等质量也开始下沉，最终只有质量≈0
   （不含 O/K/P 的分子）留在上部；分层比 T86 的档位重力更彻底（y 从 30/73/113 变为 101/197/199）。
2. **非对称力确实给团簇提供了"重力之外"的运动**：约 1/3 的 mover 向上、1/3 横向，
   这是纯重力无法产生的；且上升/横向团平均只有 ~10 个分子，说明小团更容易被净合力推着走。
3. **大团被重力锁死**。>100 个分子的团几乎都并入底部沉积层（最大团 6,046），速度虽由内部抖动贡献
   0.06 格/拍，但净位移极小；沉积层是"动态但不迁移"的。
4. **尺寸稳定的自主移动体极少**（3/1,243 持续 track）。在当前规则下，"自主移动的多分子团"
   是**瞬态现象**：合并/分裂 + 反应不断改写团簇身份，这与 T80"体是动态组装体"的结论一致。
5. **速度并不随尺寸/吸引力单调增加**（r≈0），说明在此参数下，运动更多由局部密度和
   重力/边界几何决定，而不是由 A、R 的绝对值直接决定。

## §7 诚实局限

1. 团簇跟踪靠质心匹配，团簇并合/分裂时 track 会断或串号；"3 条稳定 track"是最严格口径，
   不代表只有 3 个团在动。
2. 模拟中分子是点粒子（占格 footprint），没有内部构象；运动是"整团质心位移"，不含旋转/形变。
3. 重力用 `gacc` 线性累积（每拍最多 3 格），不是真实加速度积分；被占格时的"重压轻"交换是简化规则。
4. 非对称力无匹配度 J，意味着异种分子间也可能强吸引；这与 T81 的"同种强吸引"版本不同。
5. 单 seed（20261120），mover 统计对随机性敏感，换 seed 数量会变。
6. cap=36 会截断大团反应；反应仍用 resolve，但"团簇"本身不是反应实体。
7. 投料沿用 T86 的三价富集配方（O/X/F 54%），不是"九元素等量"配方，跨实验比较需注意。
