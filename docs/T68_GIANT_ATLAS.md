# T68 大分子骨架图册（36 个稳定大分子 / 特大分子）

> 从 T61–T64 严格六边形摆放的既有成果里，挑出 36 个**稳定**大分子（≥14 原子），
> 用 T68 形状语言画成卡片图册：每个分子标注它含有的具体骨架、骨架之间的桥、
> 以及融合 / 装饰情况。形状语言定义见 `docs/T68_GLYPH_SYSTEM.md`。

---

## 1. 选样与复核（全流程可复现）

数据来源：`t61_hex_layouts.json`、`t62_hex_layouts.json`、`t63_hex_layouts.json`、
`t64_hex_layouts.json`（均为严格六边形棋盘格摆放、`embed_mol2` 布局、经 `validate_place` 复核）。

1. `t68_build_data.py`：取 `n_atoms ≥ 14` 的分子，按 `pot_all.mol_label` 去重，得 **108 个**候选。
2. 稳定性复核：对每个候选的原子清单跑 `fast_pot.simulate_level6()`，要求
   **单产物**且产物与候选 `mol_label` 同构，即 `F(v_M) = {M}`；
   **108/108 全部通过**（已验证）。
3. 骨架复算：终态三价连通分量 = 骨架；其中三价原子 100% 落在骨架内，6 级骨架块
   **100% 落在 38 形态库内（库外块 0）**（已验证）。
4. `t68_select.py`：按实验来源、原子数、骨架数、桥数分层选 **36 个**，并用 `pot_v4.simulate()`
   逐个再复核一次 `F(v_M) = {M}`（**36/36 全 True**，已验证）。

选样分布：T61 13 个、T64 12 个、T62 8 个、T63 3 个；
原子数 40 ×14、39 ×10、22 ×1、19 ×3、16 ×3、14 ×5（共 1147 个原子）。

## 5. 关键观察

1. **稳定大分子里 0 级键（融合 / 加固）极罕见**：36 个分子共 114 个骨架，只有 G13 的
   骨架②出现 1 根同类三价 P–P 键。原因是稳定分子的价数基本已饱和（三价原子 3 键用满），
   没有剩余价再形成 0 级键——这与 T18 的结构定理（终态骨架 = 6 级块 + 0 级同类键）相容，
   只是"0 级同类键"这一项在稳定终态里几乎不出现。
2. **骨架类型高度重复**：`O2P2K` / `O2P3` / `O2K3` / `OP3K` / `OP2K` 五种形态占了 114 个骨架的
   一半以上（12+11+9+9+9 = 50）。同一个骨架形状在多个分子里反复出现，说明大分子的"模块库"
   很小，随机的组分差异主要体现在骨架的**数量、组合与桥接方式**上，而不是不断造新骨架。
3. **桥以 C 铰接与混合桥为主**（45 + 56 / 114），纯刚性的 S 焊桥只有 9 条，纯浮空 L 桥 4 条。
   真实稳定大分子更倾向"一端硬一端软"或"全铰接"的连接，纯焊接式刚性连接较少。
4. **小骨架 + 多桥 = 巨型分子**：如 G26（5 个骨架、7 条桥）、G22（5 骨架、6 桥）用 39 原子
   拼出巨型；而 G24 是唯一"1 个特大骨架 + 0 桥"的纯巨型分子（40 原子全部由装饰层挂在一个
   `O4P7K2` 骨架上）。
5. **装饰层规模可观**：36 个分子共 245 个非骨架原子（支臂 126、骨架内桥 53、一价端帽 66），
   约占总原子数的 21%；G24 单分子就有 20 个支臂原子，是"骨架小、装饰多"的极端例子。
6. **分子家族偏"秩势散"**：22/36 同时含 O、P、K 三种三价元素；无纯秩 / 纯势 / 纯散分子，
   与 T67 群系统计里"多主型产物集中在含秩势散配比"的结论方向一致（这里是抽样的 36 个大分子，
   不是全目录统计，结论标为**推断**）。

## 8. 局限

- 图册只覆盖 T61–T64 四个实验的严格六边形摆放结果（有 `place` 便于严谨作图）；
  目录里更大 / 更多的大分子（T15、T60 榜等）尚未纳入，后续可用同一管线扩展。
- "骨架 / 桥 / 装饰"的归属是几何口径（终态三价连通分量、跨骨架二价连通块），
  与化学式无关；同一分子式可能对应不同骨架组合，图册按具体分子的实际终态结构绘制。
- 全部 36 个分子都做了 `F(v_M)={M}` 复核，但没有再做"随机环境再现"实验，
  其动力学可达性以来源实验（T61–T64）为准。
