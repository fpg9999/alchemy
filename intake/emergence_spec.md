## 0. 一句话结论
生命不是某个分子或某个器官的属性，而是**九项基础能力在局部界面上的相互作用经过反馈回路放大后，
在"组装体 → 器官 → 器官系统"三个尺度上同时满足动力学条件下的涌现结果**。
本规范不设置任何"生命标志"，不计算任何一票式"生命度"：`tier` 只由 §6 的布尔判据向量与
功能回路闭合性决定，所有输入都是观测窗口内的**变化量**。

设计结果分四层：
| 层 | 单位 | 判据一句话 |
|---|---|---|
| L1 分子 | 目录记录（原子/键/摆放） | 完全饱和共价分子；只提供**位点**与**能力/物性**，不提供"身份" |
| L2 组装体 | 界面键连通分量 | 连通 + 总界面能 ≥ E_min + 内聚度 ≥ c_min + 寿命 ≥ τ_min |
| L3 器官 | 组装体内的**功能子图** | 某个功能通量 F_k 在窗口内 ≥ θ_k 且模块度 ≥ Q_min 且持续 ≥ τ_org |
| L4 生命体 | 器官系统的连通分量 | §6 五项动力学判据全部为真 + 功能回路闭合 + 至少一个可育子代 |

## 1. 设计公理（不可违反的不变量 A0–A5）
- **A0 无生命标志**：任何代码路径不得写入 `alive` / `is_life` / `life_score >= 阈值` 这类状态或门控。
  L4 判定只能是 `life_report(world, sid, window)` 对已记录观测量的**纯读取**；删除该函数后，
  世界演化必须完全不变（可测）。
- **A1 局域性**：每个分子每 tick 只与空间哈希网格 1 环内的邻居交互；器官类型由通量阈值**识别**，
  不由配方表**分配**；不存在"全局选择最优组装"的步骤。
- **A2 能力即物质操作**：九项次级能力不是标签，而是作用核（interaction kernel）。能力值来自
  `ability.scores(formula)` 的 `subs[].value`（已按价数加权），只通过位点强度 σ 与矩阵 M 进入物理。
- **A3 反馈**：组装体改变局部环境（恒素浓度 ρ_E、温度、剪切/噪声），环境反向改变界面结合/断裂速率；
  器官的功能输出调制其它器官的反应速率。没有反馈，本规范退化为"随机粘连"，见 §8.4 T2。
- **A4 守恒与界面非共价**：原子数守恒（物质交换只在自由分子池与组装体之间搬运，不销毁元素）；
  分子已完全饱和（内核"完全饱和定理"：总键级 = Σ价数/2，全目录 84,225/84,225 成立），
  **分子之间不能生成新的共价键**。L2 的结合一律是非共价界面能（等效范德华/氢键/疏水作用），
  键能上限 ~3 能量单位，远小于分子内共价键（~100），因此界面可逆、可断裂、可修复。
- **A5 窗口化**：所有生命判据用 `ΔX = X(t_end) − X(t_start)` 或窗口内通量积分定义，
  禁止用末态快照或结构静态打分。观测窗口 `T_obs = 600` tick，前 `t_warm = 300` tick 为预热不计。

> 反模式（明确禁止）：给分子/组装体打"有机度"总分；按分子式查表赋予器官类型；用中心化
> "生命场"驱动组装；任何形式的"这一步之后就是生命"的分支。

## 2. 层级定义 L1–L4
### 2.1 层级表
| 项 | L1 分子 | L2 组装体 | L3 器官 | L4 生命体 |
|---|---|---|---|---|
| 单位 | 目录记录 + 实例 | 界面键连通分量 | 组装体内的功能子图 | 器官耦合图的连通分量 |
| 边界 | 共价键图 | 界面键图 | 执行同一功能通量的边/分子子集 | 系统级边界（边界器官）+ 耦合图 |
| 可用属性 | 原子/键型/摆放/`skeleton_units`/9 能力/3 物性 | 组装体尺寸/形态/总界面能/内聚度/表面 | 功能通量 F_k/模块度 Q/持续时长/方向 | 判据向量 (B,M,R,I,H[,A])/回路闭合/子代 |
| 形成条件 | 大锅反应产物（外部给定） | 结合动力学（§4.2） | 通量阈值（§5.3） | 系统连通 + 判据全真（§6） |
| 判据 | 饱和性（内核保证） | §4.3 四条 | §5.2–5.3 | §6.2 五项 + 闭合性 |
| 时间尺度 | 静态 | 10¹~10² tick | 10²~10³ tick | 10³~10⁴ tick（含复制代际） |
### 2.2 「器官 = 组装体的功能模块」的严格含义
1. 器官**不是**更大的分子，也**不是**组装体本身。器官是组装体内满足以下条件的**子图**：
   边集 `E_k ⊆ E_asm`，其上的功能通量 `F_k`（§5.1 定义，单位是"每窗口事件数/转化率"）≥ θ_k，
   且 `Q_k = W_in / (W_in + W_out) ≥ 0.6`（模块度：内部界面能远大于跨器官界面能）。
2. 同一组装体可以同时是 1~3 个器官的载体（例如一个膜壳同时是"边界器官"与"防御器官"）；
   同一器官也可以横跨两个组装体（两组装体融合后，界面键贡献通量）。
   器官身份是**上下文相关**的：分子集合不变，环境/界面改变 → 器官类型可变、可消失。
3. 器官必须有**功能交换对象**：一个只有输出、没有输入/消费者，或只有输入、没有输出的子图，
   登记为"潜在器官"（`organ.active=False`），不进入 L4 判定。
4. 器官的判定使用**有向矩阵** `M_dir`（能力甲作用于能力乙的方向性，§3.4），
   而 L2 结合能使用对称化 `M_eff = (M + Mᵀ)/2`。两者来源同一矩阵，避免两套物理。
### 2.3 层级间因果链（为什么不是"构造"）
```
L1 位点能力 σ ──(界面能 w)──> L2 结合/断裂 ──(通量放大)──> L3 功能模块
      ↑                                                      │
      └──────── 环境反馈 (ρ_E, T, 损伤, 信号) ←── 器官输出 ←──┘
L3 器官耦合 ──(回路闭合 + 边界/能量/信息协同)──> L4 判据向量全真
```
每一层只使用下一层的**可观测量**（位点、界面键、通量），不需要也不允许调用上层的"意图"。

## 3. L1 分子与位点层
### 3.1 分子实例化
`init_world()` 从目录抽样 N 条记录，对每条执行：

1. `rec["formula"]` → `ability.scores(formula)` 取 `subs` 九项 `(element, name, value, tier)`；
2. `attrs.molecule_attrs(rec["atoms"])` → 密度/粘性/温度；
3. `attrs.skeleton_units(rec["atoms"], rec["edges"])` → 骨架块（T75 的方块单元）与 `bridge_members`；
4. `rec["place"]` → 六边形格坐标，作为分子的多格骨牌 footprint 与位点位置；缺失 `place` 的 245 条丢弃；
5. 能力值 → 三价/二价/一价元素各贡献一项能力，`σ` 计算见 §3.3。

> 全部计算**只用 formula 字符串**（目录中部分 `feed` 长度非 9，直接用 `feed` 会得到错误向量；
> 见 `intake/tmp/emergence/probe_out.txt` 的踩坑记录）。
### 3.2 位点提取（`extract_sites(rec)`）
位点是界面相互作用的载体，每个位点带 `(element, ability, sigma, bond_type, cell, kind)`：
| kind | 判定 | 数量（全目录探针） | exposure |
|---|---|---|---|
| `cap` 端帽位点 | 度为 1 的原子（一价端帽 C/L/F 为主，也可能是单连的二价原子） | 0 个 738、1 个 1295、…、中位约 5 个 | 1.00 |
| `hull` 骨架面位点 | 位于分子凸包、属于某骨架块（三价原子或其直接取代基） | 每骨架 1~3 个 | 0.55 |
| `bridge` 桥端位点 | `bridge_members` 中位于凸包上的原子（T76 的桥=功能件） | 多骨架分子常有 1~4 个 | 0.70 |
规则：每个分子最多保留 12 个位点（按 `exposure * σ` 取前 12）；每个位点最多形成 1 条界面键；
每分子界面键上限 `max_contacts = min(n_sites, 3 + natoms // 8)`。
`bond_type` = 位点原子与其母体原子之间的键型（`elements.classify_offset` → "S"/"C"/"L"），
这是 T75 方块世界里"共享边"的三类画法（S=共边、C=共顶点、L=隔格）在界面层的延续。
### 3.3 位点强度 σ
```
tier_score = {"低": 0.35, "中": 0.70, "高": 1.00}
σ_site = tier_score[tier] * exposure[kind] * affinity[element]
```
`tier` 取自 `ability.scores(formula).axes[*].by_element` 中该元素的 `value` 再套 `SUB_ABILITIES`
阈值（上界闭区间：≤t1 低、≤t2 中、否则高；0 归低）。`affinity` 默认全 1.0，留作标定参数。
例如 `O3XP4WK3A`：O=9.0（中，0.70）、X=2.0（低，0.35）、P=12.0（中，0.70）、W=2.0（低，0.35），
端帽位点 σ≈0.7~1.0，骨架面位点 σ≈0.2~0.4。
### 3.4 九项能力的联动矩阵 M（参数来源：`intake/ability_spec.md` §3）
符号顺序固定为 `[支, 刚, 粘, 分, 吸, 切, 储, 移, 信]`（= 结构支撑、刚性、粘合、分化、吸附、切割、
储能、移动、信号）。规范**不绑定具体数值**，只绑定用法：
- `M[a][b] ∈ [-1, +1]`：>0 协同/互补（促进结合与功能耦合），=0 中性，<0 拮抗（排斥或相互破坏）。
- L2 结合能使用 `M_eff = (M + Mᵀ)/2`；L3 功能耦合使用有向 `M_dir`。
- 要求 `M` 对角为正（同类能力可自聚：粘-粘、支-支、信-信），并至少含以下互补对：
  支-吸（附着包覆）、粘-粘（黏合）、刚-切（切割受挡）、储-移（能量搬运）、
  信-信（通讯）、分-分（融合分化）、吸-切（催化）、支-粘（骨架成形）、移-移（协同运动）。
- 结合能只在 `M_eff ≥ M_MIN = 0.25` 时允许成键；`M_eff < 0` 时产生**排斥项**（§4.2），
  这是防止"万物互粘"的关键负反馈。

**占位矩阵 M0**（在 ability_spec 交付前可直接实现；交付后用它替换 M 即可，代码不变）：
|      | 支 | 刚 | 粘 | 分 | 吸 | 切 | 储 | 移 | 信 |
|------|---|---|---|---|---|---|---|---|---|
| 支 | 1.0 | 0.8 | 0.7 | 0.3 | 0.6 | -0.2 | 0.4 | 0.2 | 0.1 |
| 刚 | 0.8 | 1.0 | 0.5 | 0.2 | 0.3 | 0.6 | 0.1 | 0.2 | 0.1 |
| 粘 | 0.7 | 0.5 | 1.0 | 0.3 | 0.8 | 0.1 | 0.2 | 0.2 | 0.3 |
| 分 | 0.3 | 0.2 | 0.3 | 1.0 | 0.5 | 0.4 | 0.5 | 0.3 | 0.7 |
| 吸 | 0.6 | 0.3 | 0.8 | 0.5 | 1.0 | 0.4 | 0.4 | 0.5 | 0.4 |
| 切 | -0.2 | 0.6 | 0.1 | 0.4 | 0.4 | 1.0 | 0.2 | 0.4 | 0.1 |
| 储 | 0.4 | 0.1 | 0.2 | 0.5 | 0.4 | 0.2 | 1.0 | 0.7 | 0.3 |
| 移 | 0.2 | 0.2 | 0.2 | 0.3 | 0.5 | 0.4 | 0.7 | 1.0 | 0.4 |
| 信 | 0.1 | 0.1 | 0.3 | 0.7 | 0.4 | 0.1 | 0.3 | 0.4 | 1.0 |
`M_dir` 的取法：若 ability_spec 给出有向矩阵则直接使用；否则训练一个 9×9 的反对称修正
`M_dir[a][b] = M[a][b] + A[a][b]`，其中 `A` 由"谁作用于谁"的先验给出（切→支/刚 = 破坏，+；
支→吸 = 承载，+；储→移 = 供能，+；信→分/储 = 调控，+；反向为 0 或负）。初版可令 `M_dir = M`。
### 3.5 键型与物性兼容核
键型兼容 `K[t_i][t_j]`（S=共边/刚性、C=共顶点/柔性、L=隔格/弱作用；跨类取并集，见 `elements.py`）：
| K | S | C | L |
|---|---|---|---|
| S | 1.00 | 0.85 | 0.55 |
| C | 0.85 | 0.75 | 0.60 |
| L | 0.55 | 0.60 | 0.45 |
物性兼容核（三轴都参与，但都不直接决定生死，只调节界面强度）：
```
Φ = exp(-|Δ粘性| / σ_s) * exp(-|Δ温度| / σ_T) * (1 - λ_d * |Δ密度| / ρ_max)
σ_s = 8, σ_T = 6, λ_d = 0.5, ρ_max = 40
```
`Δ粘性` 大 → 一个黏一个滑，界面抓不住；`Δ温度` 大 → 热噪声使键更易断；`Δ密度` 大 → 界面错配，
接触面积下降。三项都只乘在结合强度上，不单独作为判据。
### 3.6 结合强度公式（L2 的核）
```
w(i,j) = κ0 * σ_i * σ_j * M_eff[a_i][a_j] * K[t_i][t_j] * Φ(i,j) * Ψ(kind_i, kind_j)
κ0 = 2.5；Ψ = {顶点对 1.00, 端帽-顶点 0.90, 桥-任意 0.80}；w < W_MIN = 0.15 → 不视为键
```
补充：`M_eff < 0` 时 `w < 0`，定义排斥力 `w_rep = 0.4·|M_eff|`，在扩散步中把两分子推开一格
（负反馈，阻止全粘连）。界面键能量上界估计：σ² ≤1、M≤1、K≤1、Φ≤1 → w ≤ 2.5，
全部界面键总能量 ≤ 3 能量单位/键，符合 A4"非共价"量级。

## 4. L1 → L2：组装规则
### 4.1 接触与几何
- 世界 = 二维六边形格（与 `elements.py` 的 axial 坐标一致），尺寸 `L×L`，环面边界。
- 分子 = **多格骨牌**：每个骨架块占 1 格，`place` 给出块间相对位置；分子整体作刚体平移/旋转
  （6 个旋转/反射方向）。
- 接触判定：两分子占据格集合存在**边相邻**（距离 1）或**顶点相邻**（距离 1,1），且一对位点可达
  （位点格间距 ≤ 1.5 格）。接触面积 `A_ij` = 相邻格对数。
- 每个分子每 tick 随机尝试移动一次（概率 `p_move = 0.6`），方向由"移动 W"能力加权：
  `P(方向) ∝ exp(β_m * W_i * ∇ρ_E)`，即向恒素浓度高处走（趋化雏形）；碰撞则不动。
### 4.2 结合/断裂动力学（局域、可逆、有反馈）
```
k_on  = k_on0  * exp(β * (w - W0))                 # 形成速率
k_off = k_off0 * exp(-β * (w - W0) + β * λ_s * s)  # 断裂速率；s = 局部剪切/热噪声
p_on  = 1 - exp(-k_on * Δt),  p_off = 1 - exp(-k_off * Δt)
k_on0 = k_off0 = 0.05 /tick, β = 1.8, W0 = 0.30, λ_s = 1.0, Δt = 1
```
- 每条潜在接触对每 tick 至多一次 `p_on` 尝试；已成键每 tick 一次 `p_off` 尝试。
- 详细平衡：`w = W0` 时 `k_on = k_off`，热平衡下界面键的平均占据率由 `w` 决定，不靠手工开关。
- 反馈：`s` 由环境温度场、邻居数量（拥挤）与损伤事件共同决定，组装体越大内部 `s` 越低
  （屏蔽），形成"大者更稳"的正反馈；同时资源（自由分子/恒素）被消耗，形成负反馈。
### 4.3 组装体判据（四条同时成立才登记为组装体）
1. **连通**：界面键图连通，`|V| ≥ 2`；
2. **总界面能**：`E = Σ_b w_b ≥ E_min = 2.5`（约 4~6 条中等强度键）；
3. **内聚度**：`c = E / (|V| * w_ref) ≥ c_min = 0.50`，`w_ref = 0.8`（平均每分子至少 0.4 单位键能）；
4. **寿命**：在基线噪声下存活 `τ_min = 30` tick（期间未被完全打散）。

不满足的界面键集合仍保留在世界上（只是不登记），下一 tick 可重新满足——避免"登记/注销"状态机。
### 4.4 六类形态判定（按顺序首个命中）
记 `n=|V|`、`m=边数`、`β0 = m - n + 1`（回路数）、`deg_max`、`d`（界面图直径）、
`R`（顶点格集合的包围盒面积）、`t`（沿包围盒两方向的占用厚度最小值）、`hole`（是否存在被围住的空格）。
| 顺序 | 形态 | 判定（全部满足） | 物理含义 |
|---|---|---|---|
| 1 | 壳 shell | `β0 ≥ 1` 且 `hole` 为真 且 `n ≥ 6` 且 `t ≤ 2` | 闭合边界，隔出内外（边界器官原型） |
| 2 | 骨架网络 network | `β0 ≥ 2` 且 顶点连通度 `κ ≥ 2` 且 `deg_max ≥ 3` 且 `n ≥ 8` | 承力桁架（支撑器官原型） |
| 3 | 膜 membrane | `n ≥ 6` 且 `t ≤ 2` 且 `R/n ≥ 1.6` 且 `hole` 为假 | 二维铺展面（边界/防御器官原型） |
| 4 | 链 chain | `β0 = 0` 且 `deg_max ≤ 2` 且 `d = n-1` 且 `n ≥ 4` | 线性传动/输运（运输/信号器官原型） |
| 5 | 簇 cluster | `n ≤ 4` 且 `d ≤ 2` | 小聚集体（可作种子/催化核心） |
| 6 | 团 mass | `n ≥ 5` 且 `R/n ≤ 1.30` 且 `β0 ≤ 1` 且 `d ≤ 2·sqrt(n)` | 致密团块（储能/防御器官原型） |
阈值标定：`R/n`、`t`、`τ_min`、`c_min` 都列入 §8 的敏感度扫描；形态分类只影响器官原型的先验权重，
不进入生命判据，因此即使分类有误差也不会直接制造"生命"。
### 4.5 组装体属性（供 L3 使用）
`E`、`c`、`n`、`shape`、`A_surf`（外表面积）、`interface_bonds`、`能力谱 σ_asm[a] = Σ 位点 σ`、
`组成向量 n_elem`、`平均物性`、`age`、`损伤计数`。这些是 L3 功能通量的输入。

## 5. L2 → L3：器官规则
### 5.1 功能通量的可观测定义（只用事件计数，不用结构标签）
在窗口 `Δt = 20` tick 内统计以下事件（每种都是动力学事件的计数/比值）：
| 符号 | 含义 | 统计方式 |
|---|---|---|
| `J_bind` / `J_break` | 界面键形成/断裂 | 事件计数 |
| `J_dmg` / `J_repair` | 损伤断键 / 修复重连 | 事件计数（§7 S6） |
| `J_E` | 能量量子到达数 | P（储能）位点发出、沿界面键跳跃、到达 W/切/分 位点的量子数 |
| `J_m` | 物质通量 | 吸附（A）捕获 / 释放的自由分子数 |
| `J_s` | 信号脉冲到达数 | L（信号）位点发出、按 `M_dir ≥ 0.3` 传播、衰减 0.7/跳 |
| `J_cut` | 切割事件 | F（切割）位点破坏邻居键的次数 |
| `J_rep` | 复制事件 | 复制器官产出子体的次数 |
| `J_leak` | 边界泄漏 | 穿越边界分子的净通量 |
| `I_sig` | 信息量 | 刺激事件 → 响应事件的经验互信息（bit） |
每个通量按器官子图的边集 `E_k` 归集；**器官类型由哪个通量最先/最强超过阈值决定**。
### 5.2 九类器官原型
记 `θ` 为形成阈值，`θ_keep = 0.8·θ`（滞回：形成难、维持易，防止闪烁）；
`Q ≥ 0.6` 与 `持续 ≥ τ_org = 60 tick` 对所有原型一致；"最小能力组合"要求两个能力都在该子图
位点中出现且 `M_dir` 对应项 ≥ 0.4（协同），括号内是 §3.4 的矩阵依据。
| # | 器官 | 最小能力组合 | 功能输出 F_k（窗口内） | θ | 失效条件 |
|---|---|---|---|---|---|
| 1 | 支撑器官 | 支 + 刚（+粘） | `F_sup = Σ_{b∈E_k} w_b / (n·κ0·0.5)` | 0.30 | 载荷 > 0.8·强度，或裂缝连通度达边界 |
| 2 | 边界器官 | 粘 + 吸（+刚） | `F_bnd = 闭合率 · (1 - J_leak/J_in)` | 0.45 | 泄漏 > 0.5·J_in，或壳/膜破损 |
| 3 | 能量器官 | 储 + 移（+切） | `F_nrg = J_E / (J_E_emit + ε)` | 0.35 | 储量 < e_min，或净能量为负 |
| 4 | 运输器官 | 移 + 储（+粘） | `F_trn = 定向到达数 / 发出数` | 0.30 | 堵塞（到达率 < 0.1） |
| 5 | 传感器官 | 信 + 吸 | `F_sen = Δ响应 / Δ刺激`（归一化） | 0.25 | 饱和/配体耗尽（增益 < 0.05） |
| 6 | 信息器官 | 信 + 分 | `F_int = 输出事件数 / 输入事件数`（限幅） | 0.35 | 回路断开，或传递 < 1 跳 |
| 7 | 防御器官 | 切 + 刚（+粘） | `F_def = 1 - J_cut_in / (J_cut_out + ε)` | 0.30 | 被切割率 > 修复率 |
| 8 | 催化器官 | 吸 + 切（+分） | `F_cat = 产物通量 / 底物通量` | 0.25 | 活性位点堵塞/覆盖 |
| 9 | 复制器官 | 分 + 支 + 粘 | `F_rep = 事件数·保真度 f` | 0.25 且 f≥0.85 | 错误率 > 15%，或无模板 |
原型只约束**功能通量的来源**（哪两种能力协同），不约束分子种类：任何具有 粘+吸 位点的分子集合，
只要形成闭合壳并降低泄漏，就是边界器官——与分子式无关。
### 5.3 器官判定算法（`classify_organs(asm)`）
```
for 每个原型 k in 9:
    候选子图 = E_asm 中两端位点能力对 M_dir ≥ 0.4 且 (能力 ∈ 原型所需集合) 的边集
    if 候选子图为空: continue
    F_k = 窗口内该子图的通量（§5.1）
    if F_k >= θ_k and Q_k >= 0.6 and 持续 >= τ_org:
        登记 organ(kind=k, mols=子图分子, edges=候选边, F={k:F_k}, active=(有输入也有输出))
if 同一分子被 >2 个器官登记: 只保留 Q 最高的两个（防止同一块料被重复计数）
if 两个器官共享 >70% 边: 合并（视为同一器官的重复单元）
```
器官状态：`潜在（active=False）`、`活跃（active=True）`、`退化（F < θ_keep 持续 30 tick）`。
退化后边集保留，可被重新激活。
### 5.4 器官系统（L4 的载体）
器官耦合图：节点=活跃器官，边权 `C_kl = Σ_{i∈k, j∈l} w_ij · |M_dir[a_i][a_j]|`，`C ≥ 0.5` 连边。
**器官系统** = 连通分量，且满足：

1. `|organs| ≥ 3`；
2. 回路数 `β0_sys ≥ 1`（存在闭合功能回路：能量/物质/信号的环）；
3. 至少含 1 个 `能量` 或 `边界` 器官，且至少含 1 个 `信息` 或 `传感` 器官；
4. 方向一致性：能量器官→其它器官的净能量流为正；传感→信息→执行（防御/运输/催化）的事件流可追踪。

系统级反馈：器官 k 的输出通过 `M_dir` 调制器官 l 的反应速率（例如信息器官脉冲使修复速率 ×(1+0.5·pulse)）。
### 5.5 为什么这不是"更大的分子"
- 共价键不可断（分子内），界面键可断（L2），器官判据基于**通量**而不是结构式；
- 同一组装体在不同环境下可以是不同器官，器官会退化/消失；
- 器官可有多个载体（跨组装体），组装体可有多个器官；
- 生命判据不读形态分类，只读 §6 的动力学量——所以"看起来像器官"不等于"是器官"。

## 6. L3 → L4：生命判据
### 6.1 观测窗口与统计

## 7. 动力学循环
### 7.1 每 tick 的局部规则（S1–S8）
- **S1 环境场**：恒素浓度 `ρ_E` 扩散（`D_E=0.15`）并受组装体吸附；温度场按 T75 物性叠加，
  热噪声 `s = s0 + s_T·T_local`；能量输入 `I_E = ρ_E · η` 只注入到局部，不是全局广播。
- **S2 分子扩散**：按 §4.1 移动，W 能力加权；不消耗（低能耗）或按 P 储量扣能量。
- **S3 界面动力学**：相邻分子对 → 位点匹配 → `w` → `p_on/p_off`；成键消耗 1 能量单位，
  断键释放 0.8（滞后损失 = 能量耗散来源之一）。
- **S4 物质交换**：A 位点从自由分子池捕获（概率 `∝ A·ρ_ligand`），F 位点切断邻居界面键并释放碎片分子，
  P 位点按 `ρ_E` 充能、向 W/F/分 位点供能。
- **S5 信号**：L 位点把 A 捕获/界面断裂事件编码为脉冲（宽度 3 tick，衰减 0.7/跳），
  沿 `M_dir ≥ 0.3` 的界面键传播；到达的脉冲调制 S6 修复速率与 S3 `k_on`（×0.7~×1.5）。
- **S6 损伤与修复**：损伤概率 `p_dmg = 1 - exp(-d0·exp(-w/βT))`；修复由 支/分/粘 位点执行，
  消耗能量 `e_rep`，修复速率受 S5 脉冲调制（控制回路）。
- **S7 复制**：仅当"复制器官"活跃（§5.2 #9）且有模板（该器官中最大分子）时，按保真度 `f` 复制：
  子体由同一目录记录构建（元素替换突变率 `μ=0.02/原子`），从母体边缘释放。
- **S8 观测识别**：每 `τ_asm=10` 重建组装体（并查集），每 `τ_org=20` 重算器官通量，
  每 `τ_sys=50` 重算器官系统，每 tick 记录观测量。**不写任何生命状态**。
### 7.2 四条反馈回路
1. **富集正反馈**：组装体吸附 ρ_E → 局部 ρ_E 升高 → 界面活性/结合率升高 → 更大组装体；
   受"自由分子耗尽 + 扩散限制"负反馈平衡（不会无限长大）。
2. **热屏蔽正反馈**：大组装体内部温度低 → 损伤率低 → 更稳定；但内部物质交换困难 → 通量下降（负反馈）。
3. **功能控制回路**：传感→信息→（修复/运输/结合速率调制）；能量器官输出不足时，运输器官速度下降，
   形成"需求驱动"的负反馈。
4. **损伤-修复回路**：损伤率升高 → 修复通量升高（需求驱动），修复消耗能量 → 能量储备下降 → 限制修复，
   负反馈防止"无限修复"。
### 7.3 动力学伪代码（43 行，可直接照写）
```python
def interface_energy(a, b, sa, sb, env, P):
    dS = abs(a.attrs["stickiness"] - b.attrs["stickiness"])
    dT = abs(a.attrs["temperature"] - b.attrs["temperature"])
    dD = abs(a.attrs["density"] - b.attrs["density"]) / P["rho_max"]
    phi = exp(-dS / P["sigma_s"]) * exp(-dT / P["sigma_T"]) * (1 - P["lam_d"] * dD)
    return (P["kappa0"] * sa.sigma * sb.sigma * P["M_eff"][sa.ability][sb.ability]
            * P["K"][sa.bond_type][sb.bond_type] * phi * P["psi"][sa.kind][sb.kind])

def p_on(w, P):  return 1.0 - exp(-P["k_on0"] * exp(P["beta"] * (w - P["W0"])))
def p_off(w, s, P): return 1.0 - exp(-P["k_off0"] * exp(-P["beta"] * (w - P["W0"]) + P["beta"] * s))

def run_world(records, seed, P):
    world = init_world(records, random.Random(seed), P)      # L1：位点/能力/物性/摆放
    for t in range(P["steps"]):
        # S1 环境：恒素浓度场扩散；温度场随物性与组装体变化
        diffuse_field(world.rho_E, P["D_E"]); update_temperature(world, P)
        # S2 分子扩散：按移动(W)能力偏向高 ρ_E；碰撞不动
        for mol in world.molecules:
            try_move(world, mol, P)
        # S3 界面动力学：只检查邻接分子对；结合/断裂均为局域概率事件
        for a, b in neighbor_pairs(world, P["d_cut"]):
            for sa, sb in candidate_sites(a, b, P):
                w = interface_energy(a, b, sa, sb, world.env, P)
                if w < P["W_MIN"]:                       # 排斥：把两分子推开一格
                    push_apart(world, a, b, P); continue
                if rng.random() < p_on(w, P):
                    world.bonds.add(a, b, sa, sb, w, t)
                elif rng.random() < p_off(w, world.env.shear, P):
                    world.bonds.remove(a, b, sa, sb, t)
        # S4 物质交换：吸附捕获自由分子 / 切割释放碎片 / 储能充放
        pool_exchange(world, P); cut_and_release(world, P); charge_storage(world, P)
        # S5 信号：L 位点脉冲沿 M_dir>=0.3 的键传播，衰减 0.7/跳
        pulses = propagate_signals(world, P)
        # S6 损伤与修复：热噪声断键；支/分/粘 用能量重连，脉冲调制修复速率
        damage_bonds(world, P, rng); repair_bonds(world, pulses, P, rng)
        # S7 复制：仅"复制器官"活跃且有模板时发生（含变异）
        replicate_if_organ(world, P, rng)
        # S8 观测识别（只读观测，不写生命标志）
        if t % P["tau_asm"] == 0: rebuild_assemblies(world)      # 并查集
        if t % P["tau_org"] == 0: classify_organs(world)        # 通量阈值
        if t % P["tau_sys"] == 0: update_systems(world)         # 耦合图连通分量
        record_observables(world, P)                            # 窗口统计缓冲
    return world, life_report_all(world, P)                     # 纯读取判定
```

### 8.4 真涌现 vs 手工构造：七个判别
| 编号 | 判别 | 操作方法 | 真涌现应满足 | 手工构造的典型破绽 |
|---|---|---|---|---|
| T1 | 消融必要性 | E2：逐项清零 M 的 20 个关键项 | 对应器官类消失（效应量 ≥80%），并出现级联（如边界消失 → B 判据失败 → 拟生命降低） | 消融后生命率不变（器官只是标签） |
| T2 | 零模型 | E3：置换能力映射 / 随机化 M（保持边缘分布） | 生命率接近零模型地板（≤1.5%），显著低于 baseline | 构造系统不依赖矩阵，置换后照旧存活 |
| T3 | 阈值平滑性 | E4：扫 E_min、κ0、θ_k | `d log(生命率)/d log(参数) < 3`，无阶跃 | 某参数一过"机关"生命率从 0 跳到 50%（隐藏标志） |
| T4 | 损伤必要性 | 对活体逐一移除 1 类器官（突变其载体分子的能力位点） | 对应判据特异性失败；若移掉"必需"器官后仍全真，判据是假的 | 任何器官移除都不影响（判据与器官无关） |
| T5 | 代码审计 | `grep -E "alive|is_life|life_flag|score *>= *8"` 全仓 | 0 命中；`life_report` 纯读取；删除它不改变演化 | 存在"达标即置位"的分支 |
| T6 | 新颖性/时序 | 记录 provenance 图：分子→组装体→器官→系统，深度与出现顺序 | 深度 ≥3；器官出现在组装体之后；合成路径不能被单分子一步到位 | 生命体形态 = 单一分子放大；顺序倒置 |
| T7 | 反事实重放 | 用另一 seed 重跑，检查同一条生命史是否可重放（同 seed 必须逐位一致），换 seed 后统计分布稳定 | 确定性可复现 + 分布稳定 | 不可复现 / 只能手挑一个种子出生命 |

## 10. 实现边界：`alchemy/emergence.py`
### 10.1 数据结构（dataclass 草案）
```python
@dataclass
class ElemSite:      element:str; ability:str; sigma:float; bond_type:str; cell:tuple; kind:str
@dataclass
class MoleculeInst:  uid:int; formula:str; atoms:list; edges:list; cells:list; sites:list[ElemSite]; profile:dict; attrs:dict; units:list; pos:tuple; rot:int; energy:float; age:int; elem_vec:list
@dataclass
class InterfaceBond: a:int; b:int; site_a:int; site_b:int; w:float; pair:tuple; born:int
@dataclass
class Assemblage:    aid:int; mols:list[int]; bonds:list[InterfaceBond]; shape:str; E:float; cohesion:float; born:int; organ_ids:list[int]; dmg:int; rep:int
@dataclass
class Organ:         oid:int; aid:int; kind:str; mols:list[int]; bond_ids:list[int]; F:dict; Q:float; born:int; active:bool; degraded:int
@dataclass
class OrganSystem:   sid:int; organs:list[int]; coupling:dict; cycle_rank:int; tier:str
@dataclass

@dataclass
```

`ObsBuffer` 用环形缓冲保存最近 `T_obs/Δt` 个采样：键数、E、通量计数、能量存量、信号事件、

### 10.3 复杂度与规模评估
